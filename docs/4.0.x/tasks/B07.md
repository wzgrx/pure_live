- 出设计：要（先出对比页和效果图，再实现；用户已授权“所有决定你选择”，“需要你选的”按建议 A 直接做）

## 要做的

- c1 先出设计（产出放 `docs/ui/compare/U.2n/`）：定时关闭、房间音量、投屏（选设备）、获取直链（清晰度 → 线路）、画面比例，在竖屏、横屏、全屏下用面板（`RoomSidePanel`）还是贴着按钮的小菜单，和录制、弹幕设置面板一致；横屏全屏不再出现压在画面中间的居中对话框。
- c2 B-3：手机上“房间音量”直接调系统音量（和手势、v3 一致），不再另存一层 mpv 音量；平板同手机。
- c3 B-13：获取直链和投屏里，线路页能返回清晰度页；标出当前正在播的清晰度和线路；对勾用 `AppIcons.selected`。B-14：取消静音恢复到静音前的音量。
- c4 画面比例：从菜单进和从横屏底栏进是同一个组件，当前项主色加勾。

## 验收

- 这些弹窗在三种布局里样子和操作一致，不再压在全屏画面中间；房间音量和手势音量是同一个音量。
- 测试：每个弹窗三种布局的位置；音量联动；直链和投屏的返回和当前项。

## 真机上看的（写进记录，维护者在 K90 上看）
