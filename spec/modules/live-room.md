| 术语 | 含义 |

## 1 页面构成

- **LAY-1 信息栏**（内嵌、剧场）：返回、平台/分区、标题或主播名、关注、录制、更多菜单。宽度 < 600 用紧凑样式。证据：LPCT:548-551；`lib/modules/live_play/widgets/layout/live_play_header.dart:18-105`。
- **LAY-2 画面区**：视频、画面弹幕、控制层三层，各自独立重绘（PLAN §10）。
- **LAY-3 信息区**：画质线路行（在线人数、画质、线路）；弹幕列表；醒目留言。旧版还有“弹幕设置”“屏蔽”两个标签页，v4 移到统一的弹幕设置面板（product F-DM-02、F-DM-04）。IPTV 房间旧版没有信息区，只有画面；v4 的信息区显示频道名、当前节目和“节目单”入口，回看中显示“回到直播”（iptv.md §5）。证据：LPC:73；LPCT:556-612；`lib/modules/live_play/widgets/resolution_selector/resolutions_row.dart:34-60`。
- **LAY-4 控制层必须提供的操作**（位置由设计决定，但每一项在对应状态下必须可达）：

  | 位置 | 操作 | 出现条件 |
  |---|---|---|
  | 顶栏 | 返回 | 全屏、竖屏全屏 |
  | 顶栏 | 时间、电量 | 全屏；手机 |
  | 顶栏 | 标题、当前节目 | 总是；节目只在 IPTV |
  | 顶栏 | 节目单 | IPTV |
  | 顶栏 | 切换直播间 | 全屏 |
  | 顶栏 | 纯音频 | 总是 |
  | 顶栏 | 投屏 | Android |
  | 顶栏 | 画中画 / 小窗 | Android、Windows |
  | 底栏 | 播放/暂停、刷新 | 总是（窄屏全屏可收起刷新） |
  | 底栏 | 关注 | 宽度足够时 |
  | 底栏 | 弹幕开关、弹幕设置 | “显示弹幕”设置开启 |
  | 底栏 | 画质 · 线路 | 全屏、竖屏全屏；内嵌由信息区提供 |
  | 底栏 | 竖屏铺放方式 | 竖屏全屏 |
  | 底栏 | 方向覆盖（自动/竖/横） | 触屏 |
  | 底栏 | 画面比例 | 宽度足够时（v4 同时可用双指缩放） |
  | 底栏 | 音量 | 桌面 |
  | 底栏 | 侧栏收起/展开 | 桌面剧场 |
  | 底栏 | 全屏 | 总是；窄屏时固定在滚动区外（REG-ROOM-017） |
  | 底栏中部 | 本地弹幕输入框 | 全屏、竖屏全屏 |
  | 右侧 | 锁 | 全屏、竖屏全屏 |

  证据：VCP:34-66、299-440、1394-1582。
- **LAY-5 状态页**：加载中；未开播或封禁（退出全屏和剧场，提示，更新关注快照）；获取信息失败但已有画面（继续播放并提示）；失败（提示 + 重试）；播放失败（覆盖层 + 重试）。证据：LPC:778-840；`lib/modules/live_play/widgets/video_player/playback_failure_overlay.dart`；`lib/modules/live_play/widgets/layout/live_play_video.dart:77-110`。

## 2 展示状态

### 2.1 状态定义

| 状态 | 含义 | 旧版对应 | 设备 | 副作用 |
|---|---|---|---|---|
| 内嵌 | 页面内的普通布局：画面 + 信息区 | normal | 全部 | 系统栏正常；方向跟随系统 |
| 剧场 | 窗口内画面最大化，侧栏可拖宽、可收起 | widescreen（“宽屏”= 剧场且侧栏收起）；桌面分栏 | 大、超大窗口（展开为“画面 + 右侧弹幕栏”） | 同内嵌 |
| 全屏 | 画面占满屏幕或窗口 | fullscreen | 全部 | 手机隐藏系统栏、按方向策略锁方向；桌面窗口全屏、隐藏自绘标题栏 |
| 竖屏全屏 | 竖屏源在手机上的沉浸全屏 | portraitFullscreen | 触屏 | 隐藏系统栏；锁竖屏 |
| 画中画 | 系统画中画（Android）或主窗口缩成小窗（Windows） | Android PiP / Windows PiP | Android、Windows | 见 playback PIP-2、PIP-3 |
| 小窗 | 离开直播间后浮在应用内其它页面上的窗口 | 应用内浮窗 | 全部 | 见 playback PIP-4 |

- **PS-1 单一状态源**：展示状态只有一个值；系统栏、屏幕方向、桌面标题栏、窗口全屏都由它派生，不另存副本。旧版“全屏”有两份真相（页面状态和全局标志）需要手动同步，多画面还会写全局全屏标志控制标题栏。证据：LPC:394-420、1043-1046；VC:1323-1352；`lib/modules/multiview/multiview_page.dart:185-190`。验收：【单元】任意切换序列后派生值与状态一致。
- **PS-2 纯音频、锁定是正交标记**：不是展示状态；切换展示状态不改变纯音频；进入或退出全屏、竖屏全屏、剧场侧栏切换时自动解锁。证据：VC:1326、1401、1432、1497。
- **PS-3 只有一个视频表面**：所有状态之间移动同一个表面，不重建播放器、不重新拉流（playback SURF-5）。旧版普通和全屏是两棵界面树，靠同一个全局键保住纹理。证据：LPCT:479-541。验收：【真机】连续切换 50 次无黑屏、无重连。

### 2.3 内嵌与剧场按窗口等级布局

| 等级 | 布局 | 旧版 |
|---|---|---|
| 紧凑 | 画面在上、信息区在下；竖屏源（开启竖屏适配）时画面铺满、底部三档面板（PS-4） | 宽度 ≤ 680：竖排 |
| 中等 | 画面在上，信息区可折叠 | 手机横屏约 860：左右分栏（侧栏 34%，300–400 dp） |
| 展开 | 画面 + 右侧弹幕栏 | 同上 |
| 大、超大 | 剧场：大画面 + 可拖宽侧栏 | 同上；无剧场 |

- **PS-4 竖屏面板**：可用高度 H；最低档 = 27% H（限制在 190–250 dp），最高档 = 68% H（画面至少留 120 dp），中档 = 44% H；“沉浸”布局初始为最低档，其它为中档；拖动松手吸附到最近的档；向下越过最低档的距离 ≥ 面板高 30%（限制 72–144 dp），或速度 ≥ 900 且距离 ≥ 28 dp，进入竖屏全屏；面板内容区至少 240 dp，不够时可滚动（键盘、分屏、画中画动画时）；右下角“横屏全屏”按钮位置跟随面板顶部。证据：LPCT:130-477；PFI:12-27。验收：【单元】沿用 `test/portrait_fullscreen_interaction_test.dart` 中面板档位和拖动判定的边界样本。
- **PS-5 窗口尺寸变化只换布局**：不重建播放器、保留滚动位置和面板档位（PLAN §08）。

### 3.2 手势区域划分（v4）

- **ZN-1 控制条区域**：控制层可见时，其中的点击和长按不做弹幕命中，只显示控制层（按钮本身正常响应）。
- **ZN-2 竖屏全屏恢复区**：底部 96 dp；从这里开始的上滑一律判为“退出竖屏全屏”，优先于其它滑动。

### 3.6 返回链（全部设备）

按顺序，每次只执行第一项成立的：

1. 关闭最上层面板（对话框、底部面板、菜单、快捷面板、TV 侧栏）。
2. 退出全屏或竖屏全屏（有“恢复竖屏”记录时恢复），回到进入全屏前的内嵌或剧场；在剧场时退出剧场。
3. 离开直播间：满足“离开时小窗播放”开启 + 有画面 + 无加载错误时转为小窗，否则停止播放。

画中画中由系统处理，不走本链。与旧版相同，只是把“宽屏”一步换成“剧场”（D-06；principles §6.1、§6.2）。PLAN §07 写作“收起面板 → 退出全屏 → 缩小为小窗（可设置）→ 离开直播间”，其中“缩小为小窗”与“离开”是同一次返回。证据：LBS:70-92；LPC:394-421；NO:45-67；`test/live_play_back_scope_test.dart:56,81`。

### 3.7 控制层显隐

- **CL-1** 显示后自动隐藏：触屏 4 s，指针 2 s（静止起算）。
- **CL-2** 不隐藏：指针在控制条上；任意面板打开期间（且底栏保持显示）；本地弹幕输入框有焦点；正在拖动亮度或音量。
- **CL-3** 进入或退出全屏、竖屏全屏、切换剧场侧栏后，控制层显示并重新计时。

## 4 画质与线路

- **Q-1 模型**：画质列表（平台给出的顺序，通常由高到低，每项有稳定标识）× 该画质的线路列表（地址解析结果的顺序），每条线路带租期（playback SRC-6）。证据：PC:559-684。
- **Q-2 默认画质**：按当前网络取偏好：蜂窝用“蜂窝画质偏好”，其它用“画质偏好”，默认都是“原画”。先按名称精确匹配；匹配不到时，取偏好在标准档位表（原画、蓝光8M、蓝光4M、超清、流畅）中的相对位置，映射到当前列表的同一相对位置（四舍五入）。只在本次进房的第一次选择时应用。证据：PC:611-636；`lib/player/utils/player_consts.dart:25`；`lib/common/services/settings/player_settings_controller.dart:36-37`。
- **Q-3 默认线路**：第 1 条。
- **Q-4 不按房间持久化**：用户的画质、线路选择保持到离开房间或切房为止；偏好只在设置里。与旧版相同。证据：LPC:907-910。
- **Q-5 服务端确认优先**：平台返回实际生效的画质时以它为准。与点击的不同：提示“画质受限为 X”；实际仍是当前画质：不切换并提示。画质未经确认时，标签上标出“未确认”。证据：PC:74-90、757-768；`test/stream_selection_controller_test.dart:284,311`。
- **Q-6 切换画质**：旧流继续播放，直到新地址解析并打开成功；线路保持同一下标，新画质的线路数不够时回到第 1 条；新地址与当前完全相同时不切换，提示“该画质与当前流相同”。**差异**：旧版单房间在线路不够时夹到最后一条（PC:59-72），多画面回到第 1 条（`multiview_controller.dart:866-879`）；v4 统一为第 1 条，因为第 1 条是平台默认线路。证据：PC:686-790；`test/stream_selection_controller_test.dart:389`。
- **Q-7 切换线路**：画质不变。没有签名刷新能力的平台直接使用已解析的地址列表，不重新请求；有签名刷新能力的平台重新取新地址再按下标选；自有源配方重新解析。证据：PC:717-730；`test/stream_selection_controller_test.dart:423,501,533`。

- **Q-9 失败回滚**：失败时恢复切换前的画质、线路和地址，提示“读取视频失败”；如果内核已经提交了别的源，以内核提交为准。证据：PC:820-845；`test/stream_selection_controller_test.dart:363`。

- **Q-11 纯音频下切换**：允许，切换后仍是纯音频。证据：PC:774-797。
- **Q-12 显示**：按钮文字为“画质 · 线路 N”；内嵌时信息区给出两个选择器；全屏、竖屏全屏、快捷面板用合并面板（空间够时左右两栏，否则上下排）。证据：VCP:1053-1265。

## 8 v4 预览实现记录（2026-09-28）

`apps/pure_live/lib/features/room/` 和 `features/danmaku/` 按本规格实现，下面记录实现中做出的取舍和尚未做的部分，决定见 [ADR 0023](../../docs/adr/0023-room-page.md)。

- **展示状态**：内嵌、剧场（大、超大窗口）、全屏、竖屏全屏一个枚举；系统栏、方向锁、窗口全屏只由它派生（PS-1）。平台调用 1 s 内没有返回也放行下一次切换，避免平台无响应时所有切换被 INV-ROOM-07 永久挡住。平板（最短边 ≥ 600）不锁方向（principles §5.2）。
- **手势层**在画面按钮之下而不是包住它们：包住按钮的双击识别器会让每个按钮的点击等待双击窗口（约 300 ms）。控制层的渐变遮罩不接收指针，ZN-1 由手势层判断。
- **亮度**：v4 不引入 `screen_brightness`，左侧上下滑调节画面上的一层纯色暗化（100% 到 20%），不改系统亮度，只能调暗。要真正调节窗口亮度需要插件或 Android 原生通道（`WindowManager.LayoutParams.screenBrightness`），列为缺口。
- **音量**：见 INV-ROOM-03 修订。滚轮、↑↓、右侧上下滑都调播放器音量；桌面按房间记住（`roomPrefs.volume`，600 ms 防抖写入）。
- **电量**（F-ROOM-17）：全屏顶栏只有时间；电量需要 `battery_plus` 一类插件，v4 暂不引入。
- **分享**（F-SHR-01）：所有平台都把 3.x 兼容的分享口令复制到剪贴板；手机系统分享面板需要 `share_plus` 或原生通道，列为缺口。
- **截图**：mpv 截图保存为 PNG，桌面在下载目录，Android 在应用的外部存储目录（`Android/data/<包名>/files/PureLive`），不写入系统相册（需要 MediaStore 插件）。
- **定时关闭**：全应用一个计时器，切换房间不中断；预设 15/30/45/60/90/120 分钟和自定义（1 分钟到 1 年）；到点暂停（停止后台声音），“退出应用”在暂停 300 ms 后退出；可同时切换为纯音频（F-ROOM-10 的助眠预设）。时长和动作不持久保存：`live_store` 还没有对应设置项（需要 `Settings.sleepTimerMinutes`、`Settings.sleepTimerAction`）。
- **竖屏源**：播放会话的几何判定为竖屏时，触屏上双击和全屏按钮进入竖屏全屏；紧凑宽度内嵌时使用 PS-4 三档面板（初始中档）和“横屏全屏”按钮（INV-ROOM-04 退出时恢复竖屏）；竖屏全屏底部 96 dp 上滑退出；源变横屏自动退出（REG-ROOM-029）。“竖屏适配”开关、按房间方向覆盖（GEO-7）、全屏方向策略、竖屏铺放方式、竖屏弹幕区域都还没有设置项，暂按“开启、跟随源”处理。
- **旋转**（T-09）：手机紧凑宽度、内嵌、非竖屏源时转成横屏进入全屏（不锁方向），转回竖屏退出；手动进入的全屏不因旋转退出。
- **剧场**：T 键或底栏按钮；聊天栏 C 键收起或展开，拖动分隔条调宽（280–480），宽度只在本次打开期间记住（`live_store` 还没有设置项）。
- **切换直播间**（F-ROOM-11）：面板列出开播的关注（按上次刷新的状态）和观看历史；在同一页面内切换，复用播放会话和视频表面（SES-3、PS-3），旧房间的弹幕连接断开（CONN-4）。
- **TV（§3.5，决定见 [docs/adr/0026-tv-mode.md](../../docs/adr/0026-tv-mode.md)）**：页面读 TV 模式后固定为全屏，不调用方向锁和系统栏；遥控层在画面之上，只在没有控制行和侧栏时把方向键当换台；返回链由遥控层的 PopScope 处理（侧栏 → 控制行 → 离开）；来源列表通过路由的 `extra` 传入（关注页、发现和分区、搜索结果的卡片），没有时用开播关注。
- **换台（F-NEW-04）**：TV 上下键和频道键、桌面 PageUp/PageDown、手机竖屏全屏上下滑（设置默认关）共用同一个“上一个/下一个”，都在同一页面内切换，复用播放会话和视频表面（与 F-ROOM-11 相同）。
- **未做**：画中画和小窗（P、PIP-*）、投屏、录制按钮、本地弹幕输入框（F-LI-01）、从画中画或后台返回时补刷弹幕（LST-4、INV-ROOM-16）、“第一次全屏/长按”的一次性提示需要持久标记（快捷面板的说明行目前每次启动显示一次）、在屏弹幕随屏蔽即时移除（渲染器没有按条件移除的接口，已上屏的弹幕会滚完）。
