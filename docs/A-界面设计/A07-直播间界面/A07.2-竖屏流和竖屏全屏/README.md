## 3.x 的样子和问题

文件在 `git show v3.2.11:lib/modules/live_play/...`（本机只读副本 `~/ref/v3ref/lib/modules/live_play/`），下面省略这个前缀。

**竖屏流直播间**（`widgets/layout/live_play_content.dart`）

- 进入条件：宽度 ≤680、竖屏源、开着竖屏适配和“普通页自适应视频高度”、布局不是“兼容 16:9”（`:67-79`、`:559-564`）；默认设置这几项都开（`common/services/settings/player_settings_controller.dart:54-70`）。
- 结构：顶栏（同 A07.1 的 v3：头像、两行 11 号字、心形、录制、四宫格）；下面整块是黑底画面（`Positioned.fill`，`:265-271`），竖屏画面按比例放下、上下居中；面板盖在画面下部（`:272-389`）：表面色、`elevation: 10`、顶角 22。
- 三档高度（`portraitPanelRange` `:463-477`）：最低 = 区域高度 27%（夹在 190–250），中 = 44%，最高 = 68%（至少给画面留 120）；“均衡”从中档开始，“沉浸”从最低档开始。393×852 的手机上是 200 / 326 / 503。
- 面板内容：把手行（48 高）→ `ResolutionsRow`（在线人数、原画、线路1）→ 分隔线 → 四个标签和弹幕列表（卡片样式）（`:339-382`）。
- 把手行：能进竖屏全屏时显示 `Icons.keyboard_arrow_down_rounded`（20，主色）+ “下滑进入竖屏全屏”（12 号 600 主色，`:352-374`）；不能进时只显示 38×4 的拖动横条（`:342-351`）。点把手直接进竖屏全屏（`:326-328`）。
- 拖动：松手停到最近一档（`:193-215`）；在最低档继续往下拖，超过面板高度 30%（夹在 72–144）或下滑速度 ≥900 且拖了 ≥28 就进竖屏全屏（`portrait_fullscreen_interaction.dart:12-27`）；无障碍“减小”在最低档也进入（`:299-321`）。
- “横屏全屏”按钮：黑色 68% 胶囊（圆角 24、高 48），`Icons.screen_rotation_rounded` 20 + “横屏全屏”（13 号 600 白），在面板上沿上方 12、右边 12，一直显示，跟着面板移动（`:390-434`）；点了是一次性的横屏全屏（`widgets/video_player/video_controller.dart:1398-1411`）。
- 画面控制层：上栏（标题、纯音频、投屏、小窗）在画面顶；下栏贴在整块画面底边，被面板盖住（`video_controller_panel.dart:258-262`、`layout/bottom_control_surface.dart:15-21`）。飞行弹幕铺满整块画面（`video_controller_panel.dart:186-195`）。
- 只在 Android 上能进竖屏全屏（`live_play_content.dart:578-583`、`portrait_fullscreen_interaction.dart:29-37`）。

**竖屏全屏**（`VideoMode.portraitFullscreen`）

- 进入：往下拖、点把手、双击画面（`video_controller.dart:1355-1372`）；保持竖屏方向（`:1417-1456`）。退出：返回、退出全屏按钮、双击、在下栏或屏幕最下面 96 内上滑 ≥64（或速度 ≤−850 且 ≥24）（`portrait_fullscreen_interaction.dart:7`、`:39-41`、`video_controller_panel.dart:904-930`、`:1419-1422`）；返回键。
- 背景（`PortraitFullscreenPresentation` `live_play_content.dart:623-679`）：渐变兜底 `#342B3A → #171B27 → #2A202B`，封面（封面 → 房间封面 → 头像，`:605-617`）放大 1.14 倍做半径 28 的模糊，再盖 15% 黑。
- 四种画面模式（`portrait_playback_picker_dialog.dart:159-171`，默认“沉浸背景”）：完整画面（纯黑）、沉浸背景、平衡填充（最多放大 8%，`player/core/player_manager.dart:4911-4930`）、铺满裁剪（`BoxFit.cover`，`:4877-4908`）。
- 上栏（56 高，45% 黑渐变，`video_controller_panel.dart:299-436`）：返回、时间（13 号）、电量（35×15）、标题（16 号粗体）、切换直播间 `Icons.swap_horiz_outlined`（26% 黑圆底）、纯音频 `Remix.headphone_line`、投屏 `Remix.tv_2_line`、小窗 `CustomIcons.float_window`（顺序 `:42-67`）。
- 下栏（112 高，`_buildPortraitFullscreenLayout` `:1508-1544`）：第一行本地弹幕输入框（`Expanded`）和“⚙ 原画 · 线路1”（`compact`，文字最宽 90，`:1214-1266`），两者平分宽度；第二行播放 / 暂停、弹幕开关、弹幕设置（窄屏版，没有刷新和关注，`:1546-1558`），右边画面模式（图标随模式：`crop_free` / `blur_on` / `fit_screen` / `fullscreen`，非“沉浸背景”时黄色 `#FFD166`，`:658-702`）、方向（`screen_rotation_alt` / `stay_current_portrait` / `stay_current_landscape`，非自动时黄色，`:603-652`）、退出全屏。
- 锁定按钮在右侧中间（50×50，38% 黑，`:1009-1043`）。
- 进入提示（`portrait_fullscreen_interaction.dart:100-182`）：屏幕下方、下栏上方 12，黑色 66%、圆角 24、16% 白描边，`Icons.keyboard_arrow_up_rounded` + “已进入竖屏全屏 · 上滑恢复弹幕栏”（13 号 600），3 秒后淡出。
- 手势：单击显示或隐藏、左右半边上下滑调亮度和音量、长按画面弹幕；底部上滑恢复面板优先。

**两个选择框**（`widgets/video_player/portrait_playback_picker_dialog.dart`）

- 竖屏全屏画面模式（`:85-144`）：`AlertDialog`，标题“竖屏全屏画面模式”（20 号 600），四项：图标 + 名字（13）+ 说明（12 次要色）；当前项的图标换成单选圈（主色），其他项是模式图标（`:110-113`）；“取消”。压暗背后的画面。
- 本直播间画面方向（`:17-80`）：标题“本直播间画面方向”，三项单选（自动识别、强制竖屏、强制横屏，13 号），分隔线，开关“记住单个直播间方向 / 在播放器中手动指定方向后，下次进入同一直播间继续使用”（默认开），“取消”。开关是草稿，只有点选项时才和选项一起保存（`:12-16`、`:28-32`）。

**横屏全屏和宽屏**：点“横屏全屏”后画面在中间，两边沉浸背景（这时不看画面模式设置，固定沉浸背景，`live_play_content.dart:518-520`），上下栏同 A07.4 的 v3。宽度 >680 时左右分栏，画面用 16:9 的框（`live_play_video.dart:120-131`），竖屏画面在框里左右大片黑。

**设计时 v4 的样子**：没有三档面板，竖屏流只是把画面框加高（`apps/pure_live/lib/features/live_play/live_play_page.dart:55-77`、`:349-380`，当时的行号）；全屏时竖屏流只锁竖屏方向，没有竖屏全屏的排法、画面模式按钮、进入提示和上滑恢复；方向对话框在 `features/live_play/dialogs/player_dialogs.dart:64-150`；画面模式只在设置页（`features/settings/settings_catalog.dart:620-629`）。

## 按钮的作用和用法

见对比页“每个按钮是干什么的、怎么用”（1–24 和手势、返回键，编号对应 [v4-stream-mid-n.jpg](v4-stream-mid-n.jpg)、[v4-pfs-n.jpg](v4-pfs-n.jpg)）。v3 的每个按钮、手势、设置都还在：挪了位置的是“横屏全屏”（画面上 → 把手行）、竖屏全屏的“已关注”（下栏 → 上方第一行）；竖屏全屏新加录制、菜单、刷新（刷新是加回来）。要点：

| 控件 | 怎么用 |
|---|---|
| 把手（“下滑进入竖屏全屏”） | 拖动换档，松手吸附；在最低档往下拖过面板 30% 或快速下滑进竖屏全屏；点一下直接进 |
| 横屏全屏（把手行右边） | 一次性横屏全屏，两边沉浸背景；退出后转回竖屏，3 秒后放开方向 |
| 竖屏全屏下栏：画面模式 | 小菜单选完整画面、沉浸背景、平衡填充、铺满裁剪；非“沉浸背景”时按钮变黄 |
| 方向 | 小菜单选自动识别、强制竖屏、强制横屏；“记住单个直播间方向”一拨就生效 |
| 屏幕最下面 96 或下栏上滑 | 退出竖屏全屏，回到面板 |
| 返回键 | 先关面板，再退出竖屏全屏，再离开 |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 竖屏流三档面板、竖屏全屏、横屏全屏 |
| 竖着拿的平板、窄窗口（600–839） | 手机排法和三档面板；Android 平板也有竖屏全屏 |
| 宽屏（平板横屏、Windows、Linux、iPad、macOS） | 分栏照 A07.5，竖屏流用满画面区高度、两边沉浸背景；全屏是横屏全屏的样子；没有三档面板和竖屏全屏 |
| 电脑窄窗口 | 三档面板；没有竖屏全屏，把手行只有拖动条，右边按钮叫“全屏” |
