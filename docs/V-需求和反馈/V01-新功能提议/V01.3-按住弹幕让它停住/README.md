## 目标

用户看到一条飞过去的弹幕想看清楚（长的、带表情的、飞得快的），现在只能长按打开面板（打开期间所有弹幕都停住），或者来不及。提议：手指按住一条飞行弹幕时只让这一条停在原地，其他照常飞，松手它继续飞；需要操作时再打开面板。

做不做已由 D-036 定了（同意做，第三档）；下面“评估结论和设计（定稿）”一节是 2026-10-08 补完的评估、和现有手势的冲突分析，以及维护者按 D-003 选的方案，实现任务是 [D03.4](../../../D-弹幕/D03-飞行弹幕引擎/D03.4-按住飞行弹幕让它停住/README.md)。

## 评估结论和设计（定稿，2026-10-08）

### 上游怎么做的（读过的提交）

- flame_barrage `3eddae8`（`~/ref/flame_barrage`，`lib/src/core/barrage_engine.dart` 的 `pauseItemAt`、`resumeAllPaused`；`lib/src/systems/barrage_motion_system.dart:34` 起）：被按住的那一条每帧把经过的时间“吃掉”（`lastUpdateTime = now`，到期时间往后推），所以既不走也不过期，放开时不跳；**同轨后面的照飞，从它身上穿过去**，没有特别处理。
- 上游 pure_live `2d2ad2039`：长按开始时 `pauseItemAt` 定住手指下那一条并弹出菜单，菜单开着时其他弹幕照飞；`onLongPressEnd`、`onLongPressCancel` 时 `resumeAllPaused`；没开点击互动时不定住。

### 和现有手势的冲突分析

现在直播间画面（`apps/pure_live/lib/features/live_play/player/player_view.dart` 的画面 `GestureDetector`）上一根手指能做的事：

| 手势 | 现在的结果 | 依据 |
|---|---|---|
| 单击 | 控制层隐藏时只调出控制层；控制层显示时点中飞行弹幕，等双击的时间过了没有第二下，才打开它的操作面板（面板开着整层停住） | D-038（A08.9）、A07.14 |
| 双击 | 只切换全屏，第一下的效果收回，面板一帧都不出 | B09 c1、A07.14 |
| 长按（约 500 毫秒） | 点中飞行弹幕就打开它的操作面板（整层停住） | A08.4、D-038“长按不变” |
| 上下拖 | 亮度、音量；竖屏全屏里上下滑换直播间 | `PlayerGestureLayer` |

冲突点和处理：

1. **按下就钉住会不会抢走单击、长按、双击、拖动？** 如果用 `GestureDetector` 的回调（`onTapDown`、`onLongPressStart`）来钉，要么要等手势竞技场判出结果（`onTapDown` 最晚 100 毫秒后才来），要么要多加一个识别器参加竞争，可能改变单击和双击的判定。**选择**：用 `Listener` 收原始的按下、移动、抬起、取消事件，它不参加手势竞技场，单击、双击、长按、拖动的判定一点不变；按下的那一刻就钉住。
2. **长按时打开的是不是按住的那一条？** 现在长按要按住 500 毫秒，这期间那一条飞走了约 60 像素，长按点到的常常是别的弹幕或空白。钉住以后那一条就在手指下，长按正好点中它，打开的就是它的面板——是改进，不是冲突；面板开着时照旧整层停住（3.x、A08.4 的行为）。
3. **单击和双击**：单击抬手时就放开，弹幕只停了按住的那一下（一两百毫秒），单击原来的结果不变（控制层，或者控制层显示时打开面板）；双击两下各自按下、放开，结果仍然只是切全屏。
4. **拖动**：从一条弹幕上开始拖（调亮度、音量、换直播间），手指移动超过系统的触摸容差（`kTouchSlop`，18 像素）就放开，拖动照常。
5. **同轨碰撞**：钉住的那一条后面同一条轨道上已经在飞的弹幕会追上它。可选：A 从它下面穿过去（上游的做法），把钉住的那一条画在最上面，所以它一直看得清；B 后面的也停（等于整条轨道停住）；C 后面的绕开（换轨道，飞行中换轨很怪）。**选 A**，另外钉住期间它那条轨道不进新弹幕（新的进别的轨道或排队），放开后它排到这条轨道的“最后一条”，新弹幕按它的位置让开距离，不会一放开就叠在一起。
6. **默认开不开**：D-036 要求新设置默认让老用户感觉不到变化，而“按下一条弹幕它就停”是看得见的变化。**选择**：加一个开关“按住飞行弹幕让它停住”，放在弹幕设置“画面弹幕交互”一组（点按、长按两个开关下面），**默认关**；开关只管钉不钉，不影响点按、长按开关；控制条区域和锁定时不钉（和点按一样，`danmakuTapAllowed`）。

### 做法 A、B、C 的选择

| 做法 | 选了没有 | 理由 |
|---|---|---|
| A 按住只钉那一条，其他照飞；按住到长按时间照旧打开面板（整层停住）；没打开面板时松手它继续 | **选 A**（建议） | 现有的单击、双击、长按结果都不变（A08.4、D-038、A07.14 确认过的），只是多了“那一条先停住”；看清了直接松手 |
| B 按住只钉住、不开面板，面板改成单击打开 | 不选 | 改了 A08.4 确认过的长按；D-038 刚定过单击的规则 |
| C 照上游：按住 = 钉住 + 开面板，面板开着其他照飞 | 不选 | 改了 3.x 的“面板开着整层停住” |

其他：小窗、画中画、多画面不做（小窗的弹幕层不接手势，多画面的格子单击是选格子）；电视没有触摸；读屏和键盘没有“按住”，不受影响（钉住只是看得见的效果）。
