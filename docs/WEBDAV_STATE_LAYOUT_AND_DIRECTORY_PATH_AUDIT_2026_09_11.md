固定夹具和源码检查确认：

1. 无配置、待选择、加载、空目录和错误状态都使用固定的 `SliverFillRemaining` 居中列。`320×480` / 3.0 倍
   文字下，失效配置的“创建新配置”操作没有可点击区域。
2. 长目录错误同样受固定剩余高度约束，修改前向底部溢出 **2790 像素**，“重试”操作不可达。
3. 目录点击强制读取 `file.name!`。服务器返回合法 `path` 但省略可选 `name` 时抛出空值断言，无法进入目录。
4. `name` 与 `path` 同时缺失的异常目录项没有隔离策略；相对路径末尾已有分隔符时也需要统一归一化。

## 修订

- WebDAV 页面以视口约束计算状态区最小高度；五种状态统一使用外层 Sliver 状态面。短内容保持居中，长文案自然
  扩展为同一个页面滚动范围，底部操作保留安全间距。
- 配置异常提示、空状态和目录错误统一居中文案；窄屏大字号下可滚动到“创建新配置”及“重试”并继续操作。
- 目录导航优先采用服务返回的 `File.path`，统一首尾及重复 `/`；仅在路径缺失或不可用时回落到合法名称。
- 目录同时缺少路径和名称时保持当前目录且不发请求；普通文件仍不触发目录导航。
