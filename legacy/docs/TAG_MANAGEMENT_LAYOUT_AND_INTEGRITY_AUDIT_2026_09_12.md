# 标签管理布局与数据完整性审计（2026-09-12）

- 本轮只做源码、确定性 Widget/控制器回归与静态分析；未连接手机、调用真实平台、构建安装包或发布版本。

## 复现与根因

新增回归在旧实现上为 **0/4 PASS**：

1. 320×480、英文、3.0 倍文字下，固定在外层 `Column` 的说明横幅占满正文，触发向下 771 像素的 `RenderFlex` 溢出，标签卡片和动作失去可达滚动区域。
2. 标签卡片固定为 116 像素高，详情与编辑弹窗又使用不可滚动内容，窄屏大字号没有稳定的内容/确认动作边界。
3. 描述输入框的 IME `done` 仅关闭路由，没有调用新增或更新事务，用户填写内容会直接丢失。
4. 删除标签只移除标签本身，`roomTagsMap` 继续保存已删除 ID；越界的编辑/删除索引还会抛出异常。

关注页另有一项独立红测：删除当前选中的标签后，`selectedTagId` 仍保持旧 ID，完整关注列表会被过滤为空。

## 修订

- 将说明、分组标题和标签网格合并到同一滚动面；卡片按正文宽度和实际文字缩放切换单列/多列并动态计算高度，不再截断动作区。
- 置顶、编辑、删除动作统一为 48 像素高点击区，补充稳定 Key 与 Tooltip；新增入口也补充语义提示。
- 详情、新增/编辑和删除确认统一使用有界可滚动 `AlertDialog`。
- 新增/编辑表单改为由有状态弹窗持有输入控制器；确认按钮与 IME `done` 共用同一提交函数，路由退场时再由 Widget 生命周期释放控制器。
- 编辑和删除按标签 ID 重新解析当前索引，避免弹窗期间列表变化后误操作其他标签。
- 删除标签时同步剔除全部房间映射中的旧 ID，空映射删除，剩余映射和顺序各只持久化一次；编辑/删除补齐越界保护。
- 关注页监听标签集合变化；当前选择已不存在时，以一次选择事务回到“全部”、重置页码并重建本地列表。
