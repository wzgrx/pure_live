## 是什么

把开发任务交给云端的 Claude 会话：每个会话从 master 开分支，按任务单改代码、跑门禁，推分支开草稿 PR，维护者在本地合并。

## 为什么不做

- D-014（用户定）：不使用云端会话。当时停用的提交写的是“Cloud sessions are not used”，没有展开原因；从当时的规则看，云端会话的限制是：没有 K90（真机验证只能在本机）、可能没有 Android SDK（原生部分编译不了，记录里只能写“原生部分没有编译”）、要推分支到 GitHub、门禁跑不全时只能跑一部分。4.0.x 那一轮的 19 个任务里 16 个最后在本机工作区里做完、合并（构建号 5001），P04、P06、F01（现在的 A03.3、A04.1、E06.2）暂停。
- 现在的做法：本机 git worktree（每个任务一份工作区和分支）+ 子代理；任务书照 PROCESS 第 7 节写成自包含，任何 AI 都能接。

- 用户要求再用。
