## 应用合同

- `HuajiaoSite` 接入站点工厂、热门、分类、详情、收藏元数据刷新、播放、录制与恢复。
  分类只有官网 H5 `live5` 公开视频推荐，页面持续显示范围说明；没有虚构全站分类或搜索入口。
- 持久身份是主播 UID，不是当前广播 ID。卡片、序列化和录制输入保持 UID；媒体地址仅放在
  本次详情中，不存入收藏。元数据刷新只读用户 API，播放/录制才重新查询当前广播并匹配作者、广播和串号。
- 画质标识为 URL 所示 `hls` / `flv` / `unknown`，不是分辨率或编码证明。恢复重新取流并匹配
  原格式，缺失时报告错误，不静默切到另一档。播放器、音频/多画面和 FFmpeg 使用共享请求头入口。
- 主播链接按明确域名/路径直接解析 UID；广播链接异步查询匹配的作者 UID，再进入收藏身份。
  结束广播仅在 API 仍返回匹配作者时可解析身份；这不授予媒体可用状态。超时/取消后丢弃迟到结果。
  同步网页解析器仅接受主播链接，广播链接走异步分享解析。外部打开重建官方主播主页，不信任导入的任意链接。
- 配置目录迁移 **8→9** 只追加花椒，保留已有顺序和隐藏状态；再次初始化及 Hive 关闭重开后不重新启用
  用户禁用的花椒。备份规范化去重并保留顺序。`current_heat` 只作热度，真实在线能力保持不支持。
- zh/en 各新增四个键；使用通用应用图标。图标品牌化和实际布局属于后续 UI 验收，不当作已完成设计。

## 游标所有权与分页

新增可选 `LiveSiteCursorDirectoryPager` 合同和 `LiveDirectoryPage.nextCursor`。
`LiveDirectoryController` 每个已提交/刷新缓冲区持有独立游标，不在共享站点对象中存页号映射。
返回页号、游标、去重和容量检查均成功后才一起提交卡片和下一游标；迟发旧刷新不污染新目录。

目录页的条数不等于原生步长，空页/重复行仍按 more 和 next offset 有界继续。单次加载保留请求预算、
总缓冲容量和重试位置；空刷新失败保留旧视图及其游标，已取得新页后的重试只沿新批次游标前进。
公共控制器拒绝空、过长或立即重复的继续游标，花椒 API 另要求数值 offset 严格前进。

旧式 `getDirectoryPage(page)` 没有游标参数，因此兼容路径重放最多 20 页前缀并设总计 20 秒期限；
`getRecommendRooms/getCategoryRooms` 保留完整原生页，pageSize 不裁断服务端游标页。实际 Android/Windows
目录工厂使用新游标控制器，不走此前缀重放；没有宣称旧接口支持无界随机跳页。
