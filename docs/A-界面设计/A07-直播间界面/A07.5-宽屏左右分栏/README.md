## 3.x 的样子和问题

**3.x 的样子**（`git show v3.2.11:lib/modules/live_play/widgets/layout/live_play_content.dart`、`live_play_header.dart`、`widgets/video_player/video_controller_panel.dart`）

- 宽度 ≤680 用竖屏排法，>680 左右分栏（`resolveLivePlayNormalLayout`，`live_play_content.dart:20-22`）：左边画面（黑底，16:9 居中，`live_play_video.dart:120` 的 `LivePlayVideoFrame`），右边聊天栏，宽度是可用宽度的 34%，夹在 300–400（`:94-96`）；聊天栏从上到下是 `ResolutionsRow`（人数、原画、线路，11 号字）、分隔线、四个标签和弹幕列表（卡片样式）。网络电视不显示聊天栏（`showPanel`）。
- 顶栏：宽度 ≥600 时关注是文字按钮（`FilledButton`，圆角 6，12 号字，“关注”主色底、“已关注”半透明主色底），录制是带字的按钮（图标 14 + 11 号字：录制 / 已监控 / 录制中）；<600 时是心形图标按钮和圆圈图标（`favorite_floating_button.dart:62-93`、`record_action_content.dart`）。主播名和“平台 / 分区”都是 `labelSmall`（`live_play_header.dart:42-55`）。
- 画面上栏：标题、纯音频、投屏（Android）、小窗（Android、Windows）。下栏（不是全屏时）：左 播放/暂停、刷新、“✓ 已关注”、弹幕开关、弹幕设置；右 方向（移动端）、“默认比例”文字按钮、Windows 音量条、Windows 窗口内全屏（`unfold_more`，`video_controller_panel.dart:1882-1905`）、全屏。
- 窗口内全屏（Windows）：画面占满窗口，顶栏和聊天栏藏起来，Esc 退出（`widgets/keyboard/video_keyboard.dart`）。
- 鼠标：移动时显示控制栏，静止后隐藏，鼠标指针也隐藏（`widgets/layout/control_hover_region.dart`）。

## 按钮的作用和用法

编号对应 [v4-wide-n.jpg](v4-wide-n.jpg)。

| 编号 | 控件 | 怎么用 |

| 6 | 纯音频 | 只播声音。 |
| 7 | 投屏 | 只有 Android 平板有（图里是 Windows，没有这个按钮）。 |
| 8 | 小窗 | 缩成小窗继续播（Android、桌面）。 |
| 9 | 播放 / 暂停 | 暂停或继续；空格键也可以。 |
| 10 | 刷新 | 重新连接直播流；R 键也可以。 |

## 待选和决定

- H1 中等宽度（600–839）：**A** 用手机的排法（画面在上、聊天在下），画面占满宽度；B 照 v3 左右分栏。→ 选 A（2026-10-01）。
- H2 收起聊天栏的入口：**A** 下栏按钮加聊天栏边缘的小把手；B 只放在右上角菜单里。→ 选 A。
- H3 聊天栏宽度：**A** 照 v3：窗口的 34%，最窄 300、最宽 400；B 可以拖动边缘调宽，记住宽度。→ 选 A。

## 性能要点

窗口宽度变化跨过 840 时只换排法，播放器只有一个、移动不重建，播放不中断；聊天栏收起、展开只做宽度动画，画面尺寸动画结束后再通知播放器；弹幕列表懒加载、有条数上限；人数和时长单独刷新。
