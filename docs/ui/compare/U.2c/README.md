## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 手机横屏、窄手机横屏 |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 同一套上下栏；悬停显示名称；Windows 有音量条；投屏只有 Android |
| 电视 | 直播间始终全屏，按 U.15d 的遥控器方式；同样的按钮在电视的设置面板里 |
| 苹果平台 | iPhone 横屏避开灵动岛一侧的安全区；macOS 用系统全屏空间和 Cmd 快捷键 |
