# 术语

| 词 | 意思 |
|---|---|
| 3.x、v3 | 旧版纯粹直播，基线是标签 `v3.2.11`（本机只读副本 `~/ref/v3ref`） |
| 4.x、v4 | 现在的版本：在 3.x 代码上重构，2026-10-02 发布 4.0.0（Android） |
| 组、子分类、任务 | 文档的三层：`A` 界面设计 → `A07` 直播间界面 → `A07.13` 切换直播间面板；文件夹是编号加中文名，例如 `A-界面设计/A07-直播间界面/A07.13-切换直播间面板/` |
| 登记表 | [tasks.toml](tasks.toml)：全部任务的编号、状态、阶段 |
| 档位 | 第一档马上做、第二档应该做、第三档以后 |
| 阶段 | 一个任务分成的几步，每步能单独合并和验证 |
| 待真机 | 代码已合并、门禁通过，还没在真机上逐项看 |
| 暂停 | 做到一半停下，登记了接手说明 |
| 受阻 | 外部原因做不了（例如平台要签名） |
| 任务书 | `brief.md`：交给执行者（人或任何 AI）的全部要求 |
| 记录 | `record.md`：做了什么、根因、偏差、测试、提交 |
| 合并审查 | 合并进 master 前按清单逐条检查（[PROCESS.md](PROCESS.md) 第 8 节） |
| 门禁 | `tools/gate/gate.sh --all`：格式、依赖方向、样本隐私、界面结构、文档、分析、测试；推送前必须通过 |
| 工作区 | git worktree：每个开发任务一份独立的代码副本和分支 |
| K90 | 测试手机 Redmi K90 Pro Max（Android 17，120 Hz） |
| 测试包 | `com.mystyle.purelive.v4dev`，和正式包并存 |
| 正式包 | `com.mystyle.purelive`，覆盖安装 3.x |
| 调试密钥 | 维护者的签名密钥（`~/.android-purelive/debug.keystore`），3.x 和 4.x 正式包都用它签名 |
| 效果图、编号示意图 | 界面设计的图：`v3-*.jpg` 还原 3.x，`v4-*.jpg` 新设计，`-n.jpg` 带控件编号 |
| 评审页 | 用 `page.json` 生成、发布到 claude.ai 的对比页，用户逐条表态 |
| 对比页导出 | 评审页按章节导出的图，放在任务的 `page/` 里 |
| 清点 | 把 3.x 的界面、功能点、设置项、平台逐项列出并分到任务，保证不漏（[inventory/](inventory/README.md)） |
| 竖屏普通布局 | 竖屏直播间：画面在上，信息和聊天在下 |
| 竖屏流、三档面板 | 竖屏直播（主播竖着拍）时画面加高，下面是可以拖到三个高度的面板 |
| 竖屏全屏 | 竖屏直播铺满全屏 |
| 横屏全屏 | 手机横过来的全屏 |
| 平板分栏 | 宽屏上画面加右侧聊天栏 |
| 应用内小窗 | 应用里悬浮的小播放窗 |
| 画中画 | 系统的画中画窗口 |
| 飞行弹幕 | 画面上飘过的弹幕 |
| 聊天列表 | 直播间下方的弹幕列表 |
| 醒目留言 | 付费的置顶留言（哔哩哔哩 SC 等） |
| 打码昵称 | 哔哩哔哩对未登录用户显示的“观***”这类昵称 |
| 本地互动 | 只在本机显示的本地弹幕、样式、礼物效果 |
| 平台、来源 | 直播平台（哔哩哔哩、斗鱼……）；网络电视也算一个来源 |
| 线路、清晰度 | 同一个直播的不同地址和画质 |
| 巡检 | 定期用真实接口检查各平台还能不能用 |
