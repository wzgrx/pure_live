## 3.x 的样子和问题

整体（宽度 ≤680，`live_play_content.dart` `LivePlayNormalLayout` 的 `portraitStack`，`git show v3.2.11:lib/modules/live_play/widgets/layout/live_play_content.dart:20-22`、`:30-120`）从上到下：

1. **顶栏**（`widgets/layout/live_play_header.dart`，`AppBar` 56 高）：返回；头像（半径 16）；两行小字（主播名、`平台 / 分区`，都是 `labelSmall`）；右侧三个按钮：关注（手机上是圆形浅色填充按钮 `IconButton.filledTonal`，`Remix.heart_3_line/fill`；取消关注先确认）、录制（`Remix.record_circle_line`，录制中 `record_circle_fill`、已完成 `checkbox_circle_fill`）、菜单（`Remix.apps_2_line`）。
2. **画面**（16:9），点一下显示 / 隐藏控制层，双击全屏，左右半边上下滑调亮度 / 音量，长按画面上的弹幕可操作。控制层：上栏（56 高，黑色 45% 渐变）：房间标题（白色 16 号粗体），右侧（Android）纯音频 `Remix.headphone_line/fill`、投屏 `Remix.tv_2_line`、小窗 `CustomIcons.float_window`；下栏（56 高）：左侧播放 / 暂停、刷新 `Icons.refresh_rounded`、关注（白字小胶囊“✓ 已关注 / × 关注”）、弹幕开关（`danmu_open.svg` / `danmu_close.svg`）、弹幕设置（`danmu_setting.svg`）；右侧方向（`Icons.screen_rotation_alt_rounded`）、画面比例（文字按钮）、全屏（`Icons.fullscreen_rounded`，固定在最右）。手机放不下时中间部分可横向滚动。
3. **信息行**（`resolution_selector/resolutions_row.dart`，56 高）：左侧一个人数（图标 + “在线 1.2万”，按设置选在线 / 热度 / 累计）；右侧画质（“原画”）、线路（“线路1”），主题色小字，点开弹出菜单。
4. 分隔线；**四个等宽标签**：弹幕列表、醒目留言、弹幕设置、屏蔽管理。
5. **弹幕列表**：每条一张小卡片（白色 72% 底、圆角 10、细边框），左边 8 像素的彩色圆点，“用户名：”粗体 + 内容（14 号，表情图片）；双击复制，长按 / 右键弹出操作；往上翻时右下角“有 N 条新弹幕”。

**直播间详情**（点信息行展开，盖在画面下面的弹幕区，画面和控制栏照常可用）：主播（头像、名字、平台图标、可点的分区、关注按钮）→ 状态行（红底“直播”+ 开播时间 + 已播时长；回放、未开播、受限时相应变化，受限附原因和下一步）→ 完整标题（最多三行）→ 四格数字（在线、热度、累计观看、已开播，只显示平台有的）→ 公告、简介（各两行，可展开）→ 房间号、链接（复制）→ 分享、在平台打开。点“收起”、再点信息行、下拉或返回键关闭。宽屏时盖在右侧聊天栏上。

**这一屏其他优化**：E1 点顶栏头像或名字也展开详情；E2 进房时名字、信息行、人数先显示占位；E3 断流重连时画面中间显示“正在重连（第 N 次）”和“换线路”；E4 第一次关画面弹幕时提示一次“列表照常显示”；E5 纯音频时画面区显示封面和“纯音频播放中”；E6 方向不是“自动”时图标变黄，长按显示当前设置。

## 按钮的作用和用法

对比页“每个按钮是干什么的、怎么用”一节（a–y）是确认时的完整说明；下面是现在代码里的竖屏控件（操作方式照 v3）：

| 区域 | 控件 | 怎么用 |
|---|---|---|
| 顶栏 | 返回 | 关详情或面板后离开直播间（返回链） |
| 顶栏 | 头像、主播名 | 点开直播间详情（E1） |
| 顶栏 | ＋ 关注 / ✓ 已关注 | 关注；已关注时点开取消关注（先确认） |
| 顶栏 | 录制 | 打开录制面板（A07.6） |
| 顶栏 | 四宫格菜单 | 切换直播间、定时关闭、房间音量、画面比例、投屏、获取直链、分享、在平台打开（Windows 在新窗口打开）、本地互动 |
| 画面上栏 | 标题；纯音频；投屏（Android）；小窗 | 纯音频只放声音；投屏打开投屏面板；小窗进画中画 |
| 画面下栏 | 播放 / 暂停、刷新、弹幕开关、弹幕设置 ｜ 方向、全屏 | 弹幕开关只管画面上的飞行弹幕（第一次关时提示 E4）；方向非“自动”时变黄，长按显示当前设置（E6）；全屏按钮竖屏源进竖屏全屏 |
| 信息行 | 标题行、详情 ⌄ / 收起 ⌃ | 展开或收起直播间详情 |
| 信息行 | 人数、开播时长 | 只显示；口径名在长按提示里 |
| 信息行 | 原画 ⌄、线路1 ⌄ | 换清晰度、换线路（A07.6 小菜单） |
| 标签 | 弹幕列表、醒目留言（条数）、弹幕设置、屏蔽管理 | 左右滑或点切换；详情打开期间来的新弹幕数显示在“弹幕列表”上 |
| 弹幕列表 | 一条弹幕；N 条新弹幕 | 双击复制“用户名: 内容”；长按或右键打开复制、屏蔽此用户、屏蔽关键词；往上翻后右下角按钮回到底部 |
| 画面 | 单击、双击、左右半边上下滑、长按弹幕 | 显示或隐藏控制层；全屏；亮度、音量；弹幕操作（附录 A 第 1～6 条） |

## 性能要点

画面、飞行弹幕、控制层分层重绘；人数和时长单独刷新；弹幕列表懒加载、有上限；飞行弹幕按时间算速度；控制层用黑色渐变不用模糊；视频不裁圆角。
