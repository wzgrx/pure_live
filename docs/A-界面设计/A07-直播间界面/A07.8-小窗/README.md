## 3.x 的样子和问题

文件在 `git show v3.2.11:lib/...`（`modules/live_play/`、`player/`）。

**小窗按钮**：画面上栏 `CustomIcons.float_window`，48×48 白色，提示“小窗播放”；只在 Android 和 Windows 出现（`video_controller_panel.dart:56-66`、`:563-600`）；准备中变灰；出异常时提示“打开画中画失败，请重试”（`:589-593`）。Android 进系统画中画，Windows 把主窗口缩成小窗，其他平台没有。

**应用内悬浮小窗**（`player/core/player_manager.dart:2970-3156`）：

- 什么时候出现：设置“退出小窗播放 / 返回时是否保留悬浮窗”（`floatPlay`，默认关，`player_settings_controller.dart:46`）打开时，从直播间返回；房间有画面且没有加载错误才出现（`routes/navigation_observer.dart:45-60`、`:109-121`，`live_play_video.dart:77`）。
- 大小：横的画面宽 = Windows 350、其他平台 220，高按画面比例（`:2978`、`resolveAppFloatingSize` `:4737-4757`）；竖的画面高 = 220×1.2，宽按比例、最窄 120。手机上是 220×124，竖屏直播 149×264。
- 样子：黑底，12 圆角，整块裁剪（`:3013-3015`）；画面用直播间的画面比例设置；上面一层小窗弹幕（`:3028`）。
- 位置：右 16、离底边“系统底部边距 + 80 + 16”（`:3123-3124`、`:3150-3155`，按手机底部导航栏算）；可以拖到任何地方，不吸边，拖动时 80% 不透明（`:3125-3126`）。
- 按钮（`:3053-3114`）：中间播放 / 暂停 `Icons.pause_circle_filled` / `play_circle_filled`（42，45% 黑圆底，提示“暂停”“播放”）；右上（右 4、上 4）关闭 `Icons.close`（20，48×48，45% 黑圆底，提示“关闭”）→ 停止播放并关掉小窗（`:3108`）。
- 手势：触摸（Android、iOS）出现时和第一次点时显示按钮 3 秒（`:2984-2990`），按钮显示时点画面回到直播间（`:3039-3048`）；鼠标（只认 Windows、macOS）悬停显示按钮，点画面回到直播间（`:2999-3004`）。
- 菜单、对话框、面板打开时整个隐藏（`popup_route_tracker.dart:48-74`、`:3144`）；打开任何直播间或多画面时关掉，打开的是同一个直播间则接着播（`routes/app_navigation.dart:55-63`、`multiview_controller.dart:281-282`）。
- 纯音频：显示纯音频卡片的紧凑版（高小于 500）：头像 50、标题 14 号、主播名 11 号胶囊、“纯音频模式”11 号胶囊（`:3292-3460`）；加载中：加载动画（随设置，`:3575-3580`）。

**Android 系统画中画**（`player_manager.dart:2808-2871`）：画面比例按视频比例（限制在 Android 允许的范围）；进入前先画一帧只有画面的界面，避免黑屏（`:2836-2841`）；源区域提示按画面位置（`:2843-2854`）；画中画里显示 `buildPiPOverlay`：画面 + 小窗弹幕（`live_play_content.dart:490-495`、`player_manager.dart:3215-3287`），它的播放和关闭按钮只在鼠标悬停时出现，手机上看不到；按钮由系统画。没有“离开应用时自动进入”（插件的 `OnLeavePiP` 没用到）。

**Windows 小窗**（`player/utils/window_helper.dart:217-337`）：

- 主窗口缩成小窗：横的画面宽 360，竖的画面高 380（最窄 140），接近方形 280（`:255-275`）；默认在当前显示器工作区右下角、边距 20（`:161-162`）；“记住小窗位置和大小”打开时用上次的位置，并校正到还在的显示器（`:118-163`）；最小 140×90（`:154-155`）。
- 置顶按设置“Windows 小窗始终置顶”（默认关，`player_settings_controller.dart:47`；`window_helper.dart:311`）；小窗里改不了。
- 没有标题栏（`desktop_manager.dart:124-132`）；拉边改大小（`pip_window_widget.dart:12-21`）；按住任何地方拖动（`player_manager.dart:3232`）；双击恢复主窗口（`:3233`）。
- 悬停时显示中间播放 / 暂停（同上）和右上（右 8、上 8）关闭 `Icons.close`（24，没有底色），点了是**恢复主窗口**、继续播放（`:3270-3281`）；失败提示“恢复主窗口失败，请重试”（`:2953-2960`）。Esc 在小窗里不处理（`video_keyboard.dart:93-97`）。

**小窗弹幕**（`compact_danmaku_overlay.dart:13-92`，默认值 `danmaku_settings_controller.dart:17-31`）：三种小窗共用；默认开、自动缩放、12 号、字重 500、速度 90、透明度 0.9、占画面上半（0.5）、同时最多 6 条、间隔 0.35 秒、帧率 30 或跟随刷新率档位、保留平台颜色；字体和描边跟主弹幕设置；直播间关了弹幕（`hideDanmaku`）时也不显示。自动缩放 = 小窗宽 ÷ 350，限制在 0.65–1（`compact_danmaku_metrics.dart:27-31`），所以 220 宽的小窗弹幕是 7.8 号字。

## 按钮的作用和用法

| 编号 | 控件 | 怎么用 |
|---|---|---|
| 1 | 回到直播间（新） | 应用内小窗：打开直播间页面接着看；桌面小窗：恢复成原来的大窗口 |
| 2 | 关闭 | 停止播放、关掉小窗。桌面小窗关掉后主窗口怎么办见 J3 |
| 3 | 播放 / 暂停 | 暂停或继续；暂停时一直显示 |
| 4 | 置顶（桌面，新） | 小窗留在其他程序上面；再点取消；和设置“小窗始终置顶”同一个开关 |
| 5 | 小窗本身 | 手机：按住拖动；点一下出按钮（3 秒后隐藏），按钮显示时再点画面回到直播间。电脑：按住拖动，双击回到直播间；桌面小窗拉边改大小 |
| 6 | 音量（桌面，新） | 滚轮调音量，底部出音量条 |
| — | 录制角标 | 只显示，录制中才有 |
| — | 小窗弹幕 | 只显示；样式在设置“小窗弹幕”（A11.3）；直播间关了弹幕，小窗也不显示 |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 小窗按钮进系统画中画（可选离开应用时自动进入）；“退出小窗播放”打开时离开直播间变应用内小窗（220 宽） |
| 宽屏：平板、折叠屏 | 同手机；应用内小窗 360 宽，离底边 16 |
| 宽屏：Windows、Linux、macOS | 小窗按钮把主窗口缩成桌面小窗（同一组按钮，加置顶、音量）；应用内小窗同平板，悬停出按钮；在新窗口打开的直播间一样。macOS 小窗时隐藏左上角三个窗口按钮 |
| 电视 | 不适用：电视的直播间一直全屏，pure_live_TV 没有画中画，设置里也去掉了画中画和小窗的选项（`features/settings/pages/video_settings_section.dart:15`） |

## 拿不准的地方（设计时记下的）

1. Android 画中画默认多大（图里按 240×135 画）、点开后系统按钮里有没有播放 / 暂停（取决于媒体会话），要在 K90 上看，归 A14.1。
2. v3 的 Windows 小窗里空格、R、上下键是否生效：`video_keyboard.dart` 只写了小窗时 Esc 不处理（`:93-97`），其余没在真机上确认。
3. v3 应用内小窗在手机旋转后的位置（`flutter_floating` 按右下角定位），没在真机上看。
4. iOS 画中画要把 mpv 的画面交给系统（`AVSampleBufferDisplayLayer`），能不能做到要等有 Mac 再验证；macOS 是否也改用系统画中画同理。
5. Linux 置顶随桌面环境（X11 可以；GNOME Wayland 不允许；KDE 部分支持）。
6. Windows 11 会不会给无边框的小窗自动加圆角（图里按直角画）。
