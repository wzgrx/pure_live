- 日期：2026-10-01
- 设计：[docs/ui/compare/U.2d/README.md](../compare/U.2d/README.md)（第 2 版，用户已确认；H1～H3 按建议 A）

### 窗口内全屏（电脑）

照 v3：画面铺满窗口，顶栏和聊天栏隐藏，控制层用横屏全屏的排法（U.2c，时间、关注、清晰度线路、画面比例、音量）；右下角是“退出窗口内全屏”（`unfold_less` 转 90°），没有“全屏”按钮（v3 同）；Esc、返回、双击退出。

## 测试

在 `live_play_layouts_test.dart`（共 24 个，见 U.2c 记录）里，这个任务的：

- 1280×800 Windows：分栏、聊天栏宽 400、信息行在聊天栏里、画面框 16:9、下栏顺序（播放、刷新、弹幕开关、弹幕设置、音量、收起聊天栏、窗口内全屏、全屏）和图标、提示文字、顶栏关注按钮；Android 平板的下栏（方向、收起聊天栏、全屏）；
- 720×1000 用手机排法；
- 收起聊天栏：设置写入、宽度变 0、提示变“展开聊天栏”、把手箭头、顶栏还在、面板从右侧出来宽 360、把手展开；下一个直播间打开时仍是收起的；
- 窗口内全屏（Linux）：没有顶栏和聊天栏、横屏排法、退出按钮、没有全屏按钮、Esc 退出；
- 高度不到 480（852×393）：横屏排法铺满页面，返回键提示“返回”，右下角是进入全屏。

原有测试 `live_play_page_test` 的“宽窗口把聊天放在画面旁边”（1200 宽）照旧通过。

2. 桌面窗口本身（标题栏、在新窗口打开、记住窗口大小）：U.13。
