- 猫耳 `catalog/tag` 同号是本分支新增适配的相邻集成风险。旧备份合并键只有 platform/areaId，开放新入口前需补全身份合同。本批没有新增平台注册。

## 第一个错误状态与边界

1. 收藏虎牙 `areaId=1` 后打开斗鱼 `areaId=1`：设置层 `isFavoriteArea` 和分类页按钮只比较 ID，提前认作已收藏；确认取消的 UI 路径按 ID 删除其他平台记录。
2. 设置层 `removeArea` 使用对象引用删除：从 JSON 重建同一分类后删除失败。这与 UI 按 ID 批量删除是两条独立调用路径，共同缺少领域身份合同。
3. 旧平台的 areaType 是父分类元数据，不应一律加入主键。旧备份可能省略父分类；IPTV 使用全局频道 ID，`getCategoryRooms` 仅按频道 ID 查找，provider 不参与频道身份。
4. 猫耳目录请求明确分 `catalog_id/tag_id`，必须保留命名空间；未知/缺失 type 不应当作通配符匹配二者。
5. 收藏分类页控制器只在 onInit 复制一次设置列表引用。设置层替换列表后，已挂载页面继续观察旧快照；冻结上游也有此路径。改为在页面 Obx 中读取实际收藏 observable，不添加新的 Worker 或订阅。

## 设计与数据保留

采用局部领域身份修订，不改播放、录制、弹幕、窗口或数据表结构。收藏判断、添加、删除和旧 Hive 合并共用身份生成规则。platform 去首尾空白并转小写，ID 去首尾空白但保留大小写；仅猫耳的 type 参与命名空间。使用结构化编码避免字符串分隔符碰撞。

LiveArea 仍为可变对象，不重载 `==/hashCode`，不改变现有序列化字段。没有平台或 ID 的旧记录保留原样，不自动清理用户数据，也不作为可添加/匹配的正常收藏。取消收藏只移除同一身份，保留其他平台、命名空间及确认对话框期间新增记录。旧备份合并保留当前顺序与非空展示字段，并允许补齐旧父分类字段。
