- 准备：关注里有一个横屏画面的直播间（例如哔哩哔哩）和一个竖屏主播（抖音）；设置 → 视频 →“进入全屏时的方向”先是默认“跟随直播源（推荐）”；首页 → 多画面里放 2 个直播间。每次点按前确认前台是测试包。截图放本文件夹的 `verify/`（翻转前后各一张）。

## 结论

- 通过（第 1～9 步）：登记表 `docs/tasks.toml` 的 O05.2 改成“完成”，`date` 写验证日期；运行 `python3 tools/docs/docs.py`。告诉维护者 V02.3 和 issue #36 的结论有了真机依据。
- 不通过：写现象（哪一步、哪个方向不翻、方向值是多少）和根因线索：方向值不是 `SENSOR_LANDSCAPE` → 看 `screen_orientation.dart:13` 的通道调用有没有到原生（`SystemAccessPlugin.kt:112`，没有 Activity 时回答 false）；方向值对但不翻 → HyperOS 对 `SENSOR_LANDSCAPE` 的处理，记下系统版本，开新任务（O05）；多画面不翻 → `multiview_page.dart:403`。
