# M13.7 页面：设置

- 日期：2026-10-01
- 目录：`apps/pure_live/lib/features/settings/`（路由 `RoutePath.kSettings`，类名和构造参数不变）
- v3 来源：标签 `v3.2.11` 的 `lib/modules/settings/`（23 个文件，7573 行），以及它们读写的 `lib/common/services/settings/*_controller.dart`（存储部分已在 M9 变成 `Settings` 注册表）、`lib/common/consts/app_consts.dart`（主题色、加载动画名）、`lib/player/utils/mpv_option_labels.dart`、`player_consts.dart`（播放器选项）

## 做法

整页是**声明式的目录**：每个设置是一条 `SettingsEntry`（所在分区、分组、标题、一句说明、搜索关键词、它改哪些存储项、在哪些平台和宽度出现、怎么画），页面、分区、搜索、“恢复默认”都从这一张表生成。

| 文件 | 内容 |
|---|---|
| `settings_page.dart` | `SettingsPage`：顶部搜索框；手机是分区列表（图标、名称、一句概括、已修改数量），点开进分区页；宽于 840 时左边分区、右边内容；有搜索词时显示跨分区的结果。路由参数可以是分区名（如 `'danmaku'`），直接打开该分区。`SettingsSectionPage`、`SettingsSectionView`：分组标题 + 卡片；有改动时标题栏出现“恢复本页默认” |
| `settings_model.dart` | `SettingsSection`（10 个分区）、`SettingsEnv`（平台、宽窄）、`SettingsEntry`、`searchSettings`（每个词都要命中标题、说明、关键词、分组或分区名）、`groupsOf`、`changedSettings` |
| `settings_catalog.dart` | 目录本身：118 条，按分区写；`formatMinutes` 等格式化 |

### `live_store` 的改动（只改注册表，键名不变）

- `danmakuTopArea`、`danmakuBottomArea`：范围 0～1 改为 0～300（像素，同 3.x `_boundedDouble`）。原来 3.x 的 40 像素会被夹成 1。
- `textScaleFactor`（0.5～2）和五种字号（9～15、11～17、12～18、13～20、16～26）加上 3.x 的范围，越界值读出时夹紧（3.x 同样夹紧）。
- 没有改键名和默认值，3.x 的设置和备份照旧一一对应，不需要迁移对照。

## 有意差异

| 差异 | 原因 |
|---|---|
| 去掉“播放内核切换” | v4 全平台只用 mpv（M7.2） |
| 后台播放、睡眠模式、小窗置顶、开机启动、窗口大小只存设置，不立即调用系统接口 | 对应的系统部分（audio_service、窗口管理、托盘、开机启动）还没有接入（M12 后续、M13.3b）；接入后按设置生效 |
| 分页设置只在宽于 680 时出现 | 同 v3（只有宽屏有分页栏） |

## 界面改进

1. **按用户心智重分 10 个分区**（外观、播放、弹幕、平台与账号、关注与历史、网络与代理、录制、通用、数据与备份、关于），常用项在前；v3 是 11 组、每组一两个入口、再进二三级页面。
2. **设置搜索**：标题、说明、中英文关键词、分组和分区名都能搜，多个词同时命中才算；结果按分区列出，直接在结果里改；搜不到时给示例。
3. **宽屏两栏**：宽于 840 时左边分区、右边内容，不再一层层进出。
4. **每项一句说明**，用普通的话重写（例如代理不再写“media_kit / mpv 内核”）。
5. **少一层页面**：竖屏、刷新、代理、内核、平台、通用、导航等纯列表页直接并入分区；只有需要预览或特殊操作的才单独成页（字号、加载动画、卡片外观、首页菜单、小窗弹幕、人数平台、配置预览）。
6. **恢复默认**：分区列表显示每个分区已修改几项；分区里有改动时出现“恢复本页默认”（确认框写明几项）；“数据与备份”里新增“恢复全部默认设置”（关注、历史、分组、账号不受影响）。
7. **依赖关系可见**：总开关关闭时，它下面的选项变灰不可点（自定义输出的 vo/ao/hwdec、睡眠时长、刷新间隔、相似过滤参数、竖屏各项、描边宽度、小窗颜色）。
8. **主题**：模式改成行内三段按钮；语言加“跟随系统”；主题色色板 + 十六进制；开启动态取色时主题色一行说明“暂不使用”。
9. **统一的数字对话框**：快捷值 + 自定义值，自定义值超范围时就地提示范围（v3 各对话框各写一套，有的只弹提示）。
10. **滑块**：值显示在标题旁，拖动流畅，停下后才保存。
11. **代理**：行内开关 + 当前地址，点开对话框改地址；地址去掉 `http://` 和多余的 `/`，端口校验。
12. **播放器专家选项**：只列当前平台能用的，名字可读，附风险说明。
13. **全局弹幕样式进设置页**：上下留白（像素）、区域、透明度、速度、字号、粗细、描边、帧率，和直播间里的弹幕设置是同一组存储项。
14. **卡片外观预览按实际尺寸**（`RoomCardLayoutMetrics`，跟随字号）。
15. **加载动画**：行内静止预览 + 名字，图库页播放全部 85 种，颜色可“跟随主题色”。
16. **路由参数可以直接打开分区**（如直播间的“更多设置”可以跳到“弹幕”）。
17. **配置预览**：顶部显示关注、历史、分组数量，各模块可展开、单独复制，或整体复制。
18. **Twitch 语言**：多选，带“全部语言”和“中文 + 韩语（旧版）”两个快捷选项。
