- 构建：`com.mystyle.purelive.v4dev`，提交 ……（master 上包含合并提交 `531fcd0ba` 的任一提交；profile / debug）
- 日期：YYYY-MM-DD；验证人：……
- 准备：关注里有 10 个以上直播间（有在播的、有没开播的、有回放）；观看记录里有几条；一个竖屏主播；设置 → 视频 → 竖屏直播适配 →“竖屏全屏上下滑换台”打开（第 8 步用）。截图放 `verify/`。

| 步骤 | 期望 | 结果 | 截图 |
|---|---|---|---|
| 1. 竖屏进一个直播间，点右上四宫格 →“切换直播间” | 面板从画面下沿升起盖住信息行和聊天区，画面照常播；默认两列小卡片：封面、左上红色“直播中”和人数、封面下沿一行标题、下面主播名；最上面一行“正在观看 · 主播 · 标题” | | |
| 2. 点头部的列表图标；关掉面板再打开；换个直播间再打开；再点切回网格 | 每行一个 16:9 小封面加三行字；重开、换直播间后仍是列表；切回网格后也记住 | | |
| 3. 点刷新；过几分钟再打开 | 转圈写“正在刷新”，完了写“刚刚”；之后写“X 分钟前” | | |
| 4. 开飞行模式后点刷新 | 按钮变红写“刷新失败”，底部提示条说几个直播间刷新失败、显示的是上次的状态，带“重试” | | |
| 5. 横过手机进全屏，点顶栏 ⇄ | 面板在右侧（宽 360、全高），一屏 2×2 四张 | | |
| 6. 在全屏面板里点一个直播间 | 面板关上，画面原地换台，**还在全屏**，没有退出再进的闪动；标题、弹幕是新直播间的 | | |
| 7. 横屏全屏点右上角四宫格 | 菜单里没有“切换直播间”“投屏”“画面比例”，只剩定时关闭、房间音量、获取直链、分享、在平台打开、本地互动；退出全屏后竖屏菜单不变（第一项仍是“切换直播间”） | | |
| 8. 竖屏主播进竖屏全屏，点第二行 ⇄ | 面板占底部 60%；选一个后，在画面中间上下滑按刚才那个分组换台 | | |
| 9. 从热门或分区点进直播间再打开面板；再从关注点进一个打开面板 | 前者多一个“来源列表 N”，打开就停在它；从关注进来的没有“来源列表” | | |
| 10. 切到“观看记录”分组；长按一张卡片 | 没开播的卡片封面压暗，左上写“未开播 · 上次看 2 小时前”；长按弹出房间卡片的对话框（分享、标签、关注） | | |
| 11. 点放大镜，输入主播名的一部分；再输入不存在的名字；再点放大镜 | 只剩匹配的；显示“没有名字包含……的主播”；搜索框收起并清空 | | |
| 12. 进一个未开播或出错的直播间，点画面上的“切换直播间” | 打开同一个面板 | | |
| 13. 面板开着时按返回键 | 先关面板，不离开直播间 | | |
