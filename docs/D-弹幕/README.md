# D 弹幕

弹幕的“行为和数据”：各平台怎么连、怎么解，哪些弹幕能上屏，画面上的飞行弹幕怎么画，弹幕进来到聊天列表的数据流和性能，以及弹幕设置真正生效。看直播时弹幕是除画面外用得最多的东西，所以排在界面（A）、直播间（C）之后。

## 范围

- 管什么：
  - 平台弹幕协议（D01）：`packages/live_danmaku`（纯 Dart）的连接框架和 28 个平台的实现，应用里的平台登记（`apps/pure_live/lib/app/platforms.dart:196`），连接状态变成聊天里的系统行；哔哩哔哩访客昵称提示、粉丝牌和头像。
  - 过滤和屏蔽（D02）：`packages/live_danmaku/lib/src/filters/` 的去重闸门、屏蔽、合并重复、相似度，屏蔽表的存储（`packages/live_store/lib/src/block_lists.dart`），打码昵称不能屏蔽（`apps/pure_live/lib/shared/danmaku/masked_blocks.dart`）。
  - 飞行弹幕引擎（D03）：`apps/pure_live/lib/shared/danmaku/danmaku_overlay.dart`（直播间、小窗、多画面、电视共用）。
  - 数据流和性能（D04）：直播间控制器的弹幕分发（`features/live_play/logic/room_controller.dart`）、聊天记录 `ChatFeed`、聊天列表的跟随和定住、表情解析缓存、昵称对比度。
  - 弹幕设置生效（D05）：设置换算成弹幕层参数（`shared/danmaku/danmaku_settings.dart`、`danmaku_templates.dart`），在直播间、小窗、多画面、电视上真的生效。
  - 弹幕功能余项（D06）：清点和审查里发现的零散弹幕问题。
- 不管什么：
  - **弹幕的界面在 [A08 弹幕界面](../A-界面设计/A08-弹幕界面/README.md)**：聊天列表、醒目留言卡片、弹幕设置面板和设置页、屏蔽管理、长按弹幕面板、画面弹幕的点按和长按、本地互动的全部界面，以及这些界面各状态怎么说。分工的规则：**长什么样、怎么点、说什么话归 A08；数据从哪来、什么规则、多快、什么时候重建归 D**。同一个文件两边都管的（`chat_list.dart`、`danmaku_overlay.dart`），A08 管样子和点按命中（`messageAt`、`held`），D 管数据流、绘制和性能；具体到哪几行见两边的代码地图。本组的文档不重复界面内容，界面的问题开到 A08。
  - 直播间什么时候连、断弹幕（进房、开播重连、小窗返回）和直播间本身的状态 → [C 直播间](../C-直播间/README.md)（C01）；弹幕连接要的参数（`*DanmakuArgs`）由平台适配器给 → [E 直播平台](../E-直播平台/README.md)。
  - 小窗、画中画里弹幕的样子和 12 项设置的界面 → A07.8、A08.1；多画面 → N01；电视 → A17.4。
  - 录制时同时录弹幕 XML → H 组；网络层 `LiveSocket`、Brotli、握手 User-Agent → Q 组；刷新率 → R02；英文界面下平台给的中文 → Z05.2。
  - 本地互动的数据和规则（`features/live_play/local_interaction/logic/`）目前没有归到本组，见 A08 的已知问题。

## 风险和注意

- **平台改接口**：弹幕协议没有公开文档，平台随时可能改。对策：每个平台都有真实样本和冻结输出；巡检归 E01.6；改协议时先录新样本（`fixtures/README.md` 的脱敏规则，门禁查样本隐私），再改代码。
- **签名和登录**：抖音的签名在连接前本地算；TikTok 要平台 SDK 现场签名、LiveMe 要登录 IM，所以受阻；不运行平台的私有 SDK，不引入许可证和 AGPL-3.0 不兼容的代码（相似度的 fuzzywuzzy 就是因此自己实现）。
- **隐私**：哔哩哔哩的打码昵称不去还原（D-013）；样本里的真实昵称、Cookie、uid 要脱敏。
- **性能**：热门直播间每秒上百条。规则：弹幕不能让整页重建（只通知 `ChatFeed`）；飞行弹幕层单独一个重绘边界，排版一次录成 Picture；测试里的基准是调试模式，只能前后对比，真机数字要 profile 构建（计划书第 9.4 节）。
- **测试**：定时器至少 1 秒、不访问真实平台、用到样本时间时把“现在”固定成录制时间（D-017）。
- **设置**：3.x 的设置键名和含义不变（D-018），过滤和样式的 20 多个键都在用。
- **代码注释里的旧编号**（M5.x、U.2h、F.2a、B08 等）：找文档时先查 [MAPPING.md](../MAPPING.md)。
