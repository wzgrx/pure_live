# 关注分区状态、布局与容错审计（2026-09-12）

- 基线：`34633698b64bf731cb375666a70d52f2a8ebec37`。

- 本轮只做源码、确定性 Widget/数据回归、静态分析与仓库审计；未连接手机、请求直播平台、构建安装包或发布版本。

## 复现与根因

修改前新增 Widget 回归为 **0/3 PASS**，稳定复现：

1. 关注分区页的平台 `TabController` 只按打开页面时的显示平台数量创建；显示平台列表变化后，`TabBarView` 已响应新列表，但顶栏和控制器仍停留在旧长度，直接触发“控制器长度 3、子页数量 2”异常。
2. 当前选择只保留数字下标。平台重排或移除发生在页签动画中时，同一数字可能指向另一个平台，视觉标签、过滤结果与用户刚选择的平台发生错位。
3. 关注按钮固定为 48 像素高；320×480、3.0 倍英文下两行文字向下溢出 38 像素。
4. `LiveArea` 的历史/外部字段允许空名称和空类型，但分区卡片、详情标题、关注按钮及取消关注文案直接使用空值断言，实际构建会抛异常。

根因是页签动画生命周期放在长期 GetX 控制器中，而页面只有一半订阅了平台目录；按钮尺寸又把普通字号下的视觉高度当作硬约束。分区模型为兼容外部目录保留可空字段，呈现层却没有统一回落。

## 修订

- 页面先生成一份不可变的平台快照，并用平台 ID 序列作为页签宿主键；显示平台增加、移除或重排时，旧动画控制器随旧 Widget 安全释放，新控制器与标签/子页使用同一快照。
- 控制器同时记录所选平台 ID 和下标；重建时优先按 ID 恢复，平台确已移除才将旧下标限制到当前范围。点击立即提交平台身份，水平滑动则在动画稳定后提交。
- 每个平台瀑布流增加独立 `PageStorageKey`，分区卡片使用模型身份键，过滤、删除和列表重建不再把旧卡片状态转交给另一条记录。
- 关注按钮由固定高度改为最小 48 像素、自然高度，并增加垂直内边距；普通字号保持原触控尺寸，大字号可按实际文本增长。
- 分区名称和类型在卡片、详情标题、关注/取消关注动作中统一使用双语回落；损坏或旧版空字段仍能显示、取消关注和继续导航。
