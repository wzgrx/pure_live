## 目标

用户看到一条飞过去的弹幕想看清楚（长的、带表情的、飞得快的），现在只能长按打开面板（打开期间所有弹幕都停住），或者来不及。提议：手指按住一条飞行弹幕时只让这一条停在原地，其他照常飞，松手它继续飞；需要操作时再打开面板。

本文件是**评估初稿**，由执行者补完、出图、发评审页，**由用户决定做不做、怎么和现在的长按并存**（D-026）。

## 3.x 和现状

| 方面 | 3.x（`v3.2.11:lib/`） | 4.x 现在（`apps/pure_live/lib/`） | 上游 pure_live `2d2ad2039` | 提议 |
|---|---|---|---|---|
| 点按、长按飞行弹幕 | `modules/live_play/widgets/video_player/video_controller.dart:262`（`triggerItemAt`，找手指下那一条）、`video_controller_panel.dart` 的手势：开了“点击互动”时长按弹出消息菜单，菜单开着时整个弹幕层暂停 | `features/live_play/player/player_view.dart:416-438` 的 `_danmakuAt`：要开“点按”（`enableDanmakuTapInteraction`）或“长按”（`enableDanmakuLongPressInteraction`）；`:444-449` 打开面板期间 `_danmakuHeld = true`，**整个弹幕层停住**（`shared/danmaku/danmaku_overlay.dart:200` 的 `held`），关面板才继续 | 长按开始：`pauseItemAt` 定住手指下那一条 + 弹出菜单；`onLongPressEnd`、`onLongPressCancel` 时 `resumeAllPaused` | 按住只定住那一条，其他照飞；松手继续 |
| 引擎 | flame_barrage（3.x 没接 `pauseItemAt`） | 自己的引擎：`danmaku_overlay.dart`（1022 行），`messageAt`（`:292`）能找到手指下那一条，但**没有单条暂停** | flame_barrage 0.0.8 的 `pauseItemAt`（`lib/src/core/barrage_engine.dart:441`） | 引擎加“按住的那一条停住”（每条已有自己的时钟，见 `_clockOf` `:298`） |

和上游的差别：上游是“按住 = 定住 + 弹菜单”，菜单开着时其他弹幕还在飞；4.x 现在是“长按 = 弹面板 + 全部停住”（照 3.x）。两者都要保留哪个，需要用户选。

## 方案（评估初稿）

| 做法 | 手势 | 说明 |
|---|---|---|
| A（建议） | 按住：手指下那一条停住、其他照飞；按住超过长按时间（约 500 毫秒）仍打开面板（面板开着时照现在全部停住）；松手（没打开面板时）那一条继续 | 不改现在的长按结果，只是按下到面板出来之间多了“那一条先停住”，看清了可以直接松手 |
| B | 按住：只定住，不开面板；面板改成点按打开 | 改了 A08.4 确认过的手势，要重新评审 |
| C | 照上游：按住 = 定住那一条 + 开面板，面板开着时其他照飞 | 改了 3.x 的“面板开着全部停住” |

改动（做法 A，确认后在目标组开任务）：

| 编号 | 改什么 | 目标组 |
|---|---|---|
| c1 | 引擎：`DanmakuOverlay` 加“按住的那一条”状态（按下时用 `messageAt` 找到它，记下它的时钟值，按住期间它的位置不再前进、不过期；松手后从原位接着飞，后面的同轨弹幕不能穿过它） | D03 |
| c2 | 手势：`player_view.dart` 的 `onLongPressStart` 之前（按下时）就定住；`onLongPressEnd`、`onLongPressCancel`、面板关掉时放开；只在开了“点按”或“长按”互动时生效 | A08（A08.4 的后续） |
| c3 | 小窗、多画面不做（太小，按不准） | — |
| c4 | 读屏：没有变化（定住是视觉上的） | — |

规模：小（引擎半天，手势和测试半天）。A07.14 也改同一段手势代码，两个任务不要同时做。

## 验证（做了以后怎么验证）

- 自动测试：`apps/pure_live/test/shared/danmaku_overlay_test.dart` 加“按住的那一条 2 秒内位置不变、其他继续前进、放开后从原位继续”；`player_view` 的组件测试加“按下定住、松手放开、长按到面板打开时全部停住、关面板后都继续”。
- 真机：K90 上开“长按”互动，按住一条飞得快的弹幕 2 秒再松手；按住到面板出来；横屏全屏同样。
