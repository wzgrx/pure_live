## 根因、来源与处理

只读取冻结的本地上游 `c6c9bd70aedc503c003110dae10a83ad0bb891d8`，没有 fetch/merge。证据目录保留上游和本批基线 importer、sync engine、M3U/TXT parser 共八份完整源码。下列原有机制在冻结上游中亦存在，分类为 upstream-existing；八项红测运行在当前修订前基线，并非对上游独立构建的测试结果。

| 首个错误状态 | 影响与修订 |
|---|---|
| forceUpdate 跳过同名来源选择 | 强制仅跳过确认，仍复用来源 ID；显式同步核对完整来源快照，已删除或等待期间编辑的来源保持现状；同名歧义保留旧数据并返回失败，不删除其他来源 |
| 覆盖缓存后删来源/频道再重建默认值 | 先生成独立本地文件，再在单一 DB 事务中写来源、频道及映射；来源设置与可明确匹配频道的收藏、隐藏、排序和自动更新设置保留 |
| 解析器 hash ID 直接进入持久层 | 新协调器优先匹配 TVG/名称、原 URL 与组别；仅唯一匹配继承旧 ID，新频道使用 UUID；同 TVG 多线路分别保留，完全重复条目合并，歧义旋转整批保留旧快照 |
| 同步提前按名称删除，临时路径固定、失败仍报成功 | 网络请求使用独占临时目录，解析并提交成功才报告成功；本地路径和 file URI 可同步，旧来源文件在成功前保留 |
| 下载格式直接受查询串影响，临时文件残留 | 用 URI path 判断格式，按内容辅助识别；签名 TXT URL、HTTP 错误及 .part 随所属临时目录清理；本地/下载共用 UTF-8 与 GBK 回退解码入口 |
| 确认动作脱离返回 Future | 等待真实 Get 对话框返回值，取消/返回完成 false，确认写入结果真实返回；长名称采用可滚动内容 |

另有**本批初稿引入的 fork-regression**：清理旧缓存时只比较 URL 字符串，另一来源使用 file URI 或不同分隔符引用同一文件时会误删。两个有效红测证明文件确实被删；最终补上本地路径解析、规范路径/真实路径比较及新鲜 DB 引用检查，两项均转绿。没有将它归为上游缺陷。

## 数据、文件和并发合同

- 导入选择/确认/提交串行；锁序为 mapping → DB。事务内再次比较来源快照，避免确认、下载或文件准备期间的旧操作覆盖新编辑。
- 自动映射在外层导入事务中使用明确的新 savepoint；SQL 失败回滚整个导入，切换 EPG 来源只回滚过期映射工作，已验证的列表仍提交。
- 来源 ID、创建时间、启用、排序、账号字段及自动更新开关保留；频道停止自动更新时保留整行。旧版错误 ID 前缀在可明确匹配时也保留，避免破坏既有引用。
- 真正消失的频道清理其 favorite-list、failover 和该来源 EPG 映射子项；保留频道的已锁定映射和列表成员仍在。预约提醒/录制历史表未改动，未宣称其完整生命周期已验收。
- 本地文件采用 `playlist_UUID.ext`，独占创建、写入 flush 后才进入 DB 提交；失败只删除本次新建文件。成功后仅清理缓存根目录下已识别且无来源引用的旧普通文件，保留外部文件及共享引用。
- 文件系统与 SQLite **不是跨系统原子事务**。进程在暂存后被终止仍可能留下孤儿文件；本批没有断电测试或自动孤儿 GC。提交后清理失败只记录，不将已成功导入误报失败。
- 网络来源保存 URL 和解析后的 DB 频道，不再生成持久的重复播放列表缓存；临时目录按每次调用归属清理。缓存调用点清单已核对，PlaylistStorage 使用独立子目录；旧版网络缓存可能仍保留。
- 原公开 `deletePlaylistsByName` 不再被同步调用，但其历史删除/缓存路径尚待单独统一；没有声称所有删除入口已经修订。
