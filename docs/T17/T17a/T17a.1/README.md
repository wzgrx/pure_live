## v3 的样子（`v3.2.11`）

**窗口**（`lib/common/global/platform/desktop_manager.dart:48-99`）

- 打开时用记住的大小（默认 1280×720，`window_size_controller.dart:97-98`），最小 400×300（`:99-100`），每次都在屏幕正中（`center: true`，`desktop_manager.dart:60`）；位置和最大化不记。拖边改大小后 0.5 秒自动记下大小（`window_size_controller.dart:129-136`）。
- 系统标题栏藏起来（`TitleBarStyle.hidden`，`:63`），关闭按钮被拦下来自己处理（`setPreventClose(true)`，`:67`）。
- Windows 开了 Mica 效果，窗口底色透明（`:61`、`:69`、`:78-83`）。
- Windows 只允许开一个：再点桌面图标时把已有窗口带到前面（`windows/runner/main.cpp:40-58`）。系统里的窗口名一律是“纯粹直播”（`main.cpp:18`），Alt+Tab 和任务栏都显示这个。
- Linux 运行器给 GNOME 加了标题“pure_live”的系统标题栏（`linux/my_application.cc:40-47`），但随后被上面的“藏起来”藏掉；自绘的标题栏只在 Windows 画（`desktop_manager.dart:126-128`）。

**标题栏**（`CustomTitleBar`，`desktop_manager.dart:263-381`）

- 高 32（`:292`）。左边：图标 `assets/icons/icon.png` 16、空 6、“纯粹直播”13 号 600 字重（`:313-317`、`:480-482`）；拖边或拖动窗口时后面加“[1280 × 800]”12 号、60% 透明（`:318`、`:483-490`），停下 2 秒消失（`window_size_controller.dart:138-145`）。左边整块可以拖动窗口、双击最大化 / 还原（window_manager 的 `DragToMoveArea`）；**点图标和名字打开项目主页**（GitHub，`:306-326`、`:421-438`）。
- 右边三个按钮，各 46×32、图标 16（`:572-580`）：最小化 `Icons.remove`、最大化或还原 `Icons.crop_square`（最大化以后图标不变，`:349`）、关闭 `Icons.close`（悬停红底 `#E81123` 白字，`:366-369`）；悬停底色浅色是主色 8%、深色是白 8%；键盘焦点时加边框；没有名称提示（标题栏在导航器外面，不能用 Tooltip，`:560-561`）。
- 颜色：浅色是页面底色、字黑色；深色是纯黑、字 75% 白（`:284-285`）；启动页时是一条青色渐变 `#E8FAFC → #C8F1F5 → #9BE7F0`（`:270-280`、`:294`），而启动页本身是 `#E0F7FA → #B2EBF2 → #80DEEA`（`app_pages.dart:196-205`）。
- 全屏、小窗时整条藏起来（`:132`）。

**托盘**（`desktop_tray_service.dart:17-76`、`desktop_manager.dart:139-239`）

- 图标 `assets/icons/icon.png`，悬停提示“纯粹直播”（`desktop_manager.dart:164`）。
- 左键：窗口显示并到前面（`:213-229`）。右键：先刷新文字再弹菜单（`:231-239`）：“隐藏窗口”（窗口藏着时是“显示窗口”）、分隔线、“退出应用”（`desktop_tray_service.dart:55-57`；文字 `desktop_manager.dart:165-168`）。“退出应用”直接退出，不问（`:198-200`）。
- 每个窗口进程都建自己的托盘图标（`initialized.dart:126-130` 对每个进程都调 `DesktopManager.initialize`）。

**关闭时的选择**（`plugins/utils.dart:228-393`）

- 标题栏 ✕、Alt+F4 都走这里（`desktop_manager.dart:207-211`、`:672-679`）。设置“退出不再询问”打开时直接按记住的做（`utils.dart:246-256`），否则弹对话框（`:258-261`）。
- 对话框（`:346-391`）：标题“提示”（20 号 600）；“确定要退出吗？”（15 号 500）；分隔线；“不再询问”复选框（14 号 500，框在右边）；底下两端各一个按钮：左“最小化”（文字按钮）、右“退出应用”（红底白字）。点外面、Esc 等于取消。
- “最小化”其实是**藏起来**：窗口从任务栏消失，只剩托盘图标（`:96-108`，拦下关闭时用 `hide()`）；macOS 才是真的最小化。
- 记住的是“最小化”还是“退出”（`exitChoose`）在设置里看不到，设置只有“退出不再询问”开关（`general_settings_page.dart:157-162`）。

**在新窗口打开**（`common/utils/windows_multi_instance_launcher.dart`）

- 首页左上菜单“新建独立播放窗口”`Icons.add_to_photos_outlined`：只在 Windows 并且设置“新建独立播放窗口”（默认开）打开时有（`menu_button.dart:56-61`）。
- 直播间右上菜单最后一项“在新窗口播放此直播间”`Icons.open_in_new_rounded`：Windows 上一直有，不看那个设置（`live_play_menu_button.dart:206`）；和第一项“打开直播间”是同一个图标（`:188`）。
- 新窗口是另起一个进程：把当前全部设置导出成临时文件交给它（`windows_multi_instance_launcher.dart:118-129`、`:148-189`），它用自己的数据目录（`app_path_manager.dart:140-141`），打开后直接进那个直播间（T07i.2-05）。失败时提示条“新窗口启动失败，请重试”。

**设置里和窗口有关的**（页面在 T09a.5）：开机启动、开机窗口尺寸（对话框里预设第一项写“1080 × 720 (默认)”，`general_settings_page.dart:339`）、退出不再询问、新建独立播放窗口、Windows 动态刷新率；Windows 小窗始终置顶等在 T09a.4。

## v4 现在的偏差（`apps/pure_live/lib/app/desktop/`）

- 标题栏和托盘仍然只在 Windows（`desktop_window.dart:69-70`）；名字仍然打开项目主页；最大化图标不变；深色仍然纯黑。
- 关闭对话框改成了“关闭窗口时”两个单选 + 不再询问 + 取消 / 确定（`desktop_window.dart:284-339`），和 v3 的两个按钮不一样。
- 已经记住位置（新）、新窗口不建托盘、新窗口点 ✕ 直接关（这两条和新设计一致）；没有 Mica。
- 直播间菜单“在新窗口打开”仍用 `open_in_new`（`AppIcons.newWindow`，`packages/live_ui/lib/src/icons/app_icons.dart:202`）。

## 按钮的作用和用法

| 编号 | 控件 | 怎么用 |
|---|---|---|
| 1 | 图标（标题栏左） | 点一下弹出系统的窗口菜单（还原、移动、大小、最小化、最大化、关闭）。 |
| 2 | 名字和空白处（拖动区） | 按住拖动窗口；双击最大化 / 还原；右键弹出系统的窗口菜单；拖到屏幕顶上最大化、拖到两边分屏（Windows 贴靠）。 |
| 3 | 最小化 | 缩到任务栏。悬停显示“最小化”。 |
| 4 | 最大化 / 向下还原 | 最大化或还原；最大化以后图标变成两个方框。悬停显示名称。 |
| 5 | 关闭 | 按“关闭窗口时”的设置：询问、最小化到托盘或退出。Alt+F4 同。新窗口直接关。 |
| 6 | 不再询问 | 勾上后下次点 ✕ 直接按这次的选择做；正在录制时还是会问。 |
| 7 | 最小化到托盘 | 窗口藏起来，托盘图标还在，播放、录制照常；点托盘图标拿回来。没有托盘时是“最小化”。 |
| 8 | 退出应用 | 退出（正在录制的停止，已录的保存）。Esc、点对话框外面等于取消。 |
| 9 | 托盘图标 | 左键：显示窗口并放到前面；右键：菜单；悬停：提示文字（录制中带个数）。 |
| 10 | 显示窗口 / 隐藏窗口 | 窗口藏着时是“显示窗口”，开着时是“隐藏窗口”。 |
| 11 | 退出应用（托盘） | 退出；正在录制时先确认。 |
| 12 | 在新窗口打开（直播间菜单） | 在一个新窗口里打开这个直播间，原窗口接着用；首页菜单的“新建独立播放窗口”打开一个新的首页窗口。 |
| — | 窗口边和角 | 拖动改大小，标题栏显示“[宽 × 高]”。 |
| — | 键盘 | Alt+F4 关闭（同 5）；Alt+空格弹出窗口菜单；Win+↑ / ↓ 最大化 / 还原（系统自带）。 |
| — | 第二次打开 | 再点桌面图标：把开着的窗口带到前面（包括藏在托盘里的）。 |
| — | 桌面小窗置顶 | 见 [T05j.1](../../../T05/T05j/T05j.1/README.md) 的编号 4（图钉），和设置“小窗始终置顶”同一个开关。 |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Windows | 上面的图。 |
| Linux | 同一个标题栏和按钮（按钮在右）；托盘随桌面环境（KDE、Xfce 有；GNOME 要装托盘扩展），没有托盘时“最小化到托盘”变成“最小化”；只开一个窗口（再打开时带到前面），和 Windows 一致；置顶在部分 Wayland 桌面上不能用（见 T05j.1）。 |
| Android 手机、平板 | 不适用（没有窗口）。 |
| 电视 | 不适用。 |
| 苹果平台 | macOS 用系统的窗口按钮（左上角红黄绿），标题栏左边给它们留位置，名字居中或右移；关闭按钮是关窗口不退出（macOS 习惯），退出用 Cmd+Q 和菜单栏；托盘对应菜单栏图标。细节在 T19b.1。iPad 不适用。 |

## 待选（建议 A）

- T1 标题栏左边的图标和名字：A 不再是链接，点图标或右键标题栏弹出系统的窗口菜单（项目主页在“关于”里）；B 照 v3 点了打开项目主页。
- T2 Linux 的标题栏：A 和 Windows 同一个自绘标题栏；B 用桌面环境自己的标题栏（GNOME、KDE 各不一样）。
- T3 新窗口里的关注和设置：A 和主窗口共用一份，改了都生效；B 照 v3 是打开时的副本，关掉就没了。
- T4 托盘：A 录制中在提示文字和菜单第一行显示“正在录制 N 个直播间”；B 照 v3 只有两项。

## 拿不准的地方

1. v3 在 Linux 上没有标题栏是按代码推算的（window_manager 的“藏标题栏”在 GNOME 上把运行器加的标题栏藏掉，自绘的只在 Windows 画）；v3 没有发布 Linux 版，没在真机上看过。
2. 无边框窗口在 Wayland 上能不能用鼠标拉边改大小，取决于桌面环境（GNOME 要客户端自己画边框）；开发时在 Linux 真机上确认。
3. Windows 11 会给无边框窗口自动加圆角，图里按直角画。
4. 托盘菜单、系统窗口菜单、任务栏缩略图是系统画的，字体、间距按 Windows 11 浅色示意；实际跟系统主题走。
5. 新窗口和主窗口共用一份数据（T3 选 A）要处理两个进程同时写；做不到时退一步：新窗口里的关注、设置改动写回主窗口的数据。
