## 0. 结论

1. **本地互动的功能一项没少，但没人在手机上用过一遍。** 4.x 把 3.x 的本地互动全部照搬（29 个 `localInteraction.*` 键、6 个样式模板、34 个平台资源包、8 个平台各 3 个礼物、等级 = 经验 ÷ 500 + 1），还修了 3.x 的几处毛病（发出立即显示、进备份、礼物行不再重复名字）。上游 v3.2.11 之后也没有改本地互动的功能。可是 CHECKLIST 第 2 节第 8 条结果为空，V03.4 两轮真机对照都没看互动面板（P1）。
2. **“玩起来”的部分几乎是空的**，这正是用户点名要加强的：
   - 体验币点按钮就能免费加，经验只来自送礼，币和等级都没有意义（P5）；
   - 礼物一次 1 个，没有连击和批量；只有一种横幅，新的直接顶掉旧的（P6、P7）；
   - 记录只记送礼和加币，而且存的是拼好的句子；自己发过的本地弹幕离开直播间就没了（P2、P3）；
   - 没有常用语；本地样式的“自定义”存不下来，一点模板就被覆盖（P11）。
3. **照搬了 3.x 的几个问题**：
   - “粗体”开关会改掉字重（P16）；
   - 本地弹幕的“屏蔽关键词”其实不起作用（P17）；
   - 画面上认不出哪条是自己发的（P18）。

   4.x 自己又带进来两处：同一个星形图标有两种意思（P8），清空记录没有撤销（P4）。
4. **弹幕整体和 3.x 比没有少**，上游的新东西 4.x 大多已经有了（按住停住、同屏条数、表情图、撤回、粉丝牌、头像）。和常见客户端比，缺的是：
   - 聊天列表文字大小；
   - “+1”（跟一句）；
   - 正则屏蔽；
   - 屏蔽纯表情和超长弹幕；
   - 聊天列表的筛选和搜索；
   - 自己的弹幕加框；
   - 区域和密度的快捷档。

   这些都是第三方客户端做得到的。
5. **建议先做**：
   - 第一步：真机走一遍（E1）；
   - 第二步：四件小事。修小毛病（E2），加“+1（本地）”（E3），加聊天列表文字大小（E4，和 A08.10 一起排），在 D 组加子分类 **D07 本地互动**（E20），给以后的任务一个归属；
   - 第三步：用户点名的几块。本地记录和常用语（E5、E6）、成长（E7）、连击（E8）、特效（E9）、正则屏蔽（E11）。

   特效可以借 flame_barrage 里现成但上游自己都没用上的“座驾”动效和连击动画（MIT 许可，`~/ref/flame_barrage/lib/src/effect/motion/`、`lib/src/animation/combo_animation.dart`）。
6. 提议的 20 条增强见第 4 节，前几条的推荐做法见第 5 节“设计建议”，建议登记的 18 个任务见第 6 节。这些都是 3.x 没有的新功能，按 D-026 要用户或维护者确认后才开工；建议的确认方式见第 6 节开头。

## 3. 弹幕系统整体（从用户这边看）

现状的细节各子分类 README 写得很全（[D](../../../D-弹幕/README.md)、[A08](../../../A-界面设计/A08-弹幕界面/README.md)），这里只按“用户用起来”的顺序列现在能做什么、缺什么。“常见客户端”指哔哩哔哩、斗鱼、虎牙官方客户端和弹弹play、Simple Live 这类第三方客户端的公开功能（按公开说明和常识列出，没有核对它们的代码）；只列第三方客户端做得到的（不靠平台服务端，或者只用平台已公开给客户端的数据）。

### 3.1 飞行弹幕

### 3.2 聊天列表

- 现在：紧凑行（默认）或 3.x 卡片；名字颜色保证 4.5:1；粉丝牌、平台徽章（E06.2）、哔哩哔哩头像；系统行、礼物行（可关，`Settings.showChatGifts` `settings.dart:498`）、醒目留言行；往上翻定住并显示“N 条新弹幕”；长按、右键、双击复制（`chat_list.dart:611-619`、`:707-709`）；500 条（`chat_feed.dart`）。
- **A08.10 正在重做名字和内容的样式**，本报告不提样式方案，只列功能缺口：
  - 没有聊天列表字号和行距（常见第三方客户端都有“聊天区文字大小”“上下间隔”）。字号跟系统字体缩放走，弹幕密时一屏行数改不了。
  - 没有按类型筛选（全部 / 只看弹幕 / 只看礼物 / 只看醒目留言 / 只看我的本地弹幕），也没有在列表里搜索。
  - 没有时间（每行的发送时间，平台给了 `sentAt`）。
  - 没有“清屏”（只清本机列表）。
- 和 3.x 比没有少的；“拖回底部松手恢复跟随”是 4.x 加的（D04.1，待真机）。

### 3.3 屏蔽和过滤

- 现在（D02，3.x 原样）：关键词（每个最多 40 字、包含即屏蔽）、用户（整名相同）、合并重复（默认关，窗口 5 秒）、相似弹幕（默认关，阈值 85）、斗鱼疑似机器人（默认关）；打码昵称不能屏蔽（D-013）；屏蔽表全局、所有平台共用；改了下一条就生效。
- 缺口：

| 缺口 | 常见客户端 | 第三方能不能做 | 说明 |
|---|---|---|---|
| 正则屏蔽（`/…/` 写法） | B 站、弹弹play、Simple Live | 能（纯本地） | 现在只有“包含”；要防坏正则拖慢（超时、长度上限） |
| 按等级屏蔽（屏蔽 N 级以下） | 斗鱼、虎牙 | 部分平台能（D01 解出了等级的平台） | 没有等级的平台不生效，要写清楚 |
| 屏蔽超长弹幕、只有表情的弹幕 | B 站“屏蔽表情弹幕” | 能 | `noEmojiMode` 只是把表情去掉，不是屏蔽整条 |
| 画面和列表分开屏蔽（例如礼物、系统行只在列表） | B 站“弹幕屏蔽类型” | 能 | 现在只有“礼物进不进列表” |
| 屏蔽表的批量导入导出、从选中的字加 | 弹弹play | 能 | 现在要一个个加；备份会带上屏蔽表 |
| 本场屏蔽打码观众 | — | 能 | D02 已记“有需要在 V01 提议” |
| 屏蔽统计（这一场屏蔽了多少条） | B 站 | 能 | 让人知道屏蔽在起作用；便宜 |

### 3.4 模板、字体、性能

- 模板：平台弹幕 3 套观看模板 + 1 个“我的模板”（`shared/danmaku/danmaku_templates.dart:43-48`、`danmaku_settings_content.dart:301-370`）；本地弹幕 6 套 + 自定义（`logic/local_catalog.dart:156-225`），**自定义不能存成命名模板**，换一次模板自定义就没了（`logic/local_interaction.dart:369-388` 整套覆盖）。
- 字体：平台弹幕可以下载、换字体（`app/fonts.dart`，I01.3）；本地弹幕只有“系统、圆润、衬线、等宽”四种，映射成 `sans-serif-rounded`、`serif`、`monospace`（`logic/local_catalog.dart:593-598`），**用不了下载的弹幕字体**；`sans-serif-rounded` 不是 Android 标准字体族，很多机型上“圆润”和“系统”画出来一样（要在 K90 上确认）。
- 性能：弹幕层每条录一次 Picture、每帧只 translate + drawPicture（D03.1）；聊天列表每帧最多通知一次（D04.1）。**K90 上的 profile 数字一个都没测**（D03、D04 README 的已知问题），D04.1 待真机。本地弹幕的“发光”用带模糊的文字阴影（`danmaku_overlay.dart:831`），和 [specs/UI.md](../../../specs/UI.md) 第 9.3 节“弹幕只描边、不加模糊阴影”不一致：现在本地弹幕很少，影响小；如果做“+1/复读”、连击这类会让本地弹幕变多的功能，要先量一次。

## 5. 设计建议（前几条的推荐做法）

每条给 A、B 两种做法，推荐 A；按 D-003，界面上要选的由维护者定，定稿时在任务 README 注明。

### 5.1 E3“+1（本地）”

- **A（推荐）**：长按弹幕面板（`message_panel.dart`）在“复制”下面加一行“+1（本地）”，说明“用你的本地身份和样式再发一次，只有你看得到”；点了就关面板、发出、提示“已发送本地弹幕”。本地互动关着时没有这一行。本地弹幕自己的面板里，这一行叫“再发一次”。
- B：画面上双击弹幕直接 +1。不选：双击画面已经是全屏或暂停的手势，会冲突（A07.14 的教训）。
- 要改：`message_panel.dart`（面板行）、`LocalRoomScope` 拿会话、`LocalRoomSession.sendChat`。测试：面板有这一行；点了之后列表多一条本地行；关着本地互动时没有。

### 5.2 E4 聊天列表文字大小

- **A（推荐）**：新设置 `danmakuListFontSize`（默认 0 = 跟现在一样，按主题的正文字号；可选 12～22）和 `danmakuListLineSpacing`（紧凑、标准、宽松，默认“标准” = 现在的行距），放在“弹幕列表”一组的“列表样式”下面；行样式由 A08.10 定，这两个设置只当它的参数。
- B：直接跟系统字体缩放。不选：现在就是这样，用户改不了。
- 风险：字号大了以后“N 条新弹幕”按钮、粉丝牌、头像要跟着变，所以和 A08.10 一起排。

### 5.3 E5、E6 本地记录和常用语

- 数据（**A，推荐**）：`live_store` 加一张表 `local_events`：`id`、`at`（时间）、`kind`（`chat`、`gift`、`recharge`、`level`）、`platform`、`roomId`、`roomName`、`text`、`giftId`、`count`、`coins`、`style`（本地弹幕发出时的样式 JSON，可空）。最多保留 2000 条，超出从旧的删。旧的 `localInteraction.history`（30 条句子）第一次启动时转成 `kind = legacy` 的记录，原键不删（D-018）。备份带上这张表，设备同步作为一项可选内容（J05）。
- B：继续用设置里的字符串列表，加长到 200 条。不选：按直播间查要全量读，换语言的问题还在。
- 界面：互动面板的“本地互动记录”改成分段按钮“全部 / 弹幕 / 礼物 / 币”，每条显示时间和直播间，点一条“再发一次”；设置页同一个组件，加“导出到剪贴板”。清空改成 4 秒撤销（E2）。
- 进房放回：同一个直播间（`platform + roomId`）24 小时内发过的本地弹幕，进房时在列表顶上放回最多 20 条，标“之前发的”（新设置，默认开；关掉和现在一样）。
- 常用语：输入框获得焦点时上方一排小标签，最近 5 条 + 常用语（`localInteraction.phrases`，字符串列表，最多 20 条）；长按本地弹幕“存为常用语”；设置页管理（排序、删除）。

### 5.4 E7 本地成长规则

推荐的数字，都写在 `LocalCatalog` 里当常量，改规则时不动已有数据：

| 来源 | 经验 | 体验币 | 上限 |
|---|---|---|---|
| 送礼 | = 价格（照 3.x） | −价格 | — |
| 看直播，每满 10 分钟（只在播放时、应用在前台或小窗时计） | +10 | +20 | 每天 300 经验 |
| 每天第一次进直播间（签到） | +20 | +100 | 每天一次 |
| 发本地弹幕 | +1 | — | 每天 50 |
| 点“+500/+2000/+10000” | 0 | 照 3.x 加 | — |

- 等级照 3.x（经验 ÷ 500 + 1，D-001），每 10 级一个段名（例如 1～9 “新人”、10～19 “常客”……，放翻译文件）；身份卡下面一条进度条“Lv.3 · 还差 120 经验到 Lv.4”。头衔不按等级锁（3.x 是随便选的），只在升级时提示“解锁了新的徽章颜色”这类纯外观的东西。
- **A（推荐）**：加一个开关“本地成长”（默认开）；关掉后只有送礼加经验，和 3.x 一样。B：不加开关。不选：有人只想要“无限币”的玩法。
- 计时：直播间控制器已经知道播放状态，每分钟记一次（定时器 ≥1 秒，D-017），离开直播间时结算；不在后台另起计时。

### 5.5 E8、E9 礼物连击和特效

- 连击（**A，推荐**）：3 秒内再点同一个礼物算连击，横幅不换新的，只把“×N”跳一下（借 flame_barrage `ComboAnimation`：放大到 1.8 倍再回缩）；聊天列表把这次连击合成一行“送出 🌶 辣条 ×5”；记录也记成一条 `count = 5`。长按礼物格弹出小菜单选 1、10、66、520（余额不够的灰掉）。不同的礼物排队（最多 5 个），一个横幅播完再下一个。B：每次一个独立横幅（现在的样子）。不选：连点时横幅一直重来。
- 特效三档（**A，推荐**）：按价格分档，不按平台：
  - 小（< 100）：只有聊天行，外加一条顶部飘屏（一行字从右往左飞过画面上方，用本地弹幕的顶部轨道）；
  - 中（100～999）：现在的横幅；
  - 大（≥ 1000，或礼物标了 `big`）：横幅 + 一段“座驾”动效 2～3 秒（借 flame_barrage `effect/motion/` 里的火箭、飞机、流星这类，纯 Canvas，不用图片）。

  设置“显示本地礼物特效”保留键名（D-018），改成三选一“全部 / 只要大礼物 / 关”：新键存三选一，旧的布尔键还在，开 = 全部、关 = 关。系统要求减少动态时只有横幅。
- 借代码：flame_barrage 是 MIT，借来的文件保留版权声明；只借画法，不借它的引擎（4.x 有自己的弹幕层，D03.1）。座驾动效画在 `LocalGiftLayer` 自己那一层，不进弹幕层，不影响平台弹幕的帧时间。要在 K90 上量 120 Hz 下的帧时间。

### 5.6 E11 正则和更多屏蔽

- **A（推荐）**：屏蔽词以 `/` 开头并以 `/` 结尾的当正则（不分大小写），其余照旧按“包含”。添加时先编译，编译不过就在输入框下面提示，不加进去。正则最长 200 字；每条弹幕只匹配前 200 个字。加两个开关：“屏蔽只有表情的弹幕”（默认关）、“屏蔽超过 N 字的弹幕”（默认关，N 默认 30）。弹幕设置的“屏蔽管理”标签角标显示本场屏蔽了多少条（只数，不存）。
- B：单独一个“正则”列表。不选：两张表，用户分不清加在哪；而且 3.x 和导入导出都只认一张表。
- 3.x 兼容：屏蔽表格式不变，正则就是一个以斜杠包起来的关键词，覆盖回 3.x 时只会当普通词，不出错。
- 性能：正则编译一次存起来；在 `chat_benchmark_test.dart`（每秒 200 条）里加 20 条正则对照前后的耗时。

### 5.7 E20 本地互动的归属

- **A（推荐）**：D 组加子分类 **D07 本地互动**：管 `local_interaction/logic/`、本地记录的存储、成长规则、礼物规则；界面仍归 A08（和 D01～D06 与 A08 的分工一样）。A08 README、D README 的“不包括”一句改成指向 D07。加子分类升文档小版本（PROCESS 第 13 节）。
- B：并进 D05（弹幕设置生效）。不选：D05 管的是设置到弹幕层的换算，本地互动的币、记录、礼物不是弹幕设置。
