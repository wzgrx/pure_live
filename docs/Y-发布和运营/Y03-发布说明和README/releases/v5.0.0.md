# 纯粹直播 5.0.0（Android、电视、Windows、Linux）

5.0.0 是第一个全平台版本：Android 手机和平板、Android 电视、Windows、Linux 同时发布，四个平台用同一套代码和界面设计。另外，录像可以在应用里直接播放，电视界面补上了退出确认、可收起的导航栏、直播间的播放设置和链接放映。

从这一版起项目搬到独立仓库 [wzgrx/PureLive](https://github.com/wzgrx/PureLive)。原来的 wzgrx/pure_live 保留不删，装着 3.x、4.x 的设备会照常收到更新提示，下载到这里的新版本。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### 新平台

- **Windows**（Windows 10、11，64 位）：安装版和便携版。自绘标题栏、托盘（录制时显示正在录几个直播间）、关闭窗口时询问或最小化到托盘、开机启动、记住窗口大小和位置、桌面小窗置顶、在新窗口打开直播间、鼠标悬停显示控制层。安装版装到 3.x 原来的目录，3.x 的数据自动导入。
- **Linux**（x86_64，GTK 3）：压缩包，解压即用，和 Windows 同一套桌面外壳（标题栏、托盘、关闭方式、开机启动）。没有应用内网页登录，账号可以在手机或 Windows 上登录后用“设备同步”带过来。
- **Android 电视**：和手机是同一个 APK，在电视上自动进入遥控器操作的电视界面。

### 电视界面

- 左边导航栏平时只显示图标，焦点移进去时展开、盖在页面上；设置里可以改成“导航栏始终展开”。名字和图标跟手机一致（关注、热门、分区、链接放映、搜索、观看记录、网络电视、设置）。
- 在导航栏按返回键弹出退出确认，焦点在“退出”，再按返回键取消。
- 第一次打开时显示使用须知，上下键滚动正文。
- 新加“链接放映”：用遥控器输入或粘贴直播间链接、分享口令，按“播放”直接进电视直播间；解析中、失败的原因写在输入框下面。
- 直播间：右键（或菜单键、信息键）打开右侧“播放设置”，有弹幕设置（和手机一样一项不少）、弹幕屏蔽、录制三个标签，改了立即生效；左键打开左侧的切换直播间列表。

### 录像

- 录制面板和录制中心的“播放”在应用里打开，不再交给其他应用：进度条拖动、倍速（0.5～3 倍）、同一个直播间的录像按顺序切换上一段/下一段，每个文件记住看到哪，下次接着播。

### 其他

- 小米、红米手机上“在快手打开”这类跳转被系统拦住时，会说明去哪里打开“打开其他应用”权限，并能直接打开应用信息页。
- 应用内更新改从新仓库读取；Windows 和 Linux 的版本页能挑到自己的安装包。

## 从 3.x 或 4.x 升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。Android 直接装新的 APK；Windows 运行安装版会装到原来的目录。
- 这一版没有改数据库，4.x 的数据原样使用。从 3.x 升级时第一次打开会自动导入 3.x 的数据，导入只读、不改 3.x 的文件。
- 新设置“导航栏始终展开”（电视）默认关。

## 已知问题

- 新功能通过了自动测试，在 K90 手机和 Windows 电脑上做了快速测试。电视界面只在手机的电视模式下测过，没有在电视真机上测；Linux 版只在 WSL 里启动测过；Windows 安装版没有在测试电脑上安装（那台电脑装着 3.x，不能覆盖），便携版测过。遇到问题请反馈。
- 电视：设置里的大多数项目和网络电视的订阅源管理还是手机的页面（方向键可以操作）；视频、音乐、壁纸三个模式以后再做。
- Kick 只在 Android 上能用（Windows、Linux 还没有它需要的原生网络通道）。
- 礼物的平台限制照旧：抖音网页端收不到礼物消息，FC2 和 Kick 的打赏还没录到真实样本。
- 4.0.0 的已知问题仍然存在：HyperOS 从最近任务里划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；平板上 Android 16 可能不让应用自己转屏。

## 以后要做的

- 电视：电视样式的设置目录和网络电视设置，视频、音乐、壁纸三个模式。
- 开播提醒：每个主播单独的开关、应用被系统清理后也提醒（等大家用过现在的开播提醒再定）。
- iOS、iPadOS、macOS：需要 Mac 构建和签名，以后再做。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。

## 下载哪个

| 文件 | 适用 |
|---|---|
| `PureLive-5.0.0-5100-debug-signed-android-arm64-v8a-release.apk` | 绝大多数手机、平板和电视盒子（64 位 ARM），不确定就选这个 |
| `PureLive-5.0.0-5100-debug-signed-android-armeabi-v7a-release.apk` | 老的 32 位 ARM 手机、电视 |
| `PureLive-5.0.0-5100-debug-signed-android-x86_64-release.apk` | x86_64 模拟器和设备 |
| `PureLive-5.0.0-5100-windows-x64-setup.exe` | Windows 安装版 |
| `PureLive-5.0.0-5100-windows-x64-portable.zip` | Windows 便携版（解压即用，数据在程序旁边的 UserData） |
| `PureLive-5.0.0-5100-linux-x64.tar.gz` | Linux x86_64 |

Android 包的签名和 3.2.11、4.x 相同，可以直接覆盖安装。最低 Android 8.0。
