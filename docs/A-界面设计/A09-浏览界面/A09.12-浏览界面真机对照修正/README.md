## 3.x 的样子和问题

- 01：平台标签是可滚动的 `ScrollableTabBar`（`apps/pure_live/lib/features/popular/popular_page.dart:183-191`），右边紧接 ⌄（`:192-197`）。停在第一个平台时第三个标签被生硬地截成“虎.”（K90 截图 `shots/k-hot.jpg`）；A06.1 c4 在右上加了搜索和“更多”后标题区变窄。分区页（A09.4 v4-phone）的最后一个标签是渐隐露一半，热门应该一样。
- 02：`ScrollJumpButtons`（`packages/live_ui/lib/src/widgets/jump_buttons.dart:73-74`）离底部超过阈值就显示“回到底部”，所以列表刚打开、还没滚动时右下就有 ↓。A09.2 c1 写“滚动后出现（照 3.x）”。
- 03：`showAdaptivePanel`（`popular_page.dart:152-160`）在竖屏一打开就几乎全屏（顶边约 15%），A09.2 v4-phone-picker 是半屏（顶边约 29%）；说明文字最后一个字“序”单独折行。
- 04：搜索平台条的“全部”芯片选中时前面是勾号（`apps/pure_live/lib/features/search/search_scope.dart`），A09.7 v4-phone 是四宫格图标；先核对 A09.7 的确认改动里有没有写，没有写的按设计图。

## 设计（按 D-003 由维护者定）

- c1：热门的平台标签条右端加 24 宽的渐隐（和分区页同一个组件参数），⌄ 左边不再生硬截断。
- c2：“回到顶部 / 回到底部”只在用户滚动过以后出现（第一次 `ScrollUpdateNotification` 之后），之后照现在的阈值规则。
- c3：“全部平台”面板在竖屏先停在半屏（照 A03.2 的面板停靠，最上面那一档是全屏），说明文字改短到一行放得下（“点一个直接切过去；在‘平台显示’里隐藏和排序”）。
- c4：“全部”芯片按 A09.7 的设计用四宫格图标，选中时底色变主色容器，不加勾。
