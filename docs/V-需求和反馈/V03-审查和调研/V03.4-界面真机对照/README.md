## 目标

在 K90 上把 Android 手机的每个界面区域实际看一遍，和确认过的设计图（`v4-*.jpg`）、3.x 的样子对照，找出布局、尺寸、间距、对齐、文字、颜色、状态、手感上和设计不一致或明显不好的地方。每个问题写清在哪、看到什么、应该是什么、截图和代码位置，登记成 A 组的任务（或并进已有任务）。

## 方法

- 设备：K90（Android 17，120 Hz）和本机模拟器（Android 16，和 K90 同尺寸；看不了直播画面），测试包 `com.mystyle.purelive.v4dev`（master 的 profile 构建）。不碰正式包 `com.mystyle.purelive`（D-019）。
- 每个界面：竖屏截图（必要时横屏），缩到宽 540 和设计图并排看；逐条核对 README 里“确认的改动”（c 编号）。
- 记录格式（`record.md`）：编号 `V03.4-NN`、区域、步骤、现象、设计要求（任务和 c 编号）、截图文件名、代码位置（文件:行）、严重程度（影响使用 / 明显不好看 / 细节）。
- 截图：只提交说明问题需要的，放本文件夹 `shots/`，宽 540，单张不超过 300 KB。
