## 目标

docs v1 只有结构（20 组、按优先级排字母、登记表、生成的进度），多数组、子分类和任务只有一行标题。v2 让每一层都能单独拿给人或 AI 开工：

- 组和子分类的 README 分成两部分：上面手写（范围、现状和怎么工作、代码地图、3.x 基线、已知问题、相关决定、测试和验证、路线），下面由 `tools/docs/docs.py` 从登记表生成（任务表和进度）。
- 每个任务都有文件夹和 README；没完成的都有 v2 任务书（`brief.md`）；“待真机”的都有验证清单（`verify.md`）；“不做”的写清原因和以后在什么条件下重新考虑。
- 写的时候读现在的代码核对（文件:行），记录和代码不一致的以代码为准并写明后来哪个任务改的；发现的问题登记成任务。
