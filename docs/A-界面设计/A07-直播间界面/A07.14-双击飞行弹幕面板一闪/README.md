## 3.x 的样子和问题

**3.x**（`git show v3.2.11:lib/modules/live_play/widgets/video_player/video_controller_panel.dart`）：画面的 `GestureDetector` 同时挂 `onTap` 和 `onDoubleTap`（`:196-249`）。Flutter 的单击识别器要等双击识别器放弃（300 毫秒）才回调 `onTap`，`onTap` 里才判断点没点中弹幕（`:213-215` 的 `handleDanmakuPointer`）。所以：单击弹幕慢 300 毫秒打开操作面板；双击弹幕直接全屏，面板从没出现。

**现在（v4，A07.11 c1 之后）**（`apps/pure_live/lib/features/live_play/` 省略前缀）：

- `player/player_view.dart:333-366` 的 `_onTap`：手指抬起时立即生效；按下时已经记下点中的弹幕（`:653-656` 的 `onTapDown` → `_tapHit`，`:416-438` 的 `_danmakuAt`）。点中弹幕时调 `_tapMessage`（`:389-398`）立即打开面板，并把“关掉这个面板”记成撤销动作 `_undoTap`。
- 300 毫秒、100 以内来了第二下（`:338-350`）：先调撤销（关面板），再 `widget.onToggleFullscreen()`。
- 面板打开、关上都有动画：`live_play_page.dart:894-911` 的 `_panelLayer`（进 220 毫秒、出 160 毫秒，从下方或右侧滑入）。第二下通常在 100～250 毫秒之间，面板已经滑出来一截又滑回去，接着画面切全屏——这就是“一闪”。
- 打开面板时飞行弹幕被定住（`:443-450` 的 `_openMessage` 设 `_danmakuHeld`），关上后恢复，所以弹幕也会顿一下。

| 手势 | 怎么用（c1 之后） |
|---|---|

## 待选和决定

- X1：双击飞行弹幕时怎么办。**A**（建议）照 c1：点中弹幕时才等 300 毫秒再开面板，双击只切全屏（3.x 的结果，单击其他地方仍立即响应）；B 保持现在（单击弹幕立即开面板，双击时接受一闪）。理由：点弹幕是低频操作，晚 300 毫秒 3.x 用户本来就习惯；双击全屏是高频操作，不该带闪动。（A07.11 记录请维护者决定；按 D-003 没有回复时用 A。）
