## v3 的样子

- **数据和默认值**（`widgets/local_interaction/local_interaction_controller.dart`）：总开关默认开（:86）；昵称“Pure Live”（:87，最多 20 字 :821-830）；头衔“听众”（:88，四个：听众、守夜人、应援团、守护者 :718）；在画面显示（:89）、平台徽章（:90）、等级（:91）、礼物特效（:92）默认都开；体验币 1000（:94）；等级 = 经验 ÷ 500 + 1（:724）；记录最多 30 条、新的在前（:905-908）。本地弹幕样式默认“清爽”：白色、19、130 px/s、600、描边 1.5 黑（:97-114）。6 个模板（:116-192）、12 种弹幕颜色（:194-207）、7 种描边阴影颜色（:209）、4 种字体（:211）、3 个位置（:212）。34 个平台资源包，各有主题色、等级称呼、币名、徽章 emoji（:248-521）；8 个平台各有 3 个礼物（每个平台一个高价值礼物是大特效），其他平台用通用的爱心 10、鲜花 50、火箭 500、城堡 2000（:214-237、:523-716）。
- **本地弹幕**：名字是“徽章 emoji 徽章名 · 头衔 · 昵称”（:857-874）；礼物消息是“礼物 emoji 徽章 · 头衔 · 昵称 送出 礼物名 ×1”，名字另存为昵称（:876-903）。在弹幕列表里和别人一样是卡片“名字: 内容”（`danmaku/danmaku_list_view.dart:504-519`），等级只在长按弹幕的面板里显示“Lv.N”（`danmaku_message_actions.dart:19`），长按没有“屏蔽用户”（:30）。画面上飞过的只有内容，带本地样式，画面弹幕关着时不飞（`video_player/video_controller.dart:183-223`）。
- **弹幕列表下的输入框**（`danmaku_list_view.dart:386-436`）：表面容器（低）底，左右 10/8 边距；输入框 48 高、圆角 22、描边，前面星形 `Icons.auto_awesome_rounded` 19（主色），提示“发送一条本地字幕”；后面实心圆按钮 `Icons.send_rounded`（说明“发送本地弹幕”）。发出后等 2 秒（`live_play_controller.dart:105`），提示“发送成功，将在 2 秒后同步显示”（:255-266）。
- **全屏输入框**（`video_controller_panel.dart:1584-1750`）：下栏左右两组按钮中间，最宽 420（:1443-1463），48 高、黑 54% 底、圆角 20、白 24% 描边；星形 18，颜色是当前本地弹幕颜色（默认白，:1719）；发送 18 白；输入的字用本地样式（颜色、粗细、斜体、字间距、阴影，13 号，:1670-1686）；获得焦点时边框是主色 1.3（:1741-1744），控制栏不隐藏（:1612-1628）；点星形时控制栏也保持显示（:1704-1718）。竖屏全屏时在下栏上方一行，旁边是清晰度线路（:1508-1527）。发送同样等 2 秒并提示（:1643-1655）。
- **本地互动面板**（`local_interaction_sheet.dart`，菜单 `button/live_play_menu_button.dart:145-166`、:203-204）：模态底部面板（可滚动、有拖动条，表面容器底、顶角 24）。从上到下：标题“本地互动体验”（20 号 600）和关闭；说明“资料、体验币、礼物和记录只保存在本机，不会向直播平台提交。”；本地昵称输入框 + 标签“[币图标] 1000 电池 · 用户等级 1”；“本地头衔”4 个选择片；开关“在画面显示本地字幕与礼物特效 / 关闭后仍会保留在本地弹幕列表”；展开项“本地弹幕样式”（星形，副标题是同步说明），展开后是紧凑的样式编辑器；发送框（提示“发送一条本地字幕”）+ 实心发送按钮；“本地礼物”每行 4 个格（emoji 28、名字、价钱，格比 0.9，最高容器底、圆角 14）；“本地体验币”+500 +2000 +10000（描边按钮）；展开项“本地互动记录”（最近 10 条，空时“还没有互动记录”）。点礼物余额不够提示“体验币余额不足”（:160-165）。面板里发的弹幕不等 2 秒、不提示（:160-162）。宽屏时是 640 宽居中的底部面板；全屏没有菜单打不开。
- **本地弹幕样式**（`local_danmaku_style_editor.dart`）：竖屏是 86% 高的模态底部面板（:33-43），横屏是右半边的对话框（宽为可用宽度一半、最高 680、边距窄屏 8 宽屏 20、圆角 16，`content_first_panel_layout.dart:24-51`），宽 ≥340 时左预览右设置（:115-138）。标题行：星形、“本地弹幕样式”、恢复默认 `Icons.restart_alt_rounded`（只有图标，:90-99）、关闭。预览：深色渐变卡片 112 高（紧凑 82）、圆角 16、中间淡电视图标，文字“Pure Live 本地弹幕预览”按当前速度滚动，横屏分栏时左上角“实时预览”（:170-282）。设置（:376-666）：样式模板（清爽、醒目、霓虹、极简、底部字幕、赛博，各带颜色点）→ 显示位置（滚动、顶部固定、底部固定）→ 字体与颜色（系统、圆润、衬线、等宽；弹幕颜色 12 个圆，36，选中主色粗边加勾）→ 字体大小 14–32、滚动速度 60–260、不透明度 35–100%、字间距 -0.5–3（宽 ≥340 两列）→ 文字效果（粗体、斜体、描边、阴影 / 微光）→ 描边开着时：描边颜色、描边宽度 0.5–4 → 阴影开着时：阴影颜色、模糊强度 0–6、阴影偏移 0–4 → 位置不是滚动时：固定弹幕停留时间 2–10 秒 → 同步说明“所有选项实时保存，并同步用于竖屏、横屏、小窗、发送框和本地互动页。”。改任一项后模板变成自定义（:817）；“恢复默认”就是套用“清爽”（:819）。
- **礼物特效**（`pages/live_play_page.dart:47-92`、`live_play_controller.dart:594-597`）：盖在整页中间，从 0.72 放大到 1（420 毫秒，回弹曲线），礼物色 94% 到黑 78% 的横向渐变、圆角 24、白 45% 描边、礼物色模糊发光；普通礼物最宽 320、16 号，大特效最宽 440、20 号；内容就是整条礼物消息；3 秒后消失，新的顶替旧的；只看“显示本地礼物特效”。
- **设置页**（`settings/pages/local_interaction_settings_page.dart`，入口 `settings/settings_page.dart:124-133`）：标题“本地用户与互动”。组“本地用户与互动”：启用本地互动体验。关掉时下面全部隐藏（:49-50）。开着时：组“平台体验资源包”（说明、34 个平台选择片、预览卡“徽章 平台名 / 等级称呼 Lv.1 · 1000 币名 / 礼物片”，:55-85、:211-245）→ 组“本地用户资料”（本地昵称、本地头衔、在画面显示本地字幕与礼物特效、显示平台身份徽章、显示本地体验等级、显示本地礼物特效、体验币与等级“1000 · Lv.1”，:87-159）→ 组“本地弹幕样式”（完整编辑器，:161-167）→ 说明“启用后可从直播间右上角菜单进入本地互动面板。”（:168-172）→ 组“本地体验币与记录”（说明、+500 +2000 +10000、“清空本地互动记录”，记录空时不可点，:174-201）。

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 竖屏：输入框在弹幕列表最下面，面板在画面下方；横屏全屏：输入框在下栏中间，面板在右侧；窄横屏：星形按钮 |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 输入框在聊天栏最下面；面板盖在聊天栏上；回车发送、Esc 关面板、悬停显示按钮名称；设置页内容最宽 720 |
| 电视 | 不适用（pure_live_TV 没有这个功能，遥控器输入文字不便） |
| 苹果平台差异 | iOS 键盘弹出时输入行贴键盘上方；macOS 回车发送；其余同手机和宽屏 |

## 拿不准的地方

1. 提示条的样子按 `flutter_smart_dialog` 默认近似画（深色圆角、底部居中），v3 没有自定义（`common/utils/toast_util.dart:23`）。
2. v3 互动面板的高度按内容估（约 770，加拖动条区 48）；宽屏底部面板最宽 640 是 Flutter 默认值，v3 没有另设。
3. M3 选择片选中时有头像（颜色点、平台徽章）的画法按“勾代替头像”画。
4. U.2a、U.2d 的 v3 还原图和新设计都没画弹幕列表下的输入框（v3 默认开着），这里补上；U.2a、U.2d 的开发要留出这一行（总开关开着时）。
5. 横屏全屏弹出键盘时画面和下栏怎么让位，v3 代码里没有专门处理，没有真机核对；新设计要求输入行贴在键盘上方。
6. 竖屏全屏的输入框位置（下栏上方一行）属于 U.2b，这里没有单独出图，组件和行为同本任务。

## 给工具的建议

- `src/emoji.woff2` 是 Noto Color Emoji 的子集（Google Fonts `text=` 取的），放在任务文件夹里只为这一个任务能渲染 emoji。以后别的任务也要 emoji 时，建议把它加进 `tools/ui/mock/fetch.sh` 和 `kit.css`（`font-family` 回退加上它）。
