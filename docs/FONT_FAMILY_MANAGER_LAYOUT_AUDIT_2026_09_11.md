## 修改前复现与代码审查

旧页把“Open Folder”图标和文字固定放在 AppBar 尾部。新增页面回归在基线上稳定得到
`RenderFlex overflowed by 182 pixels on the right`，长标题和文件夹动作共同挤出 320 像素顶栏。

第一次只完成紧凑顶栏、惰性列表和卡片堆叠后，回归继续暴露两处更深的固定横排：完整许可证徽标右溢出
**688 像素**，下载动作右溢出 **131 像素**。这两项属于中间修订仍未覆盖的卡片内部边界，均保留为失败证据。

另有三个确定性代码问题：

1. 外层 `ListView` 内嵌 `shrinkWrap` 字体列表，会为了测量长页提前构建全部字体卡片。
2. Windows 卸载当前自定义字体后把存储值写成 `Microsoft YaHei`，而默认卡片只把 `Default` 视为选中；渲染虽回落
   到微软雅黑，设置页却显示默认项未启用。
3. 下载器以不区分大小写的扩展名识别字体，字重选择器却只接受小写 `.ttf/.otf`，使有效 `.TTF/.OTF` 文件在
   应用时被当作缺失。

## 修订

- 顶栏按宽度和缩放后的操作文字切换：紧凑环境使用带本地化 Tooltip 的文件夹图标，普通桌面保留图标加文字；
  标题单行省略并保留完整 Tooltip。
- 页面改为统一 `CustomScrollView` 和 `SliverList`，字体卡片按可见范围惰性构建；名称、许可证、文件数和动作在
  窄屏/大字号下纵向排布，许可证最多两行并保留完整 Tooltip。
- 下载、应用、删除及当前状态使用可换行布局；紧凑环境的下载/应用动作使用有语义 Tooltip 的图标按钮。
- 多字重选择器改为整窗有界滚动，自然高度选项替代固定 `ListTile`，最后一个字重和取消动作均可达；超长标题与
  说明保留三行摘要和完整 Tooltip。
- 应用字体和弹幕字体的默认重置集中到控制器；Windows 也持久化统一的 `Default` 身份，再由主题解析器映射到
  `Microsoft YaHei`。卸载当前字体复用同一重置路径。
- 字体文件策略统一对 `.ttf/.otf` 使用不区分大小写判断；非 Windows 的“System Default”新增中英文资源。
