- 目录迁移 14 只追加微博；保留其他平台的隐藏/排序选择。再次隐藏后经真实 Hive 关闭重开仍保持；备份导入保留指定站点列表，复合场次 ID、主播 UID 和标签各自保留。旧版迁移测试同步最新期望，未删掉精确列表或落盘断言。
- 热门及分类 Binding 使用已有原生目录控制器。目录是有限推荐快照，卡片的直播状态和人数保持未知；页面持续显示范围说明。目录刷新失败保留旧卡片，退出取消请求并丢弃迟到结果。
- 搜索声明为精确场次查询，支持场次 ID 或已核验官方观看 URL，返回直播/回放元数据；不宣称昵称、持续追踪主播、分页或网页关键词搜索。搜索控制器的关闭令牌贯穿实际适配器。

- 外部打开由场次 ID 重建官方观看地址，不使用保存的任意 `link` 或把主播 UID 当场次；没有猜测原生 deep link。
- 录制与多画面调用严格详情和新鲜地址解析，保持同一场次与主播；未知/访问受限元数据不选择媒体，不猜测 URL 有效期。地址消费测试使用注入响应，不启动媒体后端。
- 弹幕、真实在线人数开关、账号跟随等未取得的能力不作虚假声明。没有升级依赖、修改 Root/LSP 或操作手机。

热门页改用懒加载自然高度行，维持 2–5 列断点、间距、卡片身份、每卡片绘制边界及无障碍条目索引；不重新引入瀑布流依赖，不设置固定字号上限。初稿使用 `ListView.builder` 时，其 `semanticChildCount <= itemCount` 要求与“一行多个房间”冲突，第三轮 `20260910T173715666Z-weibo-app-natural-height.json` 为 **4 PASS / 4 FAIL**：搜索动作全部通过，目录触发该构造断言。随后调整为 `CustomScrollView + SliverList`，仍按房间数而非行数维护无障碍语义，没有删掉语义计数来绕过断言。
