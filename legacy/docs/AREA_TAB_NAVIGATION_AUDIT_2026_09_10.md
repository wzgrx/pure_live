# 分类空页导航与跨页滚动位置（2026-09-10）

## 根因与修订

本轮检查共用页实际调用点，在真实 AreaGridView / AreasListController 上增加有界 Widget 场景，而不是只调用刷新回调。

1. **空分类替换了整份 TabBarView**：滑到空分类后控制器正常发布空快照，但 BasePageView 用整页空状态替换 contentBuilder，横向翻页随之消失。分类页现使用已有 preserveContentWhenEmpty 合同，空分类留在自己的横向页面内。
2. **空分类没有垂直滚动承载**：保留横向页面后，空内容由绑定该分类控制器的 SingleChildScrollView 承载，最小高度为正文视口，长提示可自然增长；继承现有 EasyRefresh 滚动物理行为，不新增一套刷新控制器。
3. **返回已卸载分类时偏移丢失**：原页面虽然按分类缓存 ScrollController，但 GridView 没有 PageStorageKey；跨过空页到第三页再返回，控制器相同、偏移却从 300 回到 0。为分类网格及空滚动页增加包含平台 tag 和分类 id 的存储键，恢复各自位置，避免平台之间同名分类共用键。

只修改 `lib/modules/areas/areas_grid_view.dart`。抖音平铺分支、分类请求/分页控制器、刷新所有权、网格尺寸与卡片、数据库和设置格式保持。已有非空分类的真实下拉刷新测试原本通过，本轮没有据结构猜测而重写该链路。

来源：本地冻结上游 c6c9bd70 与共同基线 527fea1b 均已有分类外包 BasePageView、TabBarView 空子页直接返回 EmptyView、网格缺少 PageStorageKey 的结构，归类 upstream-existing；当前分支执行上述场景取得复现。本轮没有拉取或合并上游。
