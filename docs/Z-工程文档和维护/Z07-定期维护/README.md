# Z07 定期维护

按日历要做、不属于任何功能的事：每月清理分支、工作区和本机中间文件，每次发布后更新文档，每季度复查文档和决定。依据是 [PROCESS.md](../../PROCESS.md) 第 12 节的维护表。

## 范围

- 包括（PROCESS 第 12 节）：
  - 每月：清理已合并的分支和工作区；确认暂停任务的旧工作区还要不要；清理本机中间文件（Z07.1）。同一天做的依赖检查是 Z01.2。
  - 每次发布后：STATUS 里“待真机”的逐项看完；版本路线（`docs/PLAN.md` 第 5 节）、发布说明（Y03 的 `releases/`）和根目录 README 更新（Z07.2）。回复相关 issue 在 V02。
  - 每季度：复查文档和决定——过时的规则、被取代的决定、长期没动的子分类和任务（第一档超过两周、第二档超过两个月没动的，决定降档、拆小或不做，不做的移到 V04）（Z07.3）。
- 不包括（归哪里）：
  - 每周的上游对照 → W01（PROCESS 第 9 节）。
  - 每月的依赖和工具链检查 → Z01.2（和 Z07.1 同一天做，分开记录）。
  - “随时”的维护（改状态就改登记表并运行 docs.py）→ 每个任务自己做。
  - 真机验证本身 → S02；Z07.2 只负责在发布后把“待真机”的清单排出来并推动。
