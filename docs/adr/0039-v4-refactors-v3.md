# 0039 v4 改为在 v3 代码上重构：审查、优化、完善、增强

- 状态：已接受。取代 0014 中“直接写 v4”的部分、0015 中的应用结构（包的划分仍有效）、0016（归档 v3）、0037（界面复刻）；修改 0038 中电视端的做法。构建和门禁在本机运行的约定继续有效。
- 日期：2026-09-28

## 背景

- 2026-09-27 批准的方案（docs/rewrite/PLAN.md）是另起炉灶：新写一个应用（apps/pure_live），重新设计界面，v3 归档不再构建。
- 第一次构建后用户实际使用，觉得界面和布局不如 v3。为此改成复刻 v3 的界面（ADR 0037），但仍然是新写代码。
- 用户随后明确了方向（2026-09-28）：
  - “v4 版本的目的应该是在 v3 的代码基础进行重构项目重写重构，而不是自己完全重新设计”；
  - “对 v3 版本的代码审查优化，进一步完善优化增强 v3 版本，应该是这样”。
- 用户同时选定：
  - v4 已写好的包，按模块接进 v3；
  - 电视端以 pure_live_TV 的代码为基础。

## 决定

1. **v3 的代码是 v4 的基础**。
   - v3（v3.2.11 加归档前的修复）恢复为主应用，界面、布局、操作逻辑和功能都以它为准。
   - v4 是对它的审查、优化、完善和增强，不是重新设计。
2. **做法：逐模块重构，行为不变**。
   - 每一步都保持应用可构建、可使用。
   - 改动前后对照 v3 的行为：v3 原有的测试，加上 Windows 和手机实机对照。
   - 会改变外观或操作习惯的改动，先征得用户同意。
3. **审查依据**：docs/rewrite/DIAGNOSIS.md 已经列出 v3 的主要问题，包括：
   - GetX 和全局单例互相引用；
   - PlayerManager 过大；
   - 弹幕解码和过滤在界面线程；
   - 录制的缺口和 FFmpegKit 补丁；
   - Cookie 和密码明文；
   - 专有和不兼容许可证的组件。
   
   审查从这里出发，逐模块补全问题清单，再按用户影响排序修复。
4. **v4 已写好的包按模块接入**。
   - 这些包是 live_core（33 个平台适配器）、live_net、live_media、live_player、live_danmaku、live_record、live_store、live_iptv、live_cast、live_ui。
   - 重构到哪个模块，就评估对应的包：
     - 接入：它比 v3 的实现更好、行为能对齐，就在 v3 的内部接口后面替换，界面不动；替换前后用同一组样本和实机对照验证。
     - 不接入：直接重构 v3 原来的代码。
   - GetX 不做一次性替换。重构到哪个模块，就把那个模块的依赖改成注入，逐步收缩。
5. **电视端以 pure_live_TV 的代码为基础**（修改 ADR 0038 第 1 条）。
   - 并入后作为同一应用的电视模式，共用重构后的平台层和播放层；
   - 在手机和桌面的重构稳定之后进行。
6. **包名和数据**：
   - 正式版沿用 `com.mystyle.purelive`，覆盖安装 3.x，保留用户数据。存储格式如有改动，必须带自动迁移。
   - 开发中的测试包加 `.next` 后缀，和手机上的 3.x 并存，不碰用户正在用的 3.x。
   - Windows 测试版放在工作目录，不碰 `D:\Soft\PureLive`。
7. **原来新写的 v4 应用**（apps/pure_live 中的界面和应用层）移出 workspace 归档，只作参考，不再构建。其中有价值的功能（例如 Windows 外壳、HLS 中继、局域网同步、开播提醒），在“完善和增强”阶段按 v3 的界面风格加进来。

## 放弃的做法

- 继续新写应用、只复刻 v3 的界面（ADR 0037）：用户要的是在 v3 代码上改进，不是再写一遍。
- 只重构 v3 自己的代码，v4 已写好的包全部弃用：用户选择按模块接入，以免浪费已经测过的实现。

## 影响

- 新方案见 docs/rewrite/REFACTOR.md；PLAN.md 中与本 ADR 冲突的部分作废。
- 目录调整：
  - `legacy/` 中的 v3 恢复为 `apps/pure_live`，并加入 workspace；
  - 原 v4 应用移到 `archive/v4_app/`。
- spec/design/principles.md 的界面设计不再约束实现，界面以 v3 为准。
- 截图测试、门禁、README、STATUS 随之调整。
