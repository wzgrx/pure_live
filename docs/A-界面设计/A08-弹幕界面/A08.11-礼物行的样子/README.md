## 第 1 版设计（方案 A，V03.5 第 6.3 节）

- c1 **和聊天行分开**：左边 16×16 的礼物图（`iconUrl` 有才画，`ResizeImage` 按显示尺寸解码；加载中、加载不出来、没有地址时都是 `AppIcons.chatGift` 第三色，同一个位置、同样大小，不留空位）；然后是 A08.10 的标签（“对方”、徽章、粉丝牌，G5 的顺序）和名字（名字角色，名字后面空一格、没有冒号）；然后是动词（次要色，见 G8）+ **礼物名（第三色、600）** + “×N”（第三色、600、等宽数字）；最后是价值（小一号 `bodyMedium`、次要色、等宽数字，例如“3000 金瓜子”“28 钻石”“100 Kicks”；免费、不知道单位的不显示）。紧凑样式整行没有背景，和醒目留言（彩色卡片）、通知（次要容器色）分得开。
- c2 **卡片样式**：和聊天卡片一样（`surfaceContainerLowest`、0.5 轮廓、圆角 10），左边的圆点换成礼物图。
- c3 **档位**（G1、G4）：普通没有标记；值钱的左边 2 宽的第三色竖条；很值钱的 4 宽的竖条，竖条和礼物名用平台色（过 4.5:1，G3）。只用颜色和线，不用动画和阴影（UI.md 第 9.3 节）；读屏读“值钱的礼物”“很值钱的礼物”。
- c4 **连击**：显示的数量变了（D07.1 合并、或平台的连击计数）只改“×N”，“×N”放大到 1.2 倍再回到 1（200 毫秒，先升后降都减速、不回弹；系统要求减少动态时不动）。
- c5 **“显示用户名”关掉**（A08.10 G6、G7）：礼物行同样藏名字、徽章、粉丝牌，留“送出 礼物名 ×N 价值”；“对方”留着。
- c6 **横屏 280 宽和系统字号 1.3、2 倍**：整段换行、不截断礼物名；价值是一整块，放不下时整块换到下一行；礼物图固定 16、对着第一行的中间；不溢出。
- c7 **长按、右键**：和聊天行一样打开长按弹幕面板，第一张卡片写“名字：送出 小心心 ×3 · 3000 金瓜子”；“复制”和双击都复制“名字: 送出 小心心 ×3”；“屏蔽此用户”照旧（打码昵称照 D-013 没有）；“屏蔽关键词…”的输入框先填礼物名。
- c8 **文字走翻译**：动词、“×N”“×N 个月”、各单位、档位的读屏文字、niconico 的贡献名次都是翻译键（zh、en）。
