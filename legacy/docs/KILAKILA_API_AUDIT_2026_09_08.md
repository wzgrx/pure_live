# 克拉克拉底层 API 验证（2026-09-08）

## 实现边界

在 [公开合同取证](KILAKILA_PUBLIC_CONTRACT_AUDIT_2026_09_08.md) 的基础上新增 `KilakilaApi`，本批仅为底层 API，尚未实现 LiveSite 或注册应用。当前仍为 14 个直播站点 + IPTV，13 组参考平台未注册。版本仍 3.1.8+4121；没有构建、安装、手机前台操作或发布。

- 目录与详情分别解析包装层，原生 pageNo/pageSize/isLastPage 必须匹配；目录按房间 ID 去重，不用主播 UID 或行数推导下一页。
- 广播 roomId 与主播 userId 分开保存；大整数字符串保持原值，JSON 数字仅接受精确范围内的正整数。详情校验请求房间、返回房间与预期主播配对。
- 元数据模式不携带媒体。播放模式要求已知状态 4、价格 0 和匹配该房间的服务端 HTTPS FLV/HLS 地址；不从推流字段生成播放输入，不伪造画质。
- HTTP、业务错误、取消、历史回放 5966、未知状态、受限媒体和结构异常分开。未知状态及历史回放不当作已证实的下播。
- 成功推荐可缺少 b 并返回空集合；详情/目录缺失 b 仍是错误，空推荐不表示整个站点没有直播。
- 响应读取有 1 MiB 上限和 20 秒正文总期限；流结束/异常均取消订阅。错误文本仅输出类别，原始媒体签名和推流字段不进入公共报告。
- 数字房间链接按精确主机/路径解析，拒绝重复关键参数、非标准端口及含不透明分享参数的输入。每次详情重新获取；没有持久缓存或自动续签调度。
