# A08.10 弹幕列表里用户名和内容分开显示；加“显示用户名”开关：真机验证

- 设备：Redmi K90 Pro Max（Android 17，120 Hz）
- 构建：`com.mystyle.purelive.v4dev`，提交 ……（profile / debug）
- 日期：……；验证人：……

| 步骤 | 期望 | 结果 | 截图 |
|---|---|---|---|
| 1. 哔哩哔哩一个热门直播间，竖屏看“弹幕列表”（紧凑） | 每行名字加粗、浅灰色（彩色弹幕是对应的彩色），冒号也加粗；内容是正常粗细的深色字；一眼能分开名字和内容 | | |
| 2. 同一个直播间，深色主题、纯黑主题各看一次 | 名字和内容仍然分得开（名字加粗、颜色浅一些）；彩色名字看得清 | | |
| 3. 弹幕设置 → 弹幕列表样式选“卡片” | 卡片里名字和紧凑行一样（加粗、浅色或彩色、全角冒号），左边圆点是弹幕颜色；有头像时头像在左边 | | |
| 4. 带粉丝牌的弹幕（哔哩哔哩登录后） | 粉丝牌是圆角小块，在名字前面；和“本地”“对方”小块一样高 | | |
| 5. 17LIVE 直播间（有名字颜色和徽章的观众） | 顺序是徽章图 → 名字，名字是平台的颜色、加粗；紧凑和卡片一样 | | |
| 6. 弹幕设置标签的“弹幕列表”一组 | “弹幕列表样式”下面是“显示用户名”（开着），再下面是“在聊天列表显示礼物” | | |
| 7. 关掉“显示用户名” | 列表里已经显示的行马上只剩内容（没有名字、粉丝牌、徽章，卡片没有头像、只有圆点）；新来的弹幕也没有名字 | | |
| 8. 关着时长按一条弹幕 | 长按面板第一张卡片仍然有“用户名：内容”；“复制”复制的是“用户名: 内容” | | |
| 9. 关着时发一条本地弹幕、送一个本地礼物 | 那一行前面还有“本地”，没有“听众 · Pure Live：”和徽章胶囊 | | |
| 10. 手机横着拿（不全屏），看右边的弹幕列表 | 和竖屏同一个样子，跟着开关；长名字整段换行、不截断、不出界 | | |
| 11. 系统字体调到最大（设置 → 显示 → 字体大小），重复步骤 1、3、10 | 名字和内容一起变大，换行、不溢出、不被截断；小块跟着变大 | | |
| 12. 设置 → 弹幕，找到同一个开关；设置搜索“用户名” | 设置页里同一个开关、同一个值；搜索结果在“弹幕 › 弹幕列表” | | |
| 13. 打开“显示用户名”，回到直播间 | 列表恢复显示名字 | | |

## 结论

- 通过：登记表改成“完成”，写日期。
- 不通过：现象和根因线索；开新任务或退回原分支。
