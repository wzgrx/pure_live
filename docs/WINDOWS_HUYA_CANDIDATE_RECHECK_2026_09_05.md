对照结论：

1. 这次退出确有原生资源回落，不继续把早期“首页仍有 frame 文本”直接定为解码泄漏。
   C++ stdout 的 Frame 文本没有独立时间戳，管道还可能缓冲；文件追加/读取时间不是对应视频帧呈现时间。

   当前是短窗口，既没有证明线性泄漏，也没有证明所有缓存都达到了最优平台期。
4. 后续应独立采样静态热门页的帧调度/图片/动画与多次开关房间后的平台期，不盲目缩短播放器释放时间。
