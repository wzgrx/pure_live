和设计不一样的地方：

1. **表情图要等加载**：表情图第一次出现时要先解码（包里的图，或平台给的地址），这条弹幕先在队里等，解码完再进场（解码失败就显示代码，和弹幕列表一样）。3.x 是进房后台预载整套表情。
2. **H-B 选了 Picture**，没有在 K90 上实测光栅时间（按要求不做实验），见“没验证的”。
3. **多画面、电视**没有传 `fps`、`running`（不在本批能改的目录），它们每个刷新周期都画、不随暂停停；字体、纯文字、透明度进颜色、排队、Picture 缓存它们自动就有（同一个组件）。

## 根因（v4 现在的偏差 V1～V11）

- V1 帧率、V8 字体：C01.2 搬弹幕层时 `DanmakuLook` 只带了样式数值，主画面没传 `fps`。
- V2、V4：用整层 `Opacity` 和每帧画两段文字，是 I01.2 最早的简单写法，一直没换。
- V3：排版放在了 `_add`（弹幕流的同步回调）。
- V5、V6：写法里“没空轨道就丢”“轨道高 1.4 倍”，是 v4 自己的简化，和 v3 不同。
- V7：弹幕层只认纯文字，表情只在列表里做了（S02.1）。
- V9：整层 `IgnorePointer`，没有命中检测。
- V10：弹幕层不知道播放状态。
- V11：`didUpdateWidget` 里样式一变就 `_clear()`。
