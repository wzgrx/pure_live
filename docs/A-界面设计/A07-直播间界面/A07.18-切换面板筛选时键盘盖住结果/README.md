## 3.x 的样子和问题

- 竖屏直播间里面板从画面下沿升起，占下半屏；点放大镜输入时键盘弹起，面板不往上让，筛选结果和“没有名字包含……的主播”都在键盘下面看不到（K90 截图在 S02.5 记录里）。

## 设计（按 D-003 由维护者定）

- c1：键盘弹出时面板向上扩展到画面下沿以上（盖住画面），结果区留在键盘上方；收起键盘后回到原来的高度。
- c2：输入时结果区至少能看到一行卡片或空状态提示。

## 实现和验证

- 未开始。测试：面板组件测试里模拟 `viewInsets.bottom = 300`，断言结果区底边在键盘上方。
- 真机：K90 竖屏直播间 → 切换直播间 → 放大镜输入“zzz”，能看到“没有名字包含 zzz 的主播”。
