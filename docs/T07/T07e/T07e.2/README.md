## v3 的样子（按代码）

- **顶栏**（`modules/favorite/favorite_page.dart:21-38`）：标题位置是三个固定等宽的状态标签“已开播”“录播”“未开播”（`TabBar`，`isScrollable: false`、`TabAlignment.fill`，宽屏时平分整行）；整屏宽 ≤680 时左边菜单、右边搜索菜单（`:17`、`:24-25`）。
- **平台标签**（`:125-131`）：可横滑的 `ScrollableTabBar`，“全部”加上有关注的平台（只限“平台显示”里打开的，`favorite_controller.dart:67-76`），只有文字，居中。
- **分组标签**（`:182-273`）：`ChoiceChip` 横排，“全部”加当前状态和平台下用到的房间标签（按标签顺序）；12 号字，选中主色底白字粗体，未选浅底次要色，圆角 10；整行高 60；没有标签时不显示。
- **网格**（`room_grid_view.dart:28-118`）：设置“紧凑模式”（默认开）时宽 >1280 五列、>960 四列、>640 三列、其余两列，小号卡片；关掉时 4/3/2/1 列、大号卡片；边距 12，间隙取设置；行高固定（封面 + 72，`room_card_layout.dart:35`）；核验中或状态未知的卡片右下“正在核验”或“状态待确认”（`:92-95`）。
- **排序**（`favorite_controller.dart:456-473`）：分组选“全部”按人数排；选了分组时带该分组的排前面（按分组顺序），再按人数。
- **刷新**：手机和平板下拉刷新（`room_grid_view.dart:101-114`）；再点一次底部“关注”刷新（`home_page.dart:182-196`）；电脑（宽 >680 且不是手机平板）底部翻页栏里“刷新”；回到前台、定时自动刷新按设置。
- **空**（`favorite_page.dart:275-319`）：一个都没关注：“无已开播直播间”“在热门、分区或搜索里关注主播后，会显示在这里”“重试”（三个状态页一样）；否则按状态“当前筛选暂无已开播直播 / 暂无录播 / 暂无未开播直播”，说明“关注数据仍在，共 {count} 个；可左右滑动切换平台或下拉刷新”或“此平台暂无关注直播间；左右滑动可返回其他平台”，按钮“查看未开播”（有未开播时）或“重试”；按钮图标都是刷新图标。图标 `Remix.heart_3_fill`。

### V3_UI_INVENTORY 第 3 节需要更正的地方（本任务不改那个文件）

- 网格“同热门的列数规则”只在“紧凑模式”开着时成立；关掉时是 4/3/2/1 列、大号卡片；而且边距是 12（热门 6）、行高固定。
- 分组标签只列当前状态和平台下用到的标签，不是全部分组。
- 平台标签只列“平台显示”里打开的平台。
- 问题 3“没有可见的刷新按钮”：电脑上底部翻页栏有“刷新”；手机靠下拉和再点“关注”。新设计照 v3，不另加按钮。

## 拿不准的地方

- “录播”的数量和直播间：v3 的“录播”页是平台标为回放 / 录播的直播间（`effectiveLiveStatus == replay`），示例里放了 1 个；真机上多数人这一页是空的。
- 未开播紧凑行里显示的是“上次的标题”：v3 的数据里只有最后一次拿到的标题，没有上次开播时间，所以没有写“几天前播过”。
- 横屏时导航栏的问题同 T07b.2（交给 T07）。
- 平台标签数量里的“全部”在“未开播”页写 36，按平台加起来；示例数字是虚构的。
