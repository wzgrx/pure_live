## pure_live_TV 的样子

**首页**（`features/home/home_page.dart`）

- 左边导航栏，右边页面（`:352-513`）。导航栏宽 160（电视上 80），设置“展开导航栏”打开时 228（114）（`:321`）；底色是页面背景色 62%（`:368`），默认主题下和页面同色。
- 导航栏从上到下（`:376-430`）：时钟 HH:mm（展开时 HH:mm:ss 和日期，`:384-402`）、模式按钮（直播 / 视频 / 音乐，`:48-67`、`:406`）、当前模式的目的地（`:141-211`，可以滚动）、最下面“设置”（`:418-428`，打开单独的设置页）。
- 直播模式的目的地和顺序来自“导航栏显示控制”，默认全显示（`home_provider.dart:119-176`、`core/consts/app_consts.dart`）：长名 / 短名 / 图标依次是 直播关注 / 关注 / `Icons.favorite_border`，热门直播 / 热门 / `local_fire_department_outlined`，分区类别 / 分类 / `RemixIcons.function_line`，关注分区 / 分区 / `collections_bookmark_outlined`，链接放映 / 放映 / `movie_creation_outlined`，搜索直播 / 搜索 / `search_rounded`，观看记录 / 记录 / `history`；设置 / 设置 / `settings_outlined`（`:178-186`）。图标可以在设置里换（`menuIconOverridesProvider`）。
- 收起时每项是方块：图标 28（14）上、短名 16（8）下（`tv_icon_button.dart:226-231`）；展开时是胶囊：图标加长名 18（9）（`home_page.dart:526-541`）。选中项主色实心，焦点主色 50% 加描边加光晕。设置里这一项的说明是“开启后显示完整菜单名称，关闭仅显示图标”（`nav_rail_expanded_desc`），实际收起时也有短名。
- 遥控器：上下在导航栏里移动；OK 只切换右边的页面，焦点留在导航栏（`:156`）；右键进页面；页面最左一列按左键回导航栏。启动时焦点在当前选中的那一项（`:353`）。
- 页面切换淡入加 0.95→1 放大（`:446-506`）；关注、热门、分区、关注分区、设置的页面保留状态（`:329-339`，设置里可以关）。
- 返回键：弹退出确认（`:343-348`）。

**选择模式**（`home_page.dart:73-136`）：自己画的 `TvDialog`（宽 640，电视上 320），标题“选择模式”；三行（主色图标、名字 18（9）、当前模式右边主色对勾），焦点行卡片色底加主色描边；按钮“取消”。切换模式时停止音乐（`:132-135`）。

**退出确认**（`features/home/exit_confirm_dialog.dart`）：`TvDialog` 标题“确定要退出吗？”，竖排：“感谢使用纯粹直播 TV，期待下次再见。”（22，电视上 11）、白底微信二维码 260（130）（`:29-37`）、“♥ 捐赠支持”、捐赠说明（20，10）；按钮“取消 / 确定”，默认焦点“确定”，确定后直接结束进程（`:19`）。

**新版本**（`features/home/home_update_dialog.dart`）：每次运行最多弹一次，等启动检查的结果（`:10-24`）；标题“发现新版本”（`:68`）；版本行：下载图标、“v3.0.6 → v3.0.7”（新版本主色，预览版加橙色“预览版”）（`:76-108`）；“更新内容”和日志框（最高 260，电视上 130，可滚动）（`:111-135`）；按钮“稍后 / 下载”，下载中变“加载中”；“下载”是把下载地址交给系统打开（浏览器），成功提示“已打开下载页面”，失败“无法打开下载页面”（`:37-61`）。

**协议页**（`features/agreement/agreement_page.dart`，第一次启动时路由跳到这里，`app/router/app/app_router.dart:295-296`）：宽 1200（600）居中；标题“使用须知”40（20）粗体、欢迎语 28（14）粗体、四条 32（16）、结尾一句 28（14）粗体；正文在一个滚动区里（`:26`），下面两个按钮“已阅读并同意”（默认焦点）和“确定退出吗?”（`:61-76`）。

**启动解锁**（`features/settings/pages/widgets/account_lock.dart:338-639`）：有哔哩哔哩账号设了密码锁时，盖在整个应用上面（`:606-639`）。先“选择账号”：账号卡片一排（头像 76（38）、名字、锁图标），左右选、OK 进；没上锁的账号直接进；上锁的进“输入解锁密码”：账号名、用 * 显示的密码、错了显示“密码错误”（`#FF6B6B`，`:6`）；方向键 ↑↓←→ 组成密码，OK 确认，返回键删一位、删完回选择账号（`:372-419`）。这一页没有说怎么输入（设置里设密码时才有“↑↓←→ 组成密码，OK 确认…”这句，`:322`）。

## v3（pure_live_TV）的问题

| 编号 | 问题 | 位置 |

| Q1 | 导航栏一项有长短两个名字，短名和手机对不上：“分类”指分区类别、“分区”指关注分区，手机上“分区”就是分区页 | `home_provider.dart:146-153` |
| Q2 | 导航栏收起时短名只有 8 号字；要看全名得去设置里打开“展开导航栏”，焦点进去也不展开；这个设置的说明写“关闭仅显示图标”，实际还有短名 | `home_page.dart:321`、`tv_icon_button.dart:226-231`、`nav_rail_expanded_desc` |
| Q3 | 导航栏底色是页面背景 62%，默认主题下和页面同色，看不出边界 | `home_page.dart:368` |
| Q4 | 在导航栏按 OK 只换右边的页面，焦点还在导航栏，要再按右键才进页面 | `home_page.dart:156` |
| Q5 | 图标和手机不一样：关注、热门、分区、关注分区、搜索、观看记录、设置都换成了另一套图标 | `home_provider.dart:130-185` |
| Q6 | 选择模式是自己画的一套行（焦点卡片色加描边），和别的选择框样子不同 | `home_page.dart:80-113` |

## v4 现在的偏差（`apps/pure_live/lib/tv/home/tv_home_page.dart`，X03.1）

导航栏一直展开（240，电视上 120），目的地是关注、推荐、分区（合并了关注分区）、历史、搜索、网络电视、设置，没有模式按钮（视频、音乐、壁纸写成“建设中”）；OK 切换并进入页面；返回键是“再按一次返回键退出”提示，退到后台不结束；没有协议页和启动解锁；新版本用手机的检查流程。

| 场合 | 默认焦点 | 方向键 |

| 首页 | 页面第一项（页面没加载出来时在导航栏当前项） | 页面最左一列按左 → 导航栏展开，焦点在当前项；导航栏里上下移动，右键或 OK 回页面（回到上次那一项） |
| 导航栏 | 当前项 | 上到模式按钮、下到设置；按返回键 = 退出确认 |
| 选择模式 | 当前模式 | 上下；返回键关 |
| 退出确认 | “退出” | 左右；返回键 = 取消 |
| 新版本 | “下载并安装” | 左右在三个按钮间，下到“其他下载方式”；返回键 = 取消 |
| 协议页 | “已阅读并同意” | 左右在两个按钮间；上下滚动正文 |
| 启动解锁 | 第一个账号 | 左右选账号；输入页没有焦点，方向键就是密码 |

## 拿不准的地方

- 导航栏收起时的方块大小按 `TvIconButton` 的算法推（图标 + 文字 + 内边距，约 45），没有真机截图。
- 新设计“导航栏始终展开”时页面右移多少（展开宽 248）和 4 列卡片会不会太窄，没有单独出图；打开时卡片宽约 150。
- 分区的图标跟手机 A06.1 的选择 X3（图里画的是建议的三个形状）。
- 捐赠二维码是示意图案，不是作者的真二维码。
- 电视上“本软件开源免费”不做成链接（很多电视没有浏览器），只是文字。
- 启动解锁的账号名、头像是虚构的；pure_live_TV 的选择页列出全部哔哩哔哩账号（`_roster.accounts`，`account_lock.dart:358`），一开始总在选择页（`:350`）；新设计只有一个账号时跳过选择，需要你确认。
