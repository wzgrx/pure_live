## 3.x 的样子和问题

**外壳**（`lib/modules/home/home_page.dart`、`tablet_view.dart`）

- 父组件给的宽度 >680 时用这个排法（`home_page.dart:232`）。从左到右：`NavigationRail`、1 像素竖分隔线、页面（`tablet_view.dart:95-170`）。
- 侧边栏：Material 3 默认宽 80、表面色底；`groupAlignment: -1`（靠上）、`scrollable: true`（窗口矮时整条可以滚）、`leadingAtTop: false`、`labelType: all`（导航项都显示文字）（`:100-105`）。
- 上部（`leading`，从上到下，都只有图标，48×48，提示文字只在悬停或长按时出现，`:22-30`、`:106-147`）：
  - 菜单 `MenuButton`（四周留 12，`:109`），弹出的菜单和手机左上菜单是同一个（设置、关于、历史记录、备份与恢复，Windows 另有“新建独立播放窗口”）；
  - 多画面 `Remix.layout_grid_line`（设置里开了多画面才有，`:110-121`）；
  - 链接解析 `Remix.link`（提示“链接解析”，`:122-129`）；
  - 搜索 `CustomIcons.search`（提示“搜索直播”，`:130-137`）；
  - 录制中心 `Remix.download_2_line`（导航栏显示控制里有录制中心才有，`:138-146`），点了用 `Get.toNamed` 打开**单独的录制中心页面**，盖住整个窗口，左上是返回（`recorder_page.dart:38`）。
- 下部：导航项关注、热门、分区（图标同手机，文字 12 号），录制中心不作为导航项（`home_page.dart:118-121`、`:237-239`）。
- 导航栏显示控制里只留了录制中心时，没有导航项，页面是空状态“尚未选择任何菜单 / 请点击左上角菜单按钮，添加需要展示的功能菜单”（`Remix.menu_2_fill`，`tablet_view.dart:160-166`）。
- 各页面在宽屏不显示顶栏的菜单和搜索按钮（`showAction = Get.width <= 680`，`favorite_page.dart:17` 等）；关注页标题位置的三个状态标签（已开播、录播、未开播）是 `TabBar` 铺满，宽屏时拉满整个宽度（`favorite_page.dart:26-37`）。
- 房间网格：宽 1199 时 4 列（`room_grid_view.dart:38-40`，属于 A09）。

## 拿不准的地方（设计时记下的）

- 侧边栏导航项的高度和间距按 Material 3 默认值估算（每项约 72），没有在真机上量（实现时定为 68，见下）。
- Windows 菜单项“新建独立播放窗口”的图标 v3 是 `Icons.add_to_photos_outlined`，效果图工具没有 outlined 字体，用实心版近似。
- 宽屏关注页拉满的状态标签照 v3 画，A09.3 定。

- 偏差：①**自己画的侧边栏**（不再用 `NavigationRail`）：`NavigationRail` 的 `scrollable` 是整条一起滚，横屏手机（852×393）上菜单和四个工具按钮会把导航项挤到屏幕外（A09.2 记下的问题，现在按钮带名称更高）；现在是“上面的菜单和工具按钮可以滚动，分隔线和导航项固定在下面”，窗口矮到连导航项都放不下时整条一起滚（`home_views.dart:129-147`）；尺寸：菜单行 68、工具行 66、导航项 68（指示条 56×32，`HomeRailMetrics` `:55-69`）。②导航项文字未选中 400、选中 600（效果图 500；计划书第 8.2 节只用 400 和 600）。③跨过 600 时页面状态保留：每个页面一个全局键（`home_page.dart:135-138`）。④没做：macOS 侧边栏顶部给窗口按钮留位置（A18.2）；Windows 标题栏、托盘（A16.1）。
- 门禁：和 A06.1 合计 `home` 直接写的颜色和图标 23 → 0；“尚未选择任何菜单”的空状态去掉了，`no_menu_title`、`no_menu_subtitle` 两个键留在翻译文件里。

**验证**

- 自动测试：`apps/pure_live/test/features/home/home_test.dart` 宽屏部分：1280×800 侧边栏宽 80、没有底部导航、页面顶栏没有“更多”、从上到下的顺序、工具按钮名称在图标下面、点录制中心在首页里切换（侧边栏还在、没有新页面、没有返回按钮）、侧边栏的菜单是同一个小菜单、工具按钮能打开页面、只留录制中心时只有它一个导航项；600 宽是侧边栏、599 宽是底部导航；852×393 四个导航项都在屏幕内、工具按钮可以滚到多画面；字体放大 1.3 倍不溢出；从手机宽度拉到 1280 时关注页的状态对象不变。原测试“tablet: side rail without the recording centre, which becomes an action”按 c3 和偏差 1 换掉。
- 真机：没有在平板或 Windows 上看过（K90 竖屏用的是手机排法；S02.2、S02.3 都没有宽屏）。横屏手机（852×393）在 K90 上属于宽屏排法，也没有单独截图核对。
- 留下的问题和去向：宽屏关注页拉满的状态标签 → A09.3；macOS 窗口按钮的位置 → A18.2；宽屏在真机上看 → 有平板或 Windows 构建时（S03.1）。
