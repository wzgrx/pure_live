# Firebase 个人中心动作与布局审计（2026-09-12）

## 范围与基线

- 基线：`cc4d78419556069821bb88b53a1398e2060ea75d`。
- 范围：Firebase 个人中心的云端配置预览、下载、上传、退出登录、管理入口，以及相关异步动作和窄屏大字号布局。
- 本轮只做源码、确定性 Widget 回归、静态分析与仓库审计；未连接手机、访问真实 Firebase 服务、构建安装包或发布版本。

## 复现与根因

先为旧页面加入不改变行为的动作测试接缝，有效红测为 **0/4 PASS**；源码审查同时确认退出流程缺口：

1. 配置预览放在 `AppBar` 的长文本按钮中，320×480、3.0 倍英文下向右溢出 307 像素。
2. 当前 Firebase 身份为空时，预览动作对 `uid` 使用空值断言，点击后抛出类型异常。
3. 上传、下载和退出都是未等待的直接调用；连续点击可并发提交，页面既无进行中状态，也不收束异步错误。
4. 下载会直接以云端副本覆盖本机设置，没有方向说明和二次确认。
5. 退出登录没有确认；底层 `auth.signOut()` 也未等待，随后立即清理状态并依赖强制非空的全局页面上下文返回。

根因是页面把远端动作当作同步导航入口，没有页面级事务所有权；呈现层又把顶栏宽度、账号身份和普通字号作为固定前提。

## 修订

- 将配置预览移入可滚动内容卡片；预览、下载、上传和退出均补齐明确方向说明，长文案允许自然换行。
- 预览前规范化并校验当前账号 ID；缺失身份时留在当前页并给出既有账号提示。
- 页面统一持有单一活动动作：第一次点击在任何异步等待前锁定状态，其他入口同步禁用；活动项显示进度，完成或失败后恢复。
- 下载本机覆盖与退出登录增加可滚动确认弹窗；取消不产生副作用，确认后才进入对应事务。
- 页面统一捕获动作和确认异常，保留诊断并显示双语失败提示；页面退出后的收尾使用 `mounted` 栅栏。
- Firebase 退出流程改为等待认证层完成后再清理本地控制器状态，并只在仍有有效上下文且路由可返回时退出当前页。
- 新增中英文预览、同步方向、确认和失败文案，翻译键保持对称。
