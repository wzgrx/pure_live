- 当前触发链：`AreaRoomsBinding → AreaServerRemoteController → CCSite.getCategoryRooms`。API 每批 30 条，界面默认每页 20 条，第一页显示 1–20 后直接请求 offset 30，第二页从 31 开始，21–30 被丢弃。移动端追加和桌面改页大小同样受影响。上批仅验证直接 API 调用，未覆盖这条页面装配链。
- 不是单纯补传 pageSize：旧通用控制器会以剩余行数改变请求宽度；page×size 型 API 的 offset 可能随之漂移。需要分离固定网络页和可变界面页，而不是放宽测试或增加请求延迟。

## 修订设计

1. `LiveSiteCategoryDirectoryProvider` 只声明分类原生分页能力；不将尚未同批审查的推荐接口顺带切换。
2. CC 分类 pager 固定 size=30，start=(page-1)×30，透传取消令牌。消费未经筛除的 lives 原始行数，完整 30 行表示还有后页，合法短页结束该次快照；超过请求宽度或结构错误保留为可重试错误。视频仍不进入直播集合。
3. 分类绑定选择现有 `LiveDirectoryController`，保留完整响应、按房间身份去重，然后按界面页大小切分。复用它的 20,000 行容量、每次最多 20 次请求、刷新事务、失败重试和代次/退出保护；没有重写通用远程分页器或播放器。
4. 旧收藏数字 areaId、areaType 与控制器 tag 规则不变；显示名称由目录控制器复制到卡片，不回写用户收藏对象。推荐页、播放、录制、弹幕及系统设置保持原路径。
