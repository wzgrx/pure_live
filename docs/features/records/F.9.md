# F.9a～F.9c K90 验证（2026-10-02）

同 F.0b 的设备和测试包（`288fec0ec` 的 arm64 profile）。用户 10-02 授权随时接管手机；手机上有一个自动操作小红书的应用会抢前台，测试时用 `am start` 把测试包调回来。

| 项 | 结果 |
|---|---|
| F.9a 画中画：直播间上栏小窗按钮 → 系统画中画（任务 `mode=pinned`），画面在别的应用上方继续播 | 通过 |
| F.9a 后台播放和媒体通知（见 F.0b） | 通过 |
| F.9a 直播间菜单：切换直播间、定时关闭、房间音量、画面比例 / 投屏、获取直链、分享、在平台打开 / 本地互动体验 | 通过（只看了菜单） |
| F.9a 返回逐级退出：先关菜单和面板，再离开直播间，回到上一页（分区房间） | 通过 |
| F.9b 录一场过 5 分钟：第二段开始后停止，两段合成一个 MP4（339.7 秒，H.264 720p + AAC），分段文件清掉；面板“已保存 · 时长 5:39 · 48 MB · 超清” | 通过 |

| F.9b 划掉应用后继续录 | 没验证：HyperOS 最近任务里的上滑没删掉卡片（把列表滚动了）。代码上录制前台服务 `stopWithTask="false"`，进程和服务在应用退到后台时一直在，文件持续变大；真正划掉后要再试一次 |
| F.0a 分享接收：别的应用分享“快来看直播 https://live.bilibili.com/6”→ 直接进直播间（v3：链接直接进，口令才先问） | 通过 |
| F.9c 搜索：全部平台同时搜、卡片标平台、“还有 N 个平台在搜索…” | 通过 |
| F.9c 分区、分区房间（平台 · 大类、关注按钮） | 通过 |
