## 根因及设计

1. URL/名称输入后关闭弹窗，结果 Future 已结束但 TextField 仍在退场；finally释放两个控制器会触发 used-after-dispose。现在由专属 Dialog State 在子树卸载时释放，沿弹窗本地 Navigator 返回。
2. 快速点击确认可发起两次导入，第一次完成又可能借全局 context 关闭其他页面。现在同步置位提交状态、字段只读/确认禁用，并用页面级在途标志阻止关闭表单后从同页再发一次；finally释放门禁。
3. 当前操作持有自身 Route：成功只 pop 当前自身或 removeRoute 自身，不动较新的路由；弹窗已卸载就不再更新/关闭 UI。页面已卸载后不刷新列表，刷新读取结束后还会复核 mounted。
4. 网络失败/异常恢复可编辑草稿并内联显示通用错误，下一次提交由用户明确触发。导入成功但刷新查询失败独立提示“导入已完成，列表刷新失败”，不误标导入失败诱导重复写入。
5. 保留已有导入管理器和其下载/解析/写入语义，不伪造请求取消：执行中动作标为“关闭”，并解释关闭后导入继续；同页在途提示阻止重复导入。未声称支持传输中止、事务回滚或跨不同页面实例的全局任务去重。
6. 网络表单与导入方式选择器使用可滚动对话框；移除固定300高度，保留完整输入和字体缩放。新增三条中英文状态说明，未变更订阅格式、文件路径、密码或用户数据。

可选导入回调只替代测试的外部操作；生产未传入时仍调用原 EPG/IPTV 管理器。校验继续沿用原 URL 判定、非空名称和 trim；无自动重试、超时扩展或额外网络请求。
