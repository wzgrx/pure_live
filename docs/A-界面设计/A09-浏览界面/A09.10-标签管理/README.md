## v3 的样子

文件 `lib/modules/tags/tag_management_page.dart`。

- **顶栏**：“标签管理”居中，右边 `Remix.add_line`“添加标签”（`:28-42`）。
- **说明条**（`:345-371`）：主色 5% 底、圆角 16，`Remix.information_line` 18 +“长按任意标签卡片，即可自由拖拽以动态调整它们的排列展示顺序。”13 号。
- **组标题**“标签管理”，下面是可拖动的网格（`ReorderableBuilder`，`:159-210`）：宽度 <420 或字体 >1.5 倍时一列，否则每张最宽 180。
- **卡片**（`:67-157`）：次色 8% 底、30% 描边、圆角 16；名字 14/600（点开详情）；描述 11 号 `disabledColor`，没有描述时“暂无描述”斜体更浅；底部一条（`surfaceContainer` 50%、圆角 10）：置顶（`Remix.pushpin_fill` / `pushpin_line` 16 主色）、编辑（`Remix.edit_line` 16）、删除（`Remix.delete_bin_line` 16 错误色 70%），中间细分隔线，每个 48 高。
- **空**（`:51-66`）：`Remix.price_tag_3_line` 48 +“暂无自定义标签。 点击右上角 “+” 按钮即可创建。”。
- **详情**（`:277-343`）：“标签详情”16 粗；“标签名称”12 粗主色 + 名字 16/600；“备注描述”+ 描述框；实心“确认”（圆角 10）。
- **添加 / 编辑**（`:442-736`）：“添加标签 / 编辑标签”；“标签名称”+ 输入框（最多 15，提示“请输入标签名称...”，有字时清除）；“备注描述”+ 输入框（最多 40，“请输入备注/描述（可选）...”）；错误：“标签名称不能为空”“已存在同名标签”“名称无效或该标签已存在”“编辑期间此标签已发生变化。请关闭弹窗后重试。”“标签更改未保存，请重试”；按钮“取消”（次要色）、实心“确认”（圆角 8，保存中转圈）。
- **删除**：“删除标签 / 确定要永久删除标签“{name}”吗？/ 取消、红色删除”。
- **手势**：长按卡片拖动排序。没有快捷键。

## 待选（A 是建议）

- J1 排法：A 所有宽度一列（v4 已有）；B 照 v3 宽屏多列小卡片。
- J2 删除以后：A 提示“已删除”，不能撤销（v4 已有）；B 提示条带“撤销”。

## 拿不准的地方

1. 直播间数是按关注列表里带这个标签的直播间数的，v3 没有这个数；数法以 v4 `tags_page.dart` 为准。
2. 置顶在第一个标签上：v4 是灰色不可点，新设计画成实心图标（照 v3 的状态表达），开发时两者取一，评审时可以说。
