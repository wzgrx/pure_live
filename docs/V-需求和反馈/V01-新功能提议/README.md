# V01 新功能提议

3.x 没有的新功能从这里进来：先登记提议，写评估（用户要解决什么、3.x 和上游怎么做、影响哪些功能、改哪些组、规模），有界面的出效果图和评审页，**等用户确认**，确认后在目标组开实现任务；不做的移到 [V04](../V04-不做的/README.md)。

## 范围

- 包括：
  - 3.x 没有的功能（D-026）：例如开播提醒、多账号、按住弹幕定住、同屏弹幕条数、小窗拖角改尺寸、同步时选内容。

- 不包括（归哪里）：
  - 修 bug、补 3.x 已有的行为、已批准升级（[specs/UPGRADES.md](../../specs/UPGRADES.md)）的余项：直接在目标组登记任务，不走提议（[PROCESS.md](../../PROCESS.md) 第 6 节第一段）。
