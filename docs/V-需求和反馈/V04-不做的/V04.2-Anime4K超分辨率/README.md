## 是什么

Anime4K 是一组给动画画面用的 mpv GLSL 着色器（CNN 放大和修复）。上游的做法：从 Kazumi 移植 10 个 `.glsl`（`assets/shaders/`，共约 3000 行）；三档“关闭 / 效率档（轻量 CNN 链）/ 质量档（完整 CNN 链）”，只在 Windows 等桌面 GPU 上显示；着色器第一次用时解压到应用支持目录，经 mpv 的 `glsl-shaders` 属性挂上；内核设置页加选择卡片。上游提交说明自己写了“手机 GPU 无法实时跑 CNN 链”。

## 为什么不做

- 现在只做 Android（D-004）；手机 GPU 跑不动实时的 CNN 着色器链，耗电和发热大，上游自己在手机上也不显示。
- 直播内容以真人、游戏为主，Anime4K 针对的是动画线条；对直播的收益小。
- 安装包要多带约 3000 行着色器（上游 `assets/shaders/` 10 个文件），4.x 的播放层（`packages/live_player/lib/src/mpv_engine.dart` 的 `MpvEngineConfig`）现在没有挂着色器的通道，要加设置、加解压和挂载、加测试。
- 4.x 在 Windows 上已经有 RTX 超分的设置（功能清点 F-WIN-11，3.x 就有），桌面上要“画面更清楚”有现成的路。

## 验证

- 无（不做）。

## 以后在什么条件下重新考虑

- Windows 客户端（X01）开工，并且有用户要求在桌面上看动画类点播（L 组的点播）时更清楚：只在桌面 GPU 上评估，先在 V01 提议，和 RTX 超分比一比画质、耗电、兼容性。
- 手机 GPU 能实时跑轻量版本（有可靠的帧时间数据，R01 的基准能测）时，再评估手机。
