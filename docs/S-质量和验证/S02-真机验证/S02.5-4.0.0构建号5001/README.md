## 方案

- 按 [brief.md](brief.md) 的四个阶段上机，每个阶段约 1～2 小时；阶段内按布局排（竖屏普通、横屏全屏、竖屏直播、小窗和画中画、多画面、宽屏模拟），同一个布局里把几个任务的条目一起看，少来回切换。
- 结果写回各任务：在任务文件夹的 `verify.md` 的“结果”一列逐条填（任务的 `verify.md` 以它的记录为准；没有的照 [templates/verify.md](../../../templates/verify.md) 新建）；本任务的 `record.md` 只放汇总表（任务、阶段、结论、返工任务）。
- 每看完一个阶段：通过的任务登记表改“完成”并写日期；有问题的写现象和根因线索，开返工任务（标题写“接 A07.13”这样的）；`done` 加一。
