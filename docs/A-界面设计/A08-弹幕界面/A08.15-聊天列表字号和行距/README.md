## 目标

聊天列表的字可以调大调小、行距可以调紧调松：弹幕密的时候一屏多看几行，眼睛累的时候字大一点。默认和现在一模一样。常见第三方客户端都有“聊天区文字大小”“上下间隔”。

## 设计（V03.6 第 5.2 节，做法 A，D-003 维护者选 A）

- c1 新设置 `danmakuListFontSize`（`section: 'danmaku'`，整数，**默认 0 = 跟现在一样**，可选 12～22，超出读成 0）和 `danmakuListLineSpacing`（`compact`、`standard`、`loose`，**默认 `standard` = 现在的行距**）。都跟备份和设备同步。
- c2 只当 A08.10 的 `ChatText` 角色的参数：名字和内容同一个字号（A08.10 G1），字重和颜色规则不变；系统字体缩放照样乘上去。
- c3 跟着变的：粉丝牌、平台徽章、头像、礼物图（A08.11）、“本地”“对方”标签按字号等比例；“N 条新弹幕”按钮不变（它是浮在上面的按钮）。
- c4 不管：飞行弹幕（有自己的字号）、醒目留言标签的卡片、长按面板。
- 不选 B（只跟系统字体缩放）：现在就是这样，用户改不了。
