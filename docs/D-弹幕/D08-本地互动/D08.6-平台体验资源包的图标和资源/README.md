## 目标

设置 → 本地用户与互动 → 平台体验资源包：每个平台（`SiteIds.supported`，现在 35 个）都有自己的包，徽章是应用里别处用的平台图标，不再是 emoji 或两个字母；主题色和图标是一个颜色；有礼物体系的平台用自己的币名、等级名、徽章名和几个像样的礼物。

### 选择（D-003，维护者定，2026-10-09）

| 编号 | 选择 | 理由 |
|---|---|---|
| p1 | **平台颜色只有一张表** `PlatformLogos.colors`（`live_ui`，和图标、`PlatformLogos.ids` 放在一起，测试要求两者的键一样），资源包的 `accent` 和礼物行 `giftPlatformInk` 都读它；颜色取图标的主色：品牌色和图标同一个色相的用品牌值（Twitch 9146FF、抖音 FE2C55），不同的用图标取样的颜色（哔哩哔哩粉 FB7299 而不是蓝 00AEEC）；没有颜色的图标（niconico、猫耳、IPTV）留 3.x 的值 | 应用里别处都没有平台颜色，只有图标；图标和它周围的底色一样才像一套 |
| p2 | **徽章画图标**：一个组件 `LocalPackBadge`（`local_interaction/local_pack_badge.dart`），各处同一个：设置页选择片 18（选中时照 A08.2 M3 是勾）、预览 24、身份卡 40（圆角 10，代替原来的圆形 emoji）、列表里的徽章胶囊（和字一样高，圆角 3）、礼物横幅第二行 14、记录每条的时间前 14 | 用户说的“没有同步更新图标” |
| p3 | **emoji 不删**：`LocalPlatformPack.badge` 留着，用在只能是文字的地方（3.x 的 `localInteraction.history` 句子和消息的 `userName`，D-018）和**没有 `platform` 的旧消息**（D08.6 以前发的、回放的消息照旧显示 emoji 徽章）；本地消息的数据多存一个 `platform`（`LocalProfile.platform`） | 旧消息和 3.x 的记录照样能读；新消息知道是哪个平台 |
| p4 | **礼物 id 一个不改**：3.x 的 28 个（通用 4 个 + 8 个平台各 3 个）id、价格、名字的键不变，新礼物用新 id（`<平台>_<名字>`）；`giftById` 能找到所有礼物，测试要求 id 不重复 | D08.1 的 `local_events.gift_id` 和 3.x 的记录存的是 id |
| p5 | **新平台每个 3 个礼物**：一个小（10 或 50、80）、一个中（100～500）、一个大（1000～3000，标 `big`），和 3.x 的 8 个平台一样一行放得下（礼物格一行 4 个）；价格是本地币，不换算成平台的真实价格（六间房飞屏 1000 六币恰好一样） | 三档特效各有一个；本地互动只是体验，价格用来分档和扣本地币 |
| p6 | **每个新的大礼物都指定座驾**（`LocalGiftVehicle.named`，原来的 `_byGift` 改成公开）：会飞、会走的（送订阅、游艇、超跑、飞屏、赠送会员、梦幻城堡）飞机；升起来的（应援塔、任务后援、百度火箭）火箭；守护、贵族、钱、烟花、星星流星 | 不靠 id 字母的散列（D08.5 h5 “以后新加的按字母定”），每个都说得出为什么 |
| p7 | **币、等级、徽章名共用几个键**：新键按意思起名（`local_currency_kicks`、`local_level_sub`、`local_badge_guard`…），同一个意思的平台共用；3.x 的 8 个平台的键（`local_currency_bili`…、`local_badge_bilibili`…）不变；`LocalPlatformPack` 加 `badgeKey`，`badgeKeyFor` 改读它 | 不为 19 个平台各加三个一样的键；D-024 一个键也不删 |
| p8 | **emoji 子集字体**加 34 个新礼物的 emoji（40 → 74 个，55 KB → 101 KB），同一个 Noto Color Emoji 2.057（COLRv1，Google Fonts 的 `text=` 取的，去掉 SVG 表），测试检查每个礼物和徽章的 emoji 都在字体里 | K4（A08.2）：emoji 用自带字体，Linux 没有彩色 emoji 字体时不变成方块 |
| p9 | YouTube、百度没有平台币（YouTube 是买家的货币，百度没录到付费礼物的单位），币名用通用的“本地体验币”，等级、徽章和礼物用自己的 | 不编造平台没有的币 |

## 留下的问题

- 平台礼物的真实图片（D07 的 `GiftIcon`）没有用在本地礼物上：本地礼物是模拟的，平台的礼物表要联网、各平台不一样；本地礼物照旧用 emoji。
- YY、映客、LiveMe、小红书、微博的礼物体系没有调研结果（V03.5 写的受阻或不做），照旧通用礼物；以后 D07 录到样本再补。
