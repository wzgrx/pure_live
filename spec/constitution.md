# 重构宪法（v4）

本文件是 v4 重写的最高约束。所有会话、子代理和自动化都必须遵守；能自动检查的规则由 hooks 和 CI 强制执行。修改本文件需要先写一份架构决策记录（`docs/adr/`）说明原因。

完整方案见 [docs/rewrite/PLAN.md](../docs/rewrite/PLAN.md)，进度见 [docs/rewrite/STATUS.md](../docs/rewrite/STATUS.md)。

## 决策权

- 2026-09-27 用户批准 v4 方案，12 项待定事项全部采用推荐值（见下文“已确认的决定”）。
- 之后的技术和设计选择由 Claude 决定，不再逐项征求用户意见；每个有长期影响的选择都写一份架构决策记录，写明备选方案和放弃的理由。

## 原则

1. **行为以规格为准**：`spec/` 是唯一依据。实现和规格冲突时，先改规格、说明原因，再改代码。
2. **能重写就重写**：旧代码只作参考，不复制粘贴；新代码只从规格和样本出发。
3. **官方最新稳定版**：工具链和依赖只用官方最新稳定版（不用 beta/dev），精确锁定版本，每周自动检查升级。对自维护分支，“最新”指所选活跃上游的最新提交（见 ADR 0002）。落后于最新版的依赖必须登记原因和复查日期。
4. **每一步都可验证**：完成标准必须是能运行的检查——测试、真实网络探针、截图对比、性能测量或真机记录。
5. **每一步都可回退**：底层包通过开关接入旧应用；新应用使用单独的包名后缀 `.next` 并行安装，直到正式切换。
6. **性能有预算**：启动、首帧、帧耗时、内存、包体都有上限，超出即 CI 失败。
7. **依赖方向单向**：界面 → 功能 → 数据 → 平台接口；`live_core`、`live_net`、`live_danmaku` 只能是纯 Dart。
8. **隐私默认安全**：Cookie 加密存储；不默认上报任何数据；局域网功能必须配对确认。
9. **只有 master**：小步提交，每个验证过的改动都推送；版本号只随正式发布修改。
10. **Android + Windows 优先**：其它平台的能力保留，但不作为每一步的验收条件。
11. **许可证**：项目保持 AGPL-3.0。发行物不得包含专有组件、GPL-2.0-only 或许可证不明的代码；每个发布附带原生库的对应源码（ADR 0006）。

## 已确认的决定（2026-09-27）

| 事项 | 决定 |
|---|---|
| 仓库方式 | 原仓库 `master` 原地替换；旧应用收进 `legacy/`，根目录只放 v4，新应用在 `apps/pure_live`（ADR 0013） |
| 首批平台 | 5 个主力：B 站、斗鱼、虎牙、抖音、快手；其余逐个评估后迁移或下线 |
| 播放内核 | 全平台只用 mpv；去掉 IJK、Exo 和 fvp（2026-09-27 由 ADR 0006 修订：fvp 的 libmdk 是专有库，与 AGPL 冲突） |
| 录制 | 去掉 FFmpegKit，改走本地中继直写，转封装共用一份 FFmpeg |
| 状态管理 | Riverpod 3 + go_router |
| 签名 | 换正式密钥，使用 APK 签名 v3 密钥轮换保证覆盖安装 |
| Firebase | 移除，由 WebDAV 和局域网同步替代 |
| TV | 同一安装包内的 TV 模式 |
| minSdk | 保持 26 |
| JDK | 27（最新特性版） |
| 崩溃上报 | 提供可选项，默认关闭 |
| 视觉风格 | 由 Claude 在第 2 阶段调研后确定，记录在 `spec/design/principles.md` |
