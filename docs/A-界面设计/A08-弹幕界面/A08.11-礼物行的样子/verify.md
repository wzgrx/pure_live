# A08.11 礼物行的样子：全平台统一：真机验证

- 设备：Redmi K90 Pro Max（Android 17，120 Hz）
- 构建：`com.mystyle.purelive.v4dev`，提交 ……（profile / debug）
- 日期：……；验证人：……

| 步骤 | 期望 | 结果 | 截图 |
|---|---|---|---|
| 1. 哔哩哔哩（登录）热门直播间，竖屏“弹幕列表”（紧凑），等礼物 | 礼物行左边礼物图标；“名字 送出 礼物名 ×N 价值”：名字加粗浅灰、“送出”浅灰、礼物名加粗第三色、“×N”同色、价值小一号浅灰（例如“3000 金瓜子”）；没有底色，和醒目留言（彩色卡片）、通知（浅色底）一眼分开；免费礼物（辣条、小心心）没有价值 | | |
| 2. 同一个直播间等一个 10 元以上和一个 100 元以上的礼物（或上舰） | 10～100 元的左边一条细的第三色竖线；100 元以上（舰长“开通 舰长 ×1 个月”）是粗一倍的竖线，竖线和礼物名是哔哩哔哩的蓝色，看得清 | | |
| 3. 斗鱼热门直播间（荧光棒连击多） | 礼物行“送出 粉丝荧光棒 ×N”，N 是平台的连击数；收礼人是主播时不写“送给” | | |
| 4. 猫耳或克拉克拉直播间 | 有礼物图（16 大小、和字对齐），图出来前是礼物图标，字不跳；价值是钻石或红豆；送给连麦嘉宾时写“送给 嘉宾名” | | |
| 5. 弹幕设置 → 弹幕列表样式选“卡片” | 礼物是和聊天一样的卡片，左边圆点换成礼物图；档位竖线在卡片里面左边 | | |
| 6. D07.1 合并以后：斗鱼连击 | 同一行的“×N”变大一下再回去（很快），其余不动；系统“移除动画”打开时只变数字 | | |
| 7. 关掉“显示用户名” | 礼物行没有名字、徽章、粉丝牌，剩“送出 礼物名 ×N 价值” | | |
| 8. 长按一条礼物行；右键（Windows） | 长按弹幕面板打开，第一张卡片“名字：送出 礼物名 ×N · 价值”；“屏蔽关键词…”输入框里是礼物名 | | |
| 9. 双击一条礼物行 | 提示“已复制到剪贴板”，粘贴出来是“名字: 送出 礼物名 ×N” | | |
| 10. 手机横着拿（不全屏），右边 280 宽的列表 | 礼物名完整、整段换行；价值放不下时整块到下一行；不出界 | | |
| 11. 宽屏（Windows 或平板）右栏 | 和竖屏同一个样子 | | |
| 12. 浅色、深色、纯黑主题各看步骤 1、2 | 字都看得清（对比度够），很值钱的平台色在深色下是浅一些的蓝 | | |
| 13. 系统字体调到最大，重复步骤 1、10 | 名字、礼物名、×N、价值一起变大，礼物图不变大、对着第一行中间；聊天行的内容和名字一样大（以前内容会大一圈） | | |
| 14. 关掉“在聊天列表显示礼物” | 礼物行全部消失，新的礼物也不进来 | | |

## 结论

- 通过：登记表改成“完成”，写日期。
- 不通过：现象和根因线索；开新任务或退回原分支。
