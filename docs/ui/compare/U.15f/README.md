# U.15f 电视点播：设计（第 1 版）

- 状态：待确认（第 1 版，2026-10-01）
- 范围：电视“视频”模式（哔哩哔哩点播）的全部界面：首页（动态、推荐、热门）、分区、影视和番剧、视频详情、播放器（选集、画质、评论、弹幕设置、字幕、飞行弹幕）、UP 主空间、评论页、动态、我的（UP 主、稍后再看、收藏夹、历史记录、我的追番）、搜索、登录门；见下面的界面清点表
- 对应：[TASKS.md](../../TASKS.md)、[INVENTORY.md](../../INVENTORY.md#u15f)、[TASK_FILES.md](../../TASK_FILES.md#u15f)；依赖 U.15b（外壳、导航轨）、U.15a（电视设计系统）
- 基线：pure_live_TV（`~/ref/pure_live_TV/lib/modules/video`、`modules/vod`），不是 v3——手机版没有点播；v4 只有逻辑包 `packages/live_vod`（M14.0），电视界面还没做
- 评审页：源文件 [page.json](page.json)，效果图源文件 [src/gen.py](src/gen.py)；电视效果图的公共部分在 [src/tvkit.py](src/tvkit.py)（U.15g、U.15h 也用）
- 图片：还原图按 pure_live_TV 代码、默认深色主题（`core/theme/themes/dark_theme.dart`）、它的 1920×1080 设计稿画；新设计按计划书 5.5 节画在逻辑 960×540（出图 2 倍）。封面和头像是示意图片，标题和名字是虚构的

## pure_live_TV 的样子（按代码）

- **外壳**（`features/home/home_page.dart`）：导航轨默认收起（`sidebarExpanded` 默认 false），宽 160（设计像素，下同）、背景色 62% 透明；顶上时钟 `HH:mm`（t20 600），下面是模式按钮（:48-65，`Icons.movie_outlined` + “视频”），视频模式的五项是搜索、我的、首页、分区、影视（:186-205，图标 search / person_outline / home_outlined / category_outlined / movie_outlined），最下面“设置”。每项是 90×90 的圆角方块（图标 28、文字 t16），选中填主色 #00A1FF。内容区包在登录门里（:216-241）。
- **视频卡片**（`modules/video/widgets/video_card.dart`）：圆角 24，底色卡片色 #1F1F1F，焦点时换成 #1E3948、2 像素主色边、发光、放大 1.01；封面占剩下的高度，底部 64 高黑色渐变；左上分区或名次，左下播放量和弹幕数，右下时长（`TvCoverChip`：黑 98% 底、t14）；看过的在封面底边画 4 高进度条；下面头像 56、标题 t22 700 一行（焦点时滚动）、“UP · 2026-09-28” t18。长按封面换成黑 82% 的操作层：`watch_later_outlined`、`person_outline_rounded` 两个图标（:216-236）。网格 4 列（`denseRoomLayout` 默认 4），间距 6，宽高比 1.3。
- **标签栏**（`core/widgets/tv_tab_bar.dart`）：胶囊高 36、左右 28、t22 500 白字；选中填主色，焦点半透明主色加描边放大 1.08；当前标签再按确认刷新。分区标签前面是 emoji（`video_region_page.dart:21-32`）。
- **子页面**（`core/widgets/tv_page_scaffold.dart`）：顶栏高 66，“返回”小按钮（`arrow_back_ios_new`）+ t24 标题；打开时焦点给“返回”（:121）。
- **视频详情**（`video_detail_page.dart`）：左封面 400 宽 16:9，右边标题 t24、“播放 12.3万 · 2048 条弹幕 · 日期” t14、UP 主行（头像 + 名字 + `chevron_right`）、六个操作胶囊（点赞、投币、收藏、一键三连、稍后再看、评论，`video_action_chip.dart`）；下面简介卡片、“播放列表（N）”+“播放全部”、分 P 行（高 76，序号、标题、时长）、“相关视频”一行卡片（宽 300）。
- **番剧**（`video_season_page.dart`）：左边 340 宽竖封面（3:4）、评分（星 + 数字，琥珀色）、“28 话”、风格标签、简介；右边“选集（28）”+“播放全部”，选集网格 4 列、宽高比 2.6，格子里是标题（t16 两行）和会员等标记；没标题时写“第 1”（:74、:247）。
- **播放器**（`pages/playback/video_player_widgets.dart`）：黑底画面；控制栏一开始收起，确认键呼出、焦点在“播放”；收起时 ←→ 快退快进 10 秒（连按 200 毫秒内每次加 5 秒，最多 60 秒）、↑↓ 上一集 / 下一集（到头提示）；5 秒没按键收起，开着面板时不收；返回键依次关画质菜单、评论、选集、控制栏，最后退出并停止播放（:234-323）。顶部一行：电影图标（主色）+ 标题 t22 + “P1/3”、画质、在线人数（眼睛图标）、UP 名。底部控制条（`widgets/video_control_bar.dart`）：黑 72% 圆角 24、主色细边；上面时间和进度条（↓ 进入进度条，←→ 拖动，↑ 回来），下面 13 个胶囊一行横向滚动（高 52、t20）：上一集、播放、下一集、快退10秒、快进10秒、1.0x（倍速循环 1.0 / 1.25 / 1.5 / 2.0）、画质、选集、弹幕开 / 关、评论、弹幕设置、字幕开 / 关、适应 / 填满；底缘 5 高进度线（`persistentProgress` 默认开）。
- **画质菜单**（`widgets/video_quality_menu.dart`）：右上角（上 100、右 48、宽 320），黑 86%、主色半透明边；标题“画质”+ 关闭；每项高 56，当前项主色底和字加勾。
- **选集面板**（`widgets/video_parts_panel.dart`）、**评论面板**（`widgets/video_comments_panel.dart`）：右侧（上下 100、右 48，宽 520 / 620），黑 86–88%；评论每条：名字（主色）、点赞小胶囊、内容 t14、“共 N 条回复，按 OK 展开”；只有热门，没有空和出错状态（:110）。
- **评论页**（`modules/vod/pages/ugc_comments_page.dart` + `widgets/ugc_comment_tile.dart`）：“热门 / 最新”两个自绘胶囊，每条一张卡片（头像 52、名字 t18、置顶、时间、点赞、内容 t19、回复预览）。
- **UP 主空间**（`ugc_user_space_widgets.dart`、`widgets/ugc_space_header_card.dart`）：头部卡片（头像 96、名字 t24、签名、粉丝 / 关注 / 投稿，右边“取消关注 ✓”或“关注 ＋”），“投稿（N）”+ 排序按钮（最新发布 / 最多播放，按一下切换），投稿网格用另一种卡片（`ugc_space_upload_card.dart`，圆角 14，只有封面和标题）。
- **我的**（`pages/personal/video_personal_section.dart`）：顶上居中的自绘胶囊（UP主、稍后再看、收藏夹、历史记录、我的追番）；UP 主是 5 列头像卡片，长按直接取消关注（`video_follow_pane.dart:116`）；稍后再看用视频卡片，左上角写进度百分比，删除挂在 `GestureDetector.onLongPress`（`video_toview_pane.dart:69`）；历史是列表行（封面 210×122 带进度、标题 t20、P 号 + UP、时间 + “看到 01:46 / 04:12”或“已看完”），长按直接删除（`video_history_pane.dart:88`）；追番长按确认后取消（`video_bangumi_pane.dart:107-121`）。
- **搜索**（`pages/discover/video_search_results.dart`）：输入框（宽 560）+“搜索直播”按钮，搜过后右边出现视频 / 用户 / 影视三个按钮；下面热搜榜（前三名红色序号），焦点默认在第一个热搜（`widgets/video_hotword_board.dart`）。
- **状态**（`core/widgets/app_status_view.dart`）：圆圈图标（出错 `wifi_off`，其余 `live_tv`）、标题 t24、副标题 t24；各页面都没传 `onTap`，所以没有按钮；出错的副标题是 `e.toString()`。
- **颜色**：默认深色主题背景 #121212、卡片 #1F1F1F、主色 #00A1FF、主文字和次要文字都是白色（`dark_theme.dart:15-17`）。

## 按钮的作用和用法

见对比页“每个按钮是干什么的、怎么用”四节（首页 1–9、详情 1–11、播放器 1–12、其他页）。遥控器按键：

| 键 | 用法 |
|---|---|
| 确认 | 打开、执行；播放器里控制栏收起时呼出控制栏 |
| 长按确认 / 菜单键 | 卡片、历史、UP 主、追番：打开对话框（稍后再看、UP 主主页、删除、取消关注……） |
| 返回 | 逐层退出：小菜单 → 面板 / 对话框 → 控制栏 → 页面；子页面回上一页；视频模式根页面回到导航轨，再按走外壳的退出确认（U.15b） |
| 上下左右 | 移动焦点；播放器控制栏收起时 ←→ 快退快进（加速）、↑↓ 换集；控制栏显示时 ↓ 进度条、↑ 选集 |
| 媒体键 | 播放 / 暂停、上一集、下一集，任何时候都有效 |

## 焦点路线

| 页面 | 默认焦点 | 方向键 |
|---|---|---|
| 首页、分区、影视、我的、搜索结果 | 从导航轨进入时落在上次停留的卡片，第一次是第一张 | ↑ 标签栏，← 导航轨（展开），网格按行列记忆 |
| 视频详情 | 播放 / 继续 | → 点赞……评论，↑ 返回，↓ 分 P，再 ↓ 相关视频 |
| 番剧 | 第 1 话 | ↑ 播放全部、返回 |
| 播放器 | 控制栏收起；确认后在播放 / 暂停 | ←→ 按钮行（不循环），↓ 进度条，↑ 选集面板 |
| 选集、评论面板 | 正在播的一集；第一条评论的点赞 | ↑↓ 移动，返回键关闭 |
| UP 主空间 | 第一个投稿 | ↑ 排序、关注，再 ↑ 返回 |
| 搜索 | 热搜第一个（照旧） | ↑ 搜索框、“搜索” |
| 登录门、出错 | 扫码登录、重试 | ← 导航轨 |
