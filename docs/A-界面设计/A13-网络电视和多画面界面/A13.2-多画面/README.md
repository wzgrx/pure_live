## v3 的样子

文件：`lib/modules/multiview/multiview_page.dart`（下面只写行号）、`widgets/multiview_room_picker.dart`、`widgets/multiview_fullscreen_surface.dart`、`multiview_controller.dart`。

**入口**：首页顶栏“更多”（`Remix.menu_search_line`）菜单的第三项“多画面”（`Remix.layout_grid_line`，设置 `enableMultiView` 默认开，`common_appbar_actions.dart:56-66`）；宽屏导航栏上的 `Remix.layout_grid_line`（提示“多画面”，`tablet_view.dart:109-118`）。

**三种显示**（`:22-27`、`:353-419`）：普通（顶栏 + 工具条 + 格子，宽屏电脑再加右侧选台）、沉浸（黑底只有格子，右下角 16 处 48×48 恢复按钮 `Remix.collapse_diagonal_line` 20，最高表面容器 92%、圆角 14，提示“退出沉浸”，`:1360-1390`）、全屏（系统全屏，手机自动横屏；左上角安全区内 12 处 48 的圆形按钮，68% 黑底、`Remix.fullscreen_exit_line` 22 白色，提示“退出全屏”，`multiview_fullscreen_surface.dart:30-56`）。返回和 Esc：沉浸 / 全屏先回普通，普通时先停掉所有格子再退出（`:131-169`）。

**顶栏**（`:360-375`）：“多画面”居中；右边“沉浸模式” `Remix.expand_diagonal_line`、“全屏” `Remix.fullscreen_line`，再留 4。

**工具条**（`:436-556`）：宽度（整屏）<680 时两行：第一行居中的分段按钮（放不下就整体缩小），第二行靠右四个图标；≥680 一行（分段按钮在中间、图标在右）。分段按钮四段：`Remix.aspect_ratio_line` 1×1、`layout_column_line` 1×2、`layout_grid_line` 2×2、`focus_3_line` 1+3（`:444-459`）。四个图标（22）：弹幕 `CustomIcons.danmaku_open`（开时主色，提示“弹幕”）、全部静音 `Remix.volume_vibrate_line` / 静音时 `volume_mute_line` 主色（提示“全部静音”“恢复声音”）、音量 `Remix.volume_up_line`（声音来源格在播放时可点）、小格省流 `Remix.speed_mini_line`（开时主色；不是 1+3 时变灰）。

**格子**（`:576-698`、`:933-1220`）：格子区内边距 6、格间 6，铺满剩下的整个区域（不管画面比例），直角。默认 2×2（`multiview_controller.dart:291`），手机最多 4 格，电脑 1+3 最多 9 格（`:73`、`:84`）。1+3：左大格（3 份宽）+ 右边一列小格（1 份宽，一屏 3 格，多的滚动，电脑末尾“添加画面”槽 `:1321-1358`）。底色：播放中或深色主题黑色，否则（浅色主题的空、解析中、未开播、失败）最低表面容器色（`:978`）。

- 播放中：画面按比例放在格子中间；左上角房间名条（55% 黑、圆角 10，平台图标 13 + 主播名 12 号白色粗）；声音来源再加一个主色角标（`Remix.volume_up_line` 13 +“声音来源”）（`:1038-1049`、`:1231-1286`）。弹幕只画在声音来源格（1+3 时是大格）（`:601`、`:644`）。
- 空：54 的圆底 + `Remix.add_circle_line` 26，“点击选台”14 号（`:1123-1142`）。
- 解析中：转圈 + 房间名 12 号（`:1144-1158`）。
- 未开播：`Remix.live_line` 30，“该直播间未开播”14 粗、房间名、“点击此格可重新选台”（`:1160-1179`）。
- 播放失败：`Remix.error_warning_line` 30 错误色，“播放失败”、原因（“解析播放地址失败：{原因}”或“起播失败：{原因}”，最多 3 行）、“重试”按钮（`:1181-1219`）。
- 手势：点播放中的格子 = 设为声音来源；1+3 点小格 = 变成大格，点大格 = 显示 / 隐藏控制条；点空、未开播、失败的格子 = 选台；长按或右键播放中的格子 = 格子菜单（`:885-930`）。

**1+3 大画面**：控制条（左右下各 8，55% 黑、圆角 10，按钮 48、图标 20）：播放 / 暂停、刷新、弹幕（开时主色）、弹幕设置 `Remix.settings_3_line`、清晰度 `Remix.hd_line`、线路 `Remix.route_line`（线路多于 1 条时）、音量 `Remix.volume_down_line`、全屏；放不下时横向滑动（`:700-790`）。控制条隐藏时左下角显示清晰度小菜单入口（`Remix.equalizer_line` 12 + 名字 12 号，菜单 13 号、当前项主色加粗，`:1070-1121`）。

**底部面板**（主题：中表面容器色、拖动条、顶角 24）：

- 选台（`:249-267`）：最高为屏幕 72%；内容：搜索框（`Remix.search_line`，“搜索主播或标题”）、分段按钮“关注 / 历史记录”、列表（头像 38 + 平台图标、主播名 14、标题 12、右边绿点“正在直播”或灰点“未直播”“录播”“状态待确认”）；开播的在前；空时“暂无可选直播间 / 先去关注几个直播间，或切换到历史记录看看”（`multiview_room_picker.dart`）。选了以后目标自动跳到下一个空格（`:230-247`）。
- 格子菜单（`:269-315`）：换台 `Remix.tv_2_line`、选择清晰度 `Remix.equalizer_line`（没有清晰度时变灰）、关闭该格 `Remix.close_circle_line`（错误色）。
- 清晰度（`:318-339`）、线路（“线路 1”…，`:793-814`）：列表，当前项右边勾。
- 音量（`:817-870`）：主播名 + 百分比、`volume_down_line` 滑块 `volume_up_line`、“房间音量”；拖动即时生效并保存。
- 弹幕设置（`:875-883`）：直播间的弹幕设置内容，高 72%。

**宽屏**（电脑且宽度 >680，普通模式）：格子右边一条分隔线和 320 宽的选台栏，标题“为格子 {n} 选台”15 粗，内容同选台面板（`:425-434`、`:558-574`）；安卓平板、手机横屏没有这一栏，仍从底部弹出。

v4 现在已有、v3 没有的：恢复上次的提示、进入直播间、播放这一格的声音、已在第 N 格、已暂停、未开播时“重新检查”。新设计保留前五项（“播放这一格的声音”就是点格子）；“重新检查”并进未开播格子的点击（点了重新选台，照 v3），拿不准时再议。

## 按钮的作用和用法

| 编号 | 控件 | 怎么用 |
|---|---|---|
| 1 | 返回 | 退出多画面；沉浸 / 全屏时先回普通 |
| 2 | 沉浸模式 | 只留格子，状态栏还在、不转屏；电脑上窗口不变 |
| 3 | 全屏 | 系统全屏，手机自动横屏 |
| 4 | 布局 | 1×1、1×2、2×2、1+3 |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 竖屏格子在上、控制和选台在下；横屏工具条并进顶栏、右栏放控制（选台时换成选台）；最多 4 格 |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 右栏 360（控制 + 选台），能收起；电脑 1+3 最多 9 格；悬停显示名称、右键 = 长按、Esc 退出 |
| 电视 | 不适用（pure_live_TV 没有多画面） |
| 苹果平台差异 | iPhone 横屏退出按钮避开灵动岛；macOS 全屏用系统全屏空间、Cmd 快捷键 |

## 待选

- W1 竖屏的排法：建议 A 格子在上、控制和选台在下；B 照 v3 铺满、从底部弹出。
- W2 横屏和宽屏右栏：建议 A 常驻能收起；B 用时滑出。
- W3 1+3 大画面控制条：建议 A 只在沉浸 / 全屏；B 照 v3 平时也有。
- W4 已在格子里的直播间：建议 A 标“第 N 格”、点了选中；B 照 v3 能再放一格。

## 拿不准的地方

1. 竖屏 2×2 每格只有约 193×109，名字长时截断；嫌小可以改成一列四格（要上下滑）。
2. 退出按钮放在黑边里：19.5:9 手机横屏两边约 80 的黑边；16:9 屏幕没有黑边时会盖住第 1 格一角，实现时把第 1 格的名字右移。
3. “上次看了 N 个直播间，要恢复吗？”提示照 v4 保留（格子上方），图里没画。
4. 选台的“正在直播”照 v3 用绿点；全应用的直播标记等 A09.1 定。
5. 电脑 1+3 超过 4 格时，宽屏右边既有小格一列又有右栏，两列并排是否太挤，要在 1920 宽上再看。
