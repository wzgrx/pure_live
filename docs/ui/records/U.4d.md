## 和设计 / v4 不一样、需要你知道的

1. **抖音改回一个网格**（设计 c1、c3 照 v3）：v4 在 C-12（抖音“游戏”下约 155 个分区）之后改成了分类标签，现在按设计合回一页，每张卡第二行写分类。分区多的话要滚很久，如果要恢复分类标签，改 `flatAreas()` 一处即可。
2. **去掉了 v4 分类行右边的“筛选”和“刷新”按钮**：设计图没有（设计里列为 v4 的偏差）。筛选的逻辑 `filterAreas` 还在，没有入口。刷新靠下拉和电脑翻页条。
3. **X3 改成对话框**：协调员 2026-10-01 的要求（计划书原则 7：同一个操作各处同一个组件）。
