## 修复设计

- 下载恢复与删除共用页面文件操作状态，在首个 await 前占用；上传也检查该状态，文件操作同样检查上传状态，避免相互重复启动。
- 删除确认纳入同一 try/finally：取消、确认异常、网络失败和成功刷新结束都释放门禁；确认仍绑定原服务与原目录，未删除任何用户云盘内容。
- 文件操作状态不会随连接重新初始化而清零。尤其当本地恢复已进入持久化阶段，切换配置后仍等其完成，再开放导出；服务所有权继续决定是否发布过期反馈。页面关闭后不再更新状态。
- 文件菜单和上传按钮联动禁用，列表上方展示当前恢复/删除状态。反馈复用上一批按 Scaffold 避让 FAB 的浮动提示。
- 增加可注入反馈回调，将无界面的控制器时序测试与真实页面反馈分开；生产默认继续使用 ScaffoldMessenger，真实 Widget 用例验证默认行为。
