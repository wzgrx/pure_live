## 修改前复现

干净红灯记录：
`local-artifacts/build-records/20260911T034226576Z-quality-focused.json`，结果 **0 PASS / 2 FAIL**。

- 四个带当前值的设置项继续使用标准 `ListTile.trailing`。在正文可用宽度 256 像素、3.0 倍英文下，
  `Balanced (recommended)` 等当前值占满整行，Flutter 稳定报告
  `Trailing widget consumes the entire tile width`，页面随即产生级联布局/语义异常。
- 将四个当前值先改为窄屏纵向摘要后，摘要测试转绿，并继续稳定暴露旧 `SimpleDialog` 向底部溢出 **80 像素**；
  第一组最后选项的全局底边达到 912 像素，受限视口内没有可靠操作位置。
- 后续可滚动弹窗迭代中，测试夹具最初只要求“部分可见”而没有滚到滚动范围末端；该中间断言未计作产品缺陷，
  最终改为读取弹窗自身滚动范围并实际滚到末端。

## 修订

- 四个枚举设置项启用共享窄屏摘要布局：标题、说明在上，当前值在下，进入图标单独保留，宽屏仍维持紧凑横排。
- 枚举选择器由固定高度 `SimpleDialog` 改为整体可滚动 `AlertDialog`；标题和所有选项处于同一有界滚动区域，
  每个 `SimpleDialogOption` 仍保留完整行点击、选中图标和原有返回值语义。
- 添加仅用于测试的呈现刷新回调，使全屏方向选项能够覆盖“写入设置 + 立即刷新”完整链路，生产路径仍调用真实播放器刷新。
- 新增 Widget 回归连续选择 `Compatible 16:9`、`Always landscape`、`Crop to fill`、
  `Hide on portrait sources`，同时验证四个摘要均位于标题下方、最后选项完全进入视口、弹窗关闭和呈现刷新恰好一次。
