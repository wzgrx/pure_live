## v3 在 macOS 上的样子（按代码）

**窗口**：所有桌面平台都用 `window_manager` 的 `TitleBarStyle.hidden`（`common/global/platform/desktop_manager.dart:57-64`）。在 macOS 上这会隐藏标题、让标题栏透明、内容铺满整个窗口，三个窗口按钮留在左上角的标准位置、压在应用内容上；自绘标题栏只在 Windows 画（`:121-137`，`main.dart:175-176`）。所以首页侧边栏顶上的菜单按钮、直播间顶栏的返回键和头像都被三个按钮压着。窗口背景用了毛玻璃 `WindowEffect.hudWindow`（`:85-92`）。

**关闭和退出**：`setPreventClose(true)`（`:67`），点红色按钮弹“提示 / 确定要退出吗？ / 不再询问 / 最小化 / 退出应用”（`plugins/utils.dart:242-385`），“最小化”在 Mac 上是缩到程序坞（`:97-108`）。⌘Q 走系统退出，只把设置写盘就退（`desktop_manager.dart:765-768`），录制中也不提示。`macos/Runner/AppDelegate.swift:6` 设成最后一个窗口关了就退出。

**菜单栏**：用的是 Flutter 模板 `macos/Runner/Base.lproj/MainMenu.xib`：应用菜单（About、Preferences… ⌘,、Services、Hide ⌘H、Hide Others ⌥⌘H、Show All、Quit ⌘Q）、Edit（撤销到查找、拼写、替换、转换、朗读）、View（Enter Full Screen ⌃⌘F）、Window（Minimize ⌘M、Zoom、Bring All to Front）、Help。全是英文（工程只有英文本地化），只有菜单里的应用名被换成“纯粹直播”（`Configs/AppInfo.xcconfig:8`）；“Preferences… ⌘,”没有接功能（`MainMenu.xib:36`），是灰的。Dart 里没有 `PlatformMenuBar`，应用自己的命令一个都不在菜单栏里。

**菜单栏图标（托盘）**：`tray_manager`，图标是彩色的 `assets/icons/icon.png`，提示“纯粹直播”（`desktop_tray_service.dart:17-63`）。左键：窗口在就拉到前面，不在就显示（`desktop_manager.dart:213-229`）；右键才出菜单：“隐藏窗口 / 显示窗口”、分隔线、“退出应用”（`:157-173`、`:231-239`）。

**全屏**：直播间全屏调 `windowManager.setFullScreen(true)`（`player/utils/fullscreen.dart:322-335`），进系统的全屏空间；绿色按钮、⌃⌘F 也进全屏空间。离开全屏空间时直播间不跟着变（`onWindowLeaveFullScreen` 是空的，`desktop_manager.dart:729`）。

**直播间**：上栏只有纯音频，没有小窗；下栏没有音量条和窗口内全屏，这两个只在 Windows（`video_controller_panel.dart:52-61`、`:1571-1573`）。

**其他**：快捷键同 Windows，只有单键（`video_keyboard.dart:53-80`），没有 Cmd 组合；分享在电脑上是复制口令，提示“已复制到剪贴板”（`common/utils/share_command_handler.dart:195-199`）；滚动是弹性的（`pure_live_scroll_physics.dart:13`）；开机启动和“新建独立播放窗口”只有 Windows（`general_settings_page.dart:57`、`:119`，`initialized.dart:134`）；版本页有“macOS 通用 ZIP”（`version_page.dart:89-99`），下载完的按钮是“立即安装”（用系统打开 ZIP，也就是解压）和“打开文件夹”（`common/widgets/download_apk_dialog.dart:675`、`:688`）。

## 每处差异依据的苹果规范（Human Interface Guidelines）

| 差异 | 依据 |
|---|---|
| 三个窗口按钮留在左上，内容让开 | 《Windows》（macOS）：关闭、最小化、缩放按钮在窗口左上角，由系统提供；《Toolbars》：标题栏和工具栏合成一行时按钮在这一行里 |
| 标题栏空白处拖动、双击缩放 | 《Windows》：窗口要能从标题栏区域拖动 |
| 去掉毛玻璃 | 计划书 9.3（性能）；不是 HIG 要求 |
| 中文菜单、应用菜单的标准项和顺序、所有命令都在菜单栏里 | 《The menu bar》：应用菜单依次是关于、设置…（⌘,）、服务、隐藏、退出；菜单顺序是应用、文件、编辑、显示、应用自己的菜单、窗口、帮助；应用的命令都要能在菜单栏找到；菜单跟应用用同一种语言 |
| Cmd 快捷键 | 《Keyboards》：用标准快捷键（⌘, ⌘W ⌘Q ⌘H ⌘M ⌘F ⌘[ ⌃⌘F 等），不占用系统保留的组合 |
| 关窗口不退出，⌘Q 退出，有后台工作时退出前确认 | 《Windows》（关闭窗口不等于退出应用）、《The menu bar》（退出在应用菜单，⌘Q） |
| 单色菜单栏图标、点了出菜单、可以关 | 《The menu bar》的 Menu bar extras：用单色（模板）图标，点了显示菜单，让用户决定要不要显示 |
| 系统全屏空间、各种退出方式都有效 | 《Going full screen》：用系统的全屏，Esc、菜单、绿色按钮都能退出，指针到顶端显示菜单栏 |
| “在访达中显示” | macOS 的标准说法（访达和系统菜单都这么叫） |

## 拿不准的地方

1. 菜单里的 APP_NAME 被换成应用名是 Flutter 的 `FlutterAppDelegate` 做的（按 Flutter 引擎的行为），菜单全是英文按工程只有英文本地化推断，没有在 Mac 上核对。
2. `window_manager` 隐藏标题栏时三个按钮的确切位置，图里按标准标题栏（左 8、上 8）画；统一标题栏的位置（左 20、在 56 高的一行里垂直居中）要用 `macos_window_utils`（v3 已经依赖）加工具栏或移动按钮，要在 Mac 上试。
3. 全屏空间里指针到顶端时，系统的标题栏会盖住我们的上栏一部分（图里示意），能不能让上栏让开要在 Mac 上试。
4. 菜单栏图标图里用应用图标的单色剪影，正式图形另画（A14.1）。
5. v3 离开全屏空间时直播间不跟着退出，是按代码推断，没在 Mac 上看。

## 交给其他任务的

- A16.1：Windows、Linux 的托盘菜单要不要也加录制中的两行、Ctrl 快捷键是否用同一组命令，和这里一致。

- A11.4：开机启动在 macOS 叫“登录时打开”（v3 只有 Windows），用系统的登录项；K1 选 A 时 Mac 上不显示“关闭窗口时”的设置。
