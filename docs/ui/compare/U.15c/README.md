## pure_live_TV 的样子

共同点：每页是 `TvScaffold` 里一列：标签栏（胶囊，U.15a）、空 8、网格（`BasePagedTvView`，每页 12 个，滑到离底 400 时加载下一页，`core/pagination/base_paged_tv_view.dart:68-79`）；房间网格 4 列、宽高比 1.3、间距 6（`ThemeSettingsController.cardGridDelegate`）；在当前标签上再按 OK 刷新；页面最左一列按左键回导航栏、最上一行按上键到标签。空状态文字在 `core/widgets/empty_scene.dart:46-92`。

- **热门**（`modules/live/hot/hot_page.dart`）：平台标签（“平台显示”里的平台，带平台图标，`:81`、`:106-116`）；平台一个都没有时整页是空的 `SizedBox`（`:76-78`）；卡片长按是“关注提示”确认框（`:137`）；空“该平台暂无直播 / 请切换平台或稍后重试 / 重试”。
- **关注**（`modules/live/favorite/favorite_page.dart`）：三行：状态标签“正在直播 / 正在重播 / 未开播”（`:264-268`、`:282-294`），平台标签“全部”加有关注的平台（`:272-273`、`:296-311`），分组标签（mini 按钮，`:313-353`）；卡片不显示“已关注”（`:387`），长按是菜单“取消关注 / 设置房间标签 / 分类”（`:384-386`）；未开播也是大封面卡片。空：一个都没关注时“无已开播直播间 / 请先关注其他直播间 / 重试、去搜索”（`:105-116`），筛选为空时“当前筛选暂无已开播直播”等加“关注数据仍在，共 {count} 个；可按左右键切换平台或清除标签筛选”，按钮“查看未开播”或“重试”加“去搜索”（`:117-139`）。
- **分区**（`modules/live/areas/areas_page.dart`、`area_grid_view.dart`）：平台标签（`areas_page.dart:35-39`），下面分类标签（同样的胶囊，`area_grid_view.dart:71-84`；平台只有一个分类或在 `area_display_config.dart` 的 20 个平台里时不显示，平铺），分区网格 6 列、宽高比 1.5（`:98`）；卡片 OK 进分区房间，长按“关注提示 / 确定要关注“英雄联盟”分区吗？ / 确定关注”（`:107-109`、`favorite_operation_util.dart:86-111`）；空“未发现分区 / 请点击上方按钮切换平台 / 刷新”，出错“数据加载失败”加原文（`areas_page.dart:111-133`）。
- **分区房间**（`modules/live/areas/area_rooms_page.dart`）：单独一页（没有导航栏），顶栏“‹ 返回”和分区名（`:93-94`），焦点先在“返回”上（U.15a P13）；4 列房间网格；长按“关注提示”（`:115`）；哔哩哔哩 -352、抖音风控时显示“需要登录账号”（`:30-46`）。
- **关注分区**（`modules/live/favorite_areas/favorite_areas_page.dart`）：平台标签是“全部”加所有显示的平台（`:29`）；6 列分区卡片，OK 进分区房间（`:78-83`），长按取消关注确认（`:84-86`）；空“暂无收藏夹 / 收藏分类后可整组查看直播 / 重试”（`:64`、`empty_scene.dart:66-72`）。
- **观看记录**（`modules/live/history/history_page.dart`）：最上面两个 mini 按钮“清空历史”“观看记录保留数量: 50”（`:211-242`）；平台标签是“全部”加所有显示的平台（`:38-39`）；在当前平台标签上再按 OK 重新核对每条记录是否在播（`:59-62`、`:109-128`）；清空先确认“将删除全部 {count} 条观看记录，是否继续？ / 清除”（`:154-166`）；保留数量是选择框 20 / 50 / 100 / 200 / 不限 / 自定义数量（`:169-207`）；长按“历史管理：关注 / 取消关注、删除历史”（`:87-89`）；空“暂无观看记录 / 观看记录将自动保存 / 浏览热门”（按钮是刷新图标）。
- **搜索**（`modules/live/search/tv_search_page.dart`）：居中一列：手机遥控二维码和地址（没有说明，`:97-100`）、“主播 / 直播间”（默认主播，`:30`、`:158-185`、`tv_search_provider.dart:15`）、平台标签（没有“全部”，`:28-29`）、输入框“输入主播/直播间名称搜索”（`:116-150`）、“搜索历史（长按删除）”和历史标签、“清空”（不确认，`:187-235`）；历史标签放大了两次（`:253-255`）。OK 提交后打开结果页。
- **搜索结果**（`modules/live/search/tv_search_result_page.dart`）：单独一页，顶栏“搜索: 晚风 (哔哩哔哩)”（`:155`）；按主播搜时把主播转成直播间卡片，封面就是头像、标题和主播名都是名字（`:77-92`）；长按“关注提示”。

## v3（pure_live_TV）的问题

| 编号 | 问题 | 位置 |
|---|---|---|
| L1 | 关注页状态叫“正在直播 / 正在重播”，手机叫“已开播 / 录播”；状态标签和平台标签是同一种胶囊、上下两行，看不出哪行是什么；没有数量 | `favorite_page.dart:264-311` |
| L2 | 未开播也用大封面卡片，封面是上次的截图，一眼看不出没开播；一屏只看到 8 个 | `favorite_page.dart:380-388` |
| L3 | 一个都没关注时写“无已开播直播间 / 请先关注其他直播间”，按钮“重试” | `favorite_page.dart:105-116` |
| L4 | 热门的平台只能左右一个个移，后面的平台要按很多次；“平台显示”全关时热门、分区整页空白 | `hot_page.dart:76-78`、`:106-116`；`areas_page.dart:20-22` |
| L5 | 分区的平台标签和分类标签同一种胶囊，两行分不清 | `areas_page.dart:35-39`、`area_grid_view.dart:71-84` |
| L6 | 分区卡片长按是确认框，看不出哪些分区已经关注 | `area_grid_view.dart:107-109` |
| L7 | 分区房间：标题只有分区名，看不出平台和大类；不能在这一页关注分区，要退回分区页长按 | `area_rooms_page.dart:93-94` |
| L8 | 关注分区：平台标签列出所有平台（不管有没有关注）；“全部”里卡片不写平台；空状态说“收藏夹”，和“关注分区”对不上，也不说怎么关注 | `favorite_areas_page.dart:29`、`empty_scene.dart:66-72` |

| L11 | 默认按主播搜，结果卡片的封面是放大的头像，标题和主播名重复 | `tv_search_provider.dart:15`、`tv_search_result_page.dart:77-92` |
| L12 | 二维码没有说明是干什么的；“主播 / 直播间”顺序和手机相反 | `tv_search_page.dart:97-100`、`:30` |
| L13 | 搜索历史“清空”不确认就全删；历史标签焦点时放大了两次 | `tv_search_page.dart:209-216`、`:253-255` |

## v4 现在的偏差（`apps/pure_live/lib/tv/pages/`，M14.1）

热门叫“推荐”；分区和关注分区合在一页（关注的分区在前）；历史是网格加清空；搜索是一页（按 OK 打开输入框、最近搜索、结果网格），没有二维码；网络电视单独一页。字号、焦点同 U.15a 的偏差。

## 焦点路线

| 页面 | 默认焦点 | 方向键 |
|---|---|---|
| 热门 | 第一张卡片（回来时是上次那张） | 网格按行列；最上一行按上到平台标签，标签行最右是“全部平台”；最左一列按左到导航栏 |
| 全部平台面板 | 当前平台 | 3 列格子；上到“平台显示”“关闭”；返回键关 |
| 关注 | 第一张卡片 | 卡片 → 上到分组 → 上到状态和平台一行（左右走到底从状态跨到平台） |
| 分区 | 第一张分区卡片 | 卡片 → 上到分类 → 上到平台 |
| 分区房间 | 第一张卡片 | 最上一行按上到“关注”；返回键回分区 |
| 关注分区 | 第一张分区卡片 | 卡片 → 上到平台 |
| 观看记录 | 第一张卡片 | 卡片按行列跨过日期分组；→ 上到平台 → 上到按钮行 |
| 搜索 | 搜索框（还没输入时） | 下到平台和筛选 → 说明行 → 最近搜索；右边二维码不能获得焦点；有结果时 OK 后焦点到第一张结果 |
