# 主题设置持久化、备份与首帧安全审计

## 范围与根因

本轮以 `15b71678` 为基线，修订提交为 `6ebd3686`。范围限主题模式、主题色、语言、网格间距、加载样式及加载颜色的持久化、当前/旧版备份、导出和首帧消费路径；没有构建安装包、操作手机、发起生产网络请求或执行 Windows GUI，Computer Use 与 Astra Light 使用均为 **0 次**。

源码审查确认七个相邻缺口：

1. 主题模式原始持久值直接进入 `AppConsts.themeModes[...]!`；损坏值或已移除选项可在应用首帧触发空值异常。
2. 主题色和加载颜色由多个页面及控制器直接交给 `HexColor`；异常文本最终进入 `int.parse`，可在启动、状态页、设置页、热门分区或弹幕屏蔽页抛出格式异常。
3. 网格横纵间距的界面虽限制为 0～64，但 Hive、备份和运行时直接写入没有共享有限值边界；负值、无穷值或超大值可进入网格布局。
4. 语言持久值没有支持项归一化，最终仍通过非空断言读取语言表。
5. 已移除的加载样式只在绘制层临时回落，异常键仍会保留在持久化与设置选中状态中。
6. 主题解析的默认主色曾使用橙色，而字段初始值和提取路径使用蓝色，缺省备份语义分裂。
7. 旧版独立字段 `languageName` 虽曾参与迁移，却没有进入主题解析别名与备份身份识别。

## 修订

- 建立主题模式、语言和加载样式的支持项合同；忽略首尾空白和大小写后输出当前规范键，未知值分别回落到系统模式、简体中文和默认加载动画。
- 建立共享颜色合同：主题色只导出规范大写 RGB/ARGB 十六进制，异常值回落为蓝色；加载颜色允许空值继承主题色，异常值修复为空。
- 将横纵间距统一为有限的 **0～64**，非有限持久值回落为 6，普通越界值钳制到边界；备份中的非有限值按畸形输入拒绝。
- 控制器在注册观察器前修复 Hive；运行时直接写入也会归一化。所有首帧、设置页、热门分区和弹幕屏蔽消费者改用安全解析后的 getter。
- 当前备份、旧版备份、完整往返和导出共用同一合同；解析缺省主色统一为蓝色，并识别旧版 `languageName`。
- 加载状态组件在异常颜色或已移除样式下仍呈现默认动画，持久值和设置页选中状态同步回到规范值；控制器关闭时释放全部观察器。
