# 纯粹直播 4.0.0（Android）

这是 4.x 的第一个稳定版，也是纯粹直播的一次整体重写：网络、平台适配、弹幕、播放、录制、存储和每一个界面都重新写过。功能以 3.x 为基础，3.x 的问题逐个找出原因修掉，3.x 的设置和数据照旧生效。

这一版发布 Android（手机和平板），需要 Android 8.0 及以上。Windows 等客户端以后发布。

下载：[Releases](https://github.com/wzgrx/pure_live/releases/latest)，不确定选哪个就下载文件名带 `arm64-v8a` 的 APK。

## 主要变化

### 全新界面

- 每个界面在 3.x 的布局和操作习惯上重新设计：手机竖屏、横屏、平板各自排版，旋转、分屏、折叠屏开合时布局跟着变，不会错乱。
- 房间网格的列数按可用宽度计算，手机两列，平板和横屏自动增加。
- 加载、空、出错、受限、离线、权限被拒等状态统一了样子，每种都写清原因和下一步。
- 默认主题色换成对比更清楚的蓝色（3.x 里自己选过的颜色照旧）；次要文字的对比度提高，深色和浅色主题都看得清；新增纯黑背景。
- 关注页的状态和平台标签带数量；搜索结果、关注的“全部”里，卡片标出所属平台。

### 直播间

- 竖屏直播间保留 3.x 的上栏和按钮位置，信息行分开显示在线人数、热度和开播时长，详情（公告、简介）可以展开。
- 横屏全屏加入时间和电量、锁定、本地弹幕输入；竖屏直播流有三档面板和竖屏全屏；平板上画面加右侧聊天栏。
- 平台实际给的画质比选的低时（例如没登录拿不到原画），会提示真实画质。
- 加载、未开播、封禁、轮播、需要登录、付费、地区限制、播放中断各有说明和按钮；8 秒还没出画面时提示换线路；未开播的直播间每 60 秒检查一次，开播后自动播放。
- 应用内小窗、系统画中画重新设计：小窗里能回到直播间、暂停、关闭，显示录制、重连、未开播等状态。
- 新增“离开应用时自动画中画”（默认关）。
- 屏幕常亮只在播放或缓冲时生效，设置里关掉后不再常亮。
- 本地互动体验：只有自己看得到的本地弹幕、礼物特效、体验币和等级。

### 弹幕

- 有弹幕的平台从 3.x 的 8 个增加到 28 个。
- 飞行弹幕重写：速度按时间计算，60 到 144 赫兹的屏幕上一样快；改设置不会清屏；没有空位时排队，不再直接丢掉。
- 飞行弹幕显示表情图片；弹幕帧率、弹幕字体、纯文字模式都按设置生效。
- 画面上飞过的弹幕可以点按或长按（在弹幕设置里打开）：复制、屏蔽此用户、屏蔽关键词；面板打开时弹幕停住。
- 视频暂停时弹幕跟着停。

### 录制

- 录制中心重做：九种状态一目了然，全部、进行中、等待开播、已保存、失败五个筛选带数量；已保存的可以直接播放、打开文件夹、再录一次。
- 合成 MP4 时显示进度。
- 录制的清晰度按平台实际给的标注，被限制时提示一次。
- 录制通知显示主播和计时，可以直接停止或打开录制中心；被系统停掉时会发通知，说明已录的部分已经保存。
- 录制文件可以设总大小上限，超出时自动删除最早的录像。

### 设置

- 设置分成界面、直播来源、播放、通用和网络、数据五组，可以按名字搜索设置项；平板上左右两栏。
- 新开关：“播放时匹配视频帧率”（默认开）、“离开应用时自动画中画”（默认关）、“识别剪贴板中的分享口令”（默认开）。
- 日志管理移到“设置 → 数据”。

### 系统集成

- 从其他应用分享直播间链接给纯粹直播，直接进入直播间；分享或用“打开方式”打开 M3U、TXT 文件，导入网络电视。
- 复制了别人分享的直播间口令，回到应用时提示打开对应的直播间（可以在设置里关掉）。
- 长按应用图标：搜索直播、录制中心和最近看过的两个直播间。
- 媒体通知的按钮改成中文；系统画中画窗口里有暂停和播放按钮。
- 打开后台播放或自动助眠时，先说明再申请通知权限和“忽略电池优化”；被永久拒绝时引导到系统设置。
- 新的单色通知图标和主题图标；系统启动画面和应用的启动页一致。
- Cookie 和 WebDAV 密码用 Android Keystore 加密保存（3.x 是明文）。

### 性能

- 播放只用 mpv（libmpv 0.41.0、FFmpeg 9.0.2）。
- 数据从 Hive 单文件换成 SQLite：按行写入、有事务，不会写一半；读 3.x 的数据时不改动原文件。
- 播放时按视频帧率选择屏幕刷新率（30、60 帧的视频用 60 或 120 赫兹，25、50 帧用 50 或 100 赫兹），只在能无缝切换时切换（Android 12 起）；3.x 的三档界面刷新率保留。
- 飞行弹幕的排版缓存成图，帧率取屏幕刷新率的整数分之一。
- 封面按显示尺寸解码，图片缓存有上限。

## 从 3.x 升级

- **直接覆盖安装，不要先卸载**：卸载会连同 3.x 的数据一起删掉。
- 第一次打开时自动导入 3.x 的设置、关注（含关注的分区）、观看历史、分组、屏蔽词、账号 Cookie、WebDAV 设置、录制任务和网络电视列表。导入只读取 3.x 的文件，不修改、不删除。
- niconico、YouTube 和抖音的关注改为按主播关注，启动后在后台自动换过去；暂时解析不了的保留原样，下次再试。
- 3.x 导出的备份文件可以在 4.0 恢复。保险起见，升级前可以先在 3.x 里做一次完整备份。
- 播放内核只保留 mpv，3.x 里选的其他内核不再使用。
- 3.x 的云账号登录已经停用，配置可以改用 WebDAV 或设备同步转移。

## 已知问题

- 3.x 的数据导入用模拟的 3.x 数据测试过，还没有在大量真实设备上覆盖安装验证。如果升级后发现数据不全，可以用 3.x 的备份文件恢复，并请反馈。
- 部分系统（例如 HyperOS）从最近任务里划掉应用后，可能会结束录制和后台播放。需要长时间录制时，请在系统设置里允许纯粹直播自启动和后台运行。
- 下面这些已经完成，但还没在真机上完整走过，遇到问题请反馈：多画面、网络电视、投屏、账号登录、备份和恢复、WebDAV、设备同步、扫码、应用内更新、字体下载，以及 Twitch 和 Kick。
- 平台限制：网易CC、映客、小红书、微博直播、LiveMe、TikTok LIVE 没有弹幕；小红书、微博直播只能按房间号查找，只能关注某一场直播；SOOP 的密码房暂时不能输入密码；在中国大陆访问海外平台一般需要代理。

## 以后要做的

- 卡片显示开播时间和简介、备份带上网络电视列表和多画面会话等增强。
- Windows：界面已经做好，补上 Windows 专属的功能后发布。之后是 Linux、电视（Android TV）和苹果平台。
