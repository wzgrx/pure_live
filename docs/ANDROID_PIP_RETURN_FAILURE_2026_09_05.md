## 尚未证明的原因

此前几个不同抖音房间的同一路径均通过，所以本次是已观察但尚未稳定重复的失败，不能直接归为虎牙/上游/用户设备或宣称整体模式都正常。

可能涉及恢复时的播放器源/Surface、当前源返回的尺寸、直播内容变化或短暂恢复过程。画质源开启会重置几何代次；PiP 状态监听本身只更新模式和弹幕恢复。需要补齐同一房间恢复前后的 source/session generation、尺寸与首帧时间，再判断是否发生了不必要的重开或陈旧回调。原生日志在恢复附近出现 720×1280 解码器配置，但这单独不足以证明实际播放器输出已稳定。

禁止用任意延时、强行锁定竖屏、忽略失败断言或无条件重建播放器来盖过症状。当前改为代码优先：从现有日志追踪尺寸、源代次和展示路径，先以故障夹具复现可证实的问题，再修改。无需等待手机；详见 `CODE_ONLY_PLAYER_AUDIT_2026_09_05.md`。
