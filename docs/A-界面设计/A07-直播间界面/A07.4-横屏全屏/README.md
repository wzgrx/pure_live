## 3.x 的样子和问题

**3.x 的样子**（`git show v3.2.11:lib/modules/live_play/widgets/video_player/video_controller_panel.dart`，下面省略这个文件名）

- 进入：画面下栏全屏按钮、自动方向时把手机横过来、双击画面。退出：返回、全屏按钮、Esc、双击。
- 顶栏（高 56，渐变透明 → 45% 黑，`:299-458`）：返回；Android 上紧跟时间（14 号白字）和电量（35×15 的电池框，9 号数字）；标题（16 号粗体，网络电视多一行“正在播放：节目名”）；网络电视的节目单 `Icons.assignment_outlined`；切换直播间 `Icons.swap_horiz_outlined`（带 26% 黑圆底，`:411`）；非 Android 平台时间和电量在这里；纯音频 `Remix.headphone_line/fill`；投屏 `Remix.tv_2_line`（Android）；小窗 `CustomIcons.float_window`（Android、Windows）。顺序由 `resolveTopActionLeadingSlots` / `resolveTopActionTrailingSlots`（`:42-66`）固定。
- 下栏（高 56，`:1394`）：左组 播放/暂停、刷新、“✓ 已关注”文字、弹幕开关、弹幕设置（后两个在弹幕显示打开时才有）；中间本地弹幕输入框（最宽 420，左边 ✨ 改样式，右边发送）；右组 “⚙ 原画 · 线路1”合并按钮（打开半屏两栏对话框，`:1048-1265`）、方向（移动端）、“默认比例”文字按钮（`:2068-2118`）、Windows 音量条、Windows 窗口内全屏（非真全屏时）、退出全屏。宽度不到 760 时左组去掉刷新和已关注、右组去掉画面比例（`:1439-1441`、`:1546-1578`）。
- 右侧中间锁定按钮 `Icons.lock_open_rounded / lock_rounded`（所有平台的全屏都有，`:1009`）。
- 手势：左半边上下滑调亮度、右半边调音量（中间显示黑色进度卡片，`:817-1006`），单击显示或隐藏控制栏（触屏播放中第二次点击隐藏），双击退出全屏，长按画面上的弹幕打开屏蔽操作；控制栏范围内的点击不当作点弹幕（`shouldHandleVideoSurfaceTap`）。
- 键盘（`widgets/keyboard/video_keyboard.dart`）：Esc 退出全屏、空格暂停或继续、R 刷新、上下键音量、媒体键。
- 进出全屏的方向：`widgets/video_player/video_controller.dart:1374-1396`（`enterFullScreen`）、`:1472-1494`（`applyFullscreenOrientationPolicy`：跟随画面、跟随系统、始终横屏）。

## 按钮的作用和用法

编号对应 [v4-phone-n.jpg](v4-phone-n.jpg)（手机横屏）和 [v4-desktop-n.jpg](v4-desktop-n.jpg)（电脑，多一个音量条 21）；7、8 是新加的。

| 编号 | 控件 | 怎么用 |
|---|---|---|
| 1 | 返回 | 退出全屏，回到竖屏（或窗口）。 |
| 2 | 时间、电量 | 只显示。 |
| — | 标题 | 直播间标题；网络电视时下面多一行“正在播放：节目名”，旁边多一个节目单按钮（看节目单、回看）。 |
| 3 | 切换直播间 | 打开切换直播间面板，不退出全屏（A07.13）。 |
| 4 | 纯音频 | 只播声音、不解码画面，省电省流量；再点恢复画面。 |
| 5 | 投屏（Android） | 搜索局域网里的电视或盒子，把直播投过去。 |
| 6 | 小窗 | 缩成小窗继续播（Android 画中画；桌面小窗）。 |
| 7 | 录制（新） | 和竖屏顶栏的录制按钮一样；点开录制面板（右侧）。 |
| 8 | 四宫格菜单（新） | 和竖屏一样的菜单（A07.13 之后去掉栏上已有的切换直播间、投屏、画面比例）：定时关闭、房间音量、获取直链、分享、在平台打开、本地互动。 |
| 9 | 播放 / 暂停 | 暂停或继续播放。 |
| 10 | 刷新 | 重新连接直播流，卡住或黑屏时用。 |
| 11 | 已关注 / 关注 | 关注或取消关注（取消时先确认，A07.12 改成贴着按钮的小菜单）。 |
| 12 | 弹幕开关 | 画面上的飞行弹幕开或关；弹幕列表不受影响。 |
| 13 | 弹幕设置 | 打开弹幕设置面板（右侧），边看边调。 |
| 14 | 本地弹幕输入框 | 发一条只有自己看得到的弹幕；左边的星形按钮改样式，右边发送。窄屏时收成星形按钮，点开再输入。 |
| 15、16 | 原画 ⌄、线路1 ⌄ | 换清晰度、换线路（小菜单，选完就关）。 |
| 17 | 方向（Android） | 这个直播间的画面方向：自动、横屏、竖屏；不是“自动”时图标变黄（A07.1）。 |
| 18 | 画面比例 | 默认比例、适应宽度、适应高度、填充屏幕等（小菜单）。 |
| 19 | 退出全屏 | 回到竖屏或窗口；Esc 和双击画面也可以。 |
| 20 | 锁定 | 锁定后点画面不出控制栏、手势不生效，防止误触；再点锁解开。 |
| 21 | 音量条（电脑） | 拖动调音量。 |
| — | 手势 | 左半边上下滑调亮度，右半边上下滑调音量；单击显示或隐藏控制栏；双击退出全屏；长按画面上的弹幕打开屏蔽操作。 |
| — | 键盘（电脑） | Esc 退出全屏，空格暂停或继续，R 刷新，上下键调音量，媒体键播放暂停（macOS 用 Cmd 组合键）。 |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 手机横屏、窄手机横屏（上图） |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 同一套上下栏（平板图、电脑图）；电脑上悬停显示按钮名称；电脑有音量条；投屏只有 Android |
| 电视 | 电视的直播间始终全屏，按 A17.4 的遥控器方式操作（上下键换台、左键直播间列表、右键播放设置），同样的按钮在电视的设置面板里，不出这排下栏 |
| 苹果平台差异 | iPhone 横屏避开灵动岛一侧的安全区；macOS 进入系统全屏空间，快捷键用 Cmd；其余同宽屏 |

## 待选和决定

- G1 全屏顶栏加录制和菜单：**A** 加（和竖屏顶栏一致）；B 照 v3 不加，要录制或开菜单先退出全屏。→ 选 A（2026-10-01）。
- G2 窄屏时：**A** 输入框收成星形按钮，其他按钮全在；B 窄屏不显示输入框，其他按钮全在。→ 选 A。
- G3 时间和电量的位置：**A** 所有平台都在左边，紧跟返回键；B 所有平台都在右边。→ 选 A。

## 性能要点

控制栏、飞行弹幕、画面分层重绘；时间每分钟、电量变化时才刷新，录制计时每秒只重绘角标；渐变用固定的黑色渐变，不用模糊；控制栏显示和隐藏只做位移和透明度动画；横屏时按视频帧率匹配屏幕刷新率（R02.1）。
