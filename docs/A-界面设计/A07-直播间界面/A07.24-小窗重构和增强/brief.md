# A07.24 小窗重构和增强：任务书

## 背景

用户 2026-10-14 要增强小窗，并指出不能无级拉伸、放不到和手机一样宽，要求全面重构。现在有三种小窗：应用内小窗（离开直播间后浮在其他页上）、Android 系统画中画、Windows 桌面小窗（A07.8）。A07.22 加过拖角和两指缩放，但有 0.9 的上限。

## 目标和验收

- 应用内小窗能无级缩放，横屏画面最大和屏幕一样宽；拖动不卡，松手贴边，甩出去收边。
- 单击显示 / 隐藏按钮，双击回直播间；有静音、主播名、弹幕开关、切到画中画。
- 小窗开着离开应用会进系统画中画（开着“离开应用时自动画中画”时）。
- 系统画中画从画面那块长出来，比例跟着画面变，有标题和静音按钮。
- 已有小窗测试全过，新行为都有测试；全量门禁通过。

## 现状（读代码得出）

## 3.x 基线

3.x 的应用内小窗大小固定（`resolveAppFloatingSize`）、不能缩放；按钮显示时再点就回直播间；画中画只有画面没有按钮（4.x 加了播放 / 暂停）。D-001：这些功能都保留，只是更好用。

## 范围

应用内小窗、系统画中画、它们共用的 `MiniPlayerSurface`；桌面小窗只跟着改共用的部分。不改“小窗弹幕”的 12 项设置。

## 方案和阶段

1. 几何：整宽的可用空间、去掉 0.9 上限、满宽不留边距、收边、拖动中的范围、松手的落点（纯函数，先写测试）。
2. 小窗重写：位置和大小放进 `ValueNotifier`，画面只建一次；滑动动画；记住位置。
3. 交互和按钮：单击 / 双击、静音、主播名、弹幕开关、画中画按钮。
4. 画中画：原生参数一处组装（比例、`sourceRectHint`、动作、自动进入、关无缝缩放、标题），`update` 方法；Dart 端传画面位置（物理像素）、跟随比例、布防带主人；小窗离开应用转画中画。

## 测试

几何纯函数（满宽、收边、拖动范围、落点）；小窗：拖角拉到满宽再缩回、拖动中 `MiniPlayerSurface` 不换（不重建）、松手贴边、收边和拉回、记住位置、单击 / 双击、静音、主播名、弹幕开关；画中画：标题先于进入、画面位置是画面不是整页、竖屏首帧后更新比例、静音动作、小窗按钮进入后整屏只有画面、回来回到原位置、关闭撤防。

## 风险和注意

- `sourceRectHint` 要在页面切成“只有画面”之前取，否则就是整屏。
- 画中画参数现在每次整套重设（以前只合并动作），比例和位置要一直是最新的。
- 布防交接：页面撤防不能撤掉小窗的布防（c10）。
