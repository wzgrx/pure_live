# 已知直播间直链/投屏选择器布局与生命周期审计（2026-09-12）

## 范围与基线

- 基线：`26b54c88a70e56811cee409694492ef097d85eac`。
- 范围：播放器内已知直播间的“获取直链”和“投屏”动作，共用的清晰度/线路选择器、取消与系统返回语义、阶段切换及窄屏大字号布局。
- 本批使用真实对话框 Widget、受控站点响应和剪贴板/投屏替身；没有连接手机、请求真实平台、构建安装包或发布版本。

## 稳定复现与根因

1. 旧 `SimpleDialog` 把全部清晰度/线路和取消动作放在同一个滚动内容中。320×480 / 3.0 倍英文、16 个选项时，取消动作随列表滚出视口，清晰度和线路两个阶段都不能保持固定可达；原始实现对应新增场景为 **20/22 PASS**。
2. 两个选择阶段复用同一滚动位置。滚动到底部选择 `Quality 16` 后，线路阶段仍从末端偏移开始，首个 `Line 1` 不可直接点击；独立红测为 **0/1 PASS**。
3. 每个阶段的局部 `Completer` 只由选项点击完成。系统返回、外部路由移除或 State 销毁虽然会取消外层动作，当前选择等待本身仍缺少明确完成者。

## 修订

- 选择器改为受视口约束的自有 `Dialog`：标题和选项位于弹性滚动主体，底部分隔线、SafeArea 与取消按钮固定，不随长列表滚动。
- 清晰度进入线路阶段时显式归零滚动位置；选项增加稳定键，两个阶段的首项、末项与固定取消动作可分别验证。
- 当前阶段保存唯一取消回调；按钮取消、系统返回、路由移除和 `dispose` 都会完成等待并释放单次动作门禁。
- 保留既有根 Navigator 路由所有权、同房间/同来源校验、跨动作 single-flight、网络取消/超时、剪贴板完成确认及投屏子路由语义。
