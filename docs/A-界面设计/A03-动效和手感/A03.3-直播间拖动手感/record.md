说明 1（越界回弹 0.42 s）：`AppMotion.overscrollSpring` 是 1/250/1（周期 0.4 s，照 HyperOS），临界阻尼从静止出发到离目标 1% 要 0.42 s，按 Flutter 严格容差（1 个物理像素）是 0.57 s。任务书写“约 0.4 秒”，测试按 ≤0.45 s。要更快得改 `live_ui` 的常量，不在本任务范围。

说明 2（慢松手的第一帧比例）：和 A03.2 说明 2 一样，弹簧起始速度就是手指速度，但离目标远近不同，慢速松手时弹簧的拉力占主导（换台拉 60 dp 慢松手回位、慢拉面板吸档，第一帧都会被拉回或加速），不是断速。快甩时比例都在 0.8～1.25。

说明 3（快甩到很近的档位会“贴住”）：`ReleaseSpringSimulation` 到目标就停、不越过（A03.2 定的写法）。手指很快、档位又很近时（例如从中间档往下快甩 75 dp，最低档只剩 57 dp），面板几帧就到档位并停住，0.04 s。这是“夹住目标不过冲”的直接结果。

## 根因

- **换台松手顿一下、要等动画完才连新房间**：`_settleTo` 用 `AnimationController.forward(from: 0)` 走 220 ms easeOutCubic，从 0 速起步，第一帧还是时间 0（重复松手前那一帧）；`onSwitch` 在 `_finish`（动画结束）里才调。动画控制器在 `RoomSwipeStage` 里，而换台会让页面按 `_roomEpoch` 重建整个直播间（舞台也换新），所以只能等动画完再换。
- **到头硬停**：`update` 里没有邻居的一边 `math.max/min(value, 0)`。
- **三档面板拖动每帧重建播放器**：`_drag` 每次移动 `setState` 整个布局，`build` 里每次 `widget.player(covered)`，页面那边每次 `new RoomPlayer(...)`，于是 `RoomPlayer` 每帧 `didUpdateWidget` + `build`（测试量到 2 秒 226 次）。松手 `AnimatedPositioned` 180 ms 曲线，速度丢掉。
- **起拖跳**：把手 `DragStartBehavior.down`，越过阈值那一帧把按下以来的全部位移（≥18 dp）一次给出。
- **详情把手难拖、不跟手**：把手只有 20 高；拖动只累加 `_pull`，面板本身不动，拉够 64 或 >600 dp/s 才直接关。
- **亮度音量**：`_onDragUpdate` 每次移动都 `unawaited(_apply(...))`，每次都走一次平台通道（触摸 240/480 Hz 时一帧 2～4 次）。
- **预览**：封面默认 `BoxFit.cover` 铺满竖长的屏幕。

## S11 结论（触摸重采样）

没有开，代码没改。理由：Flutter 的 `GestureBinding.resamplingEnabled` 把触摸点按帧时间重采样，默认 `samplingOffset` 是 −38 ms（这个 Flutter 版本 `gestures/binding.dart:224`），也就是画面跟着 38 ms 前的手指位置走，1:1 跟手会明显“拖后”；它解决的是触摸采样率和刷新率不成整数倍时每帧事件数不均匀造成的抖动，K90 触摸 240/480 Hz、屏幕 120 Hz 是整数倍，收益很小。要真正判断得在真机上开着、关着各录一段慢动作对比（本次不能接真机）；想试的话在 `main` 里设 `GestureBinding.instance.resamplingEnabled = true`，再把 `samplingOffset` 调到 −8 ms 左右比较。

## 需要维护者决定的

1. **详情把手行从 20 高变成 48 高**，面板内容整体下移 28 dp（任务书要求 48 dp 热区；条本身还是 32×4）。如果觉得内容下移不好，可以改成把手行保持 20 高、热区往下盖住列表顶部 28 dp，但那样会挡住主播那一行（关注按钮）的点按，所以没这么做。
2. **松手当帧换台的副作用**：页面换台时立刻按新房间重建播放器（`_roomEpoch`），所以松手后正在滑出去的那一半显示的是新房间的画面层（同一个播放会话，旧房间停下前可能还是旧画面，之后是加载中），不再是旧房间完整的画面。要完全保住旧画面，得让页面在动画结束前不换播放器组件、只先开始连接，这要改换台流程（A07.3 的“前一个停了才开下一个”），不在本任务。
3. **三档面板快甩选档**：3.x 只按位置吸最近一档；现在快甩（≥700 dp/s）去甩的方向的下一档。觉得不对可以改回只按位置（`releaseStop` 一处）。
4. **三档面板最高档往上的橡皮筋**是本任务加的（任务书阶段 2 只写了换台；调研报告“面板：越界加阻尼”）。换台的橡皮筋按任务书做了，但列表首尾相接，真机上碰不到。
