# T18d.3 电视音乐：设计（第 1 版）

- 状态：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 范围：电视“音乐”模式的全部界面：导航轨五项（正在播放、搜索、歌单、推荐、我的）及其标签（推荐：每日、动态、排行；我的：关注、UP主、最近、云端）、迷你播放条、播放器（歌词、控制栏、音质、播放内核、队列、设置）、歌单和歌单详情、同步的哔哩哔哩收藏夹、曲目列表（专辑详情）、导入歌单和各种对话框；见下面的界面清点表
- 对应：[TASKS.md](../../../TASKS.md)、[inventory/UI.md](../../../inventory/UI.md#t18d3)、[inventory/UI_FILES.md](../../../inventory/UI_FILES.md#t18d3)；依赖 T18a.3（外壳）、T18a.2（设计系统）；卡片、控制栏、状态页、小菜单、对话框的写法在 [T18d.2](../T18d.2/README.md) 定
- 基线：pure_live_TV（`~/ref/pure_live_TV/lib/modules/music`），手机版没有这个功能；v4 只有逻辑包 `packages/live_vod`
- 评审页：源文件 [page.json](page.json)，效果图源文件 [src/gen.py](src/gen.py)（公共部分 [../U.15f/src/tvkit.py](../T18d.2/src/tvkit.py)）
- 图片：还原图按 pure_live_TV 代码和默认深色主题、1920 设计稿画；新设计按计划书 5.5 节画在逻辑 960×540。封面和头像是示意图片，歌名、歌词、UP 名都是虚构的

## pure_live_TV 的样子（按代码）

- **外壳**（`features/home/home_page.dart:160-184`、`music_section.dart`）：导航轨五项 queue_music / search / playlist_add_check / explore_outlined / person_outline（正在播放、搜索、歌单、推荐、我的）；一组里多于一项时顶上是标签栏（每日、动态、排行；关注、UP主、最近、云端，`music_section.dart:12-18`）；内容区下面常驻迷你播放条（`home_page.dart:224-236`）。
- **迷你播放条**（`widgets/music_mini_bar.dart`）：卡片色圆角 20、主色细边；UP 头像 40、歌名 t18 700、UP t14、“01:12 / 04:48”；喜欢、加入歌单、上一首、播放 / 暂停（大一号）、下一首；底下 6 高进度条。
- **正在播放**（`pages/playback/music_now_playing_queue_widgets.dart`）：“正在播放（12）”t24；队列来自同一 UP 时有来源卡片（头像 80、标题 t20、UP 和“已关注”、右边封面，`widgets/now_playing_source_card.dart`）；歌曲行（`widgets/music_song_row.dart`）：序号或波形图标、封面 132×120、歌名 t18 600、“专辑 · UP”和“P1/12 · 时长”两行小图标；正在播的一行主色底；长按或 → 打开歌曲菜单。
- **播放器**（`pages/playback/music_player_page.dart`）：黑底；纯音频时左边封面 300、歌名 t26、UP，右边歌词（当前行 t26 700 白，其他 t20 60% 白，`widgets/player_now_playing_view.dart:205-273`），没有歌词时只有封面；不是纯音频时是视频画面。顶部一行音乐图标 + 歌名 + P、画质、UP；控制栏（`widgets/player_control_bar_parts.dart`）黑 72% 圆角 24：进度条 + 居中换行的小胶囊：上一首、暂停 / 播放、下一首、画质（例如 1080P，有选项时才有）、显示画面 / 纯音频、正在播放、选择歌词、播放内核（Mpv播放器）、设置；收起时 ←→ 快退快进、↑↓ 上一首 / 下一首，确认呼出；控制栏显示时 ↓ 进入进度条；返回键收起控制栏、再按离开页面，音乐继续播。
- **音质、播放内核**：控制条里往上展开一个列表（标题 t20、选项 t16，当前项加勾），↑↓ 选、← 关（`:417-450`）。
- **队列面板**（`widgets/player_queue_panel.dart`）：右侧黑 88%，标题“正在播放（12）”+ 清空（`playlist_remove`）、播放模式（图标循环：`playlist_play` / `repeat_one` / `shuffle`）、关闭；行高 88，选中整行填主色；底部“↑↓ 选择 · OK 确认 · ← 关闭”。
- **歌单**（`pages/playlist/music_fav_folders_page.dart`）：“歌单（7）”+ 导入歌单、新建歌单、全部同步；自建歌单 6 列（宽高比 1.5，封面 + 名字，喜欢的歌曲带心形、置顶的带图钉、右下首数）；“同步歌单（3）”4 列收藏夹卡片（“同步于 9/30”或“尚未同步”）。
- **歌单详情**（`music_user_playlist_detail_page.dart`）：“（18）”+ 多选、正在播放、播放全部；歌曲行；长按是它自己的菜单（移出歌单、置顶、清除默认歌词，`:300-360`）。
- **每日**（`pages/discover/music_daily_page.dart`）：选择收藏夹按钮、重新生成；音乐卡片网格（`widgets/music_video_card.dart`：圆角 18、头像 40、标题 t16）；长按“重新推荐”。
- **对话框**：TvDialog（卡片色、主色边、标题 t32，`core/dialog/tv_dialog.dart`）；歌曲菜单是选项行加图标（删除项红色），“取消”在右下。

## 按钮的作用和用法

见对比页三节（正在播放 1–15、播放器 1–11、其他页）。遥控器按键：

| 键 | 用法 |
|---|---|
| 确认 | 播放这一首、打开歌单 / 卡片；播放器里呼出控制栏 |
| 长按确认 / 菜单键 / →（歌曲行，照旧） | 歌曲菜单；歌单、收藏夹、推荐卡片、云端历史各自的菜单 |
| 返回 | 小菜单 → 面板 → 控制栏 → 离开播放器（音乐继续播）；子页面回上一页 |
| 上下左右 | 移动焦点；播放器控制栏收起时 ←→ 快退快进、↑↓ 上一首 / 下一首；控制栏显示时 ↓ 进度条、↑ 队列 |
| 媒体键 | 播放 / 暂停、上一首、下一首 |

## 焦点路线

| 页面 | 默认焦点 | 方向键 |
|---|---|---|
| 正在播放 | 正在播的一首（照旧） | ↑ 列表循环、清空；↓ 迷你播放条；← 导航轨 |
| 歌单 | 第一个歌单 | ↑ 导入、新建、全部同步；↓ 收藏夹、迷你播放条 |
| 歌单详情、收藏夹详情、曲目列表 | 播放全部 | ↓ 歌曲 |
| 推荐、我的、搜索结果 | 上次停留的卡片 | ↑ 标签栏，网格按行列记忆 |
| 播放器 | 控制栏收起；确认后在播放 / 暂停 | ←→ 按钮行，↓ 进度条，↑ 队列面板 |
| 对话框、小菜单 | 第一项（加入歌单：第一个还没加入的） | ↑↓，返回键关闭 |
