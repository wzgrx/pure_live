## 要做的

- c1 先出设计（按 `docs/ui/PROCESS.md` 第 1～4 步，产出放 `docs/ui/compare/U.2a2/`：README、`src/gen.py`、效果图、编号图、`page.json`、导出的章节图）：未录、等待开播、准备中、录制中、重连中、合成中、失败七种状态，在直播间顶栏（亮背景页）、画面上（暗）、全屏顶栏、录制中心、状态卡、通知图标里各是什么样。方向：**未录单色无红**（2dp 圆环 + 中心小实心圆，和其他图标同色）；**录制中红色实心圆底 + 白色圆角方块**，外圈慢慢呼吸（减少动态效果时常亮），全屏顶栏有空间时右边加 mm:ss；红色只给真正在写文件的 running；等待开播：圆环右下角小钟；准备中、合成中：中性色环形进度；重连中：琥珀色虚线圆环。
- c2 实现：`packages/live_ui` 的 `RecordGlyph`、`RecordingBadge` 扩成这些状态；`features/live_play/buttons/record_button.dart`、`player/recording_badge.dart`、`shared/record/record_status_card.dart`、录制中心按 `task.status` 映射，不再用 `RecordStatus.isActive` 二分；角标文字按状态写“录制中 / 重连中 / 合成中”。
- c3 Android 通知小图标（录制）跟着新图形（单色）。

## 验收

- 只看图标就能分出“没在录”和“在录”；合成、准备时不再显示红色“录制中”。
- 测试：每种状态的图标、颜色和文字；减少动态效果时不呼吸。
