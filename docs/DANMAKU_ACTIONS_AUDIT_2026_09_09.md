## 三个根因

| 复现 | 第一个错误状态 | 修订 |
| --- | --- | --- |
| 编辑关键词后取消/确认报 TextEditingController used after disposed | showDialog 的结果 Future 完成时，退出动画的 TextField 仍挂载，方法立即 dispose 草稿控制器 | 私有 StatefulWidget 持有控制器，仅随弹窗子树 dispose 释放；没有延长任意计时或屏蔽异常 |
| 320×480、2 倍字体、长消息使中英文关键词动作不命中 | 菜单 Wrap 没有滚动能力，完整消息把后续动作推至可交互区域之外 | 保留全文和字号，外加 SingleChildScrollView；关键词弹窗内容也可滚动 |
| 打开菜单后原消息行卸载，再点关键词动作报失效 BuildContext | 菜单回调保留旧行 context，调用 showDialog 时行已不存在 | 使用仍挂载的菜单 context 发起弹窗，不依赖旧行或全局 Get.context |

这三处在冻结上游 `c6c9bd70aedc503c003110dae10a83ad0bb891d8` 中都有相同实现，来源为 **upstream-existing**。原实现提交 133466e0 是该冻结上游的祖先，已核验；基线为 `4b2a1b3ec428afa47401d7ba0576bd44f76df841`，没有同步/合并上游。源快照和具体表达式记录在忽略目录的 `frozen-upstream-actions.dart.txt` 与 `provenance.json`。

没有改变关键词 trim/空值/40 字符 UI 限制、已保存字段、用户匹配规则、直播消息计数或暂停状态。复制仍包含用户名和完整消息；仅明确确认才添加关键词并发送匹配删除通知。菜单前的原行生命周期隔离用确定性卸载模拟，不伪报为已在高消息量实机中复现相同时间序列。
