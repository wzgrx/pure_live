## 目标

- 有数字：K90 上同一个直播间播 30 分钟，4.x 三档刷新率、纯音频、后台锁屏各耗多少电、多热，和 3.x 省电档比。
- 结论：4.x 省电档（默认）不比 3.x 省电档更耗电；均衡档、最高档的额外代价有多大，写进记录，作为设置说明和 D-010 的依据。
- 测出明显的浪费（例如纯音频和视频耗电差不多、后台锁屏仍在高耗电）时，开到对应的组修。

## 方案

- c1 统一条件：K90 无线 adb（不插线、不充电）、亮度固定 50%（关自动亮度）、音量 30%、Wi-Fi、关掉其他应用、手机降到室温再开始；同一个房间（选一个 24 小时轮播或长时间直播的哔哩哔哩房间，码率稳定），同一个清晰度。
- c2 每一组：`adb shell dumpsys batterystats --reset` → 播放 30 分钟（不碰屏幕）→ 记 `dumpsys battery` 电量差、`dumpsys batterystats --charged com.mystyle.purelive.v4dev`（应用的估算耗电 mAh）、`dumpsys thermalservice` 的皮肤温度；每组测两次。
- c3 组：4.x 省电、均衡、最高（帧率匹配开）；4.x 省电 + 帧率匹配关；4.x 纯音频（屏幕亮着）；4.x 后台播放锁屏；（可选）弹幕多的房间省电档；3.x 省电（v3bench 包）。
- c4 结论和去向：省电档 > 3.x 省电档 5% 以上时找原因（刷新率投票、弹幕帧率、渲染）并在对应组开任务；纯音频和视频差 <15% 时在 G05 提议“纯音频超过一段时间改 `vid=no`”；把均衡、最高档的代价写进记录，交 A11.1 决定设置说明要不要提。
