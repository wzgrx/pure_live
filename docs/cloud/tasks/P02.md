## 要做的

- c1 维护者已选报告里的**方案 A**：所有能下拉刷新的列表（热门、分区房间、关注、历史、分区列表、WebDAV、备份）照 v3 用两端回弹（Bouncing 系）、不画拉伸、经典下拉头；其他列表（设置、详情等）保持 Android 的 Clamping + 拉伸。理由：v3 用户的习惯（UI_PLAN 原则 1），国内系统应用也是回弹。v3 关注页原来是 Material 圆圈，这次为了一致也换成经典头，记录里写明。
- c2 在 `packages/live_ui` 做一个下拉刷新组件（建议 `AppRefreshView`）：经典头（向下箭头 → 松手前箭头朝上 → 刷新中小转圈 → 完成或失败），文字用 U.1c c19 改对后的（下拉刷新 / 松开刷新 / 正在刷新... / 刷新成功 / 刷新失败，下面一行“上次刷新时间”）；触发距离 = 头部高度；刷新期间头部停在顶部，完成后弹簧收回（质量 1、刚度 500、阻尼比 1）。不加新的第三方依赖；行为照 v3 用的 easy_refresh 3.5.1（可以 `dart pub cache add easy_refresh --version 3.5.1` 下来看 `lib/src/physics/scroll_physics.dart`）。上拉加载更多照 v3（到底自动加载，“没有更多数据了”）。
- c3 替换全部 `RefreshIndicator`：`shared/rooms/room_grid.dart:666,746`、`features/favorite/favorite_page.dart:549`、`features/history/history_page.dart:415`、`features/areas/platform_areas_view.dart:262`、`features/web_dav/web_dav_page.dart:515,535`、`features/backup/backup_page.dart:294`。
- c4 S10：`features/search/search_widgets.dart:100` 的 `overscroll:false` 去掉，横条和其他横条一样。
- c5 平板和电脑布局照旧（电脑没有下拉，用刷新按钮）。

## 验收

- 所有能下拉刷新的列表手感一致、和 v3 一样两端回弹；下拉头文字正确。
- 测试：固定 500/3000/6000 dp/s 的滑行距离和时长（和报告 2.2 节表里 v3 一列误差 <1%）；下拉位移随手指距离单调变沉、到头部高度触发、刷新期间头部停住、完成后 ≤400 ms 收回；文字和状态。

## 真机上看的（写进记录，维护者在 K90 上看）

- 热门页快速上滑、到底、到顶：两端回弹，不出现拉伸。
- 下拉热门：箭头 → 松开刷新 → 转圈 → 刷新成功，头部停住再收回。
- 设置页到头仍然是拉伸（不变）。
