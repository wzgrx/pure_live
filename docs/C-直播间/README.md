# C 直播间

直播间的功能和逻辑：进房、房间控制器、播放接入、小窗和后台播放、菜单里的工具。界面在 A07。

排在界面设计（A）之后的第一个功能组：直播间是用户打开应用的主要目的，3.x 里它一个模块就有 67 个文件、18475 行（`lib/modules/live_play/`）；4.x 直播间的界面任务（A07）都建立在这一组的房间逻辑上。

## 范围

- 管什么：
  - **进房和房间状态**（C01）：取详情、合并卡片上的信息、选默认清晰度、取地址、打开播放会话、记观看历史、更新关注快照；房间阶段 `RoomStage`；每 60 秒刷新详情（开播自动播放、弹幕结束后重连）；重试；连弹幕、拉醒目留言、人数。代码 `apps/pure_live/lib/features/live_play/logic/room_controller.dart`。
  - **一个房间拥有的东西和它们的生命周期**（C01）：`RoomRuntime`（控制器、播放会话、断流监视、后台策略、方向选择）、`PlayerStandby`（离开直播间时把播放器留给下一个房间）、原地换台的列表 `RoomPlaylist`，以及页面怎么建、怎么交接、怎么拆（`live_play_page.dart`）。
  - **小窗、画中画、后台**（C02）：应用内悬浮小窗 `FloatingRoom`、系统画中画的 Dart 一侧（`PictureInPicture`、`RoomMiniWindow`、离开应用时自动画中画）、离开应用 1.5 秒后暂停和后台播放（唤醒锁、Wi-Fi 锁、媒体通知，`RoomBackgroundPolicy`）。
  - **直播间工具**（C03）：右上角菜单里的定时关闭（含自动助眠）、房间音量、画面比例、获取直链、投屏入口、分享、在平台 App 打开（`externalRoomTarget`）、在新窗口播放、本地互动入口；Android 返回的接管（`RoomBackChannel`）。
- 不管什么：
  - 看得见的样子：布局、控制层、面板、小菜单、状态画面、切换直播间面板归 [A07](../A-界面设计/A07-直播间界面/README.md)；弹幕列表、醒目留言、弹幕设置页归 A08；通知和画中画窗口的外观归 A14。这里只管行为和数据。
  - 播放会话本身（打开、恢复、换线、卡住检测、空闲 45 秒释放引擎）归 G02（`packages/live_player`）；竖屏画面比例预判归 G04；纯音频和音量的播放层归 G05。
  - 弹幕协议、过滤、飞行弹幕引擎归 D；录制按钮背后的录制归 H；节目单和回看规则归 L01；DLNA 协议归 N02（`packages/live_cast`）；多画面归 N01。
  - Android 原生一侧：`MainActivity.kt` 的 `pure_live/pip`、`pure_live/predictive_back`、`pure_live/background_playback`、`pure_live/device_controls` 通道归 [O](../O-Android系统集成/README.md)；播放时的刷新率（`logic/room_refresh_rate.dart`）归 R02。
  - 电视的直播间（`apps/pure_live/lib/tv/room/`）归 X03、A17.4。

## 风险和注意

- **异步和换房间**：进房、刷新、换清晰度都是异步的，晚到的回答必须丢掉：`LiveRoomController.load` 每次加 `_epoch`（`logic/room_controller.dart:362`），回答到了先查 `_current(epoch)`（`:396`）；原地换台时旧房间停完才交出播放器（`live_play_page.dart:360-397` 的 `_handover`）。改这些地方要先写竞态测试。
- **后台**：直播间页面在后台不会被销毁，定时器照跑。定时刷新每 60 秒运行（`room_controller.dart:325-327`），未开播的房间在后台开播时 `refreshDetail` 直接 `load()` 开始播放（`:775-777`），而 `RoomBackgroundPolicy` 只在离开应用的那一刻决定是否暂停（`logic/background_playback.dart:472-490`）。这是读代码得出的，还没在真机上确认，归 C01.3。
- **只有 Android 有的**：画中画、媒体通知、返回接管、亮度和音量手势都靠 `MainActivity.kt` 的通道（O 组）；Dart 一侧改了要在 K90 上看，单元测试只测到通道。
- **规则**：3.x 的设置键名和含义不变（D-018：`useHardStopOnExit`、`portraitPipFollowSource`、`enableScreenKeepOn`、房间音量的 `room_vol_<平台>_<房间>` 等）；暂停后单击画面不继续播放（D-012）；在直播间里取消关注用贴着按钮的小菜单（D-021）；切换直播间默认小卡片网格（D-022）；横屏全屏按传感器翻转（D-023）。[specs/UI.md](../specs/UI.md) 附录 A 第 7～12、16、18 条（返回链、应用内小窗、切画质不重建播放器、进房不改设备音量、强制横屏后恢复竖屏、默认全屏、空格和媒体键、定时关闭）都有测试，改动时一起跑。测试里的定时器至少 1 秒，不访问真实平台（D-017）。
