## 目标

录完的直播现在点“播放”是交给系统里的其他应用打开（和 3.x 一样）。提议：在应用里直接放：按房间列出录像，记住每个文件看到哪，倍速、±10 秒、选集、全屏、小窗，控件和手势和直播间一样。

本文件是**评估初稿**，由用户决定做不做（D-026）。

## 方案（评估初稿）

- c1：录制中心和直播间录制面板的“播放”打开应用内播放页；长按或菜单里保留“用其他应用打开”。
- c2：播放页：画面、进度条（拖动、±10 秒）、倍速、同一房间的录像列表（选集）、全屏；每个文件看到的位置存本地，再打开接着放。
- c3：小窗、画中画沿用直播间的（A07.8、O 组），小窗里有进度条。
- 要出效果图和评审页（PROCESS 第 4.1 节）；规模大，分阶段。
