## v3 的样子（`v3.2.11`）

**启动页**（`lib/modules/splash/splash_screen.dart`、`lib/routes/app_pages.dart:188-235`）

- 设置“启动动画”（`showSplashPage`，默认开，`app_settings_controller.dart:52`；开关在 `general_settings_page.dart:64-69`，说明“启动时显示 Logo”）开着时，应用从启动页开始（`main.dart:197`），否则直接进首页。
- 背景：左上到右下的固定渐变；浅色 `#E0F7FA → #B2EBF2 → #80DEEA`（青色），深色 `#0D1B2A → #1B263B → #141E27`（`app_pages.dart:196-205`）。
- 正中一列（`splash_screen.dart:86-111`）：应用图标 `assets/icons/icon.png`（宽 150）；紧接着“欢迎使用”（20 号粗体，浅色 54% 黑、深色 70% 白，`app_pages.dart:213-216`）；空 30；进度条（宽 200，白色，底轨 30% 白，来回跑，`:124-127`）；空 30。
- 动画：图标和文字一起淡入（0→1，`easeIn`）并放大（0.8→1，`easeOutBack`，会先超过 1 再回来），共 2 秒（`splash_screen.dart:50-58`）。
- 1 秒后离开：再最多等 0.35 秒让关注核验先跑完，然后换成首页（`app_pages.dart:218-233`）。
- 宽屏同样居中，没有别的排法。

**启动后的提示**

- 口令导入：应用第一帧后、以及每次回到前台 1 秒后读剪贴板，有分享口令就等到离开启动页，弹“分享”对话框（`desktop_manager.dart:595-650`，`MyApp` 在所有平台都用这一段，`main.dart:53`）。
- 新版本：首页第一帧后 2 秒检查，有新版就弹“检查更新”对话框，挂在最外层导航上（`useRootNavigator: true`，`home_page.dart:99-104`、`:198-216`）。
- 两个提示之间没有协调。

## v3 的问题

| 编号 | 问题 | 位置 |
|---|---|---|
| S1 | 淡入动画 2 秒，可是 1 秒（最多 1.35 秒）就离开：离开时图标和“欢迎使用”只到 32%～52% 不透明，用户每次看到的都是半透明的 Logo | `splash_screen.dart:50-58`；`app_pages.dart:233` |
| S2 | 背景是固定青色渐变，不跟用户的主题色（默认蓝）；图标的青色部分在青色背景上不显 | `app_pages.dart:196-205` |
| S3 | 浅色时进度条是白色、底轨 30% 白，在浅青背景上几乎看不见 | `splash_screen.dart:124-127` |
| S4 | 图标和“欢迎使用”之间没有间距，文字贴着图标 | `splash_screen.dart:89-106` |
| S5 | 两个提示会叠在一起：剪贴板里有分享口令时，离开启动页就弹“分享”，2 秒后“检查更新”再盖在上面（背景暗两层，下面的对话框看不见） | `desktop_manager.dart:595-599`、`:631-650`；`home_page.dart:99-104`、`:208-212` |
| S6 | “检查更新”不管当时在哪一页：启动后很快点进直播间（或者从口令、命令行直接进房），它会盖在播放画面上 | `home_page.dart:208-212` |
| S7 | Android 系统启动画面是白底（深色是黑底），接着换成青色渐变，颜色跳一下 | `android/app/src/main/res/drawable-v21/launch_background.xml`、`values/styles.xml` |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 竖屏图；状态栏透明，图标颜色跟深浅色。 |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 同一个页面居中（宽屏图）；电脑上点一下或按任意键都可以跳过；Windows 标题栏在 A16.1。 |
| 电视 | 不适用：电视有自己的启动流程（协议页、启动解锁，在 A17.2）。 |
| 苹果平台差异 | iOS 的系统启动画面（LaunchScreen）用同样的底色和图标（A14.1）；macOS 同 Windows。 |

## 待选（建议 A）

- K1 启动页背景：A 跟主题（表面色带一点主色）；B 照 v3 固定青色渐变，只把进度条改成看得见的颜色。
- K2 新版本提示什么时候弹：A 排在口令导入后面，只在首页弹（在直播间等回到首页）；B 照 v3 2 秒后就弹，只保证不叠在别的对话框上。

## 拿不准的地方

- v3 图里的进度条位置是随手取的一帧（它一直来回跑）。
- 启动页换成首页时的过渡（v3 用 `Get.offAllNamed`，`app_pages.dart:231`）没有在真机上看，新设计照 v3。
- 系统启动画面的具体做法（`android:windowSplashScreenBackground`、iOS LaunchScreen）在 A14.1 定。
