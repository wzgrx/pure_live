- 准备：每次点按前确认前台是测试包（D-019）；测完把系统设置改回原样（电池优化、自启动、省电策略）。看前台服务：`adb shell dumpsys activity services com.mystyle.purelive.v4dev | grep -iE "AudioService|isForeground"`；看锁：`adb shell dumpsys power | grep -i purelive`、`adb shell dumpsys wifi | grep -i purelive`；断网用 `adb shell svc wifi disable`、`svc data disable`（网络 ADB 会断，用 USB 或先连好再定时恢复）。
