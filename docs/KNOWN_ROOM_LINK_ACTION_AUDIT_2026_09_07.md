- 新 KnownRoomLinkDialog 同一 root Navigator 共用单动作门禁，首次异步等待前占用，菜单/控制栏和复制/投屏互相覆盖；退出释放。
- 三处调用提供来源 context 和当前房间/控制器存活校验。动作持有来源 Route，控制栏隐藏不直接等同播放器页面退出。

- 网络和复制等待有 12 秒期限；选择及接收器交互不自动倒计时。取消隔离共享站点请求的迟到结果，不关闭其他页面使用的 HTTP 客户端。
