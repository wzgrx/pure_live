# 网页搜索生命周期、返回语义与状态布局审计（2026-09-12）

## 范围与基线

- 基线：`7bb6a4cbd3ea3442cf424fa8b87295f166991ab1`。
- 范围：搜索结果页进入网页搜索后的启动参数、WebView 所有权、浏览历史返回、直播链接识别确认、加载错误/重试、外部浏览器回落、日志及发布版调试入口。
- 本轮只做源码审查、确定性单元/Widget 回归、静态分析与仓库审计；未连接手机、打开真实平台网页、修改 Cookie、构建安装包或发布版本。

## 复查发现

1. 路由参数直接强制转换为 `Map`、`String`，缺失、类型错误、非 HTTP(S) 或带凭据地址会在页面初始化/加载阶段抛异常。
2. 顶栏返回只处理浏览器历史，Android/Windows 系统返回直接退出路由；返回、关闭和确认直播间各自重复停止/销毁 WebView，并依赖固定 500 毫秒等待和全局路由上下文。
3. 直播链接确认期间的新地址被直接丢弃；页面退出后迟到确认仍可能打开直播间，同一时刻的返回/关闭也没有任务合并。
4. 控制器已有 HTTP/加载错误回调但页面未接线，WebView 加载中、主文档失败和重试均没有可见状态；外部浏览器连续点击会重复发起，异常也会从回调逸出。
5. WebView 重建直接覆盖旧控制器句柄；页面日志记录完整 URL、响应头和网页控制台文本，查询词、会话参数或站点信息可能进入应用日志。
6. 开发者工具按钮和 `isInspectable` 在发布版始终启用；非 HTTP(S) 导航也按普通网页放行。

## 修订

- 新增严格启动请求解析，只接受无内嵌凭据的 HTTP(S) 地址与非空平台 ID；非法输入进入可关闭的双语终态，不创建 WebView。
- 用可替换浏览器端口统一加载、重试、历史返回、停止与销毁；WebView 重建先释放旧实例，关闭/返回任务合并，退出代次隔离迟到加载、外部打开及确认结果。
- 页面接入主文档 HTTP/加载错误和进度，增加可滚动错误说明与重试；系统返回、顶栏返回共用“先浏览器历史、后退出页面”的 `PopScope` 语义。
- 房间识别改为单一确认队列：当前对话框期间只保留最新目标，取消后继续处理；确认前后核对生命周期，退出后不再打开房间。
- 外部浏览器动作合并并显示进行中状态，失败/异常统一提示；320×480、3.0 倍英文下说明、按钮和非法地址终态均可滚动到达。
- 发布版隐藏开发者工具并关闭 WebView 可检查标记；非 HTTP(S) 跳转终止。日志只保留 scheme/host、平台和错误类别，不记录查询、响应头、房间 ID 或网页控制台正文。
