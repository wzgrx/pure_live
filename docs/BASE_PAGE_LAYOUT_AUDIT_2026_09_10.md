## 为什么没有把共用页直接改成一个外层列表

BasePageView 的 contentBuilder 可以返回 TabBarView、独立列表或自己拥有刷新的嵌套页面。直接包进另一份统一滚动列表会改变高度约束、分页和所有权。这里保留原正文、控制器与刷新边界，只给提示区设置独立、非 primary 的滚动区域；普通短提示按自然高度显示，没有提示时占用 0 高度。

只读检查实际调用点：热门、分类、分类房间、关注和用户管理的自定义空视图均最终使用 AppStatusView/EmptyView，没有依赖有限高度 Expanded 的自定义空状态。LiveDirectoryNotice 当前用于花椒、映客、克拉克拉、OPENREC、TTingLive、小红书；组合测试是共用 UI 合同压力输入，不代表小红书实际目录返回了房间列表。
