## 修订与兼容边界

- 剪贴板识别和手动解析共用 HTTP(S) URI 提取；支持无协议 www 与分享末尾标点，先分离完整 URL，再核对主机及路径，不从未知主机的查询参数里提取第二个嵌套链接。
- 排除 userinfo、非 HTTP(S)、空主机/路径与畸形路径编码。主机按完整根域或点分隔子域判断；查询/片段不参与房间 ID。
- 按文本顺序寻找首个可解析目标，无关链接不再遮蔽后续房间。优先复用 WebSearchRoomParser 的平台规则及保留导航词检查；手动工具继续保留斗鱼/CC 别名、快手 cn、SOOP com 等兼容入口。
- 中英文支持说明补上 AcFun 房间格式。示例地址只是格式，不是在线房间证据。
- 抖音 www/video 与 webcast reflow 用例只锁定已有 ID 提取行为；内部 room_id 与 web_rid 的真实转换、视频页是否具备直播身份仍待接口证据，不据此宣称播放成功。
- 未修改播放/投屏选择器、直播平台适配器、存储字段、迁移或版本。搜索解析器仅提取其原有 ID 校验为公共方法，原搜索规则保持。
