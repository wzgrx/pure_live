# 文档的版本

文档结构有变化时升版本：**大版本**（v1 → v2）是分组、编号或目录结构变了；**小版本**（v1 → v1.1）是加了组或子分类、改了做法里的规则。每个版本打一个 git 标签（`docs-v1` 这样）。日常加任务、改状态不算版本变化。

## v1（2026-10-03，标签 `docs-v1`）

- 20 组改成按优先级排的字母（A～Z，跳过 B、F、M、P、T、U），文件夹用“字母-中文名”，例如 `A-界面设计/A07-直播间界面/A07.13-切换直播间面板/`。
- **界面设计单独成组、排第一**（A）：以前分散在各组的界面设计和它们的实现都集中到这里，共 18 个子分类。
- 新增 **V 需求和反馈**（新功能提议、用户反馈和 issue、审查和调研、不做的）、**W 上游借鉴**（定期对照、参考仓库）、**Z07 定期维护**；三个客户端组合并为 **X 多端客户端**。
- 登记表加 `from`（来源）、`to`（去向）字段；门禁检查文件夹名和登记表一致。
- 做法里加了新功能怎么提、上游怎么借鉴、维护怎么做、文档怎么升版本。
- 旧编号对照见 [MAPPING.md](MAPPING.md)（v0 的 T00～T19 也在里面）。
