## 已接入

- `ttinglive` 注册进平台全集、首页排序、单站点工厂和录制资格检查；显示 FLEX TV (TTingLive)。当前为 **18 个直播站点 + IPTV、9 组参考平台未注册**。
- 首页/分区共用真实 LiveDirectoryController；主目录明确为有限公开首页快照，首个响应结束分页，不从卡片数推断下一页或声称全站目录。目录保留频道 ID、标题和 playerCount，不虚构响应缺失的 owner 数字 ID。
- 精确频道号或两个品牌的频道直播链接查询 profile，支持已下播频道，不声称昵称/关键词搜索。搜索单平台与聚合说明均标注该边界；不存在对应网页关键词搜索入口。关键词输入不发请求，不把它记成平台网络故障。
- 收藏刷新只请求 profile，不获取签名流；channel 与 owner 分别保存。主目录在线数与频道详情缺失值分开，详情不会伪造 0 或累计观看值。受限频道元数据显示提示，正式播放继续返回限制错误，而非冒充下播。
- 分享入口使用精确路径解析；外部打开由合法频道 ID 生成固定官方网页，忽略导入数据里的任意 link。图片和签名地址不进入平台身份。
- 播放质量按 API resolution 稳定标识，保留 HLS / LL-HLS 源族说明；质量对象不携带可注入的 URL。正常解析复用未过期快照，过期及 recovery 重新读取 profile/stream；频道 owner 变更、请求档位消失、下播都停止本次选源，不静默冒用旧流。
- 每次结果携带精确单源 HlsSourceQueryPolicy、已应用画质 ID 与过期时刻，更新后旧 token 策略不匹配新 URL。播放器/多画面/录制复用前序公共输入链路；当前新增测试直接走真实 StreamResolverService，验证录制续签游标保持画质并替换策略。媒体统一 Origin/Referer/User-Agent，不夹带 API 的 x-site-code。
- 目录迁移升至 11、在线人数设置迁移升至 7，旧平台顺序和已隐藏选择保留，仅追加新平台一次；关闭 TTing 后写盘、关闭 Hive 并重开仍保持关闭。备份导入继续按导入顺序与选择恢复，不擅自补齐用户关闭的平台。双语键和真实设置页开关均已覆盖。
- 未加入弹幕能力，EmptyDanmaku 及多画面弹幕能力表保持明确未支持。
