# 映客应用接入与有限目录说明（2026-09-08）

## 范围与来源

从 `0c02556e7408d6f561f7df683f51019d6d6faa96` 的[公开 API 合同](INKE_PUBLIC_CONTRACT_AUDIT_2026_09_08.md)接入应用。属于用户要求的平台扩展，不是上游合并或已发布版本的回归修复。官网精选缺少部分在播房间的公开媒体，是现有覆盖限制，不将其标成下播或全平台支持。

## 应用合同

- `InkeSite` 注册为 `inke`，接入热门/分类的可选原生目录、详情、收藏状态刷新、严格录制输入与播放恢复。UID 为收藏身份，广播 ID 每次从详情重新读取；恢复重新解析公开媒体。
- 官网有限精选一次提交完整快照，移动端和桌面复用共同目录缓冲；旧列表消费者按页切片，含超大页码边界。界面持续说明“官网精选、非全站目录、部分在播间缺公开媒体”。说明和请求错误分离，旧平台默认没有新增说明。
- 导航、设置与备份保留 `inke`，目录迁移版本从 6 到 7，仅追加新平台，不重新启用此前隐藏的站点。用户随后隐藏映客不应因下一次启动恢复。
- 分享入口按精确官方主机解析 UID，不将旧广播 ID 当持久房间号；相似域名、用户信息和重复 UID 均不进入该分支。
- 外部官网按钮需要房间身份匹配且带广播 ID 的官方链接；旧收藏空链接、离线元数据或损坏导入链接回到官网首页，不猜测广播 ID 或打开任意导入主机。
- 播放与生产 FFmpeg 请求头共用官网 Referer/Origin/UA，无新增 Cookie。只有已验证公开 FLV 一档，不虚构分辨率、HLS、CDN 或观众数。
- 搜索与远端弹幕明确未接入；实际搜索流程返回能力说明，不伪装成功空列表或跳到虚构搜索网站。缺公开媒体的在播详情显示专门说明，元数据刷新仍独立可用。
- 不新增固定续签计时器。签名字段存在不等于已验证期限含义；本批只证明恢复入口重新查询广播与地址，不声称长期无缝续签。
