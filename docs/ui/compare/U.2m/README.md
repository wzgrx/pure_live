## v3 的样子

`lib/modules/live_play/dialogs/play_other.dart`，大小在 `widgets/content_first_panel_layout.dart`。

- **弹法**：竖屏菜单（`live_play_menu_button.dart:88-94`）和全屏 ⇄（`video_controller_panel.dart:394-410`）都是 `showDialog`：靠右的圆角 16 对话框，宽是可用宽度的一半（至少 280），高最多 720；背后压暗。竖屏手机上是 280×720，横屏 852×393 上是 418×377，平板 1280×800 上是 620×720。
- **头部** 48 高：`video_library_rounded` 17、“切换直播间”（titleSmall 加粗）、刷新、关闭。刷新时顶上一条 2 高的进度条，没有时间，失败不提示。
- **分组** 48 高：“已开播”（`sensors_rounded`）、“录播”（`fiber_smart_record_rounded`）、“观看记录”（`history_rounded`），12 号字。已开播和录播按人数排（`compareAudienceRanking`）。
- **小卡片**（`_RoomSwitchCard`）：网格内边距 6、间距 5；列数 `resolveRoomHistoryColumns`：内容宽减 12 后够 168×2+5 就 2 列，否则 1 列（**最多 2 列**）；卡高 `resolveRoomHistoryCardHeight`：16:9 封面加 36 的底栏，2 列时压到两行能放下（不低于 112）。封面右上平台名，左下渐变上写人数（观看记录写“YYYY-MM-DD HH:mm 观看”）；底栏标题一行加粗、人形图标和主播名、右箭头。
- **点一张**：关掉对话框，`controller.switchRoom(room)` 在同一页换台（`live_play_controller.dart:884-930`）。

## 新设计

同一个面板，屏幕大小只决定放在哪（U.2f 统一规则）：

| 布局 | 位置 |
|---|---|
| 竖屏普通布局 | 从画面下沿升起，盖住信息行和聊天区（和录制、弹幕设置一样） |
| 竖屏流（U.2b 三档面板） | 在三档面板里，盖住面板内容 |
| 竖屏全屏 | 底部 60% |
| 横屏全屏、平板和宽屏 | 右侧 360 宽、全高（宽屏时盖在聊天栏上） |

面板从上到下：

1. **头部**（效果图按 56 画；实现用 U02 统一的面板头 `PanelHeader`，52 高、标题 17 号，一屏卡片数只会更多）：“切换直播间”；刷新按钮带上次刷新时间（“2 分钟前”“刚刚”，刷新中转圈写“正在刷新”，失败变红写“刷新失败”并弹提示条“N 个直播间刷新失败，显示的是上次的状态 · 重试”）；搜索；网格 / 列表切换（图标是切过去的样式）；关闭。
2. **分组**（40）：关注在播（数量）/ 来源列表（数量；从热门、分区、搜索进来时才有）/ 观看记录 / 关注回放（数量）。横向排开，放不下时横向滚动。
3. **搜索框**（点搜索后出现）：按主播名筛选当前分组；再点搜索或清空收起。
4. **正在观看**（36，固定在最上面，不可点）：主播名 · 标题。
5. **内容**：
   - **网格**（默认）：照 v3 小卡片——内边距 6、间距 5，最小卡宽 168 算列数，两列时卡高压到两行放得下；封面左上“直播中”和人数（回放写“回放”，未开播写“未开播 · 上次看 2 小时前”并压暗），封面下沿渐变上一行标题；封面下一行主播名，列表里有多个平台时右边写平台名。
   - **列表**：每行 16:9 封面 112×63（左上同样的标记），主播名、标题一行、“平台 · 分区”（未开播写“未开播 · 上次看 X 前”）。
   - 空：每个分组一句话（“关注的主播现在都没开播”等）；筛选没结果：“没有名字包含“X”的主播”；读取失败：“列表读取失败”和“重试”。

点一张：面板关上，在同一页原地换台（页面已有的 `_switchRoom`，和上下滑换台同一条路：同一个播放器，保持全屏和方向），竖屏全屏上下滑的列表换成所选分组。长按：房间卡片的对话框（分享、标签、关注 / 取消关注）。

## 按钮的作用和用法

## 待选和决定（按建议 A）

- X1 打开时停在哪个分组：**A** 有来源列表时停在来源列表，否则关注在播；同一页面里记住上次选的。B 总是关注在播。
- X2 列数：**A** 按最小卡宽 168 算（手机上和 v3 一样，宽的地方多列，平板竖屏一屏 16 张）。B 照 v3 最多 2 列（平板竖屏一屏只有 4 张完整，比 v3 的 8 张少）。
- X3 从关注进来（列表里都是关注的直播间）：**A** 不显示来源列表（和关注在播重复）。B 也显示。
- X4 平台名：**A** 列表里有多个平台时写在卡片底行右边。B 照 v3 一直写在封面右上（窄卡片上和“直播中”、人数挤在一起）。
- X5 刷新失败：**A** 刷新按钮变红写“刷新失败”，同时弹一次提示条。B 只弹提示条。

## 性能要点

- 网格和列表都是懒加载（`GridView.builder`、`ListView.builder`），封面按卡片宽度解码（`memCacheWidth`）。
- 分组列表在关注、观看记录变化时算一次（排序、去掉当前房间），筛选只在输入时算；不按帧重建。
- 面板只在打开时构建；“X 分钟前”每分钟重画一次头部的那个按钮。
- 换台复用播放器，不建新页面（U.2b2 的同一条路）。
