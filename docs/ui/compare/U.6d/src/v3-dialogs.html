界面刷新率（Android、Windows）
界面刷新率
应用会动态检测当前设备与分辨率支持的最高刷新率，切换后立即生效。启用弹幕的“跟随界面策略”时，主画面与小窗弹幕也会按此档位联动。
省电（默认）低耗电
界面由系统动态调度；主画面弹幕上限 60 FPS，小窗弹幕上限 30 FPS，适合长时间观看。
均衡中等耗电
触摸、滑动和转场时使用最高刷新率，操作结束后交还系统；主画面与小窗弹幕上限 60 FPS。
最高（设备上限）高耗电
前台界面跟随当前设备或显示器上限；自动模式下主画面与小窗弹幕同步使用该上限，耗电和 GPU 占用可能更高。
