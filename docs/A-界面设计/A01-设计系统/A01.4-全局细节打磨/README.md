## 设计（按 D-003 由维护者定）

- c1 不留单字行：`live_ui` 的说明文字组件（设置行的 `subtitle`、面板说明、状态页说明、提示条）统一用 `TextWrapping` 规则：最后一行只有一个字时，把前一行最后一个词带下来（Flutter 3.x 没有自带 `text-wrap: pretty`，用简单的“最后两个字之间换成不换行空格”实现：中文在最后两个字之间插 `⁠`，英文最后一个空格换成 ` `）。只对说明文字做，标题不做。
- c2 设置行说明不截断：设置行的说明最多 3 行，超过的改文字（每条说明 40 个字以内，在翻译文件里改短）；去掉设置行说明的 `maxLines: 2`。
- c3 空状态标题不带句号；说明是整句的带句号（统一检查 `*_empty_title` 这一类翻译键）。
- c4 图标含义：“手机端默认音量”换成音量图标（`AppIcons.volume`）；“启用应用层代理”换成网络或代理图标；顺带检查设置页里的所有图标，一个图标只表达一个意思（清单写进记录）。
- c5 最小字号：用户看得到的文字不小于 12 号（`UI.md` 第 4 节的字号表里加这一条），多画面小格“点击选台”改 12 号，图标 20。
- c6 字数计数：带 `maxLength` 的输入框计数放在输入框右下角（Material 默认位置），屏蔽关键词的输入框和“添加”按钮在同一行时，计数仍贴输入框。
