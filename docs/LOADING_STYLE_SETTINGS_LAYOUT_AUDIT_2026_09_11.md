# 加载样式设置窄屏大字号布局审计（2026-09-11）

## 范围与基线

- 基线：`5326e92e168a07ed226264e0a741d054a6e0438e`。
- 对应验收组：A2-01 的加载样式二级设置页增量。
- 固定矩阵：Windows `320×480`、英文、3.0 倍文字。
- 操作链：核对颜色标题和说明 → 滚动至最后一个加载样式 → 选择该样式 → 恢复默认样式及颜色。

## 修改前复现

旧页面把颜色卡片固定在外层 `Column` 顶部，只允许下方样式 `GridView` 滚动；颜色标题、长说明和颜色指示器继续
占用同一固定高度设置行。在 `320×480` / 3.0 倍英文下，颜色设置行稳定向底部溢出 **234 像素**，样式选择入口也
失去可靠的可达边界。

第一次只让颜色卡片按内容自然增高并把大字号网格改为单列时，外层固定 `Column` 仍没有给自然高度标题区提供滚动空间，
因此中间回归进一步暴露 **702 像素**底部溢出。该结果保留为布局所有权仍在错误层级的证据，没有把局部堆叠当成最终修复。

## 修订

- 将颜色设置区和全部样式单元统一放入一个 `CustomScrollView`：标题卡片使用 `SliverToBoxAdapter`，样式使用
  `SliverGrid`，短窗口下整页共享滚动边界，同时保留 85 个动画单元的惰性构建。
- 颜色设置行在窄屏/大字号下让说明自然换行，并把颜色指示器堆叠到文本下方；常规尺寸继续保持紧凑横排。
- 大字号网格按窗口宽度使用 1/2/3 列，普通字号保持既有 2/3/4/6 列断点；样式名称在大字号下最多显示两行，
  同时用 Tooltip 保留完整名称。
- 为样式单元和名称增加稳定键，回归可明确定位末项并验证真实设置写入；恢复默认继续同时清空自定义加载颜色。
