- 状态：待确认（第 1 版，2026-10-01）
- 范围：电视的焦点样式、颜色和字号、按钮、标签、导航栏项、房间卡片、分区卡片、封面角标、设置行、子页顶栏、状态页（加载、空、出错、需要登录）、提示条；电视对话框一族（TvDialog 外框、确认、输入、选择、菜单、多选），以及用到它们的卡片长按弹窗、设置房间标签、手机推送直播间
- 对应：[TASKS.md](../../TASKS.md)、[INVENTORY.md](../../INVENTORY.md#u15a)、[TASK_FILES.md](../../TASK_FILES.md#u15a)；计划书第 5.5 节（电视）、第 7 节（弹窗）、第 8 节（设计系统）
- 评审页：源文件 [page.json](page.json)，效果图源文件 [src/gen.py](src/gen.py)；电视公共部分在 [src/tvkit.py](src/tvkit.py)（U.15b、U.15c 也用）
- 图片：基线是 pure_live_TV（`~/ref/pure_live_TV`，提交 `b9d2f739`），文字取自它的 `assets/translations/zh.json`；画布 960×540（1080p 电视的逻辑尺寸），pure_live_TV 的尺寸按 1920×1080 设计稿写、在电视上乘 0.5（`core/theme/tv_text_scale.dart:23`、`app/app.dart:45`），还原图按减半后的尺寸画；封面和头像是示意图片，主播名和标题是虚构的（和手机 U.4a 同一套示例数据）
- 新设计的颜色是手机深色主题的颜色角色（`tools/ui/mock/kit/kit.css` 的深色），默认蓝作种子；“焦点”小黄签是标注，不是界面

## pure_live_TV 的样子

**尺寸**：按 1920×1080 写，1080p 电视（逻辑 960×540）上全部减半；文字另有“720p 面板放大”（`tv_text_scale.dart:52-53`），1080p 上不放大。默认字号缩放 1.0（`font_settings_model.freezed.dart:219`）。

**颜色**（默认“深色”预设，`core/theme/themes/dark_theme.dart`）：背景 `#121212`、卡片 `#1F1F1F`、焦点色 `#00A1FF`、主文字白、**次要文字也是白**（`:15-17`；其他预设也都是白，`extra_themes.dart`）；焦点卡片底色由焦点色算出（`tv_theme_data.dart:110`，默认预设是 `#1E3948`）。另有十几个配色预设和浅色预设（设置在 U.15i）。

**焦点**（`tv_focus_style.dart`）：主色描边 2（`:52`）加 18 模糊的光晕（`:60`）加放大，获得焦点 120 毫秒、离开不动画，按下 0.97。各部件的放大不一样：房间卡片 1.01（`tv_room_card.dart:100`）、分区卡片 1.04（`tv_area_card.dart:36`）、按钮和标签 1.08（`tv_button.dart:56`、`tv_tab_bar.dart:240`）、通用 `TvFocusable` 只放大高度（`Offset(1, 1.05)`，`tv_focusable.dart:78`）；设置行不放大、底色变 `#1E3948`。长按 OK 超过 0.5 秒算长按（`app/app.dart:71`），长按松开不会再触发点按。

**按钮**（`tv_button.dart`）：胶囊；large / medium / small / mini 四个尺寸，字 20 / 18 / 16 / 14（电视上 10 / 9 / 8 / 7）（`:156-184`）；平时卡片色 75%（次要 45%），焦点主色 65%，选中主色实心；**所有状态都是白字**（`:69-92`）。

**标签**（`tv_tab_bar.dart`）：胶囊代码写 36 高，实际被列表撑到约 66（电视上 33，见“拿不准的地方”），字 22（11）（`:206`、`:255`）；选中主色实心，焦点主色 50%，平时卡片色 75%（`:245-253`）；平台标签前面是平台图标，“全部”是 `Icons.apps_rounded`（`:31-50`）；OK 切换，在当前标签上再按 OK 刷新，下面出一条进度线（`:285-291`）；默认不随焦点切换（`:282`）。

**房间卡片**（`tv_room_card.dart`）：圆角 24（12），平时卡片色；焦点底色变蓝、描边、光晕（`:98-126`）；封面占满除信息行以外的高度（`:147`）；左上平台英文 id 大写（`:201`），关注过的再加“♥ 已关注”（`:202-208`，关注页不显示）；右上“重播”（`ui_replay`，`:216`）；右下热度（`:218-225`）；角标黑 98% 底、字 14（7）（`tv_cover_chip.dart:25`、`:41`）；信息行头像 56（28）、标题 18（9）粗体一行、焦点时滚动、主播名 16（8）粗体（`:241-276`）；网络电视用频道号代替头像（`:138-140`、`:244-246`）；封面加载中转圈、失败是断网图标（`:173-180`）；OK 进直播间，把当前列表当作换台列表（`:79-88`）。

**分区卡片**（`tv_area_card.dart`）：6 列、宽高比 1.5（`area_grid_view.dart:247`）；底色和页面背景一样（`:47`），方形图片（`contain`），名字 18（9）居中（`:132`），焦点 1.04 加光晕。

**设置行**（`tv_settings_row.dart`）：标题 22（11）、说明 16（8）（`:114`、`:122`）；焦点整行底色变蓝加描边加光晕，不放大；开关是方形（`:200-238`），OK 切换、←→ 也能切换（`tv_settings_switch_tile.dart:34-43`）；选择行右边“当前值 ⌄”，OK 弹选择框；滑块 ←→ 调节，到头后焦点才离开（`tv_settings_slider_tile.dart:39-50`）；跳转行右边“›”。

**子页顶栏**（`tv_app_bar.dart`）：左边“‹ 返回”mini 按钮（`:107-122`）、标题 24（12）粗体；进入子页时焦点先落在“返回”上（`tv_page_shell.dart:164-172`、`tv_page_scaffold.dart:121`）。

**对话框**（`core/dialog/`）：`TvDialog` 宽 800（400）、内边距 32、圆角 24，卡片色底，**主色描边加光晕**（`tv_dialog.dart:56-70`）；标题 32（16）粗体（`:92`），正文 24（12）（`tv_confirm_dialog.dart:69`）；按钮靠右、取消在左、主按钮在右，都是 mini（7）（`tv_dialog.dart:107`、`:113`）；默认焦点在主按钮；确认框打开后 0.5 秒内按 OK 无效（`tv_confirm_dialog.dart:49`、`:57`）。遮罩 59% 黑，0.85→1 放大淡入 300 毫秒，关闭后焦点回到打开前的位置（`tv_dialog_utils.dart:30`、`:40`、`:49`）。选择框：每行 60 高、字 20（10），**当前项和焦点项都是整行主色**（`tv_dialog_option_tile.dart:63-73`），当前项右边对勾；打开时滚到当前项并把焦点放上去（`tv_select_dialog.dart:58-76`）；底部“关闭”（`:89`）。多选框：每行左边圆圈（`tv_multi_select_dialog.dart:106-107`），“取消 / 完成”。输入框：打开后直接进入输入，按钮“取消 / 确定”（`tv_input_dialog.dart`）。

**卡片长按**（`core/utils/favorite_operation_util.dart`）：热门、分区房间、搜索结果是确认框“关注提示 / 确定要关注主播“晚风”吗？ / 确定关注”或“取消关注”（`:59-84`）；关注页是菜单“取消关注、设置房间标签 / 分类”（`:5-36`）；观看记录是菜单“历史管理：关注 / 取消关注、删除历史”（`:113-146`）；分区卡片长按是关注分区确认框（`:86-111`）。设置房间标签是多选框，没有标签时写“暂无自定义标签。点击右上角 “+” 按钮即可创建。”（`:39-57`）。

**状态页**（`app_status_view.dart`）：圆圈图标 64（32）、标题和说明都是 24（12）（`:357-388`）；按钮 small（8）、默认焦点（`:395-415`）；图标弹出时 1 秒弹跳（`:370`）；出错默认“网络请求失败 / 无法连接到该直播平台，请稍后重试”，页面传入报错原文时直接显示（`base_paged_tv_view.dart:127-132`）；加载是整页一个转圈（样式取“加载样式”设置）。

**手机推送直播间**（`domains/device/global_room_push.dart:88-153`）：另一种对话框（`Dialog`、卡片色、宽 520（260）），标题“手机推送了一个直播间”，正文是推送来的原始文字（最多三行），按钮“取消 / 打开直播间”（medium）；打开时再解析，平台已下线时提示“该平台已下线，无法再打开，可在关注列表中取消关注”，解析不出就去搜索结果页（`:56-82`）。

## v3（pure_live_TV）的问题

| 编号 | 问题 | 位置 |
|---|---|---|
| P1 | 字太小：1080p 电视上卡片标题 9、主播名 8、角标 7、对话框按钮 7、对话框正文 12；计划书要求正文不低于 14 | `tv_room_card.dart:264-275`、`tv_cover_chip.dart:41`、`tv_button.dart:178-183`、`tv_confirm_dialog.dart:69` |
| P2 | 放大不一致：卡片 1.01、分区 1.04、按钮和标签 1.08；通用 `TvFocusable` 只放大高度，内容被竖着拉长；搜索历史标签外面又套了一层 1.05 | `tv_room_card.dart:100`、`tv_area_card.dart:36`、`tv_button.dart:56`、`tv_focusable.dart:78`、`tv_search_page.dart:253` |
| P3 | 选中和焦点分不清：标签选中是主色实心、焦点是主色 50%；选择框里当前项和焦点项都是整行主色；焦点移走后屏幕上两个差不多的蓝块 | `tv_tab_bar.dart:245-253`、`tv_dialog_option_tile.dart:63-73` |
| P4 | 对比度不够：默认焦点色 `#00A1FF` 上的白字只有 2.8:1（选中标签、选中按钮、选择框当前项）；按钮所有状态都写死白字 | `dark_theme.dart:13`、`tv_button.dart:69-92` |
| P5 | 主次不分：所有预设的次要文字色都是白色，和标题一样；卡片的主播名、设置说明、状态说明只靠字号区分 | `dark_theme.dart:17`、`extra_themes.dart` |
| P6 | 焦点光晕是 12–24 的模糊阴影，每次移动焦点都重画模糊，低端盒子容易掉帧；计划书 9.3 不用模糊 | `tv_focus_style.dart:60`、`tv_focusable.dart:79-88`、`tv_room_card.dart:108` |
| P7 | 分区卡片平时底色和页面一样，看不出一格一格；只在焦点时出现边框 | `tv_area_card.dart:47` |
| P8 | 封面角标和手机不一致：平台写英文 id 大写（BILIBILI），而且单个平台的列表也每张都写；“重播”手机叫“录播” | `tv_room_card.dart:201`、`:216` |
| P9 | 封面加载失败显示断网图标，像是没网 | `tv_room_card.dart:177-180` |
| P10 | 卡片长按有三种做法（确认框、两种菜单），和手机的长按弹窗也不一样；关注要先过一个确认框 | `favorite_operation_util.dart:5-146` |
| P11 | 设置房间标签没有标签时说“点击右上角 “+” 按钮即可创建”，电视的对话框里没有这个按钮，也没有别处能新建 | `favorite_operation_util.dart:48`、`tv_multi_select_dialog.dart:117-120` |
| P12 | 取消关注、清空历史这类确认框默认焦点在“确认”，靠打开后 0.5 秒内不响应来防误触 | `tv_dialog.dart:113`、`tv_confirm_dialog.dart:49` |
| P13 | 子页的“返回”按钮是第一个焦点：进分区房间、搜索结果，焦点先落在“返回”上，要再按下键才到内容；遥控器本来有返回键 | `tv_page_shell.dart:164-172`、`tv_app_bar.dart:107-122` |
| P14 | 出错时直接显示报错原文（常是英文异常） | `base_paged_tv_view.dart:127-132` |
| P15 | 状态页图标弹出时弹跳 1 秒；计划书 8.6 不回弹 | `app_status_view.dart:370` |
| P16 | 手机推送直播间是另一套对话框样子，只显示原始链接，看不出是哪个直播间；手机上同一件事（口令导入）显示主播、标题、平台和房间号 | `global_room_push.dart:88-153` |
| P17 | 对话框外框带主色描边和光晕，和焦点一个样子，像整个对话框“被选中” | `tv_dialog.dart:58-70` |

## v4 现在的偏差（`apps/pure_live/lib/tv/`，M14.1）

已经照 pure_live_TV 做了一版：`tv_theme.dart` 按主题色算出同样的电视配色；`widgets/tv_focusable.dart` 焦点是主色描边 3 加光晕、放大 1.05（导航 1.04），按钮焦点是主色实心；卡片字号 20 / 17（电视上 10 / 8.5）；对话框 `widgets/tv_dialogs.dart` 是另写的一套。上面 P1–P6、P17 在 v4 现在也有。

## 焦点路线

| 场合 | 默认焦点 | 方向键 |
|---|---|---|
| 页面（列表页） | 内容第一项（回到页面时是上次的那一项） | 网格内按行列移动；最上一行按上到标签；最左一列按左到导航栏（U.15b） |
| 子页（分区房间、搜索结果、设置子页） | 内容第一项（v3 是“返回”按钮） | 同上；返回键回上一页 |
| 对话框 | 主按钮；删除类在“取消” | 焦点出不了对话框；返回键 = 取消或关闭 |
| 选择框 | 当前项 | 上下移动，长列表跟着滚 |
| 多选框 | 第一项 | 上下移动；最后一项下面是按钮行 |
| 输入框 | 输入框（直接弹出键盘） | 键盘收起后下键到按钮 |
| 状态页 | 主按钮 | 左右在两个按钮之间 |

## 拿不准的地方

- pure_live_TV 的尺寸都是从代码算的（设计稿 ÷ 2），没有在 1080p 电视上截图对照；720p 盒子上文字会放大到 1.5 倍（`tv_text_scale.dart:52-53`），没有出图。
- 标签胶囊的高度：代码写 `36.h`（18），但外层横向列表给每项的高度是固定的（45 减去上下各 6），按 Flutter 的约束规则胶囊会被撑到 33，图按 33 画；`dpad` 包的源码本机没有，没法确认它中间有没有放松约束（`tv_tab_bar.dart:206-263`）。
- 提示条是 SmartDialog 默认样子，按默认值近似画（白字黑底，字号可能不随电视缩放）。
- 默认加载动画 `TvDefaultLoadingRing` 是渐变圆环，图里用描边圆环近似。
- 输入框弹出的是系统键盘（各电视不一样），图里没画键盘；新设计要保证键盘弹出时输入框在键盘上方。
- 新设计“导航栏始终展开”这一行的文字跟着 U.15b 的选择 B2 定。
- 新建标签的名字长度（15 字）照手机 v3（`room_card.dart` 的标签表单）。
