## v3 的样子

两个页面都是 v3 的设置页写法：标题栏居中标题 20 号；内容左右 16、上下 12；分组标题 12 号加粗、主色 65%（`widget_extensions.dart:21-36`）；分组卡片圆角 20、表面色 15%（`:38-112`）；一行：左图标 22 主色、标题 15 号 600、副标题 12 号 45% 黑只显示一行、右边箭头 20（`:154-258`），开关行同样（`:114-152`）。

**IPTV 设置**（`iptv_page.dart:116-228`）：

1. 分组“IPTV管理”：`Remix.cloud_line`“播放列表管理 / 从服务器同步并覆盖最新的节目排班”→ 订阅源管理（`:143-151`）。
2. “自动化周期同步设置”：`refresh_line` 开关“启动时全自动同步 / 应用冷启动时自动在后台静默检查并更新网络资源”（默认关）；打开时多一行 `time_line`“自动同步检查间隔 / 当前每隔 {hour} 小时进行一次同步”（默认 24）；`tv_line`“自定义直播源请求头”，副标题是请求头本身，没设置时空着（`:153-186`）。
3. “播放源设置”：`download_2_line`“导入播放源 / M3U / TXT”，导入中行尾转圈（`:188-199`）。
4. “EPG 电视节目单设置”：`file_add_line`“导入节目单源 / XML / GZ / JSON”；`tv_2_line`“当前启用的 EPG 数据源”，没选时橙字“点击选择一个节目单源”（`:201-223`）。
5. 顶部状态：加载中进度条；读取失败卡“读取 IPTV 配置失败。原有设置已保留，请重试。”或“默认节目单来源尚未准备好。可以重试或手动导入来源。”+“重试”（`:124-142`）。没有节目单时每次进页面自动导入默认节目单 `epg.zsdc.eu.org/t.xml.gz`，名字是“hot”（`:72-96`，`auto_sync_scheduler.dart:55-72`）。

**订阅源管理**（`iptv_manage.dart:221-321`）：标题栏右边 `refresh_line`“同步”（同步中转圈）。统计卡片：渐变底，三格“IPTV / EPG / 网络”，图标框 46、数字 12 号加粗（`:353-434`）。“网络资源”`global_line`、“本地资源”`folder_2_line` 两组，组内播放列表在前、按名字排（`:117-124`）。卡片（`:448-619`）：白底圆角 22、细边、淡阴影；左边 52 图标框（播放列表 `play_list_2_line` 主色，节目单 `tv_2_line` 橙色）右下角格式标记（M3U 主色、TXT 橙、JSON 紫、XML.GZ 蓝灰，白字 900 粗）；名字 15 号粗、地址灰字各一行；右边“网络”绿字绿底 /“本地”橙字橙底胶囊。按钮（高 48、圆角 14、浅色底）：网络来源“同步”`download_cloud_2_line`、“删除”`delete_bin_6_line`（红）、“自动同步”`repeat_line` + 开关；卡片宽 ≤680 时同步和删除一行、开关一行，更宽时三个一行；本地来源只有删除。点卡片任何地方用浏览器或文件打开地址（`:481`）。

**对话框**（都是居中 `AlertDialog`）：导入方式两项“本地导入 / 网络导入”，没有按钮（`iptv_page.dart:302-430`）；网络导入“请输入下载地址”，两个只有提示字的输入框“下载地址”“文件名”，按钮“取消 / 确认”，进行中显示进度条和“导入正在进行。关闭窗口后导入仍会继续；完成前请勿重复导入。”，取消变“关闭”（`:693-806`）；同步间隔 2/6/12/24/48/72 小时，当前项填充勾（`:240-300`）；请求头：说明、144 高的等宽输入框（清除按钮）、下面一条“－ 拖动 144 px ＋”调输入框高度、“取消 / 确认”（`:501-691`）；选 EPG 数据源：标题 12 号粗 + 右上角关闭，单选卡片（名字、地址），底部“取消”（`:808-943`）；删除“确认删除 / 你确定要删除这个订阅源吗？…”“取消 / 确认（红）”（`iptv_manage.dart:833-901`）；同名“该订阅名称已存在 /“名字”是否确认删除旧的 M3U 数据并替换为当前文件？”（`iptv_import_manager.dart:261-276`、`epg_import_manager.dart:215-228`）。

**按宽度分支**：卡片 680（`iptv_manage.dart:523`）；卡片和统计在宽 <240 或字号放大到 22 以上时竖排（`:367`、`:488`）；请求头对话框宽 >640 时 560，否则 90%（`iptv_page.dart:539`）。没有快捷键和手势。

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 竖屏如图；横屏同宽屏的单栏（852 宽时卡片按钮一行） |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 同一页，内容一栏最宽 720 居中（待选 H2）；鼠标悬停有高亮，右键卡片 = “更多”菜单；Esc 关对话框；本地导入用系统文件选择 |
| 电视 | 不在本任务：U.15e。pure_live_TV 把 IPTV 设置分成资源列表、导入（网络导入、扫码在手机网页上传）、同步、请求头（UA / Referer / Cookie）四页，出图时按本页的内容和顺序对齐 |
| 苹果平台差异 | 同宽屏；iOS 本地导入走系统“文件”；macOS 用 Cmd |

## 拿不准的地方

- v3 卡片底色用的是 `theme.cardColor`，主题里没设，按 Flutter 默认画成白色；设置行副标题按 `hintColor`（Flutter 浅色默认 60% 黑）× 0.75 画。请对照手机上的 3.x。
- v4 现在没有文件选择插件，“本地导入”是输入路径（M13.11“留给后续”）；新设计按 v3 用系统文件选择画，开发时要加依赖。
- 频道数、更新时间 v3 的库里有没有（`lastRefresh`）以 v4 的 `live_iptv` 为准，图里的数是示意。
