## 修改前问题

1. 精细字号页面为五个滑块准备了完整双语用途说明，但页面没有传入这些说明；用户只能看到内部 Material 文本层级名称，难以判断修改会影响哪些界面。
2. 字号与全局缩放的最小值、最大值和默认值分别散落在控制器与两个页面中，备份解析完全不使用 UI 支持范围。越界值会进入 `SfSlider`，损坏或手工编辑的非有限值还会继续进入主题计算。
3. Hive 中已有的越界/非有限字号在控制器启动时不归一化，首次主题构建可能先消费无效值。
4. 顶栏重置按钮单击后立即改写五项设置，没有确认步骤；误触会同时丢失全部精细调节。
5. 页面在宽桌面上让卡片横跨整个窗口，阅读行过长；窄屏大字号虽可滚动，却没有针对五段用途说明和最后滑块的明确回归。

## 修订

- 在 `FontSettingsController` 集中声明全局缩放与五项字号的默认值和支持范围；精细字号页与主题页共用同一组常量，消除 UI、启动值和备份合同漂移。
- 当前备份与旧格式提取统一经过严格解析：数值类型保持原有类型校验，有限越界值归一化到相应滑块范围，`NaN`/无穷值在任何设置写入前终止导入。
- 控制器启动在注册主题观察器和首次主题构建前归一化 Hive 值；越界值收敛到边界，非有限值恢复对应默认值并由既有响应式存储路径持久化。
- 共享滑块组件增加可选、自然换行的副标题；精细字号页呈现全部五项双语用途说明，320×480 / 3.0 倍英文可逐项滚动到最后一项。
- 页面正文在宽屏居中限制为 720 像素，窄屏继续占满可用宽度；长顶栏标题增加单行省略与完整 Tooltip。
- 重置改为可滚动确认框，取消保持五项现值，确认后由控制器一次入口恢复五个默认值并显示既有完成反馈。
