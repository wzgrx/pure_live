## 3.x 的样子和问题

**3.x 的行为**（`git show v3.2.11:lib/...`）：没有上下滑换台，也没有对应的设置项。

- 竖屏全屏里的上下滑只有两种：左半边调亮度、右半边调音量（`modules/live_play/widgets/video_player/video_controller_panel.dart:851-902`），屏幕最下面 96 内上滑回到面板（`:904-930`）。
- 换直播间只有“切换直播间”按钮（`video_controller_panel.dart:394-397`）：关注里正在播的、回放、观看记录三个列表（`dialogs/play_other.dart:41-50`），点了在同一个页面里换（`play_other.dart:259-266` → `controllers/live_play_controller.dart:884-930` 的 `switchRoom`：关掉播放器、换弹幕、重新加载）。
- 竖屏直播的设置（`common/services/settings/player_settings_controller.dart:54-70`）里没有换台开关；翻译里也没有“换台”“上下滑”的句子（只有多画面的“换台” `multiview_change_room`）。
- 电视（pure_live_TV，v4 `tv/room/tv_live_play_page.dart:214-238`）：上下键在进来时的列表里换台，按住连按 300 毫秒内合成一次，到头回到开头。

**设计时 v4 的样子**（2026-10-02，当时的行号）：

- 卡片进直播间只带一个 `LiveRoom`（`routes/app_navigator.dart:103-118`），直播间不知道是从哪个列表进来的。
- 竖屏全屏的上下滑：左右两半调亮度音量、最下面上滑回到面板（`features/live_play/player/player_gestures.dart:123-158`），没有换台。
- “切换直播间”换掉整个页面（`dialogs/room_switcher.dart:183` → `AppNavigator.offAndToRoomDetail`），播放器靠 C02.1 的待机复用（`logic/player_standby.dart`）。

**问题**：这是新功能（候选 C-9），不是修 3.x 的问题；用户确认要做，默认关，不改变 3.x 用户的手势。

必须保留的操作习惯（[specs/UI.md](../../../specs/UI.md) 附录 A）：第 4 条（左侧亮度、右侧音量；锁定锁住所有手势）、第 5 条（竖屏全屏在底部上滑退出）——开着换台时亮度和音量变成左右三分之一，底部上滑优先。

## 确认的改动

| 编号 | 类型 | 内容 |
|---|---|---|
| c1 | 增强 | 关注（各分组）、热门、分区房间、搜索（房间结果）点卡片进直播间时，把当前列表（房间顺序）随路由参数带进去（`LiveRoomArgs.playlist`，参照电视 `TvRoomArgs.playlist`）；从链接、观看记录、小窗、切换直播间等进来的没有列表 |
| c2 | 增强 | 设置“竖屏全屏上下滑换台”，默认关（新键，v3 没有）；放在“竖屏直播适配”的“全屏、小窗与弹幕”组（设计 X1 A）；只在手机上显示 |
| c3 | 增强 | 开关开、有列表（至少两个直播间）时，竖屏全屏的画面分三竖条：左边调亮度、右边调音量、中间上滑下一个、下滑上一个；最下面 96 和下栏上滑照旧回到面板；锁定时不能滑。开关关或没有列表时照旧（左右两半），不提示 |
| c4 | 增强 | 拖动时当前画面跟着手指走，下一个（或上一个）直播间的封面和名字（头像、主播名、平台 · 分区）跟上来；滑过三分之一高度或快速滑动后松手就换（这时名字下面写“松手换到这个直播间”），否则弹回；顺序同电视：到头回到开头 |
| c5 | 增强 | 换台在同一个页面里换，复用同一个播放器（`RoomRuntime` 的同一个 `PlaybackSession`），不新建页面；留在竖屏全屏，换到横屏直播时画面居中、上下用沉浸背景；连续快滑只播最后一个 |

测试要求（设计时写的）：c1 每个列表页一个（路由参数里有列表）；c2 设置行和默认值；c3 分区判定和三种情况（开、关、没有列表）；c4 松手判定（距离、速度、反向）和拖动时的预览；c5 换台后同一个播放器、同一个页面、观看记录、连续快滑。

## 按钮的作用和用法

| 手势或控件 | 怎么用 |
|---|---|
| 竖屏全屏中间三分之一上滑 | 换到列表里的下一个直播间（到头回到开头）；没过三分之一或不够快就弹回 |
| 竖屏全屏中间三分之一下滑 | 换到上一个 |
| 左三分之一 / 右三分之一上下滑 | 亮度 / 音量（开关关或没有列表时是左右两半，同 3.x） |
| 屏幕最下面 96 或下栏上滑 | 回到三档面板（优先于换台） |
| 设置“竖屏全屏上下滑换台” | 打开后上面的换台生效；默认关；“恢复默认”会把它关掉 |

- 根因（记录）：①A07.2 没做 c14 是因为直播间只认一个 `LiveRoom`、“切换直播间”换整个页面、设置不在能改的目录；②开发中发现 `PlaybackSession.stop()` 叠加时第一次的 45 秒空闲释放定时器没有取消（`packages/live_player/lib/src/session.dart`，当时 `:333-351`），页面这边用 `_handover` 排队绕开——**包本身后来在 `2f4aed12b` 修好**（现在 `session.dart:343-367`：只有最后一次 stop 设释放）；③状态层原来盖在手势层上面会挡住拖动，现在放进手势层里（`player/player_view.dart:635-697`）。
- 偏差：①v3 没有这个设置，只能新加（键名不是 v3 的）；②设置按设计 X1 A 放在“竖屏直播适配”页（任务书写的是“视频”页）；③热门和分区房间共用 `shared/rooms/room_grid.dart` 的 `RoomFeedView`，列表只能在那里带上；④状态层挪进手势层后，在加载中、未开播等状态视图上上下滑也能调亮度和音量；⑤“松手换到这个直播间”只在松手会换台时显示（设计图在拖动中一直显示）。

- 没做的：设计里“列表后面接观看记录里正在播的”；搜索的“主播”结果不带列表；拖动时临时最高刷新率属于 R02.1。
