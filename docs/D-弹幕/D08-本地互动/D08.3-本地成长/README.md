## 目标

体验币和经验有意义：看直播、每天第一次进直播间、发本地弹幕都能慢慢涨经验和币；身份卡下面一条进度条“Lv.3 · 还差 120 经验到 Lv.4”；每 10 级一个段名。3.x 的“+500/+2000/+10000”按钮保留。

## 3.x 和现状

| 方面 | 3.x | 现在 | 要做到 |

| 经验来源 | 只有送礼（= 花掉的币） | 同：`sendGift` 加 `experience + gift.price`（`features/live_play/local_interaction/logic/local_interaction.dart`） | 加观看、签到、发弹幕 |

| 身份卡 | 一行状态 | “哔哩哔哩 · 用户等级 Lv.1 · 1000 电池”（`local_interaction_panel.dart:205-211`、`statusLine`） | 加进度条 |

## 规则（V03.6 第 5.4 节的数字，写成 `LocalCatalog` 里的常量）

| 来源 | 经验 | 体验币 | 上限 |
|---|---|---|---|
| 送礼 | = 价格（照 3.x） | −价格 | — |
| 看直播，每满 10 分钟（只在播放时、应用在前台或小窗时计） | +10 | +20 | 每天 300 经验 |
| 每天第一次进直播间（签到） | +20 | +100 | 每天一次 |
| 发本地弹幕 | +1 | — | 每天 50 |
| 点“+500/+2000/+10000” | 0 | 照 3.x 加 | — |

- “每天”按本机时区的自然日；当天的计数存在新设置里（例如 `localInteraction.growthDay` 一个 JSON：日期、已得观看经验、已签到、已得弹幕经验）。
- 段名：每 10 级一个（1～9“新人”、10～19“常客”、20～29“熟客”……，放翻译文件，名字在设计时定）；头衔不按等级锁（3.x 随便选），升级时只提示一句“升到 Lv.N”（短提示）并在 D08.1 的记录里写一条 `level`。
- 改规则不动已有数据（经验、币照旧）。

## 方案（做法 A，D-003 维护者选 A）

- c1 新开关“本地成长”（`localInteraction.growthEnabled`，**默认开**——D-040 写明的例外；关掉后只有送礼加经验，和 3.x 一样）。不选 B（不加开关）：有人只想要“无限币”的玩法。
- c2 计时：直播间控制器已经知道播放状态；`LocalRoomSession` 每分钟记一次（`Timer.periodic` 1 分钟，D-017），播放中才加，离开直播间结算；退到后台不计（小窗、画中画在播算播放）；不在后台另起计时。
- c3 签到：进直播间时（`LocalRoomSession` 建立）检查当天有没有签过。
- c4 发本地弹幕 +1（每天上限 50）。
- c5 身份卡（界面照 A08.2，在它的 README 补一条）：状态行下面一条进度条和“还差 N 经验到 Lv.M”；“+500/+2000/+10000”放到身份卡的“更多”菜单里（D-001：功能不少，只是位置变）。
