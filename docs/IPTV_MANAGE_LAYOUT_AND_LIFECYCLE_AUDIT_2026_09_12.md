# IPTV 订阅源管理布局与生命周期审计（2026-09-12）

## 范围与基线

- 基线：`e45e7444e42907638097e21995b967f43a36aa6f`。
- 范围：IPTV/EPG 订阅源管理页的初始读取、失败重试、空状态、同步与自动更新事务、删除对话框路由所有权，以及 320×480、3.0 倍文字下的中英文可达性。
- 本轮只做源码、内存数据库 Widget 回归、静态分析与仓库审计；未连接手机、访问真实订阅源、构建安装包或发布版本。

## 复现与根因

六项修改前 Widget 回归为 **0/6 PASS**，有效失败如下：

1. 320×480、3.0 倍中文下统计横排向右溢出 80 像素；英文统计、资源头、自动同步行和分区标题分别出现最高 262、138、180、357 像素的横向溢出。
2. 初始数据库读取异常直接逃逸，页面没有可见错误或重试入口。
3. 页面退出后，迟到的播放列表读取仍继续发起 EPG 查询，异步任务没有生命周期边界。
4. 删除完成时通过全局最新上下文执行 `pop`；若其上已有新路由，会误关新路由而不是原删除对话框。
5. 自动同步写入等待期间若该订阅源已被删除，完成回调仍按旧对象索引列表，触发越界异常并可能回填过时状态。

根因是页面把数据库读取委托给全局加载弹层而没有错误状态、挂载检查或请求代次；卡片大量使用固定横排与固定高度；删除和自动同步完成回调又分别依赖最新全局上下文和旧对象下标，而不是原路由与稳定资源身份。

## 修订

- 初始读取改为页面内加载/错误/空状态，失败保留当前资源并提供重试；播放列表与 EPG 两阶段读取均核对页面挂载状态和最新请求代次。
- 资源结果按网络/本地、类型、名称和 ID 稳定排序；全量与单项同步有明确忙碌状态、失败收尾和页面退出隔离。
- 统计卡、分区标题、资源身份、格式徽标、操作按钮与自动同步行按可用宽度和文字缩放响应式换行；窄屏大字号使用自然高度纵排，外层保持惰性滚动。
- 删除确认使用根 Navigator 上由发起动作持有的 `DialogRoute`；完成时精确移除原路由，即使上层后来出现新页面也不影响新页面。
- 自动同步以“类型 + ID”标识进行单项互斥；数据库返回后重新按稳定身份查找资源，已删除项不再被索引或恢复。
- 补齐中英文加载失败与无订阅源文案，并纳入翻译合同回归。
