# 界面重构任务清单

- 更新：2026-10-01
- 计划书：[UI_PLAN.md](UI_PLAN.md)；做法：[PROCESS.md](PROCESS.md)；v3 界面清单：[V3_UI_INVENTORY.md](V3_UI_INVENTORY.md)
- 每个任务一个文件夹 `compare/<编号>/`，放对比图、确认结果和说明（[U.2a](compare/U.2a/README.md) 是样板）。
- 数字由 `tools/ui/inventory.py` 统计：它把 v3（`v3.2.11`）和 pure_live_TV 的每个界面文件分到一个任务，没分到的会报错，保证不漏；每个任务对应哪些文件见 [TASK_FILES.md](TASK_FILES.md)（`python3 tools/ui/inventory.py --files` 生成）。

## 1. 一共有多少界面

| 客户端 | 代码基线 | 界面文件 | 页面 | 弹窗（对话框 / 底部面板 / 菜单） | 说明 |
|---|---|---:|---:|---:|---|
| 手机、平板、Windows、Linux | v3.2.11 `lib/` | 146 | 76（路由 40） | 103（84 / 9 / 10） | 同一套代码，按屏幕大小排版 |
| 电视（Android TV） | pure_live_TV `lib/` | 203 | 102 | 34 | 遥控器操作；设置有 49 页 |
| 合计 | | 349 | 178 | 137 | |

- “界面文件”是声明了界面组件或会弹出对话框、面板、菜单的 Dart 文件；“页面”按类名统计（以 Page、Screen、View 结尾），实际要出图的界面以各任务的清单为准。
- 每个界面还要按形态出图（第 2 节），所以图比界面多：直播间一屏就有竖屏、横屏、平板、电脑四种。
- 系统界面（通知、启动图标、分享接收）是原生代码，不在统计里，单列为 U.14。

## 2. 形态和尺寸

各客户端一致（计划书第 4 节第 7 条）：同一个功能在各形态用同一个组件、同样的样子和操作，只是位置随屏幕调整。每个任务的对比图按下表出齐它在 v3 里有的形态。

| 形态 | 判断 | 出图尺寸 | 设备 |
|---|---|---|---|
| 竖屏 | 宽度小于 600 | 393×852 | 手机竖屏 |
| 横屏 | 高度小于 480 | 852×393 | 手机横屏、全屏播放 |
| 宽屏 | 宽度 600 以上 | 1280×800；电脑再加 1920×1080 | 折叠屏、平板、Windows 和 Linux 窗口 |
| 电视 | 电视模式 | 1920×1080（逻辑 960×540） | Android TV |

宽度分档（紧凑、中等、展开、大、特大）和列数公式见计划书第 8.1 节。

## 3. 编号和状态

- 编号：`U.<组>` 加小写字母，例如 U.2a。只有一个任务的组不加字母（U.8、U.9、U.13、U.14、U.16）。
- 状态：未开始 → 设计中 → 待确认 → 已确认 → 开发中 → 完成。部分确认的写明哪些已确认。
