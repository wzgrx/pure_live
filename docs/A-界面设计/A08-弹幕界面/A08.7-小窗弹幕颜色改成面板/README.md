## 3.x 的样子和问题

- 3.x：统一弹幕颜色是一行（`git show v3.2.11:lib/modules/settings/pages/pip_danmaku_settings_page.dart:445` 的 `_colorPickerRow`：名字 15 号 600、右边 28 的色圈和“#FFFFFFFF”），只在关掉“保留平台弹幕颜色”时出现（`:199-200`）；点开 `showAppColorPickerDialog`（`lib/modules/settings/widgets/app_color_picker_dialog.dart:85`，`pip_danmaku_settings_page.dart:485-499` 调用：居中对话框，色板来自 `AppConsts.colorsNameMap`，不带透明度，选了就生效）。这一组在 3.x 只出现在直播间的“弹幕设置”标签（`lib/modules/live_play/pages/danmaku_settings_page.dart:416-418`）和设置的“小窗弹幕”页；画面上的面板不带小窗弹幕（`includePipSettings: false`，`widgets/video_player/video_controller_panel.dart:2206`），所以 3.x 全屏时不会弹这个对话框。
- 4.x 现在：
  - 直播间：`apps/pure_live/lib/features/live_play/danmaku/danmaku_settings_panel.dart:192-209`：`InkWell` → `showDanmakuColorDialog`（`apps/pure_live/lib/shared/danmaku/danmaku_color_dialog.dart:66`）：`AppDialog`（居中），10 个 44 的色圈（`danmakuColorSwatches` `:8`：白、黑、红 `#FE0302`、橙、金、黄、绿、蓝、深蓝、品红；当前色主色 3 像素描边 `:126-131`），下面十六进制输入框（9 个字符、`#` 前缀，`:142-158`），“取消”“保存”（`:162-165`）；输错时框下写“请输入 6 位十六进制颜色，例如 2196F3”（`settings_color_invalid`）。A08.1 E1 把小窗弹幕也放进了画面上的面板，所以横屏全屏时这个对话框压在画面中间。
  - 设置的“小窗弹幕”页：`features/settings/playback_tiles.dart:510` 的 `PipColorTile` → `features/settings/settings_dialogs.dart:317` 的 `showColorDialog`（`LiveColorPicker`：推荐色、Material 色板、色轮、深浅、透明度、色码）。
- 问题：
  - P1 全屏时这是直播间里最后一个居中对话框，压在画面中间、挡住正在调的弹幕（规范第 7 节：直播间里设置用面板；A07.11 c8 改了其余的）。根因：A08.1 另做了一个小对话框（偏差 1），没有面板式的选色组件。
  - P2 同一个设置两种选法：直播间 10 色 + 十六进制，设置页是完整的 `LiveColorPicker`（还带透明度，而 3.x 的这一项不带透明度）。
  - P3 色圈 44 和间距 10，在 360 宽的面板里一行放 5 个，两行加输入框，放进面板里的展开区要算好高度。

## 按钮的作用和用法

| 编号 | 控件 | 怎么用 |
|---|---|---|
| 1 | 统一弹幕颜色（行） | 点一下展开或收起色板；右边是当前色圈和色值 |
| 2 | 色圈 | 点了立即生效，主色描边加勾移到这一个 |
| 3 | “#”色值输入框 | 输入 6 位（RRGGBB）或 8 位色值，回车生效；不对时框下写原因 |
