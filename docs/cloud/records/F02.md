## 根因

1. **c1**：总览的“弹幕”行打开的是 M13.7 留下的一组目录行（`settings_catalog.dart` 弹幕一节，Remix 图标、自己的分组和范围，例如显示区域 10%～100%、速度 30～400、字号 10～40），和直播间、视频页“弹幕样式”用的 `shared/danmaku/danmaku_settings_content.dart` 不是一个东西。U.6a 当时因为直播间的组件在 `live_play` 里、设置不能引用，先留了旧页；U.2f 已经把组件挪到 `shared/danmaku`，这里一直没换。
2. **c2**：“录制已停止”提醒（`RecorderForegroundService.alert`）的点击和按钮都是 `openRecordings(context, 1/2)`，意图里只有 `route`，Dart 侧 `SharedPayload` 只认 `route` 和 `room`，录制中心也没有按任务定位的入口，所以只能打开录制中心顶部。
   另外一个会跟着出现的坑：所有提醒共用请求码 1、2，`FLAG_UPDATE_CURRENT` 下 Android 认为是同一个 PendingIntent（extras 不参与比较），如果只往意图里加任务 id，多条提醒会全部指向最后一条的任务。所以每条提醒按任务 id 用自己的请求码。

## 偏差和原因

1. **“弹幕列表”“小窗弹幕”两组没有放进设置的弹幕页**：直播间的组件末尾这两组（U.2e E1）在 `features/live_play` 里（`RoomDanmakuSettings`），设置不能引用，这次也不能改 `live_play`（B09 在改）。“小窗弹幕”在总览已有自己的一行（U.6a c7 只留一个入口），“弹幕列表”是直播间聊天列表自己的样式和“显示礼物”（礼物开关存在直播间控制器里）。所以设置页 = 同一个组件 + “更多”；直播间 = 同一个组件 + 那两组。以后要完全一样，可以把这两组挪到 `shared/danmaku`（需要动 `live_play`）。
2. **“更多”一组是新的**：原来设置弹幕页有、组件里没有的几项（显示弹幕、在画面上显示、YouTube 全部聊天、字体、屏蔽）要有地方放，按“全局设置放末尾”的建议 A 做；“显示弹幕”“字体”“屏蔽”在视频页也有一行（同一个设置），和 U.6c 记录里说的情况一样。
3. **相似过滤、斗鱼过滤不在弹幕页上了**：它们在“弹幕屏蔽”页（U.12d，和直播间“屏蔽管理”同一个组件），弹幕页的“弹幕屏蔽”行说明里写着“关键词、屏蔽用户、平台和相似弹幕过滤”。
4. **改了任务单“可以改”以外的文件**：`lib/routes/`（加路由，c1 本身要求）、`lib/platform/share_channel.dart`、`android/.../RecorderForegroundService.kt`、`ShareIntakePlugin.kt`（c2 的意图 → Dart 通路，派活说明里要求的），测试 `test/features/home/home_test.dart`（路由表）和 `test/intake_test.dart`。
5. **前台录制通知（“正在录制 · 晚风”）点开仍是录制中心顶部**：任务单只要求“录制已停止”。一个房间时也可以定位，需要 Dart 把任务 id 跟通知文字一起发过去，没有做。

## 要在真机（Redmi K90 Pro Max，Android 17，120 Hz）上看的

1. 设置 → 弹幕：和直播间“弹幕设置”标签一样（观看模板、显示范围里有“暂停时的弹幕”、样式、重复弹幕、画面弹幕交互、流畅度，第一组右边“改动立即生效”）；末尾“更多”有显示弹幕、在画面上显示飞行弹幕、YouTube 显示全部聊天、更换弹幕字体（右边显示当前字体）、弹幕屏蔽。改一项后进直播间，弹幕立即按新设置显示。横屏（宽 ≥840）时在右栏打开。
2. 设置搜索“速度”“暂停”“相似”：分别找到弹幕的速度、暂停时的弹幕，和视频页的“弹幕屏蔽”。
3. 录制中心有十几个任务时，录一个排在后面的房间，切到别的应用，让它失败（例如断网等它重试用完，或系统停掉后台服务），通知栏出现“录制已停止 · 主播名”：点通知本身 → 录制中心滚到这条并有一圈主色描边，约 2 秒后淡掉；再触发一次，点通知上的“打开录制中心”按钮，效果一样。
4. 两个任务先后各出一条“录制已停止”：分别点，各自定位到自己的任务（不是都到后一个）。
5. 停在录制中心时点提醒：不会叠出第二个录制中心（返回一次回到进录制中心之前的页面）。
6. 杀掉应用后点还留在通知栏的提醒：应用启动后录制中心定位到那条（任务恢复后才出现也能定位）。
