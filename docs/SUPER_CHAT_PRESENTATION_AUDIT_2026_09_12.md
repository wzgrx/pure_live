# 醒目留言呈现与容错审计（2026-09-12）

## 范围与基线

- 基线：`864eb0fd7232a8822771d2b195109089d8f60e75`。
- 范围：直播间醒目留言空状态、平台颜色与头像输入、窄屏大字号卡片、重复事件身份及现有到期/协议链路。
- 本轮只做源码、确定性 Widget/协议回归、静态分析与仓库审计；未连接手机、制造真实付费事件、访问平台网络、构建安装包或发布版本。

## 复现与根因

六项修改前 Widget 回归为 **1/6 PASS**，五项有效失败如下：

1. 中英文醒目留言页在没有消息时返回空白控件，用户看不到当前状态或消息出现位置。
2. 平台返回 `not-a-colour` 或不完整十六进制颜色时，`HexColor` 在卡片构建阶段抛出 `FormatException`，整条付费消息不可见。
3. 320×480、3.0 倍英文下，长用户名、大金额和长正文使卡片头部出现横向溢出。
4. 没有平台事件 ID 的重复快照以重建后的开始时间参与页面去重，同一用户、正文和金额会显示两张卡片。
5. 空头像仍进入网络图片加载路径，产生没有价值的失败请求后才回落占位图。

只有“可见内容相同但平台事件 ID 不同的两次真实付费事件均保留”在修改前通过。根因是页面层另造了一套与 `LiveSuperChatMessage` 不一致的时间型身份，卡片又直接信任远端颜色并把身份、金额和倒计时固定在单行布局。

## 修订

- 空页增加中英文标题和说明，使用独立可滚动状态面，320×480、3.0 倍文字下仍可读。
- 十六进制颜色只接受 6/8 位格式；无效值回落到当前主题容器色，正文继续显示并按实际背景计算对比色。
- 卡片头部按宽度和文字缩放在横排/纵排间切换；用户名允许多行，金额使用受约束的自然换行，倒计时移到独立区域。
- 空值、非 HTTP(S) 或缺少主机的头像直接显示本地占位图；合法远端头像仍保留加载失败回落。
- 页面去重改为复用 `LiveSuperChatMessage` 的事件身份：有 ID 时按平台事件 ID，无 ID 时按用户、正文和金额；不同事件 ID 的相同可见内容继续全部保留。
- 每张卡片增加稳定值键，列表重建或重排时倒计时状态继续属于原付费事件。
