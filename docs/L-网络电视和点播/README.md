# L 网络电视和点播

网络电视（订阅源、导入、管理）、节目单和回看、点播和音乐。界面在 A13、A17。

管直播平台以外的两类内容：**网络电视**（用户自己导入的 m3u / txt 播放列表和 XMLTV / JSON 节目单，作为一个“平台”出现在分区、搜索、关注里，能看节目单、能回看）和**哔哩哔哩点播和音乐**（电视端要用的视频、番剧、歌单、歌词，核心包已经做好，界面还没有）。排在账号之后：网络电视是一部分用户每天用的（家里的 IPTV、公开的电视直播源），但数据结构独立、和直播平台的耦合少；点播和音乐只在电视端用，第三档。

## 范围

- 管什么：
  - **网络电视**（L01）：`packages/live_iptv`（播放列表解析、导入和同步、频道身份、平台适配 `IptvSite`、存储接口 `IptvLibrary`）；应用里的持久化 `apps/pure_live/lib/app/iptv_library.dart`（`StoreIptvLibrary`，表放在 `pure_live.db`）、3.x 网络电视库的迁移 `app/iptv_legacy.dart`、启动 3 秒后的自动同步（`app/bootstrap.dart:261`）、分享来的播放列表导入（`app/intake/share_intake.dart:217`）；网络电视管理页 `features/iptv/` 的逻辑部分；完整备份里的网络电视列表（`shared/backup/backup_iptv.dart`，格式归 J03）。
  - **节目单和回看**（L02）：`packages/live_iptv` 的节目单解析（`guide/guide_parser.dart`）、频道到节目单的匹配（`guide/matcher.dart`）、回看规则和地址（`catchup.dart`）；直播间里的节目单读取（`features/live_play/dialogs/iptv_guide.dart` 的 `loadChannelGuide`、`logic/iptv_guide_rows.dart`）和回看播放（`features/live_play/logic/room_controller.dart` 的 `playCatchup` / `backToLive`）。
  - **点播和音乐**（L03）：`packages/live_vod`（哔哩哔哩视频、番剧、弹幕、评论、收藏、历史、搜索、音乐、歌词、歌单导入、每日推荐、播放队列、音频缓存）。
- 不管什么：
  - 网络电视管理页、节目单面板、回看条的样子 → [A13.1](../A-界面设计/A13-网络电视和多画面界面/A13.1-网络电视管理/README.md)、A07.7（直播间的节目单）；电视端的网络电视、点播、音乐界面 → A17.5、A17.6、A17.7（第三档，已确认设计）。
  - 网络电视频道作为“房间”在直播间里怎么播（线路、请求头、局域网权限）→ C01、G；局域网直播源的本地网络权限 → O04；分享接收的原生部分 → O03。
  - 把网络电视当作一个平台的通用框架（`LiveSite`、平台登记）→ E05；分区、搜索、关注页的显示 → I。
  - 3.x 网络电视库的迁移结果核对 → J06.1（这里管转换规则）。

## 风险和注意

- **列表来源不可控**：用户导入的列表可能很大（几千个频道）、编码不是 UTF-8、行格式不规范；节目单可能几十 MB。保持“坏行只跳过这一行、截断的文件不覆盖旧列表、拉取式解析”的做法（UPGRADES 统一原则“容错”）。
- **频道 id 不能变**：关注、历史、映射都按频道 id 指向频道，同步时用 8 步唯一匹配保留 id（`reconcile.dart`）；3.x 的频道 id 迁移时原样保留。改同步逻辑的任务必须保留这一点并有测试。
- **局域网源**：家里的 IPTV 服务器多是局域网地址，Android 17 要“本地网络”权限（O04，`ensureLocalNetworkFor`）。
- **第三方服务**：L03 的歌单导入和歌词会把歌单号、歌名发给别人运营的镜像和歌词服务，界面上要写明（L03.1 记录“第三方服务”）；地址都可以改。
- **测试不访问真实服务**（D-017）：网络电视用本地造的列表和假网络；点播用 `fixtures/live_vod` 的样本；用到样本时间的测试把“现在”固定成录制时间。
- **规则**：网络电视的设置键（`selectedSourceId`、`selectedSourceName`、`isAutoSyncEnabled`、`autoSyncHoursInterval`、`customIptvUserAgent`、`m3uDirectory`）名字和含义不变（D-018）。
