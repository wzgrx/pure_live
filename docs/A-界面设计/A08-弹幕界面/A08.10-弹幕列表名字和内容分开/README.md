# A08.10 弹幕列表里用户名和内容分开显示，各平台一个样子；加“显示用户名”开关

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：界面
- 来源：用户 2026-10-09：“弹幕列表里发送者的名字和内容要用明显不同的方式显示，名字在所有平台一个样子、内容一个样子；横屏也要考虑；加一个开关，可以不显示用户名、只显示内容”。用户的要求按已确认处理；设计里要选的按 D-003 由维护者定（见下面“需要选的和选择”）。
- 相关：[A08.1](../A08.1-弹幕列表和弹幕设置页/README.md)（列表的紧凑行和卡片）、[A08.2](../A08.2-本地互动/README.md) c10（本地弹幕那一行）、[A08.6](../A08.6-设置的弹幕页补两组/README.md)（“弹幕列表”一组三处共用）、[A08.8](../A08.8-长按弹幕面板显示等级/README.md)（长按卡片的等级）、[D04.1](../../../D-弹幕/D04-数据流和性能/D04.1-弹幕性能和可读性/README.md)（名字颜色 4.5:1）、[E06.2](../../../E-直播平台/E06-平台层升级/E06.2-平台层新数据接到界面/README.md) c2、c3（17LIVE 名字颜色和徽章、酷狗“对方”、`ChatChip`、`ChatBadge`）；礼物那一行以后单独重做（V03.5 调研之后），这里只保持能用、和新的名字样子一致；决定 D-003、D-018（新设置只加不改）；任务书 [brief.md](brief.md)、记录 [record.md](record.md)、真机步骤 [verify.md](verify.md)

## 目标

1. 弹幕列表的两种样式（“紧凑”“卡片”）里，用户名和内容一眼分得开：名字一种字重和颜色、内容另一种；所有平台、两种样式、本地弹幕、长按卡片都是同一套。平台给的名字颜色（17LIVE 的名字颜色、哔哩哔哩等彩色弹幕的颜色）照样可以用，但要过 4.5:1 的对比度规则（D04.1）。
2. 名字前面的小标签和图片一个固定顺序：“本地”或“对方” → 平台徽章图 → 粉丝牌（名字和等级）→ 名字 → 内容。
3. 弹幕设置“弹幕列表”一组加“显示用户名”开关，默认开（和现在一样）；关掉后列表只显示内容。直播间的弹幕设置标签、画面上的弹幕设置面板、设置 → 弹幕是同一个组件（A08.5、A08.6），一处加三处都有。
4. 手机横着拿（右边 280 宽的弹幕列表）、宽屏右栏、系统字号 1.3 倍和 2 倍、浅色 / 深色 / 纯黑主题都不截断、不溢出、对比度够。

## 结果

- c1 两个角色（新文件 `apps/pure_live/lib/features/live_play/danmaku/chat_text.dart`，`ChatText`）：`ChatText.name(theme, [colour])`：`bodyLarge`、600、给了颜色用给的，没给用 `onSurfaceVariant`；`ChatText.content(theme)`：`bodyLarge`、400、`onSurface`；`ChatText.nameEnd` 是“：”。所有带名字的行都用它们：紧凑行、卡片、本地弹幕和本地礼物（`local_interaction/local_chat_line.dart`）、礼物一行、醒目留言一行、长按卡片（`danmaku/message_panel.dart`）。
- c2 名字颜色一条规则（`chat_list.dart` 的 `chatNameInk`）：平台名字颜色 → 弹幕颜色，过 `chatNameColor` 的 4.5:1（紧凑行按 `surface`，卡片和长按卡片按 `surfaceContainerLowest`），白、黑弹幕用次要色。卡片的圆点仍是弹幕颜色（3.x）。
- c3 顺序（`ChatLineView._lead`）：“对方” → 平台徽章图 → 粉丝牌 → 名字 → 内容，两种样式一样；粉丝牌改成 `ChatChip`（`live-play-chat-fans`，主色底、`onPrimary` 字，“粉丝牌 等级”）。
- c4 新设置 `showChatNames`（`packages/live_store/lib/src/settings/settings.dart`，`section: 'danmaku'`，默认开，跟备份和设备同步）；`ChatListSettings`（`shared/danmaku/chat_list_settings.dart`）在“弹幕列表样式”下面加开关行（`danmaku-switch-names`，“显示用户名”，说明“关掉后弹幕列表只显示内容；长按一条仍能看到是谁发的”）；设置搜索 `danmaku_show_names`（“弹幕 › 弹幕列表”，关键字“用户名”“昵称”“名字”）。
- c5 列表（`ChatList`）读这个设置传给每一行（`ChatLineView.showName`、`LocalChatLine.showName`），改了以后已经显示的行马上跟着变（行组件的缓存按样式、开关、表情表三项判断）；关掉时按 G6、G7 藏名字、徽章、粉丝牌、头像，留“本地”“对方”。
- c6 “弹幕列表样式”的说明改成“紧凑：一行一条，用户名加粗、用浅色；卡片：3.x 的每条一张卡片”。
- 不改：飞行弹幕、小窗弹幕、多画面、电视（都不画名字）；醒目留言标签的卡片；复制的文字；礼物一行的结构和配色（等 V03.5）；“N 条新弹幕”、空状态、系统消息、平台通知。
