# A07.18 切换直播间面板筛选时键盘盖住结果：任务书

## 背景

- 来源：S02.5 清单 1A-22（2026-10-08 K90）。
- 为什么做：第三档；筛选是少用的功能，但现在输入后什么都看不到。

## 目标和验收

1. 竖屏直播间里面板筛选时，结果或空状态提示在键盘上方可见。
2. 收起键盘后面板回到原来的高度和位置。
3. 横屏全屏的右侧面板不受影响。

## 现状（读代码得出，写文件:行）

- 切换直播间面板在 `apps/pure_live/lib/features/live_play/switch_room/`（开工先 `ls`，找面板和筛选框所在的文件），面板外壳 `apps/pure_live/lib/shared/panels/side_panel.dart`（`RoomSidePanel`）；查它有没有读 `MediaQuery.viewInsets`。

## 3.x 基线

- 3.x 的切换直播间是对话框（A07.13 记录），不涉及。
