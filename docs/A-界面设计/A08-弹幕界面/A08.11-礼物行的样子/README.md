## 设计要求（方案 A，V03.5 第 6.3 节）

- c1 **和聊天行分开**：左边 16 像素礼物图（`iconUrl` 有才画，`ResizeImage` 按显示尺寸解码，和 `ChatBadge` 一样；没有或加载不出来时用 `AppIcons.chatGift` 第三色，不留空位）；名字用 A08.10 的名字角色（`ChatText.name`，粉丝牌、徽章、舰长照 A08.10 G5 的顺序画在名字前）；后面“送出”（次要色）+ **礼物名（第三色、600）** + “×N”（第三色、等宽数字）；最后是价值（小一号、次要色，例如“100 元”“2000 金瓜子”“79 coins”，免费礼物不显示；单位文字走翻译）。整行没有背景，和醒目留言（有底色的卡片）、通知（次要容器色）分得开。
- c2 **卡片样式**：同样的卡片，左边的圆点换成礼物图。
- c3 **档位**（`LiveGift.tier`）：普通一行；值钱的整行左边 2 像素第三色竖线；很值钱的竖线 + 礼物名用平台色（过 4.5:1）。只用颜色和线，不用动画和阴影（UI.md 第 9.3 节）。
- c4 **连击**：D07.1 合并时只改“×N”，数字放大到 1.2 倍再回到 1（200 毫秒；系统要求减少动态时不动）。
- c5 **“显示用户名”关掉**（A08.10 G6、G7）：礼物行同样藏名字、徽章、粉丝牌，留“送出 礼物名 ×N 价值”。
- c6 **横屏 280 宽**和系统字号 1.3、2 倍：不截断礼物名；放不下时价值换到第二行；不溢出。
- c7 **长按**：和聊天行一样打开长按弹幕面板（第一张卡片显示这条礼物；复制、屏蔽这个用户、屏蔽关键词）；双击复制“名字: 送出 礼物名 ×N”。打码昵称照 D-013 不能屏蔽。
- c8 **文字走翻译**：“送出”“×”“上舰”“开通”和各单位（zh、en）；`kind = membership` 的写“开通 舰长 ×1 个月”这类。
