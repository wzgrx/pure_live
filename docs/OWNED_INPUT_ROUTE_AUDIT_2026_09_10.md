## 实现

- `LiveInputRecipe` 是无活动会话、凭据和本地 URI 的公开重建参数。niconico 保存节目、分辨率与码率；绑定层延迟构造 `NiconicoPlaybackInput.source`，解析层不依赖播放器生命周期。
- `LivePlayUrlResolution.owned` 在标准化与恢复中保留配方及画质确认；自有输入按一条逻辑线路计算，不以空的导出 URL 列表认定无源。原直链去重与查询策略校验保持。
- 页面 PlayerState 保存类型化源。音频/无关呈现更新保留，直链替换清除；自有源不导出旧媒体 URL。路由首次解析、VideoController 打开、管理器重入与页面悬浮快照传递同一能力。
- 画质切换不再把两个空 URL 列表判成同流。自有源跳过远端头部和 URL 到期策略，经过实际 `PlayerManager.playSource`，以规范提交回执更新页面；失败、暂停、关闭和迟到解析沿用提交/回滚与意图栅栏。
- 恢复闭包捕获站点、公开房间与绑定函数，不保留页面控制器；按实际请求画质绑定新配方。线路按钮、全屏线路列表与画质入口使用逻辑线路数。
