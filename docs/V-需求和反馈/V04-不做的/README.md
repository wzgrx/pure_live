# V04 不做的

决定不做的事放在这里：是什么、为什么不做（引用 DECISIONS 的编号）、做了什么替代、以后在什么条件下可能重新考虑。“不做”的任务不计进度，但要能查到，免得以后有人再提一遍又从头讨论。

## 范围

- 包括：
  - V01 的提议评估后用户决定不做的（PROCESS 第 6 节第 3 步：状态改“不做”，原因写进 DECISIONS，移到这里的说明）。
  - 审查、调研、上游对照里看到但决定不做的（例如上游的 Anime4K）。
  - 做法、流程上决定不用的（例如云端会话做任务）。
- 不包括（归哪里）：
  - 某个任务里的一小部分不做（例如 A07.13 不做某个按钮）：写在那个任务的“确认的改动”或记录里，不单独登记。
  - 因为已经被别的任务做完而关掉的余项任务（C01.3、D06.1、Q04.1，D-029）：它们留在原来的子分类，状态“不做”，不搬过来。
  - 3.x 有、4.x 决定去掉的功能（例如播放内核切换 F-ROOM-24）：记在功能清点和对应任务里。
