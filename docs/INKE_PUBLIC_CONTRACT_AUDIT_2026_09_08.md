`Live_hotlist_pc` 实测 `error_code:0,data:[]`，并不表示平台没有直播；同一时段三个官网精选接口都有实际房间。禁止据旧接口的空数组宣布全站下播，或猜测不存在证据的分页参数。

## 独立 Dart 实现

新增 `lib/core/site/inke/inke_api.dart`：

1. 固定匿名官方端点，沿用应用 Dio 接入边界；可注入请求供确定性测试。关闭 API 重定向，区分 401/403、404、429、5xx、传输、结构、取消和当前公开媒体缺失，不将错误都映射为下播。
2. 字节和 UTF-8 大小上限 1 MiB，响应体使用总截止时间并释放订阅。错误只输出类别，不包含原始响应或签名 URL。
3. UID 是持久房间身份，广播 ID 每次重新查询；元数据刷新不读取媒体，播放解析则在官网精选中按两者同时配对，至多查询三个精选端点，不跨房间拿第一条流。
4. 仅返回已取得媒体前缀证据的公开明文 FLV 路径/主机，不合成 HLS、不修改签名、不把未知或 `_en` 路径当已验证的额外线路。展示协议为 `FLV`，不虚构 1080p/原画等画质。
5. 精选目录是一页有限快照，类别保留服务端频道标识；去重按 UID，不把主播等级当观众人数。有限精选结束并不表示整个映客只有这些直播间。
6. 正式无当前广播代码才返回明确离线；官网精选暂未包含指定在播间、广播换代、未知媒体形式等返回 `mediaUnavailable`，仍允许独立刷新其在线元数据。
