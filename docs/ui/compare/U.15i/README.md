## pure_live_TV 的样子

- **外壳**：每个设置页是 `TvPageScaffold`（`core/widgets/tv_page_scaffold.dart:111-121`）：顶栏高 66 设计像素（33 逻辑），左边“返回”按钮（`TvButton` mini：图标 `arrow_back_ios_new_rounded` 20、文字 t14 =“返回”，`tv_app_bar.dart:107-114`），右边标题 t24 粗（`:132`）；内容 `SingleChildScrollView` 四周 16（`tv_settings_page.dart:360`），目录是 `ListView` 横 16、竖 12（`:210`）。没有电视安全边距。
- **打开时的焦点**：有返回按钮就落在返回按钮上（`core/widgets/tv_page_shell.dart:163-171`），要按一次下才到第一行；从子页回来，回到上次那一行（`TvFocusRestorer`）。
- **目录**（`tv_settings_page.dart:21-171`）：组和行照桌面版设置页，按模式过滤（`:200-213`）。直播模式：模式设置（切换模式）、主题设置（主题定制、导航栏显示控制）、IPTV 设置、刷新设置、播放内核设置（播放器内核）、网络与代理设置（自定义网络代理）、通用设置（通用）、平台设置（平台显示与授权）、数据管理（缓存与数据管理）、备份管理（备份与恢复，图标 `Icons.settings_backup_restore_rounded`）、关于（纯粹直播 TV / 检查更新；有新版本时副标题“发现新版本 v…”、右边主色“发现新版本”，`:220-229`）。音乐模式多“音乐设置”，视频模式多“视频设置（视频）”，没有 IPTV、刷新、平台。首页侧边栏底部的“设置”推入整页（`features/home/home_page.dart:427`）。

## 拿不准的地方

- 手机 U.6a～e、U.7b、U.10、U.11、U.12 还没定稿：电视图里同一设置项的文字和顺序是照 v3 代码和 U.6c 第 1 版草稿画的（例如兼容模式的长说明、“恢复默认设置”、当前值放右边），手机改了电视跟着改。
- “播放器强制销毁”pure_live_TV 没有，v4 有这个设置（手机在内核页）；电视要不要放，按 v4 的播放器在电视上是否有效定。
- pure_live_TV 的点播“视频设置”（U.15i-59）和直播“视频”同名不同页；视频模式下两组是否同时出现，随 U.15f 定。
- 默认 1080p 电视的逻辑尺寸按 960×540（DPR 2）算；有的盒子报 1280×720 / DPR 1，pure_live_TV 会把字放大 1.5 倍（`tv_text_scale.dart:52-54`），新设计的字号按逻辑像素给，未在 720p 盒子上核对。
- “配置预览”没有入口是按代码搜索得出的（`ConfigPreviewRoute()` 没有调用处），没在真机上核对。
