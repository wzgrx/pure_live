## 目标

应用内小窗（离开直播间时在首页角落继续播的那个）现在大小固定：手机上宽 220（屏幕短边 × 0.56，限制 220～360），不能改；看的时候想大一点只能回直播间。系统画中画在 Android 上可以用两指拉大，但拉大后飞的弹幕不跟着变大（缩放上限 1.0），显得很小。提议：

1. 应用内小窗右下角拖动改大小，记住上次的大小（c1、c2）；
2. 设置里加“小窗大小”（c3）；
3. 小窗和画中画放大时弹幕跟着按比例变大（c4，其实是现有行为的修正，可以先单独做）。

## 3.x 的样子和问题

- 3.x 应用内小窗：`git show v3.2.11:lib/player/core/player_manager.dart` 的 `:4737` `resolveAppFloatingSize`（宽按屏幕短边比例、竖屏 1.2 倍高），`:3010` 调用；不能拖角改大小；没有尺寸设置。4.x 照搬（`apps/pure_live/lib/features/live_play/logic/mini_window.dart:98` 的 `inAppMiniBase`、`:104` 的 `inAppMiniSize`）。
- 3.x 小窗弹幕：`lib/common/utils/compact_danmaku_metrics.dart`：按窗口宽度 / 350 缩放，限制 0.65～1.0，行高 18～44；4.x 照搬（`mini_window.dart:191` 的 `CompactDanmakuMetrics`，`:201` `clamp(0.65, 1.0)`，`:208` 行高 `clamp(18.0, 44.0)`；A07.8 c7 加了“不小于 10 号”）。
- 问题：
  - P1 应用内小窗手机上只有 220 宽，看不清；不能改。
  - P2 画中画拉大后弹幕不变大（上限 1.0），上游 `b2cca41c7` 改成 2.0、行高上限 88、表情上限 64。
  - P3 桌面小窗已能改大小（不是问题）；上游 `582e355f7` 的“最小宽高”滑条是 Windows 画中画驱动的，4.x 的桌面小窗不用它。
