## 验收

- 翻页不再软绵绵（约 0.27 秒停稳）、斜着上下滑不误翻；侧面板松手不断速。
- 测试：300 dp/s 不翻页、600 dp/s 翻页、停稳 ≤300 ms；侧面板松手后第一帧位移和松手前最后一帧之比在 0.8～1.25，停稳 ≤350 ms。
