## 目标

3.x 的“IPTV 设置”和“订阅源管理”两页合成一页，导入、同步、删除、切换节目单、同步设置都能用；失败说清原因；页面随数据（包括后台自动同步和分享导入）自动刷新；修掉 3.x 页面的 8 个问题。

- 提交：`abf627e86`（2026-10-01 合并）；A13.1（`7c6d685cb`）之后按确认的设计重做了样子，逻辑沿用。

  - c5 修了 8 个 3.x 问题（record“v3 问题及处理”）。
