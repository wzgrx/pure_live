# T07g.1 页面：观看历史

- 日期：2026-10-01
- 目录：`apps/pure_live/lib/features/history/`（路由 `RoutePath.kHistory`，类名和构造参数不变）
- v3 来源：标签 `v3.2.11` 的 `lib/modules/history/history_page.dart`（407 行）、`lib/common/services/settings/history_controller.dart`（236 行，存储部分已在 T09b.1 变成 `HistoryStore`）、`lib/common/widgets/room_card.dart` 里卡片的点击和长按菜单
- 用到的包：`live_store`（`store.history`、`store.follows`、设置）、`live_core`（`LiveRoom`、平台登记）、`live_ui`（`RoomCard`、`EmptyView`、`AppStatusView`、文字样式、`PlatformLogo`）

## 做法

| 文件 | 内容 |
|---|---|
| `history_page.dart` | 页面（`ConsumerStatefulWidget`）。历史来自 `store.history.watchAll()`（页面内的 `historyRoomsProvider`），写入都走 `HistoryStore`：`clear(shown)`、`update`、`setLimit`。刷新的加载器 `historyLoaderProvider` 和时钟 `historyClockProvider` 是页面内的 provider，测试替换 |
| `history_refresh.dart` | 刷新：并发数取设置 `maxConcurrentRefresh`，每个房间 12 秒超时（同 v3）；平台有 `LiveSiteRoomRefresher` 就用轻量的卡片刷新，否则 `getRoomDetail`；失败的房间用 `pendingAfterError()` 标成状态未知；离开页面后不再发新请求，已取到的照样存下 |
| `history_sections.dart` | 按观看日期分组（今天、昨天、近 7 天、更早，按日历日，跨夏令时取整）、筛选、观看时间文字 |
| `history_cards.dart` | `LiveRoom` → `RoomCardData` 的本地适配：人数（设置 `preferRealOnlineCounts`、`realOnlinePlatforms`，格式同 v3 `readableCount`）、受限标记、主播名为空时显示平台名、图片地址规范化（同 v3 `normalizeNetworkImageUrl`）、卡片外观（手机/桌面各一份的预设和自定义设置） |
| `history_limit_dialog.dart` | 保留数量对话框 |
| `history_room_menu.dart` | 卡片长按（右键）菜单 |

存储语义沿用 T09b.1：新的在前，重看移到最前，按 `historyLimit` 截断（0 = 不限）；“清空”和“删除”只删页面当时显示的那些条目，之后又看过的（`lastWatchedAt` 变了）保留；刷新保留观看时间和已存的名字（`mergeFrom` + `withAudienceFallbackFrom`），不改顺序。

## v3 问题及处理

| # | 问题 | 位置 | 处理 |
|---|---|---|---|
| 1 | 保留数量框里输入了数字但没点“应用”就点“确认”，保存的是旧值，输入被悄悄丢掉 | `history_page.dart:295-299`（`_save` 只存 `draftLimit`） | 确认时输入框里有数字就先校验并采用；不合法时停在对话框显示错误 |
| 2 | 刷新失败的房间保留旧状态：几天前看过时的“直播中”和人数一直显示 | `history_page.dart:51-54`（失败返回原房间） | 失败的房间标为状态未知（`pendingAfterError`），卡片不再显示旧的人数 |
| 3 | 桌面用鼠标无法刷新：应用的滚动行为不让鼠标拖动列表（T07a.1 `AppScrollBehavior`，同 v3 `MyCustomScrollBehavior`），下拉刷新拉不出来 | — | 标题栏加刷新按钮 |
| 4 | 刷新途中离开页面，已经取到的结果全部丢弃 | `history_page.dart:58`（`if (!mounted ...) return` 在保存之前） | 离开后不再发新请求，已取到的照样存下 |
| 5 | 每个房间都请求完整详情（播放、签名、弹幕参数），刷新几十条很重 | `history_page.dart:46-49` | 平台有轻量卡片刷新（`LiveSiteRoomRefresher`）就用它 |

另外：平台回答了另一个身份的房间时（改名、频道换场），v3 会用它替换这一条；现在算这条刷新失败，不替换。

## 界面改进

（2026-10-01 用户授权：界面、布局、操作和视觉反馈可以改进，数据仍在 `live_store`，3.x 的历史和上限设置由 T09b.1 原样导入。）

1. **按观看日期分组**：今天、昨天、近 7 天、更早，每组标题带条数；没有观看时间的旧记录归入“更早”。历史长了以后容易找。
2. **筛选**：标题栏的搜索按钮打开筛选框，按标题、主播、房间号、平台名（含中文名）筛选，显示匹配条数，没有匹配时有专门的空状态。筛选时“清空”只删匹配的（确认文字说明其他记录不受影响），刷新也只刷新匹配的。
3. **刷新**：标题栏加刷新按钮（桌面用鼠标也能刷新）；页面顶部细进度条显示进度；完成后提示“已刷新 N 个直播间”或“N 个中有 M 个刷新失败，已标为状态未知”（v3 只有下拉头部的成功/失败图标）。
4. **失败不再显示旧状态**：见问题 2。
5. **加载和出错**：首次读取时显示加载动画，读取失败显示错误页和重试按钮。
6. **空状态说明**：“看过的直播间会按观看时间出现在这里”。
7. **保留数量框**：“应用”按钮改成输入框里的勾选按钮，确认时输入的数字直接生效（问题 1）；新上限会删掉记录时用红字提示“保存后将删除最早的 N 条记录”。
8. **卡片菜单**：显示平台名、房间号和观看时间（“今天 21:05 / 09-30 21:05 观看”）；按钮有关注/取消关注、进入直播间、从历史删除，有链接时可复制链接。
9. **操作结果提示**：删除、清空、关注、取消关注成功后有提示（v3 只在失败时提示）。
10. **卡片内容**：受限直播标出类型（付费、密码房、仅限 App 等，统一原则“卡片标出受限类型”）；平台没给主播名时显示平台名（UPGRADES 28-2）；没有标题时显示“未命名直播间”。
