# 单页数量设置边界与弹窗生命周期审计

## 范围与根因

本轮以 `f132f309` 为基线，修订提交为 `68a2a9cd`。范围限单页数量设置的持久化、当前/旧版备份、导出与管理弹窗；没有构建安装包、操作手机、发起生产网络请求或执行 Windows GUI，Computer Use 与 Astra Light 使用均为 **0 次**。

源码审查确认五个相邻缺口：

1. Hive、备份和控制器公开写入可接受零值、负值、重复值、超过 100 的值或空列表；空列表最终会让紧凑选择器访问 `options.first` 时崩溃。
2. 默认单页数量可在观察器启动前与候选列表脱节，损坏持久值会短暂进入消费者；当前/旧版备份和导出也没有共用归一化合同。
3. 保存接口会原地排序调用方传入的列表，产生隐式副作用；导出还可泄漏直接写入控制器的异常值。
4. 当前备份缺省的“显示单页数量选择器”和“显示跳页按钮”为关闭，与字段和旧版提取的开启默认值不一致。
5. 管理弹窗只静默忽略异常或重复输入；确认退出时又在路由反向动画完成前释放输入控制器，编辑后确认可稳定触发 `TextEditingController` 已释放异常。

## 修订

- 建立共享 **1～100** 整数合同：过滤越界值、去重、排序；结果为空时回落到自适应候选，并保证默认值始终属于候选列表。
- 在安装观察器前同步修复 Hive 候选与默认值；运行时直接写入、保存、当前/旧版备份解析和导出均复用同一合同。
- 保存接口复制并归一化输入，不再修改调用方列表；当前备份缺省的两个可见性开关统一为开启。
- 管理弹窗仅接收数字，明确显示范围与重复提示；自适应重置和继续编辑会清除旧错误。
- 新增由弹窗路由子树持有的 `_PageSizeInputOwner`，输入控制器只在子树实际卸载时释放，覆盖确认/取消及反向动画生命周期。
