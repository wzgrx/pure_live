## 生命周期设计

1. 两个操作栏都接入 `ControlHoverRegion`，每个挂载区域有独立 owner，不会用旧栏的退出事件
   清除新栏或其他同时挂载表面的悬停状态。
2. 控制器从单个布尔值改为 owner 集合；第一次进入取消原有隐藏任务，最后一次离开重新设定
   原四秒期限。反复 hover 不新增 owner，不增加播放器/源请求。
3. 控件隐藏、锁定、换控制器或卸载显式释放。Flutter 官方说明：MouseRegion 卸载不触发
   onExit，仅绑定 onEnter/onExit 会留下假悬停，见
   [MouseRegion.onExit](https://api.flutter.dev/flutter/widgets/MouseRegion/onExit.html)。
4. 控制器替换先释放旧 owner，帧后才通知新控制器，避免 build 中写 Rx；过期帧后回调有代次校验。
5. 退出/卸载只启动隐藏期限，不强行重新显示控件；控制器已销毁时事件被忽略。多鼠标设备在
   同一区域共享一个租约，最后一个离开才释放。
6. 不替换按钮、快捷键、触摸手势或竖屏恢复区域；Android 触摸本身不产生鼠标悬停，连接鼠标
   时也使用相同规则。新增包装不拦截子按钮的触摸点击。
