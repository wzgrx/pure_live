# A 界面设计

用户看得到的一切都在这一组：设计系统（颜色、文字、图标）、通用组件和弹窗、滑动和拖动的手感、尺寸和字号适配、无障碍，以及每个区域（首页、直播间、弹幕、浏览、录制、设置、账号、网络电视、系统界面、小页面）和每个客户端（桌面、电视、苹果平台）的界面设计和实现。排第一，是因为 4.x 从 3.x 重构时用户最先、最常感觉到的偏差都在界面上（[specs/UI.md](../specs/UI.md) 第 2 节：竖屏上栏不见、按钮挪位、图标换掉），而且后面各功能组的页面都要用这里的组件（[D-025](../DECISIONS.md)）。

## 范围

- 管什么：
  - **设计系统**：`packages/live_ui/lib/src/theme/`（主题、颜色角色、文字样式、尺寸分档、动效常量）和 `packages/live_ui/lib/src/icons/`（`AppIcons`、`CustomIcons`、`DanmakuIcon`、平台标志）。
  - **通用组件和弹窗**：`packages/live_ui/lib/src/widgets/`（状态页、设置行、标签、芯片、计数、二维码、对话框、面板、小菜单、提示条、下拉刷新等，42 个文件）。
  - **每个页面的样子和交互**：`apps/pure_live/lib/features/<功能>/` 里画界面的部分（布局、控件顺序、图标、文字、弹法、手势、状态的显示），`apps/pure_live/lib/shared/` 里跨功能的界面块（房间网格、侧面板、弹幕设置行），电视外壳 `apps/pure_live/lib/tv/`，桌面窗口 `apps/pure_live/lib/app/desktop/`，Android 原生资源里看得见的部分（通知图标、启动画面，A14）。
  - **界面的工具和门禁**：清点 `tools/ui/inventory.py`、文字提取 `tools/ui/strings.py`、效果图和评审页 `tools/ui/mock/`、导出 `tools/ui/export_compare.py`；门禁“界面结构” `tools/gate/check_ui_structure.py` 和基线 `tools/gate/ui_baseline.json`（规则在 [specs/UI.md](../specs/UI.md) 第 10 节；门禁本身的维护在 [Z02](../Z-工程文档和维护/Z02-门禁/README.md)）。
- 不管什么（归哪组）：
  - 行为和数据：直播间的进房、换台、小窗逻辑在 [C](../C-直播间/README.md)；弹幕协议、过滤、飞行弹幕引擎在 [D](../D-弹幕/README.md)；首页外壳的路由和服务、热门 / 关注 / 分区 / 搜索的数据在 [I](../I-浏览和发现/README.md)；设置的存储和迁移在 [J](../J-设置和数据/README.md)；录制核心在 [H](../H-录制/README.md)。一个任务两样都有时以主要的那样为准（[README](../README.md) 的“界面和功能怎么分”）。
  - 刷新率策略、基准、内存在 [R](../R-性能和流畅度/README.md)（手感在 A03、尺寸适配在 A04）；Android 系统集成（通知渠道、画中画权限、方向锁）的原生逻辑在 [O](../O-Android系统集成/README.md)。
  - 各客户端的打包、原生和平台差异代码在 [X](../X-多端客户端/README.md)，那些客户端的界面在 A16～A18。
  - 翻译文件的维护在 [Z05](../Z-工程文档和维护/Z05-多语言/README.md)；界面任务只负责把新文字加进 `zh.json`、`en.json`。

## 子分类怎么分

前五个是全应用共用的“横向”底座（先有设计系统，组件用它，手感、适配、无障碍再覆盖到所有页面）；中间十个是按用户路径排的区域（首页 → 直播间 → 弹幕 → 浏览 → 录制 → 设置 → 账号和数据 → 网络电视和多画面 → 系统界面 → 小页面）；最后三个按客户端顺序（[D-004](../DECISIONS.md)：Android → Windows → 电视 → Linux → 苹果平台）。

## 风险和注意

- **用户确认过的设计不改**：各任务 README 里“确认的改动”是用户逐条表态的结果；要改就开新任务、出新的评审页（[PROCESS.md](../PROCESS.md) 第 4.1 节）。“需要你选的”按建议 A 由维护者定（[D-003](../DECISIONS.md)），定稿时在 README 注明。
- **3.x 是基线**（[D-001](../DECISIONS.md)）：功能、入口、手势、快捷键不能少（[specs/UI.md](../specs/UI.md) 附录 A 的 18 条回归清单）；还原 3.x 时文字从代码和 `assets/translations/zh.json` 取（`tools/ui/strings.py`），不凭印象（A07.6 五版才定稿的教训）。
- **各处一致**：同一个功能在竖屏、横屏、宽屏、电视是同一个组件，只换位置（specs/UI.md 第 3 节第 7 条）；弹法照 3.x，不先定规则再套（第 8 条）。
- **门禁“界面结构”**：`features/`、`tv/` 不直接写 `Color(0x…)`、`Colors.*`、`Icons.*`、`Remix.*`，基线 `ui_baseline.json` 只减不增，现在是 0；功能目录之间不引用内部文件（现有 17 条例外）。`shared/` 不在扫描范围内（现有 14 处直接写的颜色和图标，见 A01）。
- **`live_ui` 是热点文件**：`scope.dart`（文字）、`live_ui.dart`（导出）、`theme/live_theme.dart`、`icons/app_icons.dart` 几乎每个界面任务都会改，并行开发时一定冲突；按 PROCESS 第 5.1 节同一组同时只开一个开发，合并时两边都保留后重跑测试。主题的改动会波及直播间（A02.1 改 `ListTile` 主题后直播间的长按弹幕面板跟着变）。
- **性能约束**（[specs/UI.md](../specs/UI.md) 第 9.3 节）：不用模糊和亚克力；视频不裁圆角；骨架屏静态；状态变化只重建用到它的小部件。界面任务完成后在 profile 模式看一次帧时间（R01）。
- **文字**：用户看得到的一律中文，`zh.json`、`en.json` 都加、按键名排序（[D-005](../DECISIONS.md)）；翻译键这次不清理（D-024），运行时拼出来的键先列清单（D-016）。
- **测试**：每个界面任务要有布局测试固定按钮顺序、图标和位置，至少竖屏、横屏、宽屏各一个；定时器至少 1 秒（[D-017](../DECISIONS.md)）。
- **代码注释里的文档路径**会被 `tools/docs/docs.py --check` 检查；移动或改名任务文件夹前先 `grep -rn 'docs/A-界面设计' apps packages tools`。
- **苹果平台不能构建**：A18 只设计；电视开发按 D-004 暂缓，已出的设计保留。
