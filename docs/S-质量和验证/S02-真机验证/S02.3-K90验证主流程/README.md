## 结果

- 设备和测试包同 S02.2（`288fec0ec` 的 arm64 profile）。用户 10-02 授权随时接管手机；手机上有个自动操作小红书的应用会抢前台，测试时用 `am start` 把测试包调回来。
- 通过：画中画（系统画中画 `mode=pinned`，画面在别的应用上方继续播）；后台播放和媒体通知；直播间菜单（切换直播间、定时关闭、房间音量、画面比例、投屏、获取直链、分享、在平台打开、本地互动体验，只看了菜单项）；返回逐级退出（先关菜单和面板，再离开直播间，回到分区房间）；录一场过 5 分钟（两段合成一个 339.7 秒的 MP4，分段文件清掉，面板“已保存 · 时长 5:39 · 48 MB · 超清”）；录制通知和按钮；分享接收（别的应用分享“快来看直播 https://live.bilibili.com/6”直接进房）；搜索（全部平台同时搜、卡片标平台、“还有 N 个平台在搜索…”）；分区和分区房间（平台 · 大类、关注按钮）。
- 没验证：划掉应用后继续录（见上）；观看记录、账号页（只有组件测试）。
- 偏差：登记时的范围是 F.9a～F.9c 全部，实际只走了一部分（下面“留下的问题”），登记表按“完成”记，未走的条目转给后续任务。
