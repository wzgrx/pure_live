## 来源、根因与修订

冻结本地上游仍为 `c6c9bd70aedc503c003110dae10a83ad0bb891d8`，只读本地 git show，没有同步或合并。基线与冻结上游均包含下列原有解析机制，分类 upstream-existing；有效红测运行于本批修订前的当前基线，不宣称已对上游重新构建。

| 首个错误状态 | 用户影响 / 修订 |
|---|---|
| 正则要求属性后为空白/结尾，而扫描范围包括显示名 | 最后一个带引号的 TVG/组别丢失；无引号值可能吞入下一属性或名称；显示名里的伪属性反向覆盖真实元数据。改为单次逐字段扫描，只在引号外的第一个逗号结束元数据 |
| lastIndexOf 取显示名 | `News, World` 被截成 `World`。保留分隔符后的完整文本、空名回退 tvg-name；引号内逗号、另一种引号和 URL 查询等号均保留 |
| 固定第一物理行校验、只按 LF 切分 | BOM/空行前缀和 CR-only 列表错误。按首个非空内容行确认完整头标记，支持 LF/CRLF/CR，拒绝伪头前缀 |
| EXTGRP 被直接跳过 | 使用分组指令的频道失去分类。实现持续分组、空指令清除，显式 group-title 终止继承；不把多组字符串拆成新数据库结构 |
| 缺 URL、坏 URL、未闭合属性未形成可用失败信号，导入器只判断频道非空 | 部分解析结果可能作为完整列表提交，从而删除旧频道。parser 记录具体行错误，导入器在准备文件/数据库写入前拒绝有错误的结果，保留完整旧数据和缓存 |

分组行为参照 2026-09-08 查阅的 [Kodi IPTV Simple 官方格式说明](https://github.com/kodi-pvr/pvr.iptvsimple#supported-m3u-and-xmltv-elements)：EXTGRP 影响后续频道，空指令及 group-title 结束继承。这是兼容行为的参考，不代表实现了 Kodi 的 catchup、radio、WEBPROP 或播放器 HTTP 属性。旧注释中的自动提取 EPG URL 和 tvg-shift 支持承诺已收窄至实际行为；没有新增自动订阅或 EPG 网络请求。

## 修复后的升级风险及处理

首轮 76/76 之后，补测发现一个**本批解析修订与已有协调器组合引出的升级回归**：数据库保存着旧版截断名称且没有 TVG 时，修正后的名称/TVG 同时变化，会获得新 ID，使收藏不再关联。独立实际 SQLite 红测确认 ID 变化，未将其误记为已经通过。

协调器在原有更强的元数据匹配之后，增加唯一且保持不变的 URL 作为最后匹配条件，保留旧 ID、收藏和隐藏设置；两个非空 TVG 互相冲突时仍不匹配。多个改名频道共享同一 URL 时整批保持原快照，不猜选身份。已补正例和两项冲突/歧义保护，全部进入最终回归。

这不是任意旧库数据恢复：如果名称、TVG 和 URL 均变化，或旧 TVG 已被错误文本污染且与新 TVG 冲突，本批不凭相似性猜测。历史用户数据备份及恢复边界仍按 [身份迁移审计](EPG_SOURCE_IDENTITY_AUDIT_2026_09_08.md)。
