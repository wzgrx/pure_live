## 要做的

- c1 访客看到的打码昵称（`BilibiliDanmakuProtocol.isMaskedName` 判断，如“观***”）在长按弹幕面板、画面弹幕点按面板里**不显示**“屏蔽此用户”；屏蔽关键词照旧。
- c2 屏蔽表里已经存着的打码名：启动时（只做一次，记在 meta）从哔哩哔哩的用户屏蔽表里移除，并在屏蔽管理页顶部提示一次“已清理 N 个打码昵称的屏蔽（它们会误伤其他观众）”。
- c3 屏蔽管理页添加用户屏蔽时，输入打码名（含 `***`）给出说明并拒绝。

## 验收

- 打码名不能被屏蔽；已有的打码屏蔽被清掉且只提示一次；正常昵称照旧能屏蔽。
- 测试：打码名不出现“屏蔽此用户”；清理迁移只跑一次；正常名照旧。
