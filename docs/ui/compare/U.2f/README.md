## 各版的经过

| 版 | 内容 | 用户意见 |
|---|---|---|
| 第一版 | 所有弹窗统一成从画面下沿升起的面板 | “画质与线路不行，不如 v3” |
| 第二版 | 弹法照 v3，只修 v3 具体的问题 | 竖屏清晰度和线路可以；全屏的卡片和布局要优化、要多尺寸适配 |
| 第三版 | 全屏“清晰度与播放线路”重做，按屏幕尺寸换形态 | 线路和画质可以；录制 v3 和新设计都不行；弹幕设置放画面下方可以，但内容比 3.2.11 少 |
| 第四版 | 录制按 9 种状态重做；弹幕设置照 3.2.11 代码补全 | 录制可以；界面、布局、操作要在各客户端一致，第三版全屏清晰度面板（手机抽屉、平板电脑浮层）和竖屏不一致 |
| 第五版 | 清晰度和线路在所有客户端都是两个按钮、各弹一个小菜单；录制和弹幕设置横屏、宽屏放右侧，同一个面板同样配色 | “还可以，第五版”，开始开发 |

教训：

1. 第一版先定了“统一成底部面板”的规则再套到每个弹窗，没有逐个看 v3 的弹法：清晰度只选一项却盖住整个弹幕区、离按钮远、多一步关闭、丢了切换时按钮转圈的反馈。之后的原则是**弹法照 v3，只修 v3 具体的问题**。图留作对照：[rejected-v1-quality-panel.jpg](rejected-v1-quality-panel.jpg)。
2. 第二、三版的弹幕设置 v3 图是凭印象画的（模板名和设置项不对，也只画了前半截），看起来像少了功能。之后 v3 还原图的每个文字、选项都从代码取，长面板画完整内容，并列设置项对照表。
3. 录制要先把全部状态理清再设计：v3 的录制任务有 9 种状态，对话框只分了 3 种。
4. 各客户端一致：同一个功能在手机竖屏、横屏、平板、Windows、Linux、电视用同一个组件、同样的样子和操作，屏幕大小只决定放在哪，不换成另一种东西；弹窗配色跟应用主题，全屏不另换一套。

## 每个弹窗的弹法

| 弹窗 | v3 弹法 | 新设计 | 改了什么 |
|---|---|---|---|
| 清晰度、线路（竖屏） | 贴按钮的小菜单，选完就关 | 不变（已确认） | 字 11→14，当前项加勾，按钮加下拉箭头 |
| 清晰度与播放线路（全屏） | 右半边对话框，两组按钮，不自动关 | 和竖屏一样：下栏两个按钮“原画 ⌄”“线路1 ⌄”，各弹一个小菜单 | 各客户端一致；画面不变暗 |
| 录制 | 居中对话框 | 录制面板（已确认）：竖屏在画面下方，横屏和宽屏在右侧，同一个面板 | 状态卡跟着 9 种状态变；开播自动录开关；这次录制的清晰度和弹幕 |
| 弹幕设置（竖屏） | 居中大对话框，盖住画面 | 画面下方（位置已确认） | 设置项一项不少；分组小调整；关联项变灰不消失 |
| 弹幕设置（全屏） | 右侧面板 | 右侧，和竖屏同一个面板、同样配色 | 各客户端一致 |
| 右上角菜单 | 贴按钮的菜单 | 不变 | 分组，加“画面比例”，“打开直播间”改名 |
| 长按弹幕 | 底部面板 | 不变 | 写清后果，屏蔽关键词预填 |

## 录制（第四版）

v3 的问题：R1 对话框只是一串动作，看不到时长、大小、清晰度、位置、是否在重连或排队（`record_action_button.dart:200-330`）；R2 五个动作都列出来，用不了的变灰；R3 每行一种颜色没有含义；R4 “添加监控”要等“启用开播检测”打开才会自动开始，而它默认是关的（`recorder_controller.dart:1295-1297`、`recorder_config.dart:39`）；R5 排队、准备、重连、整理文件、失败、已完成在直播间看不到；R6 开始前看不到也改不了录制清晰度；R7 停止后不知道文件好了没有，没有入口看刚录的文件。

新设计：画面下方的录制面板。顶部状态卡跟着任务状态变（没在录、等待开播、准备中、排队中、录制中、重连中、整理文件、已保存、失败），只出现当前能做的事；录制中显示计时、大小、码率、清晰度、弹幕条数、第几段；“这次录制”可选清晰度和是否录弹幕（录制中只读）；“开播自动录”开关代替添加 / 取消监控，开播检测关着时提示；停止后显示整理进度和已保存的文件（播放、去录制中心、再录一次）；v3 的五个动作都还在。横屏全屏、平板、电脑用同一个面板、同样配色放在右侧（宽 360），点画面上的“● 录制中”角标也能打开；宽屏时盖在右侧聊天栏上。

## 弹幕设置（第四版）

全部设置项照 v3（`pages/danmaku_settings_page.dart:195-420`）：观看模板（顶部 20% · 均衡、顶部 35% · 舒适、顶部 55% · 高密度、重置）、保存 / 恢复模板、纯文字模式、画面顶部占用高度、顶部留白、区域底部留白、透明度、滚动速度、字体大小、字体粗细、弹幕描边、描边宽度、弹幕帧率跟随、手动帧率、合并相同弹幕、合并时间、点击画面弹幕、长按画面弹幕。

改动：D1 竖屏放到画面下方；D2 模板单独一组、说明跟着选中的模板变、“保存 / 恢复”改成文字按钮；D3 “显示范围”一组放占用高度和两个留白，纯文字模式移到“样式”；D4、D5 描边宽度、合并时间、手动帧率在不可用时变灰而不是消失。

## 清晰度和线路：横屏、平板、电脑（第五版）

第三版按屏幕高度换成右侧抽屉或贴按钮的浮层，和竖屏的小菜单不一致，已否决。第五版：全屏下栏把 v3 的“原画 · 线路1”拆成两个按钮“原画 ⌄”“线路1 ⌄”，各弹一个贴着按钮的小菜单（上方或下方，哪边放得下放哪边），样子、字号、勾、选完就关、切换时按钮转圈，和竖屏完全一样；菜单宽度跟内容，各尺寸一样大；画面不变暗；电脑上悬停高亮、方向键和回车、Esc 关闭。

v3 全屏的问题：FQ1 和竖屏是两种东西（`video_controller_panel.dart:1048-1265`）；FQ2 宽度固定是屏幕的一半（`content_first_panel_layout.dart:35-43`）；FQ3 盒子套盒子加分隔线、整屏压暗（`video_controller_panel.dart:1110-1180`、`:1292-1350`）；FQ4 在右侧正中，离按钮远（`:1113`）。
