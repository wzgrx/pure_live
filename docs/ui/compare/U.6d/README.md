## v3 的样子

行的组件和顶栏、对话框底色见 [U.6c](../U.6c/README.md#v3-的样子)。

**通用**（`general_settings_page.dart:16-169`）：只有一组“通用”。Android 和 Windows：界面刷新率 `speed_up_line`，说明“档位名 · 档位说明 · 当前 / 最高 Hz”（`:25-39`）；Windows：Windows 动态刷新率 `speed_up_line`，说明两行（跟随显示器 + “1920 × 1080 · 60 Hz (最高 144 Hz)”），右边刷新图标，点了重新检测（`:40-56`）；Windows：新建独立播放窗口 `add_to_photos_outlined`（默认开）；启动动画 `rocket_2_line`；自动检查更新 `refresh_line`（没有说明）；使用 GitHub 官方更新源 `github_line`；应用定时退出 `timer_line`；退出前等待时间（自绘的转动表盘图标，说明“120 分钟”或“剩余时间: 01:59:58”，`:89-117`、`:543-585`）；Windows：开机启动 `windows_line`（默认开，更新中“正在更新 Windows 启动项…”，失败红字，`:119-148`）、开机窗口尺寸 `aspect_ratio_line`（“1080 × 720”）、退出不再询问 `error_warning_line`（没有说明，默认关）。

**对话框**：界面刷新率——说明 + 三个单选（档位名旁边一个耗电小标签、下面一段说明），选了就关（`:195-260`）；开机窗口尺寸——“快捷预设选择”5 个预设、“自定义输入尺寸”宽 × 高、范围提示、取消 / 加粗“确认”，点了立即改变当前窗口并居中（`:274-424`）；设置应用退出等待时间——说明、7 个快捷时长（点了立即生效并关闭）、自定义时长输入框、取消 / 保存，超出范围弹提示条（`:426-541`）。

**关窗口**（`plugins/utils.dart:241-330`）：退出不再询问关着时弹“最小化 / 退出应用”和“不再询问”；开着时直接按记住的动作（`exitChoose`，默认退出）执行。

**平台显示与授权**（`platform_settings_page.dart:8-73`）：一组“平台显示与授权”：平台显示 `apps_2_line`、首选直播平台 `heart_3_line`（右边“哔哩哔哩”14 号 75% 灰 + 箭头）、三方认证 `accessibility_line`、标签管理 `price_tag_3_line`。首选直播平台对话框：标题粗体、搜索框“搜索已显示的平台”、平台显示里打开的平台逐个单选（没有图标），没有匹配时“没有匹配的平台”（`:85-173`）。

**刷新设置**（`refresh_settings.dart:8-170`）：一组“自动刷新设置”：开启关注自动刷新（默认关）、返回应用时刷新收藏（默认开），（自动刷新打开才有）刷新间隔时间“30 分钟”，首页并发刷新任务“4 个任务 · 说明”，自动刷新直播缩略图（默认关），（打开才有）缩略图刷新间隔。三个对话框都是 `_RefreshRadioDialog`：标题、（并发数有一段说明）、单选列表，选了就关；刷新间隔 12 档、缩略图间隔 8 档、并发数 1–20（4 标“推荐”）。

**网络与代理设置**（`network_proxy_settings_page.dart:130-190`）：两组“软件应用层代理 (解决启动、刷列表)”“播放器内核代理 (解决直播流拉取)”，每组一个原生 `SwitchListTile`（图标 `apps_line` / `video_line`），打开后下面出现“代理地址”“端口”两个输入框（窄于 420 上下排，否则 3:2 并排），输入即保存，端口不对时红字“请输入 1 到 65535 之间的端口”。默认端口 7897，地址为空。

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 界面刷新率、启动动画、更新、定时退出；横屏最宽 720 居中 |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 最宽 720 居中；Windows 多开机启动、开机窗口尺寸、关闭窗口时、新建独立播放窗口；Linux、macOS 照 v3 没有界面刷新率和这几项（是否加归 U.13）；悬停高亮、Tab 和方向键移动、空格切换开关 |

| 苹果平台 | iOS、iPadOS 同 Android 手机，照 v3 没有界面刷新率；macOS 同 Linux |

## 待选

- Y1 “退出不再询问”：建议 A 换成“关闭窗口时”三选一；B 保留开关，说明里写出记住的动作。
- Y2 时长对话框点快捷时长：建议 A 立即生效并关闭（自动助眠也改）；B 只填进输入框再保存（定时退出也改）。
- Y3 首页并发刷新任务：建议 A 行内加减；B 照 v3 20 项单选。
- Y4 Windows 动态刷新率：建议 A 并进界面刷新率；B 照 v3 单独一行。

## 拿不准的地方

1. “最小化”在 Windows 上是最小化到任务栏还是藏到托盘（`_minimizeOrHideDesktopWindow` 和托盘设置有关），选项说明开发时照实际行为写；图里写的是“缩到托盘，直播照常”。
2. Android 上 `DisplayModeService.info` 的当前 Hz 在省电档时会随系统变（60 / 120），图里按 60 画。
3. 新加的文字（“关闭窗口时”“每次询问”及其说明、“点‘应用’后窗口立即变成这个大小”、“打开……后生效”）是新写的，`zh.json` 里没有。
