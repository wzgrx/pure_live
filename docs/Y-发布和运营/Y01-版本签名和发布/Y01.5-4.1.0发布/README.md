## 目标

把 4.0.0 之后合并进 master 的改动（`4b039e0c7..master`，约 520 个提交）发布成 4.1.0。要做到的有四点：

- 发布页上有三个 ABI 的 APK 和 `SHA256SUMS.txt`。
- 正式包能覆盖安装 3.x 和 4.0.0，数据保留。
- 装了 3.x 和 4.0.0 的用户都在应用内收到“新版本 4.1.0”的提示。
- 其他平台的 3.x 用户不受影响。

## 5002（没有发布）

`02f92af81`（`4.1.0+5002`）构建的正式包通过了第 2 阶段的全部检查，K90 也做了轻量冒烟（record.md）。之后用户提了 A07.23、A11.6、D08.6、O01.3 四个问题，说 5002 不发布、修好后发新包。5002 没有打标签、没有发布页、没有改更新文件；那批安装包和哈希不会发布。版本号仍是 4.1.0：5002 没有发布、没有用户装过，不算 D-008 说的“换包”；构建号加一，是因为 5002 的包已经在本机生成过，同名不同内容的包容易混。
