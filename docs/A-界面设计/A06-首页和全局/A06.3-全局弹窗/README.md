## 3.x 的样子和问题

**流程**（`lib/plugins/update.dart`）：新版本对话框点“更新”→ 版本页（A15.2）选一个下载源 → Android 下载 APK 前先申请“安装未知应用”权限（没给就提示并打开系统设置，`:81-93`）→ 没有能用的下载目录时弹“选择下载目录”（`:119-146`）→ 弹提示条“正在下载 纯粹直播v{version}...”（`:95-99`）同时打开下载对话框（不能点外面关，`:100-111`）。同一时间只有一个下载（`:69-77`）。

**新版本**（`modules/about/widgets/version_dialog.dart:26-86`）

- `AlertDialog`，内容可滚动，左右留 16、上下留 12（`:37-38`）；表面容器高色底，圆角 24，标题 20 号半粗（主题 `theme.dart:177-182`）。
- 标题“检查更新”（`:39`）。内容：一个文字按钮“本软件开源免费”（外链图标 `Icons.open_in_new_rounded`，15 号，点了先关对话框再打开项目主页，`:44-58`）；更新日志（Markdown，正文 16 号，`:59`）；空 10。
- 按钮：取消（文字按钮）、更新（实心按钮，进版本页）（`:65-84`），按钮字 13 号（`labelLarge`）。

**选择下载目录**（`common/widgets/download_directory_dialog.dart:17-64`）

- 不能点外面关（`barrierDismissible: false`，`:21`），内容最宽 420。
- 标题“选择下载目录”；说明“当前还没有可用的下载目录。你可以自行选择目录，或使用默认下载目录来存放应用更新、下载文件与字体。”（13 号）；“默认目录：{路径}”（12 号、提示色）（`:25-43`）。
- 按钮：使用默认目录（文字按钮）、选择目录（实心按钮），都是 48 高；放不下时竖排（`:46-61`）。没有“取消”。

**下载安装包**（`common/widgets/download_apk_dialog.dart:489-702`）

- 圆角 24，表面容器高色底，最宽 440，内边距 16（`:536-546`）。
- 上部：44 的圆形图标（下载、打开时转圈；完成是 `check_circle_rounded`；出错是 `error_outline_rounded`），标题“正在下载 v{version}...”（15 号粗体，`:499-506`），状态行（12 号，主色，出错时错误色，`:508-514`）。
- 进度框：表面容器低色底，圆角 16，进度条 8 高，右边百分比（大小未知时“…”）（`:565-598`）。
- 屏幕窄于 420（手机都是）或字体放大 1.5 倍以上时换成上下排：图标在标题上面、百分比在进度条下面、按钮竖排占满宽（`:494`、`:550-563`、`:571-583`、`:660-698`）。
- 状态和按钮：下载中只有“取消”；正在打开是灰的“下载完成，正在打开文件...”；下载完成是“立即安装”（`Icons.install_mobile_rounded`）和“打开文件夹”（`Icons.folder_open_rounded`），**没有关闭**；打开失败是“重新打开”和“关闭”；打开文件夹失败也走打开失败的样子，状态行写文件位置（`:339-385`、`:622-702`）。
- 下载失败：对话框直接关掉，在页面底部弹提示条“下载失败，请稍后重试”（`:245-252`、`:479-487`）。
- 每收到一块数据就刷新一次（`:274-301`）。

**口令导入**（`common/widgets/share_command_import_dialog.dart`）

- `AlertDialog`，圆角 16（别的对话框是 24），内容最宽 360（`:23-29`）。
- 标题“分享”；头像（半径 24）+ 标题（15 号粗体，最多两行）+ 主播名；下面一个带边框的框：“平台 {平台 id}”“房间号 {房间号}”（`:30-56`、`:73-139`）。窄于 350 或字体放大 1.6 倍时头像在上（`:20-21`）。
- 按钮：取消、进入房间（48 高）（`:57-69`）。

**提示条**（v3 的 `ToastUtil`，SmartDialog 默认样子）：下载地址无效“下载失败，请稍后重试”；“请授予安装权限后再尝试下载安装”；“请求安装权限失败，{原因}”；“正在下载 纯粹直播v{version}...”（下载别的文件时“正在下载 {文件名}...”）；“未选择下载目录，已取消下载”；“所选下载目录需要存储权限：请在系统设置中授予「所有文件访问权限」，或改用默认目录”；下载失败（对话框里的 SnackBar）。

**设计时 v4 的样子**（2026-10-01，`apps/pure_live/lib/features/version/`）：新版本对话框已改成“发现新版本: v{version}”、“查看详情”、“下载并安装”（直接在应用里下载、先挑最快的下载源）；下载对话框有“关闭”、下载失败可“重试”“在浏览器中下载”。还没有选择下载目录和口令导入对话框。

## 按钮的作用和用法

编号对应 [v4-update-n.jpg](v4-update-n.jpg)、[v4-dir-n.jpg](v4-dir-n.jpg)、[v4-download-states-n.jpg](v4-download-states-n.jpg)、[v4-share-n.jpg](v4-share-n.jpg)。

| 编号 | 控件 | 怎么用 |
|---|---|---|
| 1 | 本软件开源免费 | 打开项目主页（浏览器），对话框不关。 |
| 2 | 不再提醒这个版本（新） | 勾上后关掉对话框，这个版本不再自动提示。 |
| 3 | 其他下载方式（新） | 进版本页，自己选安装包和下载源。 |
| 4 | 取消 | 关掉，下次启动还会提示（除非勾了 2）。返回键、Esc 同。 |
| 5 | 下载并安装 | 直接下载本机的安装包（本机没有安装包时是“更新”，进版本页）。电脑上回车同。 |
| 6 | 取消（新） | 不下载了；点外面、返回键、Esc 同。 |
| 7 | 使用默认目录 | 用默认目录，记住选择，开始下载。 |
| 8 | 选择目录 | 打开系统目录选择器；选的目录没有权限时提示，可改用默认目录。 |
| 9 | 取消 | 停止下载，已下载的部分留着，下次接着下。 |
| 10 | 关闭（新） | 关掉对话框，文件留着。 |
| 11 | 打开文件夹 | 打开安装包所在的文件夹。 |
| 12 | 立即安装 | 交给系统安装器（Android）或运行安装包（Windows）；打不开时显示原因和“重新打开”。 |
| 13 | 在浏览器中下载（新） | 用浏览器打开下载地址。 |
| 14 | 重试（新） | 接着下载，失败的下载源换下一个。 |
| 15 | 重新打开 | 再交给系统打开一次。 |
| 16 | 取消 | 不进房间；同一段口令这次运行里不再问。 |
| 17 | 进入房间 | 打开这个直播间。 |

## 各客户端

| 客户端 | 怎么做 |
|---|---|
| Android 手机 | 竖屏图；横屏同一个对话框，宽 560，日志太长时日志区单独滚动，按钮行固定。APK 安装前先申请“安装未知应用”权限（照 v3）。 |
| 宽屏（平板、Windows、Linux、iPad、macOS） | 同一个对话框居中，宽 560（新版本）、440（下载）、400（口令导入）；鼠标悬停高亮，回车等于主要按钮，Esc 等于取消或关闭，焦点框只在用键盘时显示。Windows 下载安装包或便携 ZIP，“立即安装”运行安装包。 |
| 电视 | 电视的更新提示在 A17.2，用这个对话框的电视样式（焦点放大、字大一级），内容同上；口令导入电视上没有剪贴板，不适用。 |
| 苹果平台差异 | iOS 不能在应用里装安装包：主要按钮换成“去下载页”，没有下载对话框；macOS 下载 ZIP，“立即安装”换成“打开文件夹”（见“拿不准的地方”）。 |

## 待选和决定

## 拿不准的地方（设计时记下的）

- v3 的提示条是 SmartDialog 的默认样子，效果图用工具里的提示条近似。
- 默认下载目录的路径（`getDownloadsDirectory()/pure_live`）是按代码推的示意，K90 上的实际路径没看。
- iOS、macOS 在 v3 里怎么更新（有没有安装包、走不走这个下载对话框）没有在代码里找到明确的分支，上面“苹果平台差异”是建议，在 X 定。
- 电脑上“立即安装”也用手机图标 `install_mobile`（v3 就是这样）；可以在电脑上换成 `install_desktop`，没有列成改动。
- “不再提醒这个版本”存在哪里、和备份是否一起导出，开发时定（实现：本机设置，不进备份，见下）。
