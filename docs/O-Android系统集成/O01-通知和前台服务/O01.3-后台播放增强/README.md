## 目标

开着“后台播放”切到后台、锁屏很久、网络抖一下、来个电话、换个网络，直播都接着播；各家手机（小米 HyperOS/MIUI、OPPO/一加/realme ColorOS、vivo/iQOO OriginOS、华为/荣耀、三星、魅族）上用户知道还要在系统里开什么，并且一点就能跳过去。

## 3.x 和现状

| 方面 | 3.x（`v3.2.11`） | 改之前（文件:行，见 record.md R1～R16） | 现在 |
|---|---|---|---|
| 媒体通知和前台服务 | audio_service，一播放就显示；`androidStopForegroundOnPause: true` | 只在后台播放、助眠时显示；重连、重新加载、断流、来电时通知变“暂停”，audio_service 随之停掉前台服务（R1、R2），之后从后台再也启动不了（Android 12+） | 离开应用后在播、重连、等开播（10 分钟）、来电（30 分钟）都算“在播”，前台服务一直在；用户自己暂停才放掉 |
| 唤醒锁和 Wi-Fi 锁 | 后台播放时一直拿 | 离开应用就拿，回来才放，暂停了也拿着（R3）；Android 10～13 的 Wi-Fi 锁后台不起作用（R4） | 只在上面“算在播”时拿；Android 10～13 多拿一个后台有效的高性能锁 |
| 后台断流 | 无自动重试 | session 两轮重试后停住，没人点“重试”（R5、R6） | 5、10、20、30、60 秒……重试，最多 30 分钟；网络回来立刻试 |
| 后台解码视频 | 一直解码 | 一直解码（R7） | 新开关“后台只播声音”（默认关） |
| 后台弹幕 | 一直连着 | 一直连着（R8） | 新开关“后台断开弹幕”（默认关） |
| 关掉画中画 | 开着后台播放时继续出声 | 同 3.x（R9） | 新开关“关闭画中画时暂停”（默认关） |
| 各家系统的设置 | 没有 | 只有打开开关时的通知和电池优化两个框（R11） | 新页面“后台播放设置”：这台手机的品牌、系统和版本；能读到的项（通知、媒体通知类别、电池优化、后台限制、流量节省、省电模式）显示状态；各家自己的项（自启动、省电策略、后台冻结、后台高耗电、应用启动管理、休眠应用、最近任务锁定）说明怎么改、一点跳到对应系统页，找不到就打开应用信息并提示找哪一项；第一次打开后台播放时在这些手机上提示一次 |

## 结果

- 改动清单见 [record.md](record.md)“改了哪些文件”；设计选择按 D-003 由维护者定（下一节）。
- 界面：只用设置页现有的行（`SettingsRow`、`SettingsLinkRow`、`SettingsSwitchRow`、`SettingsNote`）和设置页的子页面（`SettingsSubpage.backgroundPlay`），没有新组件，没有出效果图。

## 设计选择（D-003，维护者定）

| 选择 | 定了什么 | 理由 |
|---|---|---|
| S1 等开播、来电时通知显示“在播” | 是：离开应用后重连、等开播（10 分钟内）、来电（30 分钟内）都告诉系统“在播”（锁屏上是暂停按钮） | 只有这样前台服务才不停；Android 12 起应用在后台不能再启动它；HyperOS 会立刻冻结没有前台服务的后台进程。按暂停 = 不等了，马上放掉 |
| S2 后台重试的节奏和上限 | 5、10、20、30、60 秒，之后每 60 秒；30 分钟还没回来就放弃（通知变“暂停”、放锁）；网络回来立刻试；断网时由 session 自己每 2 秒探测 | 地铁、电梯常见的断网在几分钟内；30 分钟后还在重试多半是没人在听了 |
| S3 三个新开关默认关 | “后台只播声音”“后台断开弹幕”“关闭画中画时暂停”默认关 | D-040：老用户感觉不到变化 |
| S4 新开关放哪 | 视频设置 → 后台与助眠 →“后台播放设置”子页面的“离开应用时”一组 | 视频页已经很长；和检查放在一起，A11.6 改设置页滚动时不冲突 |
| S5 电池优化豁免 | 继续用 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`（3.x 已声明） | 媒体播放是本应用的核心功能，属于政策允许的用途；它也是 Android 12+ 后台重新启动前台服务的豁免条件之一；应用不在 Play 上架 |
| S6 不加“下一个直播间”通知按钮 | 不加 | 后台切房间要在后台重建直播间运行时（播放器、弹幕、页面），风险大；留给以后（record.md“留下的问题”） |

## 留下的问题

- 通知上“下一个直播间”（S6）：没有任务，用户还要时在 V01 提议。
- 各家系统页的组件名来自公开资料和常见做法，不同版本会变；K90 以外的品牌没有真机看过，跳不过去时会打开应用信息并提示要找的项（record.md“要别的手机看的”）。
- 录制的前台服务（`dataSync`）每天 6 小时上限不在本任务（O01 已知问题）。
