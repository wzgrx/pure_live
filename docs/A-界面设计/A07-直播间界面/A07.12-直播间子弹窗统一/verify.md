| 步骤 | 期望 | 结果 | 截图 |
|---|---|---|---|
| 1. 进直播间，横屏全屏，点右上四宫格 →“定时关闭” | 右侧 360 宽的面板，画面照常播、不变暗 | | |
| 2. 点“30 分钟”；按返回键 | 开关自动打开，第二行变成“30 分钟后暂停（HH:mm）”；返回键关面板，仍在全屏 | | |
| 3. 同一处 →“房间音量” | 右侧面板，百分比和当前系统媒体音量一致 | | |
| 4. 拖到 30%，关面板，在画面右侧上下滑 | 手势条从 30% 起算，两边是同一个数 | | |
| 5. 再开“房间音量”；按手机音量键；点喇叭静音再点 | 面板显示手势调后的值；一秒内跟着音量键变；取消静音回到静音前的值（不是 100%） | | |
| 6. 横屏顶栏投屏按钮（或菜单“获取直链”） | 右侧面板；当前清晰度蓝色带勾、写“正在播放”；点另一档进线路页，左上 ← 能回来；当前清晰度的线路页里正在播的线路带勾 | | |

| 8. 横屏下栏方向按钮；画面比例按钮 | 方向小菜单在按钮上方，标题“本直播间画面方向”，每项带说明；拨“记住单个直播间方向”菜单不关；点一项立即生效。画面比例小菜单在按钮上方 | | |
| 9. 退出全屏，竖屏点四宫格 | 菜单是新样子（图标 24、分组线）；定时开着时“定时关闭”下面写还剩多久，“画面比例”下面写当前比例；点“画面比例”是贴着四宫格下方的小菜单 | | |
| 10. 点“已关注”（竖屏顶栏、横屏下栏各一次），选“取消关注”，4 秒内点“撤销” | 贴着按钮的小菜单，红色“取消关注”；提示条“已取消关注 X · 撤销”；撤销后关注恢复、位置不变 | | |
