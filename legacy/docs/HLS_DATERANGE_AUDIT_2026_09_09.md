## 实现与验收合同

- 快照保留有序属性更新；窗口合并同 ID，输出一次完整标签。新增属性补充旧值，冲突使整个刷新回滚，不推进分片、版本、结束标志或事件列表。
- 属性保留引号和线格式，逗号字符串、十六进制 SCTE-35 字段、数字扩展均保持类型。本层不解码 SCTE-35 载荷。
- START-DATE 可来自已保留的旧更新；初次遇到仅有 ID/结束时间的事件不准入。日期支持无时区按 UTC，日期及 duration 的纳秒级比较使用整数，不依赖浮点近似。
- PLANNED-DURATION 不关闭事件。END-ON-NEXT 在同 CLASS 中绑定后继，后继插入改变既定边界、同类重叠、直接声明冲突时回滚。保留前驱时同时保留定义结束边界的后继链。
- 源站删去标签不立即删去本地历史事件。所有保留分片已有时间映射且闭合事件早于保留时间下界，才退休事件；零长事件恰在第一时间点仍保留。未知时钟、开放事件及 PRE/POST 生命周期事件继续占用预算。
- 额外保存由 EXTINF 十进制原文向下取整累计的时间下界；保留原有显示时间，但不拿向上取整的显示值退休事件。三段 0.6 微秒媒体、事件结束 1.5 微秒的回归确认最后一段的事件仍被保留。该边界是本批复核发现，未冒充独立执行过的旧版本红测。
- 退休事件后保留时间下界，后续跨越下界的倒退或未知映射不准入，防止用已删除的历史解释新分片。保留范围外不建立永久 ID 数据库，不声称能审计无限历史的 ID 重用。
- 单快照最多 512 次更新；单事件最多 64 属性、16 KiB 描述；窗口最多 256 个保留事件，并与分片共同计入原有 metadata byte budget。容量压力先按既有分片窗口退休规则计算，仍容不下则原子失败，不静默扔掉开放事件。
- duration 数字上限为 12 位整数、9 位小数；更高精度/大小留在未准入范围。普通 PDT 沿用既有严格日期解析，本批仅为 DATERANGE 日期补无时区处理。
- 已知 interstitial CLASS、X-ASSET-URI、X-ASSET-LIST 留有明确未处理标志，需要后续资产/时间线实现；不借普通元数据保留扩大下载集合。其余五类 LL-HLS 标签及 SKIP 的既有限制保持。
