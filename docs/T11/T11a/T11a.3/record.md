# T11a.3 页面：网络电视

- 日期：2026-10-01
- 目录：`apps/pure_live/lib/features/iptv/`（路由 `RoutePath.kIptv`，类名和构造参数不变）
- v3 来源：标签 `v3.2.11` 的 `lib/modules/iptv/iptv_page.dart`（943 行，“IPTV 设置”）、`lib/modules/iptv/iptv_manage.dart`（902 行，“订阅源管理”），以及它们调用的 `core/iptv/services/` 里的提示和同名确认框（`iptv_import_manager.dart`、`epg_import_manager.dart`）
- 用到的包：`live_iptv`（`IptvImporter`、`IptvLibrary`、`IptvPlaylist`、`EpgSource`、`IptvImportResult`）、`live_store`（设置 `selectedSourceId`/`selectedSourceName`、`isAutoSyncEnabled`、`autoSyncHoursInterval`、`customIptvUserAgent`、`hotAreasList`；`meta`；`database.watch`）、应用的 `StoreIptvLibrary`/`IptvTables`（T11a.2）、`live_ui`（设置卡片积木、文字样式、`AppStatusView`、`PureLiveScrollPhysics`）
- `docs/specs/UPGRADES.md` 里没有属于本页的条目；`~/ref/notes/m13_notes.md` 里与网络电视有关的“节目单和回看”属于直播间（M13.3b），不在本页。

## 做法

| 文件 | 内容 |
|---|---|
| `iptv_page.dart` | 页面（`ConsumerStatefulWidget`）：概览、播放列表、节目单、同步设置四块；导入、同步、全部同步、自动同步开关、删除、选节目单、默认节目单的流程 |
| `iptv_data.dart` | 页面内的 provider：`iptvImporterProvider`（`AppServices.iptvImporter`，测试替换）、`iptvClockProvider`、`iptvOverviewProvider`（`store.database.watch(IptvTables.all, …)`，每次写 IPTV 表后重读列表、节目单和频道数）；格式标记、显示名、“更新于”文字、导入结果到提示文字的对照 |
| `iptv_import.dart` | 导入方式选择框、网络导入框、粘贴文本框、文件路径框、同名替换确认框；`iptvFilePickerProvider`（选本地文件的入口，见“留给后续”） |
| `iptv_cards.dart` | 播放列表/节目单卡片、概览数字、提示卡片 |
| `iptv_settings.dart` | 同步间隔选择框、请求头编辑框 |

- 数据都经 `AppServices.iptvImporter`：导入 `importPlaylistFromUrl/Text/File`、`importGuideFromUrl/File`，同步 `syncPlaylist`/`syncGuide`，删除 `deletePlaylist`/`deleteGuide`（带快照，被改过时提示重试），自动同步开关 `library.updatePlaylist/updateGuideSource`。导入器自己排队，同名替换用 `confirmReplace` 回调弹确认框。
- 结果按 `IptvImportStatus` 给提示（T11a.1 对照表细化）：`imported` 提示名称（有跳过的行时带条数）；`cancelled` 不算失败；`unsupportedFormat`、`invalid`、`networkFailed`、`stale`、`failed` 各有一句说明。
- 页面随数据刷新：读的是 `pure_live.db` 的 IPTV 表变更通知，所以启动 3 秒后的后台自动同步、以后的分享导入完成后，开着的页面会自己更新。

## v3 问题及处理

| # | 问题 | 位置 | 处理 |
|---|---|---|---|
| 1 | 删掉正在使用的节目单后，设置里仍是它：页面显示已删除的名字，直播间按这个 id 找不到节目单 | `iptv_manage.dart:870`（删除不动 `selectedSourceId`） | 删除时改用下一个节目单，没有了就清空；页面每次读到数据都检查选中的是否还在；显示名从库里取 |
| 2 | 网络导入时在同名确认框点“取消”，导入框显示“网络订阅源下载或解析失败” | `iptv_page.dart:749-753`、`iptv_import_manager.dart:282-285`（取消也返回 false） | 取消不算失败：导入框说明“已保留同名的原有数据，可以换个名称再导入” |
| 3 | 网络导入失败一律显示“下载或解析失败”，不分格式不对、下载失败、内容截断；内核的提示还会带上异常原文（`sync_failed: $e`，可能含带令牌的地址） | `iptv_page.dart:752`、`iptv_import_manager.dart:299` | 按导入结果的状态给出具体说明，不显示异常原文 |
| 4 | 没有节目单时每次进入页面都去下载默认节目单（几 MB）：用户删掉默认节目单后，下次进来又被下回来 | `iptv_page.dart:72-96` | 只在第一次自动导入（成功后在 `meta` 记 `iptv.defaultGuideLoaded`）；之后在空状态里一键“默认节目单”，导入方式里也有 |
| 5 | “同步”只同步打开了自动同步的网络来源，关掉自动同步的手动也同步不了（单个同步可以）；都关着时提示“请设置需要同步的资源” | `iptv_manage.dart:149` | 手动“全部同步”同步所有网络来源；自动同步开关只管后台同步 |
| 6 | 页面只在进入和自己操作后读一次数据：启动后台自动同步、分享导入完成时，开着的页面不更新 | `iptv_page.dart:52`、`iptv_manage.dart:73` | 订阅 IPTV 表的变更通知，数据变了就重读 |
| 7 | 保存请求头后提示“同步配置已保存” | `iptv_page.dart:237` | 提示“请求头已保存” |
| 8 | 页面建了一个 `TabController` 却没有用（死代码） | `iptv_page.dart:24,42` | 不搬 |

## 界面改进

（2026-10-01 用户授权：界面、布局、操作和视觉反馈可以改进；数据仍在 `live_store`，设置键名没有改，3.x 的列表、节目单和设置由 T09b.1/M12.1 原样导入。）

1. **两页合一**：v3 的“IPTV 设置”只有几行入口，列表在第二页“订阅源管理”。现在一页里从上到下是：概览（播放列表数、频道总数、节目单数和两个导入按钮）→ 播放列表 → 节目单（当前节目单一行 + 卡片）→ 同步与播放设置。少一层跳转，导入后马上能看到结果。
2. **卡片信息更全**：频道数（节目单是节目单频道数）、“更新于 今天 12:05 / 09-30 12:05 / 尚未更新”；内置热门列表显示为“热门频道（内置）”，默认节目单显示为“默认节目单”（v3 显示为 `hot`）。
3. **节目单直接在卡片上切换**：非当前的卡片有“使用”按钮，当前的标“使用中”并高亮；保留 v3 的“当前启用的 EPG 数据源”一行和选择框。
4. **导入**：方式里加“粘贴文本”（播放列表，没有文件选择器也能导入；v3 只给分享用）和“默认节目单”；网络导入的名称可留空，提示框里预先显示将使用的名称，并说明同名会替换；失败原因具体（问题 2、3）；关闭导入框后导入继续，完成时提示结果。
5. **提示**：导入成功提示名称和跳过的无法识别的条目数；同步成功/失败带名称和原因；删除确认框说明会删多少频道、关注里的这些频道将无法播放；删除正在使用的节目单时说明会改用下一个。
6. **全部同步**：显示进度条和“正在同步 N/M”，结束时提示成功数或失败数（问题 5）。
7. **网络电视未启用的提醒**：网络电视不在平台列表里时，页面顶部说明“频道不会出现在分区页，启动时也不会自动同步”，一键启用（写 `hotAreasList`）。v3 没有提示，导入后在分区页找不到频道。
8. **默认节目单**：导入时显示“正在导入默认节目单”和“可以离开本页”；只自动导入一次（问题 4）。
9. **请求头**：输入框随内容增高，说明“留空用默认”，未设置时显示“未设置（使用默认请求头）”。
10. **随数据刷新**（问题 6）；窄屏（340 宽、1.3 倍字号）下卡片按钮换行、自动同步开关放到下一行。

## 留给后续

| 内容 | 去向 |
|---|---|
| 本地文件选择：应用没有文件选择插件（v3 用 `file_picker`），现在“本地导入”是输入文件路径（Windows 可用；Android 读不到其他应用的文件时提示改用网络导入或粘贴）。加上插件后在 `main` 里覆盖 `iptvFilePickerProvider` 即可，页面不用改 | 协调者（加依赖） |
| 自定义请求头 `customIptvUserAgent` 还没有用到播放上：v3 在 `playback_header_resolver` 里给网络电视的播放请求加它 | 直播间（M13.3b）/ 播放 |
| 切换节目单后重建频道到节目单的映射（T11a.1 记为可选；直播间会按 tvg-id 和名字兜底匹配，所以不影响显示）。建议在 `live_iptv` 加 `IptvImporter.rebuildGuideMappings()`（在导入队列里执行），本页切换后调用 | 协调者（`live_iptv`） |
| 分享来的播放列表文件和文本（v3 `SharedMediaIntake` → `importFromSharedMedia`/`importFromWebString`）：导入器接口已有（`importPlaylistFile`、`importPlaylistText`），要应用接收分享 | 链接解析 / 应用 |
| Android 上“打开文件”（本地列表的副本）：`url_launcher` 打不开应用私有文件（v3 用 `open_filex`），会提示打开失败；地址可以复制 | 需要时再加插件 |
| 设置页里进入本页的入口（v3 设置页“IPTV 设置”一行，文字 `manage_iptv_sources`） | 设置页（M13） |
