# 文档

- 文档版本：**v1**（2026-10-03），变化见 [CHANGELOG.md](CHANGELOG.md)。
- 纯粹直播（Pure Live）4.x 的全部文档。项目分成 20 组，每组一个字母、按优先级排序（**界面设计排第一**）；每组若干子分类，子分类里是一个个任务。所有编号、状态和进度都登记在 [tasks.toml](tasks.toml)，各种索引由脚本生成。

**界面和功能怎么分**：看得见的样子和交互（布局、组件、弹窗、手感、状态的显示）在 A 组；行为和数据（协议、播放、录制、存储、平台）在各功能组。一个任务两样都有时，以主要的那样为准，并在任务里写明关联。

## 编号速查

- **组** `A`，**子分类** `A07`，**任务** `A07.13`，**逐项界面** `A07.13-08`。
- 文件夹：组 `A-界面设计`，子分类 `A07-直播间界面`，任务 `A07.13-切换直播间面板`（编号加简短的中文名）。
- 状态：未开始 → 设计中 → 待确认 → 已确认 → 开发中 → 待真机 → 完成；另有暂停、受阻、不做。
- 档位：第一档（马上做）、第二档（应该做）、第三档（以后）。

## 怎么改

1. 改 [tasks.toml](tasks.toml)：加任务、改状态、记阶段。
2. 运行 `python3 tools/docs/docs.py`，重新生成 STATUS、TASKS、MAPPING 和各组、各子分类的 README。
3. 门禁会检查：生成的文件是不是最新、文件夹名和登记表是否一致、链接能不能打开、代码里写的 `docs/` 路径是否存在。

任务文件夹里的设计和记录是当时写的，引用的旧文件已换成新路径、旧编号已换成新编号；2026-10-02 整理前的旧文档全文在 git 标签 `docs-archive-2026-10-02`。
