## 目标

聊天列表的字可以调大调小、行距可以调紧调松：弹幕密的时候一屏多看几行，眼睛累的时候字大一点。默认和现在一模一样。常见第三方客户端都有“聊天区文字大小”“上下间隔”。

## 设计（V03.6 第 5.2 节，做法 A，D-003 维护者选 A）

- c1 新设置 `danmakuListFontSize`（`section: 'danmaku'`，整数，**默认 0 = 跟现在一样**，可选 12～22，超出读成 0）和 `danmakuListLineSpacing`（`compact`、`standard`、`loose`，**默认 `standard` = 现在的行距**）。都跟备份和设备同步。
- c2 只当 A08.10 的 `ChatText` 角色的参数：名字和内容同一个字号（A08.10 G1），字重和颜色规则不变；系统字体缩放照样乘上去。
- c3 跟着变的：粉丝牌、平台徽章、头像、礼物图（A08.11）、“本地”“对方”标签按字号等比例；“N 条新弹幕”按钮不变（它是浮在上面的按钮）。
- c4 不管：飞行弹幕（有自己的字号）、醒目留言标签的卡片、长按面板。
- 不选 B（只跟系统字体缩放）：现在就是这样，用户改不了。

## 维护者定的选择（D-003，2026-10-09）

维护者授权按建议定，不出评审页。

| 编号 | 选择 | 理由 |
|---|---|---|
| S1 | 字号滑条从左到右是“默认”、12、13……22，一档 1；“默认”存 0；右边的值写“默认”或“16 px” | 和“弹幕字号”一样带单位；最左一档就是 0，不用另加开关 |
| S2 | 值写“默认”，不写设计里的“跟随系统” | 0 跟的是应用自己的正文字号（设置里的字体大小），系统字体放大在任何档位都照样乘上去；写“跟随系统”会让人以为别的档位不跟系统 |
| S3 | 行间距三档叫“紧密、标准、宽松” | 上一行“弹幕列表样式”已经有“紧凑”，两行挨着都写“紧凑”意思不同，容易看错 |
| S4 | 行间距 = 每一行所有上下间距乘 0.5、1、1.5（紧凑行上下各 2、4、6；卡片外 2、4、6、卡片里 4、8、12；提示行、醒目留言行、系统标签同样），加上文字的行高 1.4、主题原来的 1.5、1.7 | 一屏多几条主要靠行与行之间的空；换行的长弹幕行高也跟着变才像“行距”；1.4 是 UI.md 第 8.2 节的下限 |
| S5 | 跟字号的：名字、内容、礼物行、本地弹幕和本地礼物、醒目留言行、平台提示行；系统标签（居中小灰字）不跟，只跟间距 | 系统标签是状态，不是弹幕，和“N 条新弹幕”按钮一样不变 |
| S6 | 标签和图按比例（字号 ÷ 主题正文字号）：粉丝牌、“对方”“本地”“之前发的”、本地徽章胶囊的字（不小于 12，圆角跟高度）、平台徽章图 16、头像半径 12、卡片圆点 8、礼物图 16、礼物价值（小一号，不小于 12）、提示行图标 16 | README c3；UI.md 最小字号 12 |
| S7 | 礼物图跟列表字号，不跟系统字号（A08.11 原来就不跟）；圆点同样只跟列表字号，位置按这个字号的第一行算（主题字号时离顶 6，和以前一样） | 默认设置下任何系统字号都和以前像素一致；礼物图的位置本来就按系统字号对齐第一行 |
| S8 | 系统字体放大照样乘在列表字号上，只乘一次：文字自己乘，行里的小块经 `chatInline` 乘；D08.1 的“之前发的”原来是普通 `WidgetSpan`，被乘了两次，改成 `chatInline` | A08.11 G14 的规则 |
| S9 | 不变的：“N 条新弹幕”按钮、哔哩哔哩登录提示条、列表的空状态、左右边距、飞行弹幕、醒目留言标签页的卡片、长按面板的卡片 | README c4 |
| S10 | 设置搜索：“列表文字大小”的关键词有字号、文字大小、字体大小，“行间距”有行距、间距、间隔、密度，都在“弹幕 › 弹幕列表” | 任务书验收 5 |

## 实现和验证

- 设置：`packages/live_store/lib/src/settings/settings.dart` 的 `danmakuListFontSize`（`IntSetting`，`min: 12`、`max: 22`、`resetOutOfRange`，默认 0）、`danmakuListLineSpacing`（`StringSetting`，`compact`、`standard`、`loose`，默认 `standard`），`danmaku` 一节，跟备份和设备同步。
- 参数：`chat_text.dart` 的 `ChatSizing`（字号、`ChatSpacing`；`text` 给角色换字号和行高，`piece` 给标签和价值按比例、不小于 12，`scaleIn`、`gap`）；默认的 `ChatSizing.standard` 原样返回所有样式和间距。`ChatText.content/name` 多一个 `sizing` 参数，长按卡片不传。
- 列表：`ChatList` 读两个设置，行缓存认 `sizing`（改了以后显示着的行重建一次，之后新来的行仍然只建一次）；`ChatLineView`、`GiftLine`（`giftLineOf`）、`LocalChatLine`、`ChatChip.styleOf`、`ChatBadge`、`GiftIcon` 接参数。
- 设置行：`ChatListSettings`（直播间标签、画面面板、设置 → 弹幕共用）“弹幕列表样式”下面；搜索在 `settings_catalog.dart`。
- 验证：默认设置下 9 种行 × 两种样式 × 360 和 280 宽 × 1、1.3、2 倍系统字号 × 三套主题，大小和各块位置和改之前的代码量出来的一样（`chat_list_sizing_baseline.json`）；记录见 [record.md](record.md)，真机步骤见 [verify.md](verify.md)。
