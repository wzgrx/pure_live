| 网络路径准备在 try 外抛错；整个 URL 的 endsWith 把带查询参数的 JSON/GZIP 当成 XML | 路径准备纳入错误处理，按 URI path 选择后缀；同步入口共用规则。真正本机服务器收到查询参数，数据库保留完整 URL。 |
| 下载器创建 `.part`，导入/同步失败只清理最终文件或跳过收尾 | finally 清理本轮分配的最终临时文件及 `.part`；HTTP 404/500 和同步 404 后旧 DB 保持，临时目录为空。清理异常单独记录，不把已经完成的 DB 提交误报成导入失败。 |
| 同名确认单独维护 Completer，仅按钮完成它，系统返回缺少对应完成路径 | 等待实际 `Get.dialog<bool>` 的路由结果；返回/取消均结束为 false，确认后的数据库写入由导入 Future 统一处理。确认弹窗可滚动；双语 320×480、2 倍文字、长名称下实际操作返回/取消/确认/写入失败，共 8 个 Widget 场景。 |
