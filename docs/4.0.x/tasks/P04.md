# P04 直播间里的拖动手感：上下滑换台、三档面板、详情面板

- 规模：中；分组：直播间；依赖：B09、P03；能否和别的任务同时做：直播间组最后一个
- 出设计：不用（照调研报告和本任务单；改变手感的地方在记录里写清前后对比）
- 先读：调研报告 `docs/4.0.x/research-smoothness-2026-10-02.md` 第 2.3～2.5 节（S2 直播间部分、S4、S6、S7、S8、S9、S11）、3.2 节（切房间预览解码）
- 可以改：`features/live_play/`；其他目录不改。

## 要做的

- c1 S2：`player/room_swipe.dart:94-111,182`（换台回位）、`layout/portrait_panel.dart:167-173`（三档面板）、`layout/room_details.dart`（详情面板）改成带松手速度的弹簧（常量用 P03 的 `motion.dart`），夹住目标不过冲；换台在松手时就开始连新房间，不等动画结束。
- c2 S6：`room_swipe.dart:70`（没有上一个、下一个房间时）等硬停处改成橡皮筋：d = R·(x − x² + x³/3)，最多 R/3，回弹约 0.4 秒。
- c3 S4：三档面板拖动时不再每帧重建 `RoomPlayer`（按 `covered` 缓存 player，或把拖动状态放进只包住面板的子组件；`live_play_page.dart:1118`）。S8：`portrait_panel.dart:236` 改成 `DragStartBehavior.start`。
- c4 S7：详情面板把手热区扩到 48 dp，下拉时面板跟手，用弹簧关闭。S9：亮度和音量每帧最多调一次平台方法（`player_gestures.dart:189`）。
- c5 切房间预览（`room_swipe.dart:252-259`）按实际展示方式解码，不再按屏宽解码后 cover 铺满。
- c6 S11（实验）：试开 `GestureBinding.instance.resamplingEnabled`，记录里写结论，默认不开。

## 验收

- 直播间里所有拖动 1:1 跟手、松手不断速、到头有阻力；拖三档面板时播放器不重建。
- 测试：每条 c 至少一个（松手速度连续、橡皮筋单调且 ≤R/3、`RoomPlayer` 拖动 2 秒重建 0 次、起拖第一帧位移 ≤1 dp、把手热区 48 dp）。

## 真机上看的（写进记录，维护者在 K90 上看）

- 竖屏全屏上下滑换台：跟手，快滑一下就换，到最后一个房间有橡皮筋。
- 竖屏拖三档面板：跟手、松手顺滑；`flutter run --profile` 下 DevTools 没有红帧。
