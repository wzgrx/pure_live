## 目标

在 K90 上确认：从系统画中画回到直播间后，控制条照常显示、4 秒后自己隐藏、点画面能再叫出来、全屏等按钮都有反应——也就是 S02.1 的修改真的解决了问题。顺带把画中画相关、一直没在真机上看过的几项看完（自动进入、窗口按钮、比例、系统关了画中画时的提示条），让清点 F-AND-06 的备注和 C02、O02 的“已知问题”有真机依据。

不通过时找到根因（抓日志），开修复任务；本任务只验证、不改代码。

## 方案

只验证，不改代码。在 K90（Android 17、HyperOS）上用合并后的 master 测试包逐条做 [brief.md](brief.md) 的真机步骤，结果写进本文件夹的 `verify.md`（照 `docs/templates/verify.md`），截图放 `verify/`：

- c1 按钮进入画中画 → 回来（点窗口放大、从最近任务回来两种）：控制条显示、4 秒后隐藏、点画面出来、全屏按钮有反应；暂停着回来控制条保持。
- c2 横屏全屏时进画中画 → 回来：回到全屏，锁定已解除，返回能退出全屏。
- c3 自动进入（开“离开应用时自动画中画”）→ 回来：同 c1；看画中画第一帧是不是整个直播间页面。
- c4 窗口按钮暂停和继续；画中画中换清晰度、看比例。
- c5 关掉本应用画中画权限 → 点小窗按钮：提示条、“去设置”；测完恢复权限。
- 卡住时：照 brief 的“卡住时抓什么”抓 `adb logcat` 和 Flutter 帧信息，写根因线索，开修复任务（Dart 一侧在 C02，原生在 O02）。
