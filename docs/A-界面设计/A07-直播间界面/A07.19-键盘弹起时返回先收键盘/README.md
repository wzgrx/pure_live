# A07.19 直播间里键盘弹起时，返回先收键盘

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：界面
- 来源：2026-10-08 K90 复查 A07.18（切换直播间面板的筛选框）
- 相关：[A07.18](../A07.18-切换面板筛选时键盘盖住结果/README.md)；直播间接管返回（C03.1、S02.6 第 2 步）

## 目标

直播间里任何输入框（切换直播间的筛选、本地弹幕输入、屏蔽词……）弹着键盘时，返回手势或返回键只收起键盘；再按一次才按原来的顺序关面板、退全屏、退出直播间。

## 3.x 和现状

| 方面 | 现在 | 要做到 |
|---|---|---|
| K90 实测 | 切换直播间 → 放大镜 → 筛选框弹出键盘 → 返回一次：键盘和面板一起没了（用键盘自己的“收起”按钮只收键盘，面板还在）。同理，在本地弹幕框里打字时返回会直接退出直播间 | 只收键盘 |
| 根因 | `MainActivity.kt:648` 用 `PRIORITY_OVERLAY` 注册直播间的返回回调，按 Android 的规则排在输入法前面；回调到 `RoomBackChannel._handle`（`predictive_back.dart`）直接交给 `_nativeBack`，关掉面板，焦点没了键盘才跟着收 | 键盘在、焦点在输入框时先收键盘 |

## 方案

- `RoomBackChannel` 收到 `backInvoked` 时：窗口底部有键盘（`viewInsets.bottom > 0`）且焦点在输入框里，就只取消焦点（键盘收起），不交给直播间。原生的优先级不改（改回默认会被 Flutter 自己的返回回调抢走，见 C03.1）。

## 验证

- 自动测试：`apps/pure_live/test/features/live_play/room_extras_test.dart`“A07.19”。
- 真机：切换直播间筛选框弹键盘 → 返回一次只收键盘、面板还在 → 再返回关面板；本地弹幕框打字 → 返回只收键盘。
