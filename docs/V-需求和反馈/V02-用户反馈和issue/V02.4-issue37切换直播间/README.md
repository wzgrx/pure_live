## 目标

切换直播间回到 3.x 那种一屏能看很多个的小卡片，同时保留 4.x 的列表样式，用户能自己切换。

## 3.x 和现状

| 方面 | 3.x（`v3.2.11:lib/`） | 4.0.0 构建号 5000 | 修之后（A07.13） |
|---|---|---|---|
| 样子 | `modules/live_play/dialogs/play_other.dart`：右半屏面板，封面小卡片网格（一屏能看很多） | 70% 高的底部表单，三个标签，普通 `ListTile` 列表，没有封面（审查 A-06） | 各布局同一个面板 `RoomPanelKind.switchRoom`：默认两列小卡片（封面、“直播中”和人数、标题、主播名），头部一个按钮切成列表（16:9 小封面加三行字），选择记住（设置 `roomSwitcherLayout`，`packages/live_store/lib/src/settings/settings.dart:394`） |
| 换台 | `controller.switchRoom(room)` 原地换台 | 整页替换（退出全屏、丢来源列表） | 原地换台，保持全屏和方向 |
| 入口 | 右上角 | 竖屏菜单、全屏 ⇄、状态里的按钮；横屏栏上和菜单里重复（A-08） | 三个入口同一个面板；全屏菜单去掉栏上已有的项 |
