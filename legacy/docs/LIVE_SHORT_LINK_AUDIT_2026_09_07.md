## 修订

- 每次 parse 拥有一个惰性创建的 `LiveShortLinkSession`。直接链接不创建 HTTP 客户端；短链各跳及抖音信息请求共用本次客户端，不关闭全局 HTTP 单例。
- 全过程默认 12 秒，connect/send/receive 同样有期限。总超时主动取消本次请求并强制关闭客户端；成功、失败及超时均在 finally 幂等释放，迟到结果由已关闭状态挡住。
- 单次解析共用最多 8 次 HTTP 请求和已访问 URL 集合；片段不改变网络请求身份。限制跨递归和抖音映射保持，不在下一跳重新计数。
- 显式处理 301/302/303/307/308，相对地址针对当前 URI 解析；空/重复 Location、非法 URI、userinfo、非 HTTP(S) 不继续。b23 仅把返回目标交给已有平台解析，不抓取任意未知终点。
- 抖音逐跳限制在既有短链/分享主机；规范 live.douyin.com 直接形成房间身份，reflow 内部 ID 调用既有信息 API，并逐层校验 Map 和字符串/整数 web_rid。未知主机不跟随，不把任意跳转的 reflow 字样当平台身份。
- 跳转只取响应头并取消正文流，不下载整份落地页；JSON 信息仍走 Dio 解码及总期限。生产沿用 Dio/系统 HTTP 路径，没有调整全局代理、平台 Cookie 或凭据。
