## v3 的样子

- **备份页入口**（`backup_page.dart:86-147`）：分组“云端备份”第一行，图标 `Remix.account_circle_line`（初始化失败时红色，连接中换成转圈的 `refresh_line`）；文字随状态：“正在连接 Firebase... / 正在初始化 Firebase 服务，请稍候...”“Firebase 初始化失败 / Firebase 服务初始化失败，请检查应用配置和网络后点击重试”（红字）“登录 / 点击登录，同步配置数据”“我的 / 已登录，点击查看个人中心”。下面是 WebDav、设备同步、同步TV数据（手机）。
- **登录**（`sign_in_page.dart`、`firebase_email_auth.dart:127-311`）：标题“登录”；四周 24；表单卡片（圆角 20）里邮箱框（`mail_line`“请输入邮箱”）、密码框（`lock_line`“请输入密码”，右边显示 / 隐藏）；24；“登录”实心按钮（圆角 14）；“或者”分隔线；“GitHub 登录”描边按钮（`github_fill`）；“忘记密码？”“没有账号？立即注册”文字按钮。注册时按钮变“注册”、底部“已有账号？返回登录”；找回密码时只剩邮箱框和“重置密码”“返回登录”。
- **我的**（`mine_page.dart:115-200`）：分组“我的”：配置预览 `file_text_line`、管理用户 `shield_user_line`（只有管理员）、下载用户配置 `download_cloud_line`（确认“覆盖本机设置？”）、上传配置 `upload_cloud_line`、退出登录 `logout_box_r_line`（红色，确认“退出登录？”）。
- **管理用户**（`user_manage_page.dart:192-564`）：统计卡（超级管理员、运营管理员、普通用户）、搜索框“搜索用户邮箱”、用户卡片（序号、邮箱、角色和上传状态标签；按钮设为运营 / 撤销运营、删除账号、禁用上传 / 解禁上传，每个先“操作确认”）。

## v3 的问题

| 编号 | 问题 | 位置 |
|---|---|---|
| F1 | 云端账号依赖 Firebase（谷歌服务）：国内网络、没有谷歌服务的设备连不上，备份页这一行常年是“正在连接”或“初始化失败” | `backup_page.dart:89-139`；M12 问题 10 |
| F2 | Windows 上 GitHub 登录要先在浏览器授权，再把一段 `purelive://auth?credential=` 链接粘回来 | `firebase_email_auth.dart:300-330` |
| F3 | “管理用户”是给维护者用的运营功能（升降管理员、删账号、禁上传），放在普通用户的应用里 | `user_manage_page.dart`、`mine_page.dart:137-148` |
| F4 | v4 去掉 Firebase 后，旧路由和旧版本留下的入口如果没有落点，会打开空白页或报错 | 路由 `kSignIn`、`kMine`、`kUserManage`（`app_pages.dart:78-80`） |
