# D03.4 按住飞行弹幕让它停住，松手继续（接 V01.3）

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：功能
- 来源：新功能提议 [V01.3](../../../V-需求和反馈/V01-新功能提议/V01.3-按住弹幕让它停住/README.md)（D-036 同意做）；上游 flame_barrage `3eddae8`（`pauseItemAt`）、pure_live `2d2ad2039`
- 相关：决定 D-036、D-003（设计由维护者选）、D-038（单击先调控制层）、D-018（新设置只加不改）；画面弹幕点按和长按 A08.4；双击飞行弹幕 A07.14；任务书 [brief.md](brief.md)、记录 [record.md](record.md)

## 目标

飞得快、长的、带表情的弹幕看不清时，手指按住它，它就停在手指下，其他弹幕照常飞；松手它从原位接着飞。需要操作时照旧长按（或控制层显示时单击）打开面板。功能由弹幕设置“画面弹幕交互”里的新开关“按住飞行弹幕让它停住”控制，**默认关**（D-036：老用户感觉不到变化）。

## 3.x 和现状

| 方面 | 3.x（`v3.2.11:lib/`） | 改之前（`apps/pure_live/lib/`） | 要做到 |
|---|---|---|---|
| 单条停住 | 没有（flame_barrage 后来才加 `pauseItemAt`） | 弹幕层只有整层停住（`DanmakuOverlay.held`，面板开着时） | 弹幕层能钉住一条：不走、不过期、画在最上面，放开从原位接着飞 |
| 手势 | 长按打开菜单，菜单开着整层暂停 | `player_view.dart`：单击（D-038、A07.14）、双击全屏、长按开面板（整层停住） | 都不变；开关开着时手指按下就钉住手指下那一条 |
| 设置 | 没有 | 点按、长按两个开关 | 加第三个开关，默认关 |

## 结果

- c1 弹幕层（`apps/pure_live/lib/shared/danmaku/danmaku_overlay.dart`）：`DanmakuOverlayState.pinAt(Offset)` 用和 `messageAt` 一样的命中规则找到手指下那一条并钉住（返回它，没有就 null；之前钉着的先放开）；`unpin()` 放开；`pinnedMessage`。每条 `_Flying` 记下钉住时它那条时钟的时间（`_pinnedAt`），钉着时位置和“到期”都按这个时间算，放开时把 `start` 往后挪钉住的时长，所以不跳、速度不变（和上游“吃掉经过的时间”一个意思）。整层停住（面板开着）、暂停时时钟本来就不走，叠在一起也不会算错。
- c2 同轨碰撞（V01.3 选 A）：后面已经在飞的从它下面穿过去，画的时候钉住的那一条最后画（在最上面）；钉着时它那条轨道不进新弹幕（`_place` 跳过这条轨道，新的进别的轨道或排队）；放开时它移到列表末尾，成了这条轨道的“最后一条”，下一条新弹幕按它的位置让开 40 像素再进。被撤回、整层清掉时钉住的状态一起清掉。
- c3 手势（`apps/pure_live/lib/features/live_play/player/player_view.dart`）：画面的 `GestureDetector` 外面包一层 `Listener`（原始指针事件，不参加手势竞技场）：开关开着、没锁定、按在点按可以命中的地方（`danmakuTapAllowed`：控制层显示时不含上下栏）时，按下就 `pinAt`；这根手指抬起、取消、或者移动超过 `kTouchSlop`（拖动：亮度、音量、换直播间）时 `unpin`。只认第一根手指。原来的 `_danmakuAt` 拆出 `_flyingPoint`（锁定、上下栏、坐标换算），两边共用。单击、双击、长按的代码没有改。
- c4 设置：`Settings.holdDanmakuOnPress`（`danmaku` 一节，默认 `false`，跟备份和设备同步）；弹幕设置“画面弹幕交互”组在“长按”下面加开关（直播间标签、画面面板、设置 → 弹幕同一个组件），说明“手指按住画面上的一条弹幕时只停住这一条，其他照飞，松手继续”；设置搜索“按住”“停住”能找到（“弹幕 › 画面弹幕交互”）。
- 不做：小窗、画中画、多画面（V01.3 的 c3）；电视（没有触摸）。
