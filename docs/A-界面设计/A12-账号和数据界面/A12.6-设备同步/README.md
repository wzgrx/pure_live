## v3 的样子

文件在 `lib/modules/remote_receiver/` 下。

- **顶栏**（`remote_sync_page.dart:184-200`）：标题“设备同步”居中；右边扫码（`Icons.qr_code_scanner`，桌面没有）、开始 / 停止（`Remix.play_circle_line` / `stop_circle_line`，提示“开始 / 停止”）。
- **我的设备**（`:217-262`）：`Card`（`surfaceContainerLow`、圆角 16），内边距 20，居中：“我的设备”20 号粗 → 二维码 180（白底，内边距 12）→ 地址 18/600（可选中；没有时“未获取到本机地址”）→ “配对码”+ 六位数字 28 号粗、字距 6 → “使用另一台设备扫描此二维码” → 开关“同步账号 Cookie”/“开启后会发送或提供各平台登录 Cookie，只在信任的设备之间开启” → `Icons.check_circle` / `Icons.error` 18 +“同步服务运行中 / 未运行”。
- **发现的设备**（`:264-344`）：卡片，“发现的设备”18 号粗，搜索时右边转圈；没有设备“未发现其他设备”；每台设备一张同色卡片：`Icons.devices` + 名字（粗）+ 地址；下面两个按钮“接收配置”（描边，`Icons.download`）、“发送配置”（实心，`Icons.upload`）。名字是“PureLive Android / iPhone / Windows / macOS / Linux”（`remote_sync_service.dart:68-82`）。
- **手动输入**（`:346-396`）：卡片，“手动输入”18 号粗；输入框（提示“192.168.1.100:39888”，`Icons.lan`）；整宽“发送配置”（实心）在上，“接收配置”（描边）在下。
- **流程**：发送 = 配对码 → 发送 → 提示；接收 = “接收配置 / 是否接收远程同步的配置？”→ 配对码 → 拉取 → 直接 `importAllSettings` → 提示（`:96-138`）；扫码 = 扫码页 → “选择同步操作 / ip:port / 接收配置、发送配置”（二维码带配对码，不用再输入，`:151-182`）；对方请求 = “设备同步 / 设备 {address} 请求用它的设置覆盖本机设置（读取本机设置），是否允许？/ 取消、确认”，不能点外面关（`:37-57`）。
- **服务**：进页面就开始（`remote_sync_service.dart:128-131`，Android 17 先要局域网权限），离开页面就停止（`GetxController`，路由绑定）。
- **按宽度分支**：没有；宽屏三张卡片一列拉满。没有快捷键。

## 拿不准的地方

1. 接收预览需要先把对方的配置完整拉下来再比较，v4 的 `RemoteSyncService.receive` 现在是拉取后直接写入，要拆成两步（开发时确认协议不变）。
2. 拿不到地址的原因（没连网络还是没给权限）现在服务里没有区分（`remote_sync_service.dart:145-171` 直接返回），文字先写成两种都提；要分开说需要服务给出原因。
3. v3 的配对码输入框是普通单行框（`maxLength: 6`），新设计画成六个格子；如果不想改样子，评审时说。
