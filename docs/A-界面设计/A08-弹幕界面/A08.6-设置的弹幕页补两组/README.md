## 3.x 的样子和问题

- 3.x 没有设置里的弹幕页：弹幕设置只在直播间里（`git show v3.2.11:lib/modules/live_play/pages/danmaku_settings_page.dart`，648 行；标签里 `includePipSettings: true`，末尾一节小窗弹幕 `:416-418`；画面上的面板 `includePipSettings: false`，`widgets/video_player/video_controller_panel.dart:2206`）。
- 3.x 的小窗弹幕只有一个组件 `PipDanmakuSettingsSection`（`lib/modules/settings/pages/pip_danmaku_settings_page.dart:153`），直播间标签和设置的“小窗弹幕”页（`PipDanmakuSettingsPage` `:12`，手机 `:104`、电脑 `:145`）都用它：顺序是小窗显示弹幕、纯文字、自动缩放、保留平台颜色、统一弹幕颜色（`:199-200`）、字体大小、粗细、速度、透明度、占用高度、最大同时显示、发送间隔、帧率策略。
- 3.x 没有“弹幕列表样式”和“在聊天列表显示礼物”（4.x 加的：A07.1 选择 A、已批准升级 B-21）。
- 现在的问题（4.x）：
  - P1 设置的弹幕页和直播间不一样：设置页是 `DanmakuSettingsContent` + “更多”（`apps/pure_live/lib/features/settings/danmaku_page.dart:60-63`），直播间多“弹幕列表”“小窗弹幕”两组（`apps/pure_live/lib/features/live_play/danmaku/danmaku_settings_panel.dart:97-133`）。根因：两组写在 `features/live_play/` 里，`features/settings` 不能引用别的功能目录（门禁“界面结构”，`tools/gate/check_ui_structure.py`）。列表样式的枚举 `ChatListStyle` 也在 `features/live_play/danmaku/chat_list.dart:24`。
  - P2 “在聊天列表显示礼物”不是设置，是直播间控制器存在 meta 里的 `live_play.showGifts`（`features/live_play/logic/room_controller.dart:189`），进房时读一次（`:318`），`setShowGifts` 写（`:605-610`）。没有直播间就改不了；在设置里改了，已经打开的直播间（小窗、宽屏旁边）也不知道。
  - P3 小窗弹幕有两份实现、顺序不同：直播间 `PipDanmakuSettings`（`danmaku_settings_panel.dart:143` 起，照 3.x 的顺序）；设置的“小窗弹幕”页是目录行（`features/settings/settings_catalog.dart:1085-1234`，按 A11.3 c14“小窗弹幕分组照 A07.6”分组：开关，然后“样式”组的透明度、速度、字号、粗细、自动缩放、纯文字、保留颜色、统一颜色……），颜色选择也是另一个（`playback_tiles.dart:510` 的 `PipColorTile` → `settings_dialogs.dart:317` 的 `showColorDialog`）。两个都是确认过的设计（A08.1 c9 照 3.x 顺序，A11.3 c14 照 A07.6 分组），彼此不一致；3.x 是同一个组件。

## 待选和决定

- G1 礼物开关存在哪：A（建议）新加一个布尔设置（键名开发时定，例如 `showChatGifts`，默认开；第一次读取时把 meta 里的 `live_play.showGifts` 接过来，之后 meta 不再用），直播间和设置页都用 `watchSetting`，改了立即对所有直播间生效（D-018：只加不改，3.x 没有这一项）；B 不改存储，设置页直接读写 meta，已经打开的直播间下次进房才生效。
- G2 设置的弹幕页里“小窗弹幕”怎么放：A（建议）放完整的一组（和直播间完全一样，A08.1 E1 的“各处一样”），总览上“小窗弹幕”那一行照旧（A11.1 c7）；B 只放一行“小窗弹幕 ›”，打开设置的“小窗弹幕”页（避免设置里同一组出现两次）。
- G3 设置的“小窗弹幕”页：A（建议）正文换成同一个组件，保留上面的说明和预览；同一组件的顺序取哪一种（A08.1 c9 的 3.x 顺序，还是 A11.3 c14 的分组）出图时两种都画，请用户选，直播间跟着一起变；B 不动（直播间和设置页顺序不同，违反 [specs/UI.md](../../../specs/UI.md) 第 3 节第 6 条）。
