## 实现与有界行为

- `XiaohongshuLink` 支持 www/裸主域名的 canonical 地址、观测到的 `dynpath` 加八位字母数字路径、hina 房间加可选有界路由尾段。未知动态格式继续待取证，不把任意中间路径当别名。
- 短链只请求精确 `xhslink.com` 的单段 token 或 `/m/token`。沿用一次解析独占的 `LiveShortLinkSession`：最多八次请求、重复 URL/去 fragment 后的循环检测、整体截止时间和取消、最终关闭自身客户端；不改变共享 Dio 或系统代理。
- 只消费 301/302/303/307/308 的唯一 Location；相对跳转仍受相同主机/路径限制。落到支持的直播地址后只取 ID，不请求落地页；后续详情从 canonical API 读取。主页、笔记、用户主页、其他平台、本地地址、异常端口和含凭据的 URL 不作为下一跳。
- 搜索仅第一页处理精确房间/网址，包括短链；关闭短链会话后读取房间。没有新增关键词搜索或网页搜索。分享导入允许继续处理用户独立粘贴的后一条合法链接，不从失败短链的任意页面推导房间。
- 实际分享文字在 URL 后直接跟中文逗号及说明，不一定有空格。仅对小红书三个已知分享主机处理该边界，保留百分号编码的标点和其他平台既有 URL 拼写规则。
- 不保存动态路径、分享 token 或 host_id 为收藏键；不将已下播目标的推荐直播当成当前目标。

## 可复现问题与来源

初始三项红测均失败：动态路由导入返回空、短链导入返回空、`/livestream/ID/.` 被接受为 ID。前两项是待补能力，第三项是本分支 `69f6db99` 新增解析器的 `fork-regression`：先构建 Uri 后只检查 `/./`，遗漏终端 `/.`，Uri 规范化已消去错误路径。

现在在 Uri 解析/相对跳转前检查原始路径，拒绝控制符、路径百分号/反斜杠、点段及异常协议/端口。相邻审查还发现公共分享抽取会把终端点段当句末标点去掉；已对小红书保留点段结构，新增五种导入/检测回归。有效句末标点与完整分享文字仍正常导入。

没有改动播放器、录制原生参数、数据模型、目录/观看值迁移或其他平台的解析分支；回滚该实现提交恢复旧分享范围，保留用户已存的 canonical 房间数据。前批[原生录制证据](XIAOHONGSHU_CONTROLLER_NATIVE_AUDIT_2026_09_10.md)不因本次分享修订外推为新界面或 Android 验收。
