## 目标

关注的主播开播时，手机上来一条“主播名 开播了”的通知，点它直接进直播间。设置 → 刷新设置 → “开播提醒”打开才有，**默认关**（D-036）。只在应用开着时提醒：在前台，或在后台播放、录制时（这时进程不会被系统冻结）；被系统清理后收不到，开关的说明写明了。

## 3.x 和改之前

| 方面 | 3.x（`v3.2.11:lib/`） | 改之前（4.x） | 现在 |
|---|---|---|---|
| 开播提醒 | 没有 | 没有 | 设置里一个总开关（默认关）+ 按标签选提醒哪些关注 |
| 开播状态 | 关注刷新（启动、下拉、定时、回前台） | 同 3.x（`favorite_controller.dart`），不保留上一轮的状态 | 每轮刷新的结果和录制等开播任务的每次检查，交给同一份“看到过什么”的记录比较前后状态 |
| 定时检查 | “关注自动刷新”（默认关，30 分钟） | 同 3.x | 开了它就用它；没开、开播提醒开着时，每 15 分钟只查要提醒的关注 |
| 系统通知 | 播放、录制 | 播放、录制、录制提醒 | 多一个类别“开播提醒” |

## 结果

- c1 判断（`apps/pure_live/lib/features/favorite/live_alerts.dart`）：`LiveAlertTracker` 按房间记最后一次知道的状态。`unknown`（请求失败）不算证据；第一次看到只记下；上次不在播（离线、录播、封禁、轮播）这次在播算开播，除非是同一场：开播时间相差 2 分钟以内，或下播后 15 分钟内又开播（断流重连）；一直在播但开播时间往后挪了 15 分钟以上也算新的一场。“安静”的一轮只记不报。`liveAlertRooms` 算出要提醒的关注（没选标签 = 全部；选了 = 带其中一个标签的；已删除的标签不算，都删了回到全部）。`LiveAlerts` 把两者接起来：开关关着时什么都不记（关掉时忘掉看到过的），开着时只对要提醒的关注调用发通知；`recorderChecks` 把录制任务每次成功的检查（`lastLiveCheckAt` 往前走了、`lastFailTime` 不在它之后）变成一个房间状态。
- c2 接到关注刷新（`apps/pure_live/lib/features/favorite/favorite_controller.dart`）：每轮结果先交给 `liveAlerts.observe`；启动核验、下拉、再点“关注”、直播间“看其他”的刷新按钮是“安静”的（用户看得到结果），回到前台、定时、录制检查会发。`_scheduleAutoRefresh`：开了“关注自动刷新”照旧；没开、开播提醒开着时，每 15 分钟（`LiveAlerts.checkInterval`）只查要提醒的关注；两个都关时不跑定时器。`favoriteControllerProvider` 订阅 `Recorder.changes`，交给 `recorderChanged`。
- c3 发通知（`apps/pure_live/lib/platform/live_alert_channel.dart` → `pure_live/live_alerts` `post` → `android/.../LiveAlerts.kt`，由 `AppChannelsPlugin` 注册，没有 Activity 也能用）：一个房间一条（标签 `live_alert:<平台>:<房间号>`，下一场替换上一条）；标题“主播名 开播了”（没有主播名用平台名），正文直播标题（没有写“点按进入直播间”）；有开播时间时显示为通知时间；类别“开播提醒”（默认重要性）；小图标是媒体通知的单色电视；点了走 `ShareIntakePlugin.ACTION_OPEN` 带 `platform`、`roomId`、`title`、`nick`（和桌面长按快捷方式同一条路）进直播间，点了自动消失。请求码 `0x20000000 + 28 位哈希`，和录制提醒的 `0x1000 + 28 位哈希` 不重叠。Android 以外没有发通知的实现（`liveAlertPosterProvider` 是 null），什么都不记。
- c4 设置（`features/settings/settings_catalog.dart`、`features/settings/live_alert_tiles.dart`）：刷新设置里“关注列表”下面新一组“开播提醒”，只在 Android 显示：开关“开播提醒”（`GatedToggleTile`，打开时只问通知权限，文字讲开播提醒、不问电池优化，拒绝时开关不开、说明变红）；“只提醒这些标签的关注”：没标签时说明“还没有标签，提醒全部关注……”，有标签时每个标签一个开关；开关关着时这组变灰。设置搜索“开播”“提醒”能找到。
- c5 新设置：`liveAlertEnabled`（默认 `false`）、`liveAlertTagIds`（默认空），`refresh` 一节，跟备份和设备同步。
