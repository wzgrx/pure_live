# A02.4 带“撤销”的提示条在开着无障碍服务时一直不消失

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：界面
- 来源：S02.5 清单 1A-14（2026-10-08 K90）
- 相关：A02.2（弹窗组件：提示条 `AppToast`）、A07.12-6（取消关注的撤销）

## 界面清点

| 编号 | 界面 | 怎么打开 |
|---|---|---|
| A02.4-01 | 带操作的提示条（“已取消关注 X · 撤销”“关键词已删除 · 撤销”等） | 取消关注、删除屏蔽词等 |

## 3.x 的样子和问题

- `packages/live_ui/lib/src/widgets/app_toast.dart:58-63`：`persist: persistent || (accessible && actionLabel != null)`，`accessible` 来自 `MediaQuery.accessibleNavigation`（`:137`）。只要手机开着任何无障碍服务（K90 开着小米的“选择朗读” `SelectToSpeakService`，很多手机助手类应用也会开），带操作的提示条就一直不消失，而且这时没有 ✕（`closable` 为假），只能点“撤销”或等页面换掉——K90 上离开直播间回到首页一分钟后还在。

## 设计（按 D-003 由维护者定）

- c1：提示条因为无障碍而不自动消失时，一定显示 ✕（和 `persistent` 一样）。
- c2：不自动消失的时长上限 30 秒（读屏用户来得及操作，又不会一直挂着）。
- c3：离开当前页面时（路由变化）关掉上一页的提示条。

## 实现和验证

- 未开始。测试：`packages/live_ui/test/` 的提示条测试加 `accessibleNavigation: true` 的情况：有 ✕、30 秒后消失。
- 真机：K90（开着选择朗读）取消关注一个直播间，提示条有 ✕，30 秒内消失；离开直播间时消失。
