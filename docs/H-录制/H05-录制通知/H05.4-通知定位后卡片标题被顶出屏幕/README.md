# H05.4 点录制通知定位到任务后，卡片标题被顶出屏幕

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：界面
- 来源：2026-10-08 K90 复查 [H05.2](../H05.2-只录一个直播间时点前台录制/README.md)

## 目标

从通知进录制中心定位到任务时，整张卡片（含房间名、平台那一行）都在屏幕里。

## 现状

- K90：只录一个任务（列表第一张）时，定位后列表往下滚了一截，卡片的标题行被筛选栏下面的边缘盖住，只看到“录制中”状态卡。
- 代码：`apps/pure_live/lib/features/recorder/recorder_page.dart` `_reveal` 用 `Scrollable.ensureVisible(alignment: 0.2)`；第一张卡本来就在顶上，不该滚。怀疑是定位时卡片还在长高（状态卡刷新）或高亮包了一层改变了测量。

## 方案

- 先写组件测试复现（任务在第一张时滚动位置应为 0；在中间时卡片顶边离筛选栏留出一点空）。
- 卡片已经完整可见时不滚；否则用 `alignment: 0` 加顶部留白。

## 验证

- 真机：录一个任务点通知，卡片完整可见；录三个、第三个最新时也看一遍。

## 实现（2026-10-08）

- 按方案做：整张可见不滚；否则卡片顶边停在列表顶上留白下（手机 12、宽屏 16）。根因和测试见 [record.md](record.md)。
