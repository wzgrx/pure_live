# A07.20 语音直播（猫耳FM、克拉克拉）画面换成房间封面

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：界面（直播间画面区；用已有的封面层，不需要新设计稿）
- 来源：上游对照 [W01.3](../../../W-上游借鉴/W01-定期对照/W01.3-2026-10-08上游对照/README.md)：上游 pure_live `559690d48`（“占位视频轨显示房间封面，不再是一块纯色”，用户报的“蓝屏”）、`01fd4fec5`（克拉克拉同样处理）
- 相关：纯音频模式的封面（`apps/pure_live/lib/features/live_play/player/player_status.dart:333`）；猫耳FM [E02.4](../../../E-直播平台/E02-其他国内平台/E02.4-猫耳FM/README.md)、克拉克拉 [E02.6](../../../E-直播平台/E02-其他国内平台/E02.6-克拉克拉/README.md)

## 目标

猫耳FM、克拉克拉是语音直播：流里只有一路假的视频（猫耳是 16×16 的占位画面，克拉克拉是纯色或一张背景图），4.x 把它拉满整个画面，看起来像蓝屏或卡住。改成和纯音频模式一样显示房间封面（头像、标题、主播名），画面下面照常解码，切走时不用重建。

## 3.x 和现状

| 方面 | 3.x | 现在（文件:行） | 要做到 |
|---|---|---|---|
| 猫耳FM 的画面 | 拉满 16×16 占位画面 | 同：`packages/live_core/lib/src/sites/missevan/missevan_api.dart:70-72`（“播放器按找到的轨道来”，不标纯音频） | 显示房间封面 |
| 克拉克拉的画面 | 拉满纯色或背景图 | 同 | 显示房间封面 |
| 封面层 | 纯音频模式有 | `apps/pure_live/lib/features/live_play/player/player_view.dart:725-738`：`_room.audioOnly` 为真才叠 `AudioOnlyCover`（`player_status.dart:333`） | 纯音频模式，或画面是占位（短边不超过 32 像素），或平台是语音直播时都叠 |

## 方案

- c1：判定“没有真画面”：会话状态里的视频尺寸短边 ≤ 32（`packages/live_player/lib/src/state.dart` 的 `videoWidth`/`videoHeight`；尺寸还没报上来时不算，那时是加载状态）；或者平台是语音直播（猫耳FM、克拉克拉，平台层给一个能力标记，不在界面里写平台名单）。纯函数，便于测试。
- c2：`player_view.dart:725` 的封面层条件改成“纯音频模式或没有真画面”；没有真画面时封面上的说明写“语音直播”（新翻译键，中英文都加），不写“纯音频模式”。小窗（`features/live_play/mini/`）同样处理。
- c3：封面不挡手势（和纯音频封面一样 `IgnorePointer`），视频照常解码（帧看门狗不受影响）。

## 验证

- 自动测试：判定函数（16×16、32×32、144×256、尺寸未知）；直播间画面在占位尺寸时显示封面、在正常尺寸时不显示。
- 真机（K90）：进一个猫耳FM 和一个克拉克拉直播间，画面是房间封面、有声音；切到别的平台直播间，画面正常。
