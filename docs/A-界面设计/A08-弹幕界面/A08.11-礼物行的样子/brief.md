# A08.11 礼物行的样子：全平台统一：任务书

## 背景

- 来源：V03.5（`docs/V-需求和反馈/V03-审查和调研/V03.5-全平台礼物、醒目留言和弹幕/README.md`）第 6.2、6.3、6.5、6.7 节、第 7 节 A08.11；用户 2026-10-09：“所有平台的礼物都要有自己的显示设计，并且可以打开和关闭”“考虑横屏”（D-040）。
- 现象：礼物行只有一个图标和一句文字，没有礼物图、没有价值，分不出贵的和便宜的；各平台的文字格式不一样。
- 为什么现在做：第二档；用户点名要的“礼物的显示设计”。
- 已经做过的：B-21（礼物进列表）、A08.6 c3（`showChatGifts`）、A08.10（名字和内容的样子、`showChatNames`——**开工前确认 A08.10 已合并**，用它的 `ChatText`）、E05.5（`LiveGift`）、D07.1（合并，可以并行，本任务只认“这一行更新了”的信号）。

## 目标和验收

1. 出效果图和评审页（PROCESS 第 4.1 节：竖屏、横屏 852×393、窄横屏 740×360、宽屏 1280×800；浅色、深色），列出 README 的 G1～G3，维护者按 D-003 定，README 改成第 1 版设计。
2. 紧凑和卡片两种样式的礼物行照 README c1～c3：礼物图（没有就用图标）、名字、“送出”、礼物名、×N、价值、档位线。
3. 连击合并时只有“×N”跳一下（减少动态时不跳）。
4. “显示用户名”关掉时礼物行没有名字、徽章、粉丝牌。
5. 手机横屏 280 宽、宽屏右栏、系统字号 1.3 和 2 倍：不截断礼物名、不溢出。
6. 长按打开长按弹幕面板，双击复制。
7. 所有平台用同一个组件；文字走翻译。
