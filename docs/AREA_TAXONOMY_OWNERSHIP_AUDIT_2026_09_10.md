## 范围与根因

承接[分类空页导航修订](AREA_TAB_NAVIGATION_AUDIT_2026_09_10.md)，本批处理目录替换/删除和外部选中变化，不改变分类 API、分页算法、布局尺寸或持久化格式。

| 场景 | 修订前实际证据 | 第一处错误与处理 |
| --- | --- | --- |
| 外部 selectCategory | 可见 Last 网格的 controller 与分页/滚动按钮持有的 controller 不同 | 外部监听只 animateTo，动画完成后又因 tabIndex 已相等跳过绑定；外部选中立即绑定有效分类，内部动画完成也独立确认绑定 |
| 相同数量更换分类 ID | First 换成 New，UI 已显示 New，但活动 controller 仍是旧 First | 以标签总数相同直接返回，漏掉身份变化；保留可复用的 TabController，但每份目录快照都重新核对活动分类绑定 |
| 目录清空 | TabBarView 消失，但活动 controller 仍等于旧页 | 空目录提前返回，未解绑和释放；清空时销毁标签控制器、解绑回自有控制器，旧分类控制器进入回收 |
| 分类删除/连续替换 | 原 Map 只在整页 dispose 清空 | 按当前分类 ID 清理 Map；先解除活动绑定，旧页面完成当前帧卸载后再释放其 ScrollController |

来源按组合根因记录为 **fork-regression**：旧的空目录/同数量短路来自继承代码（blame 686a4c37 / 03a7b293），本分支 4191c5b6 引入按分类持有与活动绑定后，未补齐这些生命周期入口。冻结 c6c9bd70 中也存在该组合，但这不取代引入提交证据；本轮未拉取或合并上游。

目录重排保留选中身份的场景在修订前已经通过，本批保留它作为回归，不把它算成新修复；同数量变化没有强制重建 TabController，也没有改已有刷新请求链。

## 实现与资源生命周期

- `lib/modules/areas/areas_grid_view.dart`：目录快照无论数量是否变化均核对活动控制器，索引按有效范围处理；外部选中和内部滑动的绑定不再依赖“业务索引是否刚刚变化”。
- 移除分类的控制器立即离开活动 Map，进入退役集合。帧后回调仅释放仍在集合中的对象；整页 dispose 同时清空活动与退役集合，后续回调因对象已移除而跳过，避免重复释放。
- 保留现有 PageStorageKey、每分类滚动位置、空分类横向导航、EasyRefresh 所有权。没有把所有分页页改成一个外层滚动视图。
- 释放证据仅指上述 ScrollController / TabController 生命周期，不代表整个应用内存或所有缓存已全面验收。
